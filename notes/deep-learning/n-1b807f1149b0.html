学习目标

  • 从图像张量的形状、数值范围和归一化开始，理解视觉模型到底在处理什么。
  • 串起“图像张量 -> 表示学习 -> 特征提取 -> 任务头 -> 损失训练 -> 推理/后处理”的完整链路。
  • 掌握卷积、池化、激活、BN、反向传播的直觉、公式、尺寸计算和常见工程陷阱。
  • 从 传统分割、形态学与人工特征 过渡到自动表示学习，并为后续 CNN 到 ResNet 的架构演进 与 多尺度特征与 YOLO 检测链路 打基础。

1. 图像张量：模型输入的真实形态

一张彩色图像通常从 H x W x C 的数组开始，例如 224 x 224 x 3。进入深度学习框架后，常见批量格式是：

  • PyTorch: N x C x H x W
  • TensorFlow/Keras: N x H x W x C

其中 N 是 batch size，C 是通道数，H/W 是高和宽。像素值可能是 uint8 的 [0, 255]，也可能转成 float32 的 [0, 1]。模型权重通常按浮点数训练，所以输入一般会做类型转换和归一化。

常见预处理链路：

原图 uint8[H,W,3]
-> resize/crop
-> float32
-> /255.0
-> normalize: (x - mean) / std
-> permute to [C,H,W]
-> batch stack [N,C,H,W]

归一化有两层含义：

  1. 输入归一化：让不同通道的数值尺度稳定，例如 ImageNet 常用 mean=(0.485,0.456,0.406)、std=(0.229,0.224,0.225)。
  2. 网络内部归一化：如 BatchNorm，让中间特征分布更稳定，减轻训练难度。

工程陷阱：

  • 训练和推理必须使用同一套 resize、颜色通道顺序、均值方差。RGB/BGR 搞反会让模型表现大幅下降。
  • 标注框随图像缩放、裁剪、letterbox 变化时必须同步变换。
  • uint8 直接输入模型可能导致数值范围完全不匹配。
  • 数据增强只应在训练集启用，验证/测试阶段应使用确定性预处理。

2. 表示学习：从像素到可分特征

传统图像算法常手工设计特征，例如边缘、角点、纹理；深度学习则让网络从数据中学习特征。一个视觉模型可以粗略拆成：

图像张量 -> Backbone 特征提取 -> Neck 特征融合 -> Head 任务预测

在分类任务中，Backbone 学到从低级到高级的层级表示：

  • 浅层：边缘、方向、颜色突变。
  • 中层：纹理、局部形状、部件。
  • 深层：语义概念，例如车轮、眼睛、道路、跑道异物。

在检测任务中，这些特征还要保留空间位置，因为模型不仅要知道“有什么”，还要知道“在哪里”。这就是为什么目标检测会特别重视特征图尺寸、多尺度融合、感受野和预测头设计。

3. 卷积：局部连接与权重共享

二维卷积层通常接收 N x C_in x H_in x W_in，输出 N x C_out x H_out x W_out。每个输出通道对应一组卷积核，卷积核形状是 C_in x K_h x K_w。

输出尺寸公式：

H_out = floor((H_in + 2P_h - D_h * (K_h - 1) - 1) / S_h + 1)
W_out = floor((W_in + 2P_w - D_w * (K_w - 1) - 1) / S_w + 1)

其中 K 是核大小，S 是步幅，P 是 padding，D 是 dilation。普通卷积里 D=1。

参数量：

参数量 = C_out * C_in * K_h * K_w + bias项

如果卷积后接 BN，通常 bias=False，因为 BN 的 beta 可以承担平移。

计算例子：

输入 1 x 3 x 224 x 224，卷积层 C_out=64, K=7, S=2, P=3：

H_out = floor((224 + 2*3 - 1*(7-1) - 1) / 2 + 1)
      = floor(223 / 2 + 1)
      = 112
W_out = 112
输出 = 1 x 64 x 112 x 112
参数量 = 64 * 3 * 7 * 7 = 9408（若无 bias）

卷积的核心直觉是局部模式复用。一个检测边缘的卷积核可以在图像各处滑动，识别相同类型的局部结构，这比全连接层直接连接所有像素更节省参数，也更符合图像的平移结构。

4. 特征图与感受野

特征图是卷积层输出的空间张量，例如 N x 64 x 112 x 112。每个位置不再是原始像素，而是对原图某个局部区域的响应。

感受野指某个特征图位置能“看到”的原图区域大小。层数越深、卷积核越大、步幅越大，理论感受野通常越大。

递推公式：

r_l = r_{l-1} + (k_l - 1) * j_{l-1}
j_l = j_{l-1} * s_l

其中 r_l 是第 l 层感受野大小，j_l 是相邻特征点在原图上的间隔，k_l 是核大小，s_l 是步幅。初始 r_0=1, j_0=1。

例子：连续两个 3x3, stride=1 卷积：

第1层: r=1+(3-1)*1=3, j=1
第2层: r=3+(3-1)*1=5, j=1

所以两个 3x3 卷积的感受野等价于一个 5x5，但参数量更少，还多了一次非线性。

工程陷阱：

  • 理论感受野不等于有效感受野。实际贡献通常集中在中心区域。
  • 小目标检测不能只依赖深层特征，因为深层特征图分辨率低，小目标可能被下采样吞掉。
  • stride 的累计值决定特征图一个格点对应原图多大步长，例如 stride=32 的特征图对小目标很粗。

5. 池化、激活与非线性

池化用于降低空间分辨率或汇聚局部响应：

  • Max Pooling：保留局部最大响应，强调是否出现某种模式。
  • Average Pooling：保留平均统计，更平滑。
  • Global Average Pooling：把 H x W 汇聚成 1 x 1，常用于分类头。

激活函数提供非线性。没有激活函数，多层线性变换仍等价于一个线性变换，表达能力受限。

常见激活：

  • Sigmoid：输出 [0,1]，早期常用，但容易饱和导致梯度小。
  • Tanh：输出 [-1,1]，也有饱和问题。
  • ReLU：max(0,x)，简单高效，是 CNN 经典选择。
  • Leaky ReLU / SiLU / GELU：改善负半轴或平滑性，现代检测模型常见 SiLU。

6. BatchNorm：训练和推理不是一回事

BatchNorm 对每个通道做归一化：

mean_B = batch内该通道均值
var_B  = batch内该通道方差
y = gamma * (x - mean_B) / sqrt(var_B + eps) + beta

训练阶段使用当前 batch 的均值方差，同时更新 running_mean 和 running_var。推理阶段不再使用当前 batch 统计，而使用训练时累计的 running statistics。

这带来几个重要后果：

  • 训练后推理前要调用 model.eval()，否则 BN 和 Dropout 行为不对。
  • batch size 太小时，BN 统计不稳定，检测任务常用 SyncBN、冻结 BN 或 GroupNorm。
  • fine-tune 小数据集时，是否冻结 BN 是重要选择。小 batch 下继续更新 BN 可能破坏预训练统计。

7. 任务头、损失与反向传播

Backbone 负责提特征，Head 负责把特征变成任务输出：

  • 分类：输出 N x num_classes 的 logits。
  • 分割：最终通常输出或上采样为 N x C x H x W 的像素级预测；网络原始 logits 也可能是低分辨率或带有多尺度辅助输出。
  • 检测：输出类别、框位置、置信度或 objectness。

训练时，模型前向得到预测，损失函数衡量预测和标签差距，再通过反向传播更新参数：

输入 x -> 模型 f(x; theta) -> 预测 y_hat
损失 L(y_hat, y)
反传 dL/dtheta
优化器更新 theta

常见损失：

  • 分类：Cross Entropy、Focal Loss。
  • 框回归：L1、Smooth L1、IoU/GIoU/DIoU/CIoU。
  • 分割：Cross Entropy、Dice Loss。

反向传播的核心是链式法则。如果 L 依赖 z，z 依赖 w：

dL/dw = dL/dz * dz/dw

梯度告诉参数如何变化能降低损失。学习率控制每次更新步长，过大可能发散，过小收敛慢。

工程陷阱：

  • 分类头常输出 logits，不要在 CrossEntropyLoss 前手动 softmax。
  • 检测框坐标格式要统一：xyxy、xywh、归一化坐标和像素坐标不能混用。
  • loss 数值正常不代表指标正常，要同时看 mAP、Recall、Precision、混淆矩阵和可视化结果。
  • 类别不均衡时，普通 CE 可能被大量背景或大类主导。

8. 推理与后处理

推理阶段一般关闭梯度：

model.eval()
with torch.no_grad():
    pred = model(image)

分类任务通常取 softmax 后最大概率类别。检测任务更复杂，需要把 Head 输出解码为框、类别分数，并进行阈值过滤和 NMS。完整 YOLO 检测链路会在 06 多尺度特征与 YOLO 检测链路 进一步展开。

9. 面试问答与速记

Q：为什么 CNN 比全连接更适合图像？

A：CNN 利用局部连接和权重共享。图像中的边缘、纹理等局部模式具有空间复用性，卷积能用少量参数在不同位置检测相同模式，同时保留空间结构。

Q：3x3 卷积为什么常见？

A：两个 3x3 的感受野是 5x5，三个 3x3 是 7x7，但参数更少，并且中间多了非线性表达。

Q：BN 训练和推理有什么区别？

A：训练用当前 batch 的均值方差，并更新 running statistics；推理用累计的 running statistics。忘记 eval() 会导致推理结果不稳定。

Q：为什么检测模型需要多尺度？

A：目标大小差异很大。浅层特征分辨率高、适合小目标；深层特征语义强、适合大目标。多尺度融合能兼顾定位和语义。

速记：

视觉模型主线：
像素张量 -> 卷积/归一化/激活 -> 层级特征 -> 任务头 -> 损失训练 -> 推理解码/后处理

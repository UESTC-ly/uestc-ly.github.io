学习目标

  • 理解目标检测为什么需要多尺度特征，以及 FPN/PAN 如何融合不同层级信息。
  • 掌握 Backbone、Neck、Head 在检测模型中的职责划分。
  • 能解释两阶段与单阶段检测、anchor-based 与 anchor-free、IoU 族损失、NMS、decoupled head。
  • 把 深度学习视觉基础 和 CNN 到 ResNet 的架构演进 串成 CNN -> ResNet -> FPN -> YOLO 的完整检测逻辑。
  • 为下一章 视觉任务与典型模型 建立检测任务的结构基础。

1. 检测任务比分类多了什么

分类只回答“图中是什么”，检测要回答：

有哪些目标？
每个目标在哪里？
每个目标属于哪一类？
置信度是多少？

因此检测 Head 通常输出三类信息：

  • 分类分数：目标类别。
  • 边界框回归：位置和大小。
  • 置信度/objectness 或质量分数：该预测是否可靠。

完整检测链路：

输入图像
-> 预处理/归一化/letterbox
-> Backbone提取层级特征
-> Neck做多尺度融合
-> Head输出框、类别、置信度
-> 解码到原图坐标
-> 置信度阈值过滤
-> NMS/后处理
-> 最终检测结果

2. Backbone、Neck、Head

Backbone 是特征提取器，例如 ResNet、CSPDarknet、ConvNeXt、EfficientNet。它从图像中提取不同 stride 的特征：

C3: stride 8,  高分辨率，适合小目标
C4: stride 16, 中等尺度
C5: stride 32, 低分辨率，语义强，适合大目标

Neck 负责融合不同层级特征，例如 FPN、PAN、BiFPN。它解决一个矛盾：

  • 浅层特征定位细，但语义弱。
  • 深层特征语义强，但空间粗。

Head 负责最终预测。YOLO 系列通常在多个尺度的特征图上预测，典型输出步长是 8/16/32。如果输入是 640 x 640：

stride 8:  80 x 80 特征图，偏小目标
stride 16: 40 x 40 特征图，中目标
stride 32: 20 x 20 特征图，偏大目标

3. FPN：自顶向下融合语义

FPN 使用深层语义特征逐级上采样，与浅层特征横向连接：

C5 -> 1x1 -> P5
P5 上采样 + C4的1x1投影 -> P4
P4 上采样 + C3的1x1投影 -> P3

1x1 卷积用于对齐通道数，上采样用于对齐空间尺寸，相加或 concat 用于融合信息。

直觉：

  • 深层告诉浅层“这里像什么语义对象”。
  • 浅层提供“边缘和位置在哪里”。
  • 融合后的 P3/P4/P5 都具有较好的语义信息，只是分辨率不同。

工程陷阱：

  • 相加要求通道和空间尺寸一致。
  • concat 后通道数会增加，后面通常接卷积压回目标通道。
  • 上采样后的尺寸可能因奇偶数输入出现一像素误差，需要显式对齐。

4. PAN：再把定位信息向上传

FPN 是自顶向下；PAN 在此基础上增加自底向上的路径，让低层定位信息再传回高层：

FPN: C5 -> P5 -> P4 -> P3
PAN: P3 -> N3 -> N4 -> N5

YOLO 系列常用 FPN + PAN 思想。这样每个尺度都能同时获得：

  • 深层语义：有助于分类和大目标理解。
  • 浅层定位：有助于边界框精细定位和小目标检测。

5. 两阶段与单阶段检测

两阶段检测以 Faster R-CNN 为代表：

Backbone -> RPN产生候选框 -> RoI Align -> 分类/回归Head

优点是候选区域更精细，早期精度高；缺点是流程复杂、推理较慢。

单阶段检测以 YOLO、SSD、RetinaNet 为代表：

Backbone -> Neck -> Dense Head直接预测框和类别

优点是端到端、速度快、部署简单；难点是正负样本极不均衡、密集预测后处理复杂。现代 YOLO 通过更好的标签分配、损失、Head 设计和数据增强显著提升精度。

6. Anchor-based 与 Anchor-free

Anchor-based 方法预先在每个特征图位置放若干默认框，模型预测相对 anchor 的偏移：

预测框 = anchor + delta

优点：

  • 先验明确，对传统检测框架友好。
  • 若 anchor 尺寸匹配数据集，训练较稳定。

缺点：

  • 需要设计 anchor 尺寸和比例。
  • 数据集目标尺寸变化大时，anchor 匹配可能低效。

Anchor-free 方法不依赖预设框，常直接预测中心点、边界距离或框坐标。优点是结构更简洁，减少超参数；缺点是标签分配和质量估计仍然关键。

面试中可以这样概括：

anchor-based: 先放模板框，再学偏移
anchor-free: 直接从特征点预测目标框

7. YOLO Head：密集预测

以输入 640 x 640、3 个尺度为例，YOLO Head 在每个尺度上对大量位置做预测：

80 x 80:  6400个位置
40 x 40:  1600个位置
20 x 20:   400个位置
总计:      8400个位置（anchor-free常见形式）

每个位置可能输出：

bbox: 4个数
class logits: num_classes个数
score/objectness: 1个数（视具体版本而定）

如果是 anchor-based，位置数还要乘以每个位置的 anchor 数。例如每个尺度每个格点 3 个 anchor：

总预测数 = (80*80 + 40*40 + 20*20) * 3 = 25200

这就是为什么检测需要阈值过滤和 NMS，否则输出候选框太多。

8. Decoupled Head：分类和定位分开学

早期检测 Head 常共享一组卷积后同时预测分类和回归。Decoupled Head 将分类分支和回归分支拆开：

输入特征
-> cls branch -> 类别分数
-> reg branch -> bbox / objectness / quality

原因是分类和定位关注点不同：

  • 分类需要语义判别：这是什么。
  • 回归需要几何边界：框在哪里、多大。

分支解耦通常能减少任务冲突，提高收敛和检测精度。现代 YOLO 和 anchor-free 检测器中很常见。

9. IoU 族：框质量如何度量

IoU 是两个框交并比：

IoU = intersection_area / union_area

若两个框不相交，IoU 为 0，此时单纯 IoU 损失无法提供有效的靠近方向。因此出现 IoU 族改进：

  • GIoU：加入最小外接框惩罚，解决不重叠时梯度弱的问题。
  • DIoU：加入中心点距离，让预测框更快靠近目标框。
  • CIoU：进一步考虑宽高比一致性。

计算例子：

框 A：(0,0,100,100)，框 B：(50,50,150,150)，坐标格式为 xyxy。

交集宽高 = 50 x 50
交集面积 = 2500
A面积 = 10000
B面积 = 10000
并集 = 10000 + 10000 - 2500 = 17500
IoU = 2500 / 17500 = 0.1429

工程陷阱：

  • xyxy 和 xywh 混用会直接破坏 IoU。
  • 坐标是否归一化不影响 IoU 数值本身，但同一批计算必须统一尺度。
  • resize/letterbox 后要把预测框映射回原图坐标，否则可视化和评估都会错。

10. NMS：从大量候选框到最终结果

NMS 用于去掉同一目标的重复框：

1. 按分数从高到低排序
2. 取最高分框作为保留框
3. 删除与该框 IoU 超过阈值的其他框
4. 重复直到没有候选框

常见参数：

  • confidence threshold：先过滤低分框。
  • IoU threshold：控制重复框删除强度。
  • class-aware/class-agnostic：是否按类别分别做 NMS。

NMS 陷阱：

  • 阈值过低会误删相邻目标，尤其是密集场景。
  • 阈值过高会保留重复框。
  • 小目标密集检测中，Soft-NMS、DIoU-NMS 或后处理调参可能有帮助。
  • 评估和部署端的 NMS 实现不一致，会造成离线指标和线上结果差异。

11. YOLO 训练损失的组成

不同 YOLO 版本细节不同，但通常包括：

总损失 = 框回归损失 + 分类损失 + 置信度/质量损失 + 可能的辅助项

具体分项依版本而异：有的实现保留独立 objectness，有的将目标质量融入分类分数；部分现代实现还使用 DFL（Distribution Focal Loss）等分布式框回归损失。因此分析训练日志时应以当前代码的真实 loss 定义为准。

训练关键点：

  • 标签分配：决定哪个特征点或 anchor 负责哪个 GT。
  • 正负样本平衡：背景位置远多于目标位置。
  • 多尺度训练：随机改变输入尺寸，提高尺度鲁棒性。
  • 数据增强：Mosaic、MixUp、颜色扰动、随机仿射等。

推理关键点：

  • 关闭增强或使用可控的 TTA。
  • 保持预处理与训练一致。
  • 解码坐标后再映射回原图。
  • 做阈值过滤和 NMS。

12. CNN -> ResNet -> FPN -> YOLO 的完整逻辑

可以把整条路线理解为逐步解决检测所需能力：

CNN:
  用卷积学习局部视觉模式，保留空间结构。

ResNet:
  用残差连接训练更深 Backbone，获得更强语义特征。

FPN/PAN:
  融合浅层定位和深层语义，解决不同尺寸目标的问题。

YOLO:
  在多尺度特征图上做密集预测，用单阶段方式直接输出框和类别。

IoU/NMS:
  用框质量损失训练定位，用后处理去除重复候选框。

一句话速记：

CNN 负责看局部，ResNet 负责看得深，FPN/PAN 负责大小目标都看清，YOLO Head 负责一次性把框和类别预测出来。

13. 面试问答与速记

Q：FPN 为什么适合检测？

A：检测需要同时处理小目标和大目标。FPN 把深层语义传到高分辨率特征上，让不同尺度的特征图都具备更强语义。

Q：PAN 比 FPN 多了什么？

A：PAN 增加自底向上的融合路径，让低层定位信息也能向高层传递。

Q：YOLO 为什么快？

A：它是单阶段检测器，不先生成候选区域再逐个分类，而是在多尺度特征图上密集预测框和类别。

Q：anchor-free 一定比 anchor-based 好吗？

A：不绝对。anchor-free 减少 anchor 设计负担，结构更简洁；但最终效果还取决于标签分配、损失、Head、数据和训练策略。

Q：为什么需要 NMS？

A：密集预测会对同一目标产生多个高分候选框，NMS 根据分数和 IoU 删除重复框。

速记：

Backbone: 提特征
Neck: 融合多尺度
Head: 预测类别和框
IoU Loss: 训练框质量
NMS: 推理去重

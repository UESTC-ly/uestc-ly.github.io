本章把前 8 章的 API 组织成可交付的小项目，围绕输入、流水线、输出、验收和排障训练工程判断。以下项目默认以 OpenCV 5 为主；如果仍使用 4.12，imgproc、imgcodecs、videoio、features2d、dnn 等常用接口大体一致，注意 OpenCV 5 已将 4.x 的 calib3d 拆分为 calib、geometry、stereo、ptcloud 等模块。C++ 工程建议使用 C++17；Python 示例继续采用 cv2。

资料入口：OpenCV 5 文档 https://docs.opencv.org/5.0/，4.12 文档 https://docs.opencv.org/4.12.0/，OpenCV5 与迁移说明 https://github.com/opencv/opencv/wiki/OpenCV-5、https://github.com/opencv/opencv/wiki/OpenCV-4-to-5-migration。只引用第一方资料。

9.1 实战路线总览

建议按“批处理、分割、几何校正、定位、标定、视频理解、跟踪、部署”推进。每个项目保留源数据清单、可复现实验脚本、验收报告；报告至少记录 OpenCV 版本、分辨率、样本量、平均耗时、失败样例和改进建议。

统一工程骨架如下：

from pathlib import Path
import cv2 as cv

def read_image(path: Path):
    img = cv.imread(str(path), cv.IMREAD_COLOR)
    if img is None:
        raise FileNotFoundError(path)
    return img

def timed(name, fn):
    t0 = cv.getTickCount()
    out = fn()
    ms = (cv.getTickCount() - t0) * 1000 / cv.getTickFrequency()
    print(f"{name}: {ms:.2f} ms")
    return out

def main():
    print(cv.__version__)
    # 解析参数、遍历输入、调用 pipeline、保存输出、写入指标

if __name__ == "__main__":
    main()

这个骨架连接第 1 章基础和第 8 章计时方法。后续项目只替换 pipeline，不要把读取、处理、显示、保存混在一个长函数里。

9.2 项目一：图像批处理与缩略图生成

目标：把目录图片转成缩略图，生成索引，并保留失败记录。输入是一组 JPG、PNG、BMP 或 TIFF；输出是固定最长边、固定编码格式、可选水印或边框的缩略图，以及 manifest.csv。

模块分解：imgcodecs 读写，imgproc 缩放和补边，core 处理尺寸、类型和计时。流程为：遍历文件，读取校验，按最长边缩放，必要时转通道，补齐背景，写出文件，记录尺寸、耗时和错误。

关键段：

def make_thumb(img, max_side=320):
    h, w = img.shape[:2]
    scale = max_side / max(h, w)
    new_size = (round(w * scale), round(h * scale))
    thumb = cv.resize(img, new_size, interpolation=cv.INTER_AREA)
    canvas = cv.copyMakeBorder(
        thumb, 0, max_side - thumb.shape[0], 0, max_side - thumb.shape[1],
        cv.BORDER_CONSTANT, value=(245, 245, 245)
    )
    return canvas

测试数据：至少 30 张，覆盖横图、竖图、小图、超大图、灰度图、透明 PNG、损坏文件和中文路径。正确性验收：输出数量等于有效输入数量；最长边不超过设定值；宽高比误差小于 1%；失败文件被记录。性能验收：报告 100 张 4000×3000 JPG 的平均耗时和 95 分位耗时。

常见故障：imread 返回 None 多由路径、权限、编码或格式导致；透明通道丢失要检查 IMREAD_UNCHANGED；缩小大图优先试 INTER_AREA；输出过大要调整 JPEG quality 或 PNG compression。扩展方向：EXIF 方向、重复图哈希、断点续跑、多进程分片、统一白边和水印。

9.3 项目二：颜色目标分割

目标：从图片或视频中分割指定颜色目标。输入是 BGR 图像或摄像头帧；输出是二值掩膜、轮廓、外接框和面积统计。

模块分解：videoio/imgcodecs 输入；imgproc 做 cvtColor、inRange、形态学、findContours；highgui 可做调参滑块。流程为：BGR 转 HSV，阈值得到 mask，开闭运算清理，找轮廓，按面积和形状过滤，绘制结果。

关键段：

def segment_color(frame, lower, upper):
    hsv = cv.cvtColor(frame, cv.COLOR_BGR2HSV)
    mask = cv.inRange(hsv, lower, upper)
    kernel = cv.getStructuringElement(cv.MORPH_ELLIPSE, (5, 5))
    mask = cv.morphologyEx(mask, cv.MORPH_OPEN, kernel)
    mask = cv.morphologyEx(mask, cv.MORPH_CLOSE, kernel)
    contours, _ = cv.findContours(mask, cv.RETR_EXTERNAL, cv.CHAIN_APPROX_SIMPLE)
    boxes = [cv.boundingRect(c) for c in contours if cv.contourArea(c) > 200]
    return mask, boxes

测试数据：同一目标在强光、弱光、阴影、不同背景、轻微遮挡下各 10 张；视频至少 30 秒。正确性验收：主要目标召回率达到 90% 以上，误检区域面积低于目标面积的 20%，框能覆盖主体。性能验收：640×480 视频达到实时显示，或记录离线每帧耗时。

常见故障：红色 hue 跨 0，需要两个区间合并；自动曝光会导致阈值漂移；反光会降低饱和度；形态学核过大会吞掉细小目标。扩展方向：白平衡、颜色校正卡、connectedComponentsWithStats、调参配置、第 7 章 DNN 复核。

9.4 项目三：文档扫描与透视校正

目标：把纸张、票据或白板照片转成俯视扫描图。输入是含矩形文档的照片；输出是裁剪、拉正、增强后的文档图。

模块分解：imgproc 负责灰度、模糊、边缘、轮廓、多边形逼近和透视变换；geometry/4.x calib3d 的单应性思想用于理解四点映射。流程为：降采样检测，灰度化，边缘或阈值，找四边形，四点排序，透视变换，最后增强。

关键段：

def order_quad(pts):
    pts = pts.reshape(4, 2).astype("float32")
    s = pts.sum(axis=1)
    d = pts[:, 0] - pts[:, 1]
    return np.array([pts[s.argmin()], pts[d.argmax()], pts[s.argmax()], pts[d.argmin()]], dtype="float32")

def scan_document(img, quad):
    src = order_quad(quad)
    w = int(max(np.linalg.norm(src[1] - src[0]), np.linalg.norm(src[2] - src[3])))
    h = int(max(np.linalg.norm(src[3] - src[0]), np.linalg.norm(src[2] - src[1])))
    dst = np.array([[0, 0], [w - 1, 0], [w - 1, h - 1], [0, h - 1]], dtype="float32")
    M = cv.getPerspectiveTransform(src, dst)
    return cv.warpPerspective(img, M, (w, h))

测试数据：A4 白纸、票据、白板、杂物背景、阴影、边缘不完整各 5 张。正确性验收：文本不倒置，文档边缘贴近输出边界，拉正后直线倾斜小于 2 度。性能验收：记录 1200 万像素图片总耗时；移动端应先降采样检测，再在原图上变换。

常见故障：最大轮廓不是文档，说明背景边缘太强；approxPolyDP 得不到四点时要调 epsilon 或改用霍夫线；四点排序错误会扭曲；增强过度会丢浅色文字。扩展方向：交互式四角修正、findHomography 多点映射、批量 PDF、OCR 前处理评价。

9.5 项目四：模板匹配与特征匹配定位

目标：在大图或视频帧中定位已知目标。尺度变化小用模板匹配；尺度、旋转、视角变化明显用特征匹配。输入是模板和待搜索图；输出是位置、分数和可视化。

模板路线：matchTemplate 计算相似度图，minMaxLoc 找最佳位置，阈值控制是否命中。适合 UI 图标、固定零件、印刷标识等。

def locate_template(img, templ, threshold=0.8):
    score = cv.matchTemplate(img, templ, cv.TM_CCOEFF_NORMED)
    _, max_val, _, max_loc = cv.minMaxLoc(score)
    if max_val < threshold:
        return None, max_val
    h, w = templ.shape[:2]
    return (max_loc[0], max_loc[1], w, h), max_val

特征路线：用 ORB、SIFT 等检测关键点和描述子，匹配后用 Lowe ratio 或交叉验证过滤，再用 findHomography 和 RANSAC/USAC 估计目标平面位置。OpenCV 5 中 SIFT、ORB、FAST、GoodFeaturesToTrack 和 MSER 仍在主仓库，部分旧特征被移到 contrib；4.12 用户按第 4 章示例写即可。

测试数据：不同尺度、旋转、亮度、遮挡和背景干扰各 10 张。正确性验收：模板匹配阈值能区分正负样本；特征匹配至少保留 8 个以上内点，投影四边形落在目标附近。性能验收：模板匹配裁剪 ROI 或建金字塔；特征匹配报告关键点、匹配数、内点比例和耗时。

常见故障：模板匹配对尺度和旋转敏感；纹理少会特征点不足；重复纹理会产生错误单应性；阈值只在当前数据集有效。扩展方向：多尺度模板、非极大值抑制、多模板库检索、LightGlue 评估、用 DNN 检测框约束匹配范围。

9.6 项目五：相机标定

目标：估计相机内参、畸变系数，并验证去畸变效果。输入是棋盘格、圆点格或 ChArUco 图像；输出是相机矩阵、畸变参数、重投影误差、去畸变示例和配置文件。OpenCV 5 中标定能力归入 calib，4.12 中主要在 calib3d。

模块分解：imgproc 做灰度和亚像素角点；calib/calib3d 做检测、calibrateCamera、undistort、initUndistortRectifyMap、remap；配置文件保存参数。流程为：采集不同姿态，检测角点，构造世界坐标，标定，算误差，保存并验证。

关键段：

pattern = (9, 6)
objp = np.zeros((pattern[0] * pattern[1], 3), np.float32)
objp[:, :2] = np.mgrid[0:pattern[0], 0:pattern[1]].T.reshape(-1, 2)
objp *= 25.0  # 每格 25 mm

ok, corners = cv.findChessboardCorners(gray, pattern)
if ok:
    corners = cv.cornerSubPix(gray, corners, (11, 11), (-1, -1),
                              (cv.TERM_CRITERIA_EPS + cv.TERM_CRITERIA_MAX_ITER, 30, 0.001))
    object_points.append(objp)
    image_points.append(corners)

rms, K, dist, rvecs, tvecs = cv.calibrateCamera(object_points, image_points, image_size, None, None)

测试数据：至少 20 张有效标定图，覆盖中心、四角、远近、倾斜和旋转。正确性验收：重投影 RMS 通常低于 1 像素，高要求场景低于 0.5 像素；去畸变后直线明显变直；重复标定差异可解释。性能验收：在线去畸变应使用预计算 map。

常见故障：棋盘格内角点数量写反；打印比例不准；图片模糊、反光或角点只覆盖中心；广角镜头可能要用 fisheye；标定文件和分辨率不匹配。扩展方向：手眼标定、双目标定、多相机标定、姿态估计、AR 叠加或工业测量。

9.7 项目六：运动检测

目标：在固定摄像头视频中检测运动区域。输入是视频文件或摄像头流；输出是运动框、掩膜、事件时间戳和短片段。

模块分解：videoio 读写帧；video 做 MOG2/KNN 背景建模；imgproc 做形态学和轮廓；第 8 章方法统计帧率。流程为：读帧，背景减除，阈值，清理，过滤轮廓，合并框，状态机判断事件。

关键段：

bg = cv.createBackgroundSubtractorMOG2(history=500, varThreshold=32, detectShadows=True)

def detect_motion(frame):
    fg = bg.apply(frame)
    _, mask = cv.threshold(fg, 200, 255, cv.THRESH_BINARY)
    kernel = cv.getStructuringElement(cv.MORPH_RECT, (5, 5))
    mask = cv.morphologyEx(mask, cv.MORPH_OPEN, kernel)
    mask = cv.dilate(mask, kernel, iterations=2)
    contours, _ = cv.findContours(mask, cv.RETR_EXTERNAL, cv.CHAIN_APPROX_SIMPLE)
    boxes = [cv.boundingRect(c) for c in contours if cv.contourArea(c) > 800]
    return mask, boxes

测试数据：白天、夜晚、开灯关灯、空场景、多人经过、树影或屏幕闪烁视频。正确性验收：空场景误报率低；真实运动 3 帧内触发；事件结束有防抖。性能验收：处理速度不低于输入帧率，或报告每分钟视频处理耗时。

常见故障：影子被当作前景；摄像头抖动导致全画面运动；自动曝光导致大面积误报；雨雪、反光和屏幕刷新造成周期噪声；背景学习太快会吞掉慢速目标。扩展方向：ROI 屏蔽、区域计数、轨迹追踪、预录缓存、目标检测复核。

9.8 项目七：目标跟踪

目标：给出初始框后，在后续帧持续输出目标位置。输入是视频和初始框；输出是每帧目标框、状态、丢失提示和轨迹。

模块分解：videoio 读帧；跟踪器维护状态；imgproc 绘制结果；检测模块可周期性重初始化。流程为：选初始 ROI，初始化 tracker，逐帧 update，记录状态，失败时重新检测或重选。

代码骨架：

def create_csrt_tracker():
    candidates = [
        ("cv.TrackerCSRT.create", lambda: cv.TrackerCSRT.create()),
        ("cv.TrackerCSRT_create", lambda: cv.TrackerCSRT_create()),
        ("cv.legacy.TrackerCSRT.create", lambda: cv.legacy.TrackerCSRT.create()),
        ("cv.legacy.TrackerCSRT_create", lambda: cv.legacy.TrackerCSRT_create()),
    ]
    errors = []
    for name, factory in candidates:
        try:
            return factory()
        except Exception as exc:
            errors.append(f"{name}: {exc}")
    raise RuntimeError(
        "CSRT tracker is unavailable. Install opencv-contrib-python or rebuild "
        "OpenCV with opencv_contrib tracking enabled. Tried: " + "; ".join(errors)
    )

tracker = create_csrt_tracker()
ok = tracker.init(first_frame, init_box)

while True:
    ok, frame = cap.read()
    if not ok:
        break
    success, box = tracker.update(frame)
    if success:
        x, y, w, h = map(int, box)
        cv.rectangle(frame, (x, y), (x + w, y + h), (0, 255, 0), 2)
    else:
        # 调用检测器重新定位，或标记 lost
        pass

测试数据：快速移动、短时遮挡、尺度变化、相似目标干扰、出画再入画。正确性验收：用人工标注框计算 IoU，连续跟踪平均 IoU 大于 0.5；丢失后不能长期输出明显错误框。性能验收：目标平台达到目标帧率；CSRT 通常更稳但更慢，KCF/MOSSE 类方法更快但鲁棒性较弱。

常见故障：初始框不准；遮挡后漂移到相似物；目标尺度变化过大；跟踪器 API 可能位于 cv 或 cv.legacy；只看显示效果会高估质量。扩展方向：检测跟踪融合、多目标 ID、Kalman 平滑、越线计数、长视频断点恢复。

9.9 项目八：ONNX 检测部署

目标：用 OpenCV DNN 加载 ONNX 检测模型，完成预处理、推理、后处理和性能报告。输入是 .onnx、类别文件和图片/视频；输出是框、类别、置信度、可视化和结构化结果。OpenCV 5 DNN 有新推理引擎和更好的 ONNX 支持；4.12 仍可用 readNet、blobFromImage、forward，但动态形状和新算子要实测。

模块分解：dnn 做模型读取、blob、后端/目标和推理；imgproc 做 letterbox、缩放、绘制；core 做 NMS 和计时。流程为：确认输入契约，预处理，推理，解析张量，坐标回原图，NMS，导出 JSON。

关键段：

net = cv.dnn.readNet("detector.onnx")
net.setPreferableBackend(cv.dnn.DNN_BACKEND_OPENCV)
net.setPreferableTarget(cv.dnn.DNN_TARGET_CPU)

blob = cv.dnn.blobFromImage(frame, 1 / 255.0, (640, 640), swapRB=True, crop=False)
net.setInput(blob)
pred = net.forward()

# 按模型说明解析 pred，得到 boxes/confidences/class_ids
indices = cv.dnn.NMSBoxes(boxes, confidences, score_threshold=0.25, nms_threshold=0.45)

测试数据：验证集至少 100 张，覆盖大小目标、遮挡、背景和负样本；视频覆盖稳定光照和运动模糊。正确性验收：比对 mAP、precision、recall 或抽样统计 TP/FP/FN；坐标映射与原图对齐；类别顺序正确。性能验收：报告三段耗时，记录模型尺寸、输入尺寸、线程数、后端和目标。部署验收：冷启动、连续运行 10 分钟、异常路径、空输入和无检测结果都能处理。

常见故障：ONNX 含不支持的算子；NCHW/NHWC、BGR/RGB、归一化或 letterbox 反算不一致；类别顺序错；示例阈值不适合本数据。扩展方向：多模型路由、批量推理、异步视频流水线、量化、后端对照、COCO 格式评估。

9.10 API 学习地图

按流水线记 API：输入输出用 imread、imwrite、VideoCapture、VideoWriter；表示层看 Mat、ROI、通道、convertTo；预处理串起 cvtColor、resize、滤波、阈值；区域分析用形态学、connectedComponentsWithStats、findContours；几何用仿射、透视、findHomography、solvePnP；特征用 ORB、SIFT、BFMatcher、ratio test、RANSAC/USAC；相机用 calibrateCamera、undistort、remap；视频用背景减除、光流、跟踪和状态机；DNN 用 readNet、blobFromImage、forward、NMS、backend/target；诊断用 getBuildInformation、getTickCount、日志和中间结果可视化。

9.11 数学先修

数学要能用于排障：线性代数看矩阵乘法、齐次坐标、逆矩阵和 SVD；几何看面积、单应性、针孔模型和畸变；统计看分位数、混淆矩阵、precision、recall、IoU；优化看最小二乘、RANSAC/USAC；信号处理看卷积、边缘、采样和混叠。练习时手算 IoU，画四点透视映射，解释阈值漂移的像素分布。

9.12 调试方法

第一步查输入：路径、空图、尺寸、dtype、视频帧读取状态。第二步查中间结果：保存灰度图、mask、边缘、轮廓、匹配点、畸变前后、DNN 输入；非 uint8 图先 normalize 到 0～255 再写出。第三步查坐标：缩放、裁剪、letterbox 和透视变换都要写清原图到处理图再回原图的映射。第四步查阈值：记录正负样本分布。第五步查性能：把读取、预处理、核心算法、后处理、显示保存分开计时。

常用断言：图像不为空；通道数正确；mask 只有 0/255；框坐标在图像范围内；单应性矩阵非空；DNN 输出维度和模型说明一致；视频循环能在 EOF 退出。调试完成后删除大量 imshow、临时文件和固定绝对路径。

9.13 练习题与答案要点

  1. 透明 PNG 缩略图如何保留透明背景？答案要点：IMREAD_UNCHANGED 读取，判断 4 通道，缩放时保留 alpha，保存 PNG；贴背景时做 alpha blend。
  2. 红色目标为什么常用两个 HSV 区间？答案要点：hue 是环形，红色跨 0，分别 inRange 后 bitwise_or。
  3. 小图检测、原图变换容易错在哪里？答案要点：四点坐标要按缩放、裁剪或旋转关系映射回原图。
  4. 模板匹配为什么怕旋转？答案要点：相关性比较固定像素布局；可用旋转模板、多尺度搜索或特征匹配。
  5. 特征匹配内点比例低怎么办？答案要点：查纹理和清晰度，调特征数、ratio 阈值和匹配方式，用 RANSAC/USAC 过滤，必要时限制 ROI。
  6. 标定 RMS 低但去畸变差，可能原因是什么？答案要点：覆盖不足、棋盘尺寸错、分辨率不一致、畸变模型不适合、训练图过拟合。
  7. 开灯瞬间全屏运动报警怎样处理？答案要点：全局亮度变化判断、事件防抖、短暂冻结背景更新、ROI 限制。
  8. ONNX 检测框整体偏移，优先查什么？答案要点：letterbox 反算、输入尺寸、坐标格式、输出格式、RGB/BGR。
  9. 如何比较 OpenCV 4.12 和 5？答案要点：记录版本和构建信息，固定数据和阈值，分别跑正确性和性能指标。

9.14 术语表

流水线：读取、预处理、核心算法、后处理、保存和评估的稳定阶段。ROI：感兴趣区域，常是共享底层数据的视图。掩膜：用 0/255 或布尔值表示像素是否属于目标。形态学：对二值区域做腐蚀、膨胀、开闭运算。轮廓：二值区域边界点集合。单应性：平面到平面的透视映射。内点：符合估计模型的数据点。RANSAC/USAC：在噪声和离群点中鲁棒估计模型的方法。重投影误差：投影点与观测点的距离。背景减除：估计背景并提取前景运动。IoU：两个框交并比。NMS：去掉高度重叠的重复检测框。Backend/Target：DNN 推理后端和计算目标。Letterbox：等比例缩放后补边。Manifest：批处理结果清单。

04-计算机基础 / 数字图像处理

数字图像处理知识库

这套笔记面向视觉/影像系统工程师与视觉算法工程师，目标不是记住模型名单，而是建立一条可以解释、实现、诊断和部署的完整链路：

数字图像 → 成像与数字化 → 传统预处理/先验 → 神经网络表示学习 → 多尺度特征 → 任务头 → 损失与优化 → 推理与后处理 → 评价、部署与业务决策

如何使用

  • 第一次系统学习：按 01～11 顺序阅读，最后用 12 复习；每章完成末尾检查清单。
  • 准备面试：先读 12，再回到对应章节补公式、原理和工程细节。
  • 定位项目问题：从 10 的系统流水线和排查顺序开始，再查 08、09。
  • 传统视觉转深度学习：重点阅读 03 → 04 → 05 → 06，比较人工特征与表示学习。

两代方法不是替代关系

维度 传统图像处理 深度学习视觉
特征来源 人工设计边缘、纹理、几何与规则 从数据中端到端学习层次化表示
数据需求 较低，依赖稳定先验 通常较高，依赖覆盖真实分布的数据
可解释性 处理步骤和阈值通常可解释 可通过可视化、归因和误差分析部分解释
场景适应 固定场景、明确规则下高效稳定 复杂变化和高维语义问题更有优势
工程角色 标定、ROI、增强、测量、后处理与规则 分类、检测、分割、异常表征等核心感知

成熟系统通常组合两者：传统方法约束问题和清洗信号，深度模型负责难以手工描述的表征，业务规则与时序逻辑负责把单帧预测转成可靠决策。

学习与验收标准

完成本知识库后，应能做到：

  1. 从采样、卷积、频域和形态学解释常见传统处理算子的作用与边界。
  2. 手算卷积输出尺寸、参数量和感受野，解释 BN 的训练/推理差异与残差连接。
  3. 连续讲清 CNN → ResNet → FPN/PAN → YOLO 的设计动机与信息流。
  4. 区分分类、检测、语义/实例分割等任务的标签、输出、损失和指标。
  5. 正确解释 IoU、NMS、Precision、Recall、F1、AP/mAP、Dice 及阈值权衡。
  6. 按“数据 → 标注 → 划分 → 输入 → 训练 → 损失 → 后处理 → 部署”定位效果问题。
  7. 根据硬件和业务约束权衡精度、漏检率、时延、吞吐量、显存、功耗和成本。
  8. 说明工业视觉为何需要成像、传统视觉、深度学习、时序和业务规则协同。

推荐练习

  • 不调用库，手算一次二维相关、卷积输出尺寸、IoU、混淆矩阵和 Dice。
  • 用同一幅图比较均值/高斯/中值/双边滤波及 Sobel/Canny 的结果。
  • 用一个小型 CNN 打印每层张量尺寸，并可视化浅层与深层特征图。
  • 对一个检测结果调节置信度阈值和 NMS IoU，观察 Precision/Recall 变化。
  • 对部署模型分别测量预处理、推理、后处理和端到端时延，不只报告 FPS。

所属模块：机器学习与深度学习基础
学习顺序：第 01 课 监督学习与无监督学习 → 第 02 课 训练集、验证集、测试集 → 第 03 课 过拟合、欠拟合与正则化 → 第 04 课 分类、回归与聚类

资料说明：当前项目没有可读取的本课直接参考资料，以下内容依据通用机器学习知识整理。

一、学习目标

完成本课后，应能够：

  1. 解释欠拟合和过拟合的含义；
  2. 根据训练集和验证集的表现判断模型状态；
  3. 理解偏差与方差的基本概念；
  4. 说明正则化的目的以及 L1、L2 正则化的区别；
  5. 了解 Early Stopping、Dropout、数据增强等改善泛化能力的方法；
  6. 明确验证集用于调参，测试集用于最终评估。

二、模型真正要学习的是泛化能力

模型训练时可以看到训练数据，但上线后面对的是没有见过的新数据。模型在新数据上的表现称为泛化能力（Generalization）。

机器学习的目标不是单纯让训练误差最低，而是让模型学习到能够推广到新数据的规律。

例如，垃圾邮件分类模型如果只是记住训练集中出现过的邮件内容，面对新邮件时就可能失效；如果它学到了垃圾邮件常见的语言和行为特征，才具有较好的泛化能力。

三、欠拟合（Underfitting）

3.1 定义

欠拟合是指模型没有充分学习训练数据中的规律，在训练集上的表现就已经较差。

可以简单理解为：模型连训练题都没有学会。

3.2 典型表现

数据集 示例 Accuracy
训练集 65%
验证集 63%

常见特征：

  • 训练集误差较高；
  • 验证集误差也较高；
  • 训练集与验证集的表现通常比较接近；
  • 模型表达能力不足或训练尚未充分。

3.3 常见原因

  1. 模型过于简单：数据具有非线性关系，却使用了表达能力有限的模型；
  2. 输入特征不足：缺少完成任务所需的关键信息；
  3. 训练不充分：训练轮数太少、优化尚未收敛或学习率不合适；
  4. 正则化过强：模型受到过度限制，无法学习必要规律；
  5. 数据或标签质量较差：输入信息不足、标签错误或预处理不当。

3.4 改善方法

可以尝试：

  • 使用表达能力更强的模型；
  • 增加有效特征；
  • 适当增加训练轮数；
  • 调整学习率等训练超参数；
  • 减小正则化强度；
  • 改进数据质量和标签质量。

四、过拟合（Overfitting）

4.1 定义

过拟合是指模型在训练集上表现很好，但在未见过的验证集、测试集或线上数据上表现明显变差。

模型不仅学习了真实规律，还记住了训练数据中的噪声、异常样本和无关细节。

可以简单理解为：模型记住了答案，但没有真正理解题目。

4.2 典型表现

数据集 示例 Accuracy
训练集 99%
验证集 78%
测试集 76%

常见特征：

  • 训练集误差很低；
  • 验证集或测试集误差明显较高；
  • 训练集与验证集之间存在较大的性能差距；
  • 继续训练时，训练集表现继续变好，但验证集表现开始下降。

4.3 常见原因

  1. 模型过于复杂：参数过多、表达能力过强，容易记住样本细节；
  2. 训练数据太少：模型难以区分真实规律与偶然现象；
  3. 训练时间过长：训练后期开始拟合噪声；
  4. 数据噪声较多：存在错误标签、异常样本或低质量输入；
  5. 训练集缺乏代表性：训练数据与实际数据分布不同；
  6. 数据泄漏：训练过程错误地获得了验证集或测试集的信息。

五、如何通过训练曲线判断模型状态

假设损失越低越好：

模型状态 训练损失 验证损失 典型含义
欠拟合 高 高 模型没有学好训练数据
过拟合 很低 较高，或后期上升 模型过度适应训练数据
泛化较好 较低 较低 两者差距合理且比较稳定

一种典型的过拟合过程是：

训练损失：持续下降
验证损失：先下降，达到最低点后上升

验证损失最低的位置通常是比较合适的停止位置。需要注意，训练集表现略好于验证集是正常现象，小幅差距不等于严重过拟合。

六、偏差与方差

6.1 偏差（Bias）

偏差表示模型的假设与真实规律之间的差距。

高偏差通常意味着：

  • 模型过于简单；
  • 学习能力不足；
  • 容易欠拟合。

6.2 方差（Variance）

方差表示模型对训练数据变化的敏感程度。

高方差模型通常具有以下特点：

  • 在当前训练集上表现很好；
  • 更换一批训练数据后，模型结果可能明显变化；
  • 对新数据表现不稳定；
  • 容易过拟合。

6.3 与拟合状态的关系

模型状态 偏差 方差
欠拟合 高 通常较低
过拟合 通常较低 高
泛化较好 适中 适中

模型不是越复杂越好，而是要在模型复杂度与泛化能力之间取得平衡。

七、正则化（Regularization）

7.1 核心思想

正则化是在训练目标中加入对模型复杂度的约束，以降低过拟合风险、提高泛化能力。

原始目标函数可以表示为：

\[ J(\theta)=L(\theta) \]

加入正则化后：

\[ J(\theta)=L(\theta)+\lambda R(\theta) \]

其中：

  • \(L(\theta)\)：模型在训练数据上的原始损失；
  • \(R(\theta)\)：正则化项，用于惩罚模型复杂度；
  • \(\lambda\)：正则化强度；
  • \(\theta\)：模型参数。

7.2 正则化强度的影响

  • \(\lambda\) 太小：约束不足，可能仍然过拟合；
  • \(\lambda\) 适中：有助于改善泛化能力；
  • \(\lambda\) 太大：限制过强，可能导致欠拟合。

因此，正则化并不是越强越好，需要通过验证集选择合适强度。

八、L1 正则化与 L2 正则化

8.1 L1 正则化

L1 正则化在损失函数中加入参数绝对值之和：

\[ J(\theta)=L(\theta)+\lambda\sum_i |w_i| \]

主要特点：

  • 容易将部分参数压缩为 0；
  • 能够产生稀疏参数；
  • 具有一定的特征选择效果；
  • 适合特征数量很多、希望得到稀疏模型的场景。

8.2 L2 正则化

L2 正则化在损失函数中加入参数平方和：

\[ J(\theta)=L(\theta)+\lambda\sum_i w_i^2 \]

L2 正则化也常被称为权重衰减（Weight Decay）。

主要特点：

  • 抑制参数变得过大；
  • 让权重整体变小；
  • 减少模型对个别特征的过度依赖；
  • 通常不会像 L1 那样直接产生大量 0 权重。

8.3 对比

对比项 L1 L2
惩罚形式 参数绝对值 参数平方
参数结果 部分参数容易变为 0 参数通常变小但不为 0
稀疏性 强 弱
特征选择 有一定作用 通常不直接选择特征
典型作用 构造稀疏模型 平滑、稳定模型

九、其他改善泛化能力的方法

9.1 Early Stopping

Early Stopping 即提前停止训练：

  1. 每轮训练后计算验证集指标；
  2. 保存验证集表现最好的模型；
  3. 如果验证集表现连续若干轮没有提升，则停止训练；
  4. 恢复验证集表现最佳时的模型参数。

它可以避免模型在训练后期继续拟合噪声。

Early Stopping 应根据验证集表现决定，不能根据测试集表现决定。

9.2 Dropout

Dropout 常用于神经网络。训练过程中随机暂时关闭一部分神经元，使模型不能长期依赖固定的少数神经元。

作用包括：

  • 减少神经元之间的过度依赖；
  • 提升模型鲁棒性；
  • 降低过拟合风险。

训练和推理阶段的行为不同：

  • 训练阶段：启用 Dropout；
  • 验证和推理阶段：关闭随机丢弃。

9.3 数据增强

数据增强通过对训练样本进行合理变换，产生更多样的训练数据。

例如图像任务可以使用：

  • 随机裁剪；
  • 水平翻转；
  • 轻微旋转；
  • 颜色变化。

文本任务中的增强需要更加谨慎，必须保证语义和标签不被改变。

9.4 降低模型复杂度

可以通过以下方式限制复杂度：

  • 减少参数量；
  • 减少模型层数；
  • 缩小隐藏层；
  • 删除无效特征；
  • 限制决策树深度。

9.5 增加高质量数据

增加与实际任务分布一致、标签正确的训练数据，通常有助于减少过拟合。单纯增加低质量、错误或分布不匹配的数据，不一定有效。

9.6 改善数据质量

应检查并处理：

  • 错误标签；
  • 异常样本；
  • 不合理的重复数据；
  • 训练数据代表性不足；
  • 数据泄漏。

十、欠拟合与过拟合的处理对照

问题 训练集表现 验证集表现 优先考虑的处理方式
欠拟合 差 差 增强模型、增加特征、训练更久、减弱正则化
过拟合 好 明显较差 增加数据、增强正则化、降低复杂度、提前停止
泛化较好 好 好且差距合理 保持方案，并用测试集做最终评估

十一、推荐的诊断流程

第一步：检查训练集表现

如果训练集表现也很差，优先考虑：

  • 欠拟合；
  • 数据或标签错误；
  • 训练流程有问题；
  • 优化尚未收敛。

第二步：比较训练集和验证集

如果训练集很好、验证集明显较差，优先考虑：

  • 过拟合；
  • 训练集与验证集分布不同；
  • 数据泄漏；
  • 验证集太小导致评估不稳定。

第三步：选择处理方案

  • 欠拟合时：提高模型能力、增加有效特征、训练更充分；
  • 过拟合时：增加正则化、增加数据、降低复杂度、使用 Early Stopping。

不要在模型已经欠拟合时继续增强正则化，也不要在模型已经过拟合时盲目扩大模型。

第四步：使用验证集调参

可根据验证集选择：

  • 模型结构；
  • 正则化强度；
  • 训练轮数；
  • 特征方案；
  • 学习率等超参数。

第五步：最后使用测试集

测试集应在模型方案基本确定后使用，用来估计模型在未知数据上的最终表现。

如果反复根据测试集结果修改模型，测试集实际上就被当成了验证集，最终评估会失去客观性。

十二、案例分析

案例一：训练集和验证集都较差

训练集 Accuracy：61%
验证集 Accuracy：60%

更可能是欠拟合。可以检查模型复杂度、特征、训练轮数、学习率和正则化强度。

案例二：训练集很好，验证集较差

训练集 Accuracy：99%
验证集 Accuracy：74%

更可能是过拟合。可以增加高质量数据、增强正则化、使用 Early Stopping、降低模型复杂度，并检查数据分布是否一致。

案例三：三个数据集差距合理

训练集 Accuracy：91%
验证集 Accuracy：89%
测试集 Accuracy：88%

模型的泛化表现通常比较合理，不应为了消除小幅差距而盲目加强正则化。

案例四：离线好、线上差

训练集 Accuracy：98%
验证集 Accuracy：97%
线上 Accuracy：70%

这不一定只是传统过拟合，还可能是：

  • 线上数据与离线数据分布不同；
  • 训练集和验证集存在数据泄漏；
  • 数据划分方式不合理；
  • 线上特征处理与训练阶段不一致；
  • 线上任务环境发生变化。

十三、常见误区

误区 1：训练准确率越高，模型越好

错误。训练准确率只能反映模型对训练数据的拟合程度，不能直接代表泛化能力。

误区 2：训练集和验证集有差距就是过拟合

不一定。小幅差距是正常现象，需要关注验证集表现是否明显变差以及差距是否持续扩大。

误区 3：正则化越强越好

错误。正则化过强会限制模型学习，导致欠拟合。

误区 4：增加训练轮数一定能提升效果

错误。欠拟合时可能有效，但模型开始过拟合后，继续训练可能让验证集表现下降。

误区 5：使用测试集选择最佳参数

错误。调参应使用验证集，测试集只用于最终评估。

误区 6：增加数据一定有用

只有新增数据质量高、标签正确且与目标任务分布一致时，才更可能改善模型。

误区 7：验证集表现差一定是过拟合

不一定，还应检查数据分布差异、数据泄漏、标签错误、验证集规模、评估指标和预处理流程。

十四、面试表达模板

14.1 什么是欠拟合和过拟合？

欠拟合是模型表达能力不足或训练不充分，导致模型在训练集和验证集上的表现都较差，通常对应高偏差。过拟合是模型在训练集上表现很好，但在验证集或新数据上的表现明显下降，通常对应高方差。实际开发中，我会先比较训练集和验证集的学习曲线，再决定是提高模型能力，还是通过正则化、增加数据、降低复杂度和提前停止来改善泛化能力。

14.2 如何解决过拟合？

可以增加高质量训练数据，使用 L1/L2 正则化、Dropout 或 Early Stopping，降低模型复杂度，进行合理的数据增强，并检查数据质量、训练验证分布和数据泄漏问题。

14.3 L1 和 L2 有什么区别？

L1 使用参数绝对值作为惩罚，容易产生稀疏权重，部分参数可能变为 0；L2 使用参数平方作为惩罚，通常让权重整体变小而不是直接变为 0，更强调模型的平滑性和稳定性。

十五、自测题

题目

  1. 某模型训练集 Accuracy 为 99%，验证集 Accuracy 为 72%，这是什么问题？请给出三种改进方法。
  2. 某模型训练集 Accuracy 为 58%，验证集 Accuracy 为 57%，应该优先增加正则化吗？为什么？
  3. 为什么不能根据测试集结果反复调整正则化强度？
  4. 验证损失先下降后上升，而训练损失持续下降，这说明了什么？可以使用什么方法处理？

参考答案

  1. 更可能是过拟合。可以增加高质量训练数据、增强正则化、使用 Early Stopping 或降低模型复杂度。
  2. 不应该。训练集表现本身就较差，更可能是欠拟合；继续增强正则化可能使问题更加严重。
  3. 因为测试集信息会泄漏到模型选择过程中，测试集将无法继续提供客观的最终评估。
  4. 说明训练后期可能开始过拟合。可以使用 Early Stopping，并保存验证集表现最好的模型。

十六、本课小结

  • 欠拟合：训练集和验证集表现都较差；
  • 过拟合：训练集表现很好，验证集或测试集明显较差；
  • 欠拟合通常对应高偏差，过拟合通常对应高方差；
  • 正则化通过限制模型复杂度来改善泛化能力；
  • L1 倾向于产生稀疏权重，L2 倾向于让权重整体变小；
  • Early Stopping、Dropout、数据增强、降低模型复杂度和增加高质量数据都可以帮助减少过拟合；
  • 使用验证集进行诊断和调参，测试集只用于最终评估；
  • 看到离线指标很好、线上指标很差时，还要排查分布偏移、数据泄漏和特征处理不一致。

学习目标

  • 快速回忆传统图像处理、CNN、检测、训练、评价与部署的核心公式和口径。
  • 在面试或项目排障前检查符号、阈值、张量尺寸与端到端流水线。
  • 知道公式的适用前提，避免把离线代理指标直接等同于线上效果。

1. 图像与卷积

卷积层输出尺寸

对单个空间维度：

\[ O=\left\lfloor\frac{I+2P-D(K-1)-1}{S}+1\right\rfloor \]
  • \(I\)：输入尺寸；\(K\)：卷积核；\(S\)：步长；\(P\)：padding；\(D\)：dilation。
  • 普通卷积参数量：\(K_hK_wC_{in}C_{out}+C_{out}\)（若无 bias，去掉最后一项）。
  • 计算量还与输出空间尺寸相关；参数少不代表延迟一定低。

感受野递推

令第 \(l\) 层的实际跳距为 \(j_l\)、感受野为 \(r_l\)：

\[ j_l=j_{l-1}s_l,\qquad r_l=r_{l-1}+(k_l-1)d_lj_{l-1} \]

初始 \(j_0=r_0=1\)。理论感受野不等于有效感受野，后者通常更集中在中心区域。

常见归一化

像素缩放：

\[ x'=\frac{x}{255} \]

标准化：

\[ x'=\frac{x-\mu}{\sigma} \]

训练、验证、部署必须保持颜色顺序、缩放、均值方差、resize/letterbox 规则一致。

2. 传统处理

灰度变换与直方图均衡

常见亮度近似：

\[ Y\approx0.299R+0.587G+0.114B \]

直方图均衡用累计分布函数重新映射灰度。它增强全局对比度，但也可能放大噪声；局部增强常用 CLAHE 并限制对比度。

二维离散傅里叶变换

\[ F(u,v)=\sum_{x=0}^{M-1}\sum_{y=0}^{N-1}f(x,y)e^{-j2\pi(ux/M+vy/N)} \]
  • 低频：缓慢变化、整体亮度和大尺度结构。
  • 高频：边缘、细节，也包含噪声。
  • 频域滤波的边界和截断会导致振铃；先处理 padding 和窗函数问题。

常用形态学

操作 组合 常见作用
开运算 先腐蚀后膨胀 去除小亮点、断开细连接
闭运算 先膨胀后腐蚀 填小孔、连接小间隙
形态学梯度 膨胀减腐蚀 提取目标边界
顶帽 原图减开运算 提取小亮结构
黑帽 闭运算减原图 提取小暗结构

结构元素的形状、尺度与目标几何先验同样重要。

3. 激活、归一化与优化

ReLU：

\[ \operatorname{ReLU}(x)=\max(0,x) \]

Batch Normalization：

\[ \hat{x}=\frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}},\qquad y=\gamma\hat{x}+\beta \]

训练阶段用 mini-batch 统计量并更新 running statistics；推理阶段使用累计统计量。小 batch 下统计量不稳定时，可考虑冻结 BN 或改用其他归一化。

梯度下降：

\[ \theta_{t+1}=\theta_t-\eta\nabla_\theta L \]

先检查数据和梯度，再调整优化器；“换 Adam”不能修复错标、泄漏或输入不一致。

4. 分类与分割损失

多类交叉熵：

\[ L_{CE}=-\sum_{c=1}^{C}y_c\log p_c \]

二分类交叉熵：

\[ L_{BCE}=-[y\log p+(1-y)\log(1-p)] \]

Focal Loss：

\[ FL(p_t)=-\alpha_t(1-p_t)^\gamma\log(p_t) \]

它降低易样本贡献，使优化更关注难样本；不能替代对采样、标注和类别定义的检查。

Dice 与 Dice Loss：

\[ Dice=\frac{2\sum_i p_ig_i+\epsilon}{\sum_i p_i+\sum_i g_i+\epsilon},\qquad L_{Dice}=1-Dice \]

Dice 对小前景和类别不均衡友好，但概率校准和像素级误差可结合 CE/BCE 一起优化。

5. 检测框、IoU 与 NMS

交并比：

\[ IoU=\frac{|A\cap B|}{|A\cup B|} \]

坐标约定必须统一：\((x_1,y_1,x_2,y_2)\) 与 \((c_x,c_y,w,h)\) 不可混用；还要确认归一化尺度、闭区间/半开区间及 resize 映射。

NMS 速记：

  1. 按分数降序选择最高分框。
  2. 抑制与它 IoU 超过阈值的同类候选框。
  3. 对剩余候选重复，直到为空。

置信度阈值升高通常使 Precision 上升、Recall 下降；NMS 阈值太低可能误删拥挤目标，太高则保留重复框。

6. 评价指标

\[ Precision=\frac{TP}{TP+FP},\qquad Recall=\frac{TP}{TP+FN} \]
\[ F1=\frac{2PR}{P+R}=\frac{2TP}{2TP+FP+FN} \]

理想化连续表达可写为：

\[ AP=\int_0^1P(R)\,dR,\qquad mAP=\frac{1}{C}\sum_{c=1}^{C}AP_c \]

实际评测会把预测按置信度排序，与同类且尚未匹配的 GT 一对一匹配；同一 GT 的重复框算 FP。VOC、COCO 及框架实现还可能采用不同插值、采样点、最大检测数和 ignore 规则，因此比较结果前必须统一评测协议。

  • mAP@0.5：固定 IoU=0.5 计算各类 AP 后平均。
  • mAP@0.5:0.95：在 0.50～0.95、步长 0.05 的多个 IoU 阈值上再平均，更强调定位质量。
  • 指标必须连同类别、尺寸、场景、阈值和统计口径报告，单一总平均值会掩盖长尾问题。

7. Self-Attention

\[ \operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V \]

Self-Attention 直接聚合远距离 token 的信息；标准全局注意力对 token 数量呈二次复杂度。CNN 的局部性与平移等变归纳偏置在小数据和边缘部署中仍很有价值，两者常被混合使用。

8. 量化

一种常见仿射量化形式：

\[ q=\operatorname{clip}\left(\operatorname{round}\left(\frac{x}{s}\right)+z,q_{min},q_{max}\right), \qquad \hat{x}=s(q-z) \]
  • PTQ：训练后校准量化，流程简单；校准集必须覆盖部署分布。
  • QAT：训练时模拟量化误差，通常更能恢复精度，但训练成本更高。
  • INT8 是否加速取决于算子、硬件、运行时和数据搬运，不能只看模型文件大小。

9. 端到端工程检查

相机/光学/照明
  → 曝光、增益与触发
  → 标定、畸变校正与 ROI
  → 颜色、resize、归一化
  → 模型推理
  → 解码、阈值、NMS/连通域
  → 几何、拓扑、时序与业务规则
  → 报警、追溯与监控

效果差的排查顺序

  1. 数据：覆盖度、重复、脏数据、场景偏移、长尾。
  2. 标注：漏标、错标、边界规范、类别定义、一致性。
  3. 划分：同源泄漏、时间/设备/对象隔离、测试集污染。
  4. 输入：颜色顺序、方向、缩放、letterbox、归一化。
  5. 训练：是否过拟合/欠拟合、学习率、梯度、batch、增强。
  6. 损失与匹配：各分量量级、正负样本分配、类别权重。
  7. 后处理：坐标还原、阈值、NMS、mask resize、规则。
  8. 部署：算子差异、精度模式、量化误差、动态 shape、并发。

性能报告最小集合

  • 任务指标：逐类 Precision/Recall、AP，或 Dice/IoU；同时给业务阈值。
  • 端到端延迟：P50/P95/P99，拆分预处理、推理、后处理和 I/O。
  • 吞吐量：明确 batch、并发数和输入尺寸。
  • 资源：峰值显存/内存、功耗、模型体积、冷启动时间。
  • 稳健性：不同设备、时段、环境、目标尺寸和遮挡条件的切片指标。

10. 一分钟面试回答模板

回答技术问题时按四层组织：

  1. 定义：一句话说明它解决什么问题。
  2. 原理：给出信息流、关键公式或核心机制。
  3. 取舍：说明适用条件、代价和失败模式。
  4. 工程例子：说明参数如何选、如何验证、如何与系统其他模块协同。

例如“为什么不能只看 mAP”：mAP 是离线平均检测指标；业务还受类别代价、工作阈值、尾延迟、内存、环境漂移和误报警策略约束；因此应在目标硬件和真实数据切片上，以业务漏检/误检成本为核心做多目标验收。

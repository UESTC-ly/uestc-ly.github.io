交付平台学习笔记

本组笔记面向已有 C++ 或后端开发基础的学习者，目标是把“能写服务”推进到“能可靠测试、打包、部署、暴露和持续交付服务”。推荐按下面顺序学习，因为后续主题会复用前面的概念。

推荐学习顺序

  1. 测试体系：单元测试、集成测试、接口测试
  2. Docker：镜像、容器与交付一致性
  3. Kubernetes 基础：声明式部署与服务编排
  4. Nginx：反向代理、负载均衡与入口层
  5. CI/CD：从提交到可回滚发布

学习路径

先用测试明确“什么是正确”，再用 Docker 固化运行环境；随后用 Kubernetes 管理多实例服务、配置和发布；用 Nginx 处理入口流量、TLS、代理和静态资源；最后用 CI/CD 把测试、构建、镜像、安全检查和部署串成可重复流水线。

本组检查清单

  • 能为 C++、Python 和 HTTP API 分别设计单元测试、集成测试和接口测试。
  • 能写出可缓存、可复现、非 root 运行的 Dockerfile。
  • 能理解 Pod、Deployment、Service、ConfigMap、Secret、Ingress 的边界。
  • 能配置 Nginx 反向代理、健康检查、超时、限流和静态文件服务。
  • 能设计一条包含测试、构建、镜像推送、部署、回滚的 CI/CD 流水线。

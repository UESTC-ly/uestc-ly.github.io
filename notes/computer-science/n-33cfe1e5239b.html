11. 面试前优先复习清单

时间有限时，优先系统掌握以下 20 个主题。对应完整说明均已整理在前文，本节可作为复习索引：

  1. B+ 树、联合索引、覆盖索引与索引失效。
  2. 慢 SQL 的定位与优化流程。
  3. ACID、隔离级别、MVCC 与数据库锁。
  4. 进程、线程和协程的区别。
  5. 虚拟内存、缺页中断与页面置换。
  6. 死锁产生条件及解决方法。
  7. select、poll 和 epoll 的区别。
  8. 输入 URL 后发生的完整过程。
  9. TCP 三次握手、四次挥手与 TIME_WAIT。
  10. TCP 可靠传输、流量控制与拥塞控制。
  11. HTTPS/TLS 握手过程。
  12. 线程池参数、任务队列和拒绝策略。
  13. Redis 的性能来源及缓存穿透、击穿和雪崩。
  14. 缓存与数据库一致性。
  15. MQ 消息不丢失、重复消费和顺序消费。
  16. CAP、分布式事务与最终一致性。
  17. 限流、熔断、降级、重试和幂等。
  18. 高并发系统的通用设计方法。
  19. 秒杀系统与库存防超卖。
  20. 线上服务变慢或故障的排查流程。

12. 知识理解自检

掌握一个问题不等于记住结论。复习每个主题时，可以从以下维度检查理解是否完整：

  • [ ] 能准确说明概念定义，并指出定义成立的前提。
  • [ ] 能解释内部机制、状态变化或完整执行过程。
  • [ ] 能说明该机制解决了什么问题，以及为什么能够解决。
  • [ ] 能比较相近方案，指出它们在语义、成本和适用条件上的差异。
  • [ ] 能给出具体场景或数据流示例，而不是只罗列术语。
  • [ ] 能说明失败模式、性能代价、一致性边界和安全风险。
  • [ ] 能指出常见误区，以及哪些结论依赖具体产品或版本。
  • [ ] 能使用日志、指标、执行计划、抓包或实验验证关键结论。
  • [ ] 能把原理映射到真实项目的架构决策、故障和优化结果。

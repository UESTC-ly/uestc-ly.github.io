一句话总纲

链表用指针把节点串起来，不要求连续内存；它牺牲随机访问能力，换来局部插入删除的灵活性。

记忆口诀：数组靠下标，链表靠指针；查找要走路，插删改指针。

1. 链表结构

单链表节点：

value + next pointer

flowchart LR
  A["head"] --> B["val 1"]
  B --> C["val 2"]
  C --> D["val 3"]
  D --> E["nullptr"]

2. 链表和数组对比

维度 数组 链表
内存 连续 不连续
随机访问 O(1) O(n)
已知位置插入 O(n) 移动元素 O(1) 改指针
查找值 O(n) O(n)
缓存友好 好 较差
额外空间 少 指针开销

注意：链表插入快的前提是已经拿到要插入位置的前驱节点。如果还要先查找，整体仍可能是 O(n)。

3. 虚拟头节点

虚拟头节点 dummy 可以统一删除头节点和中间节点的逻辑。

flowchart LR
  A["dummy"] --> B["head"]
  B --> C["node"]
  C --> D["nullptr"]

删除值为 target 的节点：

#include <bits/stdc++.h>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v) : val(v), next(nullptr) {}
};

ListNode* removeValue(ListNode* head, int target) {
    ListNode dummy(0);
    dummy.next = head;
    ListNode* cur = &dummy;

    while (cur->next) {
        if (cur->next->val == target) {
            ListNode* del = cur->next;
            cur->next = del->next;
            delete del;
        } else {
            cur = cur->next;
        }
    }
    return dummy.next;
}

4. 反转链表

反转链表的核心是三指针：prev、cur、next。

flowchart LR
  A["prev"] --> B["nullptr"]
  C["cur"] --> D["next"]
  D --> E["后续链表"]

C++ demo：

#include <bits/stdc++.h>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v) : val(v), next(nullptr) {}
};

ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* cur = head;
    while (cur) {
        ListNode* nxt = cur->next;
        cur->next = prev;
        prev = cur;
        cur = nxt;
    }
    return prev;
}

步骤记忆：

先存 next，再反指针，再移动 prev 和 cur。

5. 快慢指针

快慢指针常用于：

  • 找链表中点。
  • 判断是否有环。
  • 找环入口。
  • 删除倒数第 k 个节点。
flowchart LR
  A["slow每次一步"] --> B["中点或相遇"]
  C["fast每次两步"] --> B

判断环：

bool hasCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}

6. 合并两个有序链表

flowchart TD
  A["list1和list2"] --> B["比较当前较小节点"]
  B --> C["接到结果链表"]
  C --> D["移动对应指针"]
  D --> E{是否都未空}
  E -- 是 --> B
  E -- 否 --> F["接上剩余链表"]

C++ demo：

ListNode* mergeTwoLists(ListNode* a, ListNode* b) {
    ListNode dummy(0);
    ListNode* tail = &dummy;
    while (a && b) {
        if (a->val <= b->val) {
            tail->next = a;
            a = a->next;
        } else {
            tail->next = b;
            b = b->next;
        }
        tail = tail->next;
    }
    tail->next = a ? a : b;
    return dummy.next;
}

7. 双链表

双链表每个节点有 prev 和 next，已知节点时删除更方便。

flowchart LR
  A["prev"] <--> B["cur"]
  B <--> C["next"]

C++ 标准库 list 是双向链表，但刷题中更常手写节点。

8. 常见坑

坑 说明
忘记保存 next 反转时会丢失后续链表
空指针访问 fast->next 前先判断 fast
删除头节点特殊处理 用 dummy 简化
内存泄漏 手写 new 后要考虑 delete
断链 改指针顺序错误导致节点丢失

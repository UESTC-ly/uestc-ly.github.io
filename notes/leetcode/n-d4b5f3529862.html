一、什么是单调栈？

单调栈是一个栈内元素保持单调递增或单调递减的栈。它通常用于：

  • 寻找左侧或右侧第一个更大/更小的元素；
  • 确定连续区间的左右边界；
  • 当当前元素出现时，一次性确定前面若干元素的答案。

通常栈中保存下标而不是数值，因为：

  • 需要通过下标访问原数组中的值；
  • 需要通过下标差计算距离或宽度。

单调栈的线性复杂度来自一个事实：每个下标最多入栈一次、出栈一次。

二、739. 每日温度

1. 题意

temperatures[i] 表示第 i 天的温度。对于每一天，返回之后第一次出现更高温度所需要等待的天数；如果之后没有更高温度，答案为 0。

示例：

temperatures = [73,74,75,71,69,72,76,73]
answer       = [1, 1, 4, 2, 1, 1, 0, 0]

例如：

  • 第 0 天温度 73，第 1 天温度 74，等待 1 天；
  • 第 2 天温度 75，第 6 天温度 76，等待 4 天；
  • 第 6 天温度 76 后面没有更高温度，答案为 0。

2. 核心思路：单调递减栈

栈中保存：

还没有找到右侧更高温度的日期下标。

从栈底到栈顶，对应温度保持单调不增（允许相等）。相等温度不能解决等待升温的日期，所以可以同时留在栈中。例如：

[75, 71, 69]

当当前温度为 72 时：

  • 72 > 69：第 69 度那天找到了更高温度，弹出并计算答案；
  • 72 > 71：第 71 度那天也找到了更高温度，继续弹出；
  • 72 < 75：第 75 度那天还不能确定，停止弹栈。

因此弹栈条件必须使用 while。

3. 变量含义

变量 含义
temperatures 每天的温度数组
n 天数
answer[i] 第 i 天等待更高温度的天数
st 单调递减栈，保存尚未找到答案的日期下标
i 当前正在处理的日期下标
previousDay 被当前更高温度解决的日期下标

4. C++ 代码

#include <stack>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        // n 表示总天数。
        int n = temperatures.size();

        /*
            answer[i] 表示第 i 天需要等待多少天才能遇到更高温度。

            先全部初始化为 0：
            如果某一天遍历结束后仍没有找到更高温度，
            它的答案就保持为 0。
        */
        vector<int> answer(n, 0);

        /*
            st 是单调递减栈，保存日期下标而不是温度值。

            保存下标的原因：
            1. 可以通过 temperatures[st.top()] 比较温度；
            2. 可以通过 i - st.top() 计算等待天数。
        */
        stack<int> st;

        // 从左到右处理每一天。
        for (int i = 0; i < n; i++) {
            /*
                当前温度比栈顶日期的温度高时，
                说明当前第 i 天就是栈顶日期右侧第一个更高温度。

                使用 while 是因为一个当前温度可能连续解决多个更冷的日期。
            */
            while (!st.empty() &&
                   temperatures[i] > temperatures[st.top()]) {
                // previousDay 是尚未找到答案、现在被解决的日期。
                int previousDay = st.top();

                // 从 previousDay 到当前 i，需要等待 i - previousDay 天。
                answer[previousDay] = i - previousDay;

                // previousDay 已经得到答案，从栈中移除。
                st.pop();
            }

            /*
                当前第 i 天暂时还没有找到右侧更高温度，
                所以先把它压入栈，等待未来的更高温度处理它。
            */
            st.push(i);
        }

        // 栈中剩余的日期后面都没有更高温度，答案已经默认为 0。
        return answer;
    }
};

5. 示例推演重点

temperatures = [73,74,75,71,69,72,76,73]

关键步骤：

  • 74 到来：弹出 73，answer[0] = 1；
  • 75 到来：弹出 74，answer[1] = 1；
  • 71、69 依次入栈；
  • 72 到来：连续弹出 69 和 71，分别得到 1 和 2 天；
  • 76 到来：连续弹出 72 和 75，分别得到 1 和 4 天；
  • 最后 76 和 73 没有遇到更高温度，保持 0。

6. 常见注意点

  • 栈中存下标，不存温度值；
  • 使用 while，因为一个当前温度可能解决多个之前的日期；
  • 比较使用 >，不是 >=，因为题目要求“更高”，相同温度不算；
  • 未解决的答案初始化为 0。
  • 等待天数是日期差 i - previousDay，不是闭区间元素个数，不加 1：下标 2 到下标 3 是 1 天后。

7. 复杂度

  • 时间复杂度：O(n)；
  • 空间复杂度：O(n)。

三、84. 柱状图中最大的矩形

1. 题意

给定 n 个非负整数 heights，每个元素表示一个宽度为 1 的柱子高度，求柱状图中能够勾勒出的最大矩形面积。

示例：

heights = [2,1,5,6,2,3]

下标 2 和 3 的柱子高度为 5、6，取较小高度 5，连续宽度为 2，面积：

5 × 2 = 10

所以输出为：

10

2. 把每个柱子当作矩形的最低高度

对于下标 middleIndex 的柱子，如果把它作为矩形的最低高度，需要找到：

  • 左侧第一个高度小于它的柱子 leftBoundary；
  • 右侧第一个高度小于它的柱子 rightBoundary。

那么这个柱子可以覆盖的范围是：

leftBoundary + 1 到 rightBoundary - 1

矩形宽度：

width = rightBoundary - leftBoundary - 1;

矩形面积：

area = heights[middleIndex] * width;

3. 核心思路：单调递增栈

栈中保存柱子下标，并保持对应高度从栈底到栈顶单调递增（当前实现允许相等高度相邻存在）。

当当前柱子高度小于栈顶柱子高度时：

当前柱子就是栈顶柱子右侧第一个更小的柱子，栈顶柱子的右边界已经确定。

弹出栈顶后，新的栈顶就是它左侧第一个更小的柱子，因此可以立即计算面积。

4. 为什么需要 while？

例如：

[5, 6, 2]

处理高度 2 时：

  1. 2 < 6，高度 6 的右边界确定，弹出 6；
  2. 弹出后看到 5，2 < 5，高度 5 的右边界也确定，继续弹出 5。

所以必须连续弹栈：

while (...)

而不能只使用 if。

5. 变量含义

变量 含义
heights 柱子高度数组
n 柱子数量
maxArea 当前找到的最大面积
st 单调递增栈，保存柱子下标
i 当前处理的下标
currentHeight 当前高度，最后使用虚拟高度 0
middleIndex 被弹出的柱子下标，作为当前矩形最低高度
rectangleHeight 当前矩形高度
leftBoundary 左侧第一个更小柱子的下标
rightBoundary 右侧第一个更小柱子的下标
rectangleWidth 当前矩形宽度
currentArea 当前矩形面积

6. C++ 代码

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        // n 表示柱子的数量。
        int n = heights.size();

        // maxArea 保存遍历过程中出现过的最大矩形面积。
        int maxArea = 0;

        /*
            st 是单调递增栈，保存柱子的下标。

            栈中下标对应的高度从栈底到栈顶保持递增。
            保存下标是因为计算宽度时需要使用下标差。
        */
        vector<int> st;

        /*
            i 从 0 遍历到 n。

            i < n：处理真实柱子；
            i == n：处理一个虚拟高度 0。

            虚拟高度 0 不属于输入，只用于让最后仍在栈中的柱子全部出栈。
        */
        for (int i = 0; i <= n; i++) {
            // 到达末尾时，把虚拟柱子的高度设为 0。
            int currentHeight = (i == n ? 0 : heights[i]);

            /*
                当前高度低于栈顶高度时，
                当前下标 i 就是栈顶柱子右侧第一个更小柱子的下标。

                栈顶柱子的左右边界因此确定，可以计算面积。
            */
            while (!st.empty() &&
                   currentHeight < heights[st.back()]) {
                // middleIndex 是刚刚弹出的柱子下标。
                int middleIndex = st.back();
                st.pop_back();

                // 被弹出柱子的高度就是当前矩形的高度。
                int rectangleHeight = heights[middleIndex];

                // 当前下标 i 是右侧第一个更小柱子的下标。
                int rightBoundary = i;

                /*
                    弹栈后新的栈顶是左侧第一个更小柱子的下标。
                    如果栈为空，说明左边没有更小柱子，边界记为 -1。
                */
                int leftBoundary = st.empty() ? -1 : st.back();

                /*
                    有效范围是：
                    leftBoundary + 1 ... rightBoundary - 1

                    因此矩形宽度为：
                    rightBoundary - leftBoundary - 1
                */
                int rectangleWidth =
                    rightBoundary - leftBoundary - 1;

                // 当前矩形面积 = 高度 × 宽度。
                int currentArea = rectangleHeight * rectangleWidth;

                // 用当前面积更新最大面积。
                maxArea = max(maxArea, currentArea);
            }

            /*
                当前柱子暂时没有确定右边界，压入栈中等待后续更矮柱子。

                i == n 时压入的是虚拟下标，但循环马上结束，
                不会再访问 heights[n]。
            */
            st.push_back(i);
        }

        return maxArea;
    }
};

7. 示例推演重点

输入：

heights = [2,1,5,6,2,3]

在末尾补一个虚拟 0：

[2,1,5,6,2,3,0]

处理到下标 4、高度 2 时：

  1. 弹出下标 3、高度 6：左边界 2，右边界 4，宽度 1，面积 6；
  2. 继续弹出下标 2、高度 5：左边界 1，右边界 4，宽度 2，面积 10。

处理末尾虚拟 0 时，会清空剩余栈中的柱子；最终最大面积仍为 10。

8. 常见注意点

  • 栈中保存下标，不保存高度；
  • 遇到更矮柱子时要使用 while 连续弹栈；
  • 宽度公式是 rightBoundary - leftBoundary - 1；
  • 弹出一个柱子后，新的栈顶才是它左侧第一个更小柱子；
  • 末尾补虚拟高度 0，用于处理单调递增部分；
  • 当前代码使用 currentHeight < heights[st.back()]，相等高度会暂时同时保留，仍可正确计算面积。

9. 复杂度

  • 时间复杂度：O(n)，每个下标最多入栈、出栈一次；
  • 空间复杂度：O(n)。

五、方法归纳

当前元素让前面元素的边界或答案确定时，就弹出前面元素；栈中保存尚未确定结果的下标，并用单调性保证每个元素只处理有限次。

六、补充：84 题面积更新逻辑深入理解

本节针对最常见的疑问：每次面积更新到底在算什么、为什么这样算。

1. 先区分两个面积变量

int area;     // 候选面积：当前弹出柱子能形成的矩形面积
int maxArea;  // 历史最大面积：所有候选中的最大值

更新方式：

maxArea = max(maxArea, area);

这一步不是“扩大之前的矩形”，而是把两个独立的矩形面积作比较，保留较大的那个。

2. 为什么在“弹栈时”才计算面积？

一个柱子被弹出，意味着它的左右边界同时确定：

  • 当前下标 i：右边第一个更矮的柱子（右边界）；
  • 弹栈后新的栈顶：左边第一个更矮的柱子（左边界）。

有了左右边界，才能确定矩形宽度，所以面积只能在弹栈时结算。

3. 面积计算四步

1. 弹出一根柱子，它的高度作为矩形高度 height
2. 当前下标 i 作为右边界 right
3. 弹栈后的新栈顶作为左边界 left（栈空则取 -1）
4. width = right - left - 1
   area  = height * width

关键：宽度要 - 1，因为左右边界本身高度更矮，不能包含在矩形内。

4. 一次 while 可能连续结算多个矩形

以 heights = [2,1,5,6,2,3] 处理到下标 4（高度 2）为例：

下标：  1  2  3  4
高度：  1  5  6  2
  • 弹出高度 6：left=2, right=4, width=1, area=6
  • 当前高度 2 仍小于新栈顶高度 5，继续弹出高度 5：left=1, right=4, width=2, area=10

所以一次 while 里连续算出了 6 和 10 两个候选面积。

5. 完整的面积更新表（heights = [2,1,5,6,2,3]）

弹出柱子高度 左边界 右边界 宽度 面积 maxArea 变化
2 -1 1 1 2 0 → 2
6 2 4 1 6 2 → 6
5 1 4 2 10 6 → 10
3 4 6 1 3 10 → 10
2 1 6 4 8 10 → 10
1 -1 6 6 6 10 → 10

最终 maxArea = 10，即高度 5、6 组成的红色矩形。

一句话记忆：弹出的柱子决定高度，左右更矮柱子决定宽度，算出候选面积再与历史最大比较。

七、不补虚拟柱子的写法（两段式）

补高度为 0 的哨兵柱子只是技巧，不是必须。如果觉得 for (int i = 0; i < n; i++) 更直观，可以在循环结束后单独清空栈。

1. 为什么循环结束后栈里还有柱子？

弹栈条件是“遇到更矮的柱子”。如果数组末尾是一段较高或递增的柱子，它们右边没有更矮的柱子来触发弹栈，就会留在栈里。

例如 [2,1,5,6,2,3] 遍历结束后，栈中还剩下标 [1,4,5]（高度 1,2,3）。

2. 剩余柱子的右边界是 n

这些柱子右边不存在更矮的柱子，可以一直延伸到数组最右端，所以右边界固定为 n。这与“补一个高度 0 的哨兵”完全等价。

3. 完整代码

class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size();
        stack<int> st;
        int maxArea = 0;

        // 第一部分：遍历每一根柱子
        for (int i = 0; i < n; i++) {
            int currentHeight = heights[i];

            // 当前柱子更矮，栈顶柱子右边界确定，结算面积
            while (!st.empty() && currentHeight < heights[st.top()]) {
                int heightIdx = st.top();
                st.pop();

                int height = heights[heightIdx];
                int left = st.empty() ? -1 : st.top();
                int right = i;
                int width = right - left - 1;
                int area = width * height;

                maxArea = max(maxArea, area);
            }

            st.push(i);
        }   // for 循环到这里结束

        // 第二部分：处理栈中剩余柱子，右边界固定为 n
        while (!st.empty()) {
            int heightIdx = st.top();
            st.pop();

            int height = heights[heightIdx];
            int left = st.empty() ? -1 : st.top();
            int right = n;
            int width = right - left - 1;
            int area = width * height;

            maxArea = max(maxArea, area);
        }

        return maxArea;
    }
};

4. 两种写法对比

补虚拟柱子 不补虚拟柱子
循环写法 i <= n i < n
直观程度 i == n 是虚拟高度，稍绕 i 就是遍历柱子，直观
结算剩余柱子 虚拟高度 0 自动触发 循环结束后手动清空栈
右边界 i（i==n 时正好是 n） 循环内是 i，收尾时是 n

本质相同：补 0 是“自动清空栈”，手动收尾是“显式清空栈”，结果一致。

八、常见错误：收尾 while 写进了 for 内部

两段式写法里，清空栈的 while 必须放在 for 循环外面。

错误结构：

for (int i = 0; i < n; i++) {
    while (...) { ... }   // 正常弹栈
    st.push(i);

    while (!st.empty()) { ... }   // 错误：清空栈写进了 for 里
}

后果：每处理一根柱子就把整个栈清空一次，栈永远只剩当前柱子，单调栈失去作用，左边界几乎总是 -1，结果算错（偏小）。

正确结构：

for (遍历每个元素) {
    while (当前元素触发弹栈) { 结算面积 }
    入栈
}

while (栈非空) { 结算剩余元素 }   // 一定在 for 外面

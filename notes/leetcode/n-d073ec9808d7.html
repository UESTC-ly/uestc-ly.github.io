本目录整理本次新增会话中讨论的 8 道回溯题：LeetCode 46、78、17、39、22、79、131、51。

核心目标：不只记住单题代码，而是掌握“每层在做什么、有哪些选择、何时收集答案、如何恢复现场”。

一、回溯的统一模型

回溯本质上是在一棵决策树上进行深度优先搜索：

做选择 → 进入下一层 → 撤销选择

通用模板：

void backtrack(状态) {
    if (满足结束条件) {
        收集答案;
        return;
    }

    for (当前层的所有选择) {
        if (当前选择不合法) {
            continue;
        }

        做选择;
        backtrack(下一层状态);
        撤销选择;
    }
}

设计回溯时依次回答五个问题：

  1. 一层递归表示什么？
  2. 当前层有哪些选择？
  3. 怎样判断选择是否合法？
  4. 什么时候说明得到完整答案？
  5. 递归返回后要恢复哪些状态？

二、八道题的统一对比

题目 一层递归表示什么 控制重复或合法性的状态 收集答案时机
46. 全排列 填写排列的一个位置 used[i] path.size() == n
78. 子集 从后续元素中选择一个 startIndex 每个递归节点
17. 电话号码的字母组合 为当前数字选择一个字母 index index == digits.size()
39. 组合总和 选择一个候选数字 startIndex、remain remain == 0
22. 括号生成 添加一个左括号或右括号 open、close 左右括号都用了 n 个
79. 单词搜索 在网格中匹配当前字符 越界、字符、访问标记 匹配到最后一个字符
131. 分割回文串 确定当前子串的结束位置 startIndex、回文判断 startIndex == s.size()
51. N 皇后 在当前行选择一列 列与两类对角线占用状态 row == n

最容易混淆的递归参数

// 当前元素不能重复使用
backtrack(i + 1);

// 当前元素允许重复使用
backtrack(i);

典型对应：

78. 子集：下一层传 i + 1
39. 组合总和：下一层传 i

三、回溯与动态规划的边界

动态规划适合“状态确定后，后续结果与具体历史路径无关”的问题。

第 79 题“单词搜索”中，后续可以走哪些格子取决于当前路径已经使用过哪些格子。仅使用：

位置 (row, col) + 单词下标 index

不能完整描述状态。若把访问集合也加入 DP，状态数量可能达到 2^(m×n) 级别，因此通常使用 DFS + 回溯，只维护当前路径的访问状态。

详见：网格搜索与字符串分割（79、131）

五、复习口诀

排列用 used；
组合、子集用 startIndex；
可重复选就传 i，不可重复选就传 i + 1；
固定位置选候选用 index；
网格搜索要标记并恢复；
分割问题枚举当前段的结束位置；
棋盘问题逐行选择，额外记录冲突集合。

136. 只出现一次的数字

给定非空整数数组 nums，除了一个元素只出现一次，其余每个元素都出现两次。返回只出现一次的那个元素，要求 O(n) 时间、O(1) 额外空间。

核心思路：异或。

异或性质：

a ^ a = 0
a ^ 0 = a

并且异或满足交换律和结合律，所以所有数字异或起来，成对出现的数字都会抵消成 0，最后剩下的就是只出现一次的数字。

例如：

nums = [4, 1, 2, 1, 2]

可以看成：

4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4 ^ 0 ^ 0
= 4

代码：

class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;

        for (int num : nums) {
            ans ^= num;
        }

        return ans;
    }
};

复杂度：

时间复杂度：O(n)
空间复杂度：O(1)

易错点：负数也可以异或；相同负数的二进制表示相同，所以也会抵消。

记忆：

成双成对都抵消，落单那个留下来。

本文件是 二分查找 目录的统一入口，用来解决笔记分散、题型之间缺少联系、二分边界结论不统一的问题。

建议复习顺序：基础二分 → 边界辨析 → 旋转数组 → 双数组分割。

一、专题导航

1. 基础二分与常见变形

  • 二分查找专题（35、34、74）
  • 35：搜索插入位置
  • 34：查找目标值的第一个和最后一个位置
  • 74：搜索二维矩阵

2. 区间与边界

  • 二分区间与循环条件辨析
  • [left, right] 与 [left, right)
  • left <= right 与 left < right
  • mid 是否需要保留
  • mid - 1、mid + 1、right = mid 的使用条件

3. 旋转排序数组

  • 旋转排序数组专题（33、153）
  • 33：在旋转数组中搜索目标值
  • 153：寻找旋转数组中的最小值
  • 核心：利用“两段递增、一个断点”的结构继续二分

4. 两个有序数组的分割

  • 两个有序数组的中位数（4）
  • 不真正合并数组
  • 在较短数组中二分“分割位置”
  • 核心：左边数量正确，并且左边最大值不大于右边最小值

二、按题型选择方法

题目特征 二分对象 关键判断 对应笔记
有序数组中查找一个目标值 目标下标 nums[mid] 与 target 比较 35
查找第一个或最后一个满足条件的位置 边界下标 条件成立后继续向一侧收缩 34、边界辨析
二维矩阵整体递增 一维虚拟下标 matrix[mid / n][mid % n] 74
旋转数组中查找目标值 目标下标 先判断哪一半有序 33
旋转数组中寻找最小值 旋转点下标 nums[mid] 与 nums[right] 比较 153
两个有序数组求中位数 较短数组的分割位置 两条交叉边界是否满足大小关系 4

三、统一更新后的二分结论

1. 循环条件不能脱离“搜索区间”单独记忆

左闭右闭 [left, right]

int left = 0;
int right = n - 1;

while (left <= right) {
    int mid = left + (right - left) / 2;
    // 根据题意更新为 mid - 1 或 mid + 1
}

当 left == right 时，区间中还有一个元素没有检查，所以通常使用 left <= right。

最终让 left == right 指向答案

int left = 0;
int right = n - 1;

while (left < right) {
    int mid = left + (right - left) / 2;
    // 根据题意决定保留 mid，还是排除 mid
}

return left;

当答案可能就是 mid 时，不能随意写成 right = mid - 1。例如 153 题中，当 nums[mid] < nums[right] 时，mid 仍可能是最小值，因此要写 right = mid。

2. mid 的去留由题意决定

  • 已经确定 mid 不可能是答案：使用 mid - 1 或 mid + 1 排除它。
  • mid 仍可能是答案：使用 right = mid 或其他保留 mid 的写法。
  • 不要只背更新公式，要先回答：当前的 mid 还能不能是答案？

3. 不同题目的“有序性”用法不同

  • 普通二分：整个搜索区间有序。
  • 33：整体旋转，但每轮至少有一半完整有序。
  • 153：通过 nums[mid] 与 nums[right] 判断最小值在哪一侧。
  • 4：两个数组各自有序，通过分割线附近的四个值判断分割是否合法。

四、各题核心模板

1. 精确查找

while (left <= right) {
    int mid = left + (right - left) / 2;

    if (nums[mid] == target) {
        return mid;
    } else if (nums[mid] < target) {
        left = mid + 1;
    } else {
        right = mid - 1;
    }
}

2. 旋转数组搜索

先判断 mid 是否命中
        ↓
判断哪一半有序
        ↓
判断 target 是否落在有序半边的值域中
        ↓
保留可能含有 target 的一半

3. 旋转数组最小值

nums[mid] > nums[right]：最小值一定在 mid 右侧
nums[mid] < nums[right]：最小值在 mid 或 mid 左侧

4. 两个有序数组中位数

在较短数组中二分 partition1
partition2 = leftCount - partition1

合法条件：
nums1Left <= nums2Right
nums2Left <= nums1Right

五、统一检查清单

写二分代码前，按顺序回答：

  1. 二分的对象是什么？ 是目标下标、边界、旋转点，还是分割位置？
  2. 搜索区间表示什么？ 是 [left, right]、[left, right)，还是分割位置 [0, m]？
  3. 循环结束条件是什么？ 是区间为空，还是 left == right 得到唯一答案？
  4. 当前 mid 可能是答案吗？ 决定保留还是排除 mid。
  5. 每次更新后区间是否严格缩小？ 如果没有，可能死循环。
  6. 空数组、单元素、答案在端点时是否安全？
  7. 平均值是否使用浮点数计算？

六、推荐复习路线

35：建立基础二分区间意识
  ↓
34：学习寻找左右边界
  ↓
74：学习把新结构映射成有序序列
  ↓
33：学习在局部有序结构中二分
  ↓
153：学习保留 mid 并收敛到唯一答案
  ↓
4：学习对“分割位置”而不是具体元素做二分

方法归纳：二分查找并不只是“在数组中找某个数”。只要答案空间具有单调性，并且能够根据一次判断排除一半候选答案，就可以考虑二分。

本笔记整理 LeetCode 98、108：一题利用 BST 的中序性质验证树，另一题利用有序数组的中点递归构造平衡 BST。

总览：二叉树专题｜遍历基础：二叉树遍历基础（94、102）

一、二叉搜索树的核心性质

对于二叉搜索树中的每个节点：

左子树的所有节点值 < 当前节点值
右子树的所有节点值 > 当前节点值

本题组要求严格小于、严格大于，因此重复值不合法。

一个非常重要的等价性质是：

对二叉搜索树进行中序遍历，得到的节点值严格递增。

中序遍历顺序：

左子树 → 当前节点 → 右子树

这两个性质分别对应本笔记的两道题：

  • 98：用中序遍历是否严格递增来验证 BST；
  • 108：利用数组已经升序的条件，从中间切分并构造 BST。

二、98. 验证二叉搜索树

1. 题意

给定二叉树根节点 root，判断它是否为有效的二叉搜索树。

示例 1：

    2
   / \
  1   3

中序结果为 [1,2,3]，严格递增，所以返回 true。

示例 2：

       5
      / \
     1   4
        / \
       3   6

中序结果为：

[1,5,3,4,6]

访问到 3 时发现 3 <= 5，不是严格递增，所以返回 false。

2. 为什么不能只比较直接孩子

下面的局部判断不够：

左孩子 < 当前节点 < 右孩子

BST 要求的是整棵左子树和右子树都满足范围约束。

例如：

       5
      / \
     1   6
        / \
       3   7

节点 3 小于自己的父节点 6，但它位于根节点 5 的右子树中，还必须满足 3 > 5。实际不满足，所以整棵树不是 BST。

3. 核心思路：中序遍历记录前一个节点

使用：

TreeNode* previous;

记录中序遍历中上一个访问的节点。

访问当前节点时检查：

if (previous != nullptr && root->val <= previous->val) {
    return false;
}

必须使用 <=，因为 BST 不允许相等的节点值。

使用指针而不是特殊整数初值，可以用：

previous == nullptr

准确表示“还没有访问任何节点”，避免节点值恰好等于 INT_MIN 时产生边界问题。

4. 执行顺序

1. 验证左子树；
2. 比较当前节点和 previous；
3. previous 更新为当前节点；
4. 验证右子树。

previous = root 必须位于左右递归之间，才能对应中序遍历。

5. C++ 代码

class Solution {
private:
    // 中序遍历中上一个访问的节点
    TreeNode* previous = nullptr;

    bool inorder(TreeNode* root) {
        if (root == nullptr) {
            return true;
        }

        // 左
        if (!inorder(root->left)) {
            return false;
        }

        // 根：中序序列必须严格递增
        if (previous != nullptr && root->val <= previous->val) {
            return false;
        }
        previous = root;

        // 右
        return inorder(root->right);
    }

public:
    bool isValidBST(TreeNode* root) {
        // 防止同一个 Solution 对象被重复调用时保留旧状态
        previous = nullptr;
        return inorder(root);
    }
};

6. 复杂度

设节点数为 n、树高为 h：

  • 时间复杂度：O(n)；
  • 递归栈空间：O(h)，最坏为 O(n)。

7. 记忆

验证二叉搜索树：中序遍历，检查节点值是否严格递增。

三、108. 将有序数组转换为二叉搜索树

1. 题意

给定一个按升序排列的整数数组 nums，把它转换为一棵高度平衡的二叉搜索树。

高度平衡表示每个节点的左右子树高度之差不超过 1。

示例：

nums = [-10,-3,0,5,9]

一种合法结果：

        0
       / \
     -3   9
     /   /
   -10  5

2. 核心思路：中间元素作为根节点

因为数组已经升序，所以对任意区间：

左半部分的值 < 中间元素 < 右半部分的值

可以这样构造：

左半部分 → 递归构造左子树
中间元素 → 当前根节点
右半部分 → 递归构造右子树

每次选择中点，可以让左右两边的元素数量尽量接近，从而保证高度平衡。

3. 递归函数含义

定义：

TreeNode* buildTree(vector<int>& nums, int left, int right)

表示使用闭区间 nums[left...right] 构造高度平衡 BST，并返回该子树的根节点。

终止条件：

if (left > right) {
    return nullptr;
}

当前区间为空，所以没有节点可创建。

递归关系：

int middle = left + (right - left) / 2;
TreeNode* root = new TreeNode(nums[middle]);
root->left = buildTree(nums, left, middle - 1);
root->right = buildTree(nums, middle + 1, right);

4. 示例推演

下标：  0    1   2  3  4
元素：-10   -3   0  5  9

第一次处理 [0,4]：

middle = 2
根节点 = nums[2] = 0
左区间 = [0,1]
右区间 = [3,4]

继续递归左右区间，直到出现 left > right。

5. 为什么答案不唯一

偶数长度区间有两个中间候选元素。

例如：

[-10,-3]

既可以选择 -10 为根、-3 为右孩子，也可以选择 -3 为根、-10 为左孩子。两种结果都可能满足 BST 和高度平衡要求。

选择偏左中点：

int middle = left + (right - left) / 2;

选择偏右中点：

int middle = left + (right - left + 1) / 2;

题目不要求树形与示例完全一致，只要结果是高度平衡 BST 即可。

6. C++ 代码

class Solution {
private:
    TreeNode* buildTree(vector<int>& nums, int left, int right) {
        // 空区间不能构造节点
        if (left > right) {
            return nullptr;
        }

        // 选择偏左的中间元素，避免直接使用 left + right
        int middle = left + (right - left) / 2;

        TreeNode* root = new TreeNode(nums[middle]);

        // 左右区间递归构造左右子树
        root->left = buildTree(nums, left, middle - 1);
        root->right = buildTree(nums, middle + 1, right);

        return root;
    }

public:
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        return buildTree(nums, 0, n - 1);
    }
};

空数组时 n - 1 == -1，初始区间为 [0,-1]，会直接返回 nullptr。

7. 复杂度

设数组长度为 n：

  • 时间复杂度：O(n)，每个元素创建一个节点；
  • 递归栈空间：O(log n)，因为每次从中间划分；
  • 若计入创建出的树，节点本身占用 O(n) 空间。

8. 记忆

有序数组构造平衡 BST：每次取中点当根，左右区间递归建树。

四、C++ 补充：为什么是 TreeNode* root

108 题中使用：

TreeNode* root = new TreeNode(nums[middle]);

而不能写成：

TreeNode root = new TreeNode(nums[middle]); // 错误

1. new 返回的是指针

表达式：

new TreeNode(nums[middle])

会动态创建一个 TreeNode 对象，并返回它的地址，返回类型是：

TreeNode*

因此左侧也必须是指针类型：

TreeNode* root

错误写法两边类型不同：

TreeNode root         节点对象
new TreeNode(...)     节点指针 TreeNode*

不能把一个节点地址直接赋值给节点对象。

2. 对象与指针的写法区别

直接创建局部对象：

TreeNode root(nums[middle]);
root.left = nullptr;
root.right = nullptr;

动态创建对象并保存地址：

TreeNode* root = new TreeNode(nums[middle]);
root->left = nullptr;
root->right = nullptr;

对应关系：

root->left

等价于：

(*root).left

3. 为什么递归建树不能返回局部对象的地址

下面的写法有问题：

TreeNode* buildTree(...) {
    TreeNode root(nums[middle]);
    return &root; // 错误：返回局部变量地址
}

root 是局部对象，函数结束后就会被销毁，&root 会变成悬空指针。

递归建树需要把根节点地址返回给上一层，并让节点在函数结束后继续存在，所以使用：

TreeNode* root = new TreeNode(nums[middle]);
return root;

一句话记忆：

new TreeNode(...) 返回 TreeNode*，所以必须用 TreeNode* 接收。

五、两道题的统一归纳

题目 利用的 BST 性质 方法
98. 验证 BST 中序遍历严格递增 中序 DFS + 前驱节点
108. 构造 BST 有序数组中点左小右大 分治递归构造

复习口诀：

验证 BST：中序严格递增，不能只看父子节点；
构造平衡 BST：中点当根，左右区间递归；
new 返回地址：用 TreeNode* 接收，指针成员用 -> 访问。

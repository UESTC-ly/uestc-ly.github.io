题目要求：给定两个分别升序排列的数组 nums1 和 nums2，返回它们合并后的中位数，时间复杂度要求为 O(log(m+n))。

本题的主流解法不是实际合并数组，而是：在较短数组中二分寻找正确的分割位置。

一、为什么不能直接合并

最容易想到的方法是使用双指针合并两个数组，再取中间位置：

nums1 = [1,3]
nums2 = [2]

合并后：[1,2,3]
中位数：2

这种方法能够得到正确答案，但时间复杂度是：

O(m+n)

不满足题目要求的对数复杂度。因此，需要在二分过程中直接确定中位数两侧的元素。

二、核心思路：给两个数组分别画一条分割线

设两个有序数组为 A 和 B：

A: [ A 的左半部分 | A 的右半部分 ]
B: [ B 的左半部分 | B 的右半部分 ]

把两个数组分割后，可以得到合并意义下的左半部分和右半部分：

合并后的左半部分 = A 左边 + B 左边
合并后的右半部分 = A 右边 + B 右边

正确分割必须同时满足两个条件：

  1. 左半部分的元素数量正确；
  2. 左半部分所有元素都不大于右半部分所有元素。

只要找到这样的分割线，就可以直接计算中位数。

三、为什么始终在较短数组中二分

if (nums1.size() > nums2.size()) {
    return findMedianSortedArrays(nums2, nums1);
}

交换后保证：

m <= n

这样做有两个作用：

  1. 二分较短数组，时间复杂度是 O(log(min(m,n)))；
  2. 根据 partition1 计算出的 partition2 不会越过第二个数组的合法分割范围。

注意：O(log(min(m,n))) 比题目要求的 O(log(m+n)) 更好，因此满足要求。

四、左半部分需要多少个元素

int leftCount = (m + n + 1) / 2;

1. 总长度为奇数

例如总共有 5 个元素：

左边放 3 个，右边放 2 个

(5 + 1) / 2 = 3

中位数就是左半部分的最大值。

2. 总长度为偶数

例如总共有 4 个元素：

左边放 2 个，右边放 2 个

(4 + 1) / 2 = 2

中位数是：

(左半部分最大值 + 右半部分最小值) / 2

加 1 的意义是：当总长度为奇数时，让左半部分比右半部分多一个元素，从而统一奇偶情况。

五、分割位置的含义

设：

int partition1 = ...;
int partition2 = leftCount - partition1;

partition1 表示 nums1 左边取多少个元素，而不是某个元素的下标。

例如：

nums1 = [1, 3, 5]
partition1 = 2

分割结果：[1, 3 | 5]
nums1 左边有 2 个元素

因为 nums1 左边可能取 0 个，也可能取全部 m 个，所以二分范围必须是：

int left = 0;
int right = m;

不能写成 right = m - 1，因为分割线可能位于最后一个元素之后。

左右两侧的元素数量必须满足：

partition1 + partition2 = leftCount

所以确定 partition1 后，可以直接计算：

partition2 = leftCount - partition1;

六、只需要检查分割线旁边的四个值

定义：

nums1Left  = nums1 分割线左边的最大值
nums1Right = nums1 分割线右边的最小值
nums2Left  = nums2 分割线左边的最大值
nums2Right = nums2 分割线右边的最小值

图示：

nums1: [ ... nums1Left | nums1Right ... ]
nums2: [ ... nums2Left | nums2Right ... ]

因为两个数组内部已经有序，所以不需要检查所有元素。合法分割只需要满足两条交叉关系：

nums1Left <= nums2Right
nums2Left <= nums1Right

此时，左边所有元素都不大于右边所有元素。

注意，不需要比较：

nums1Left 与 nums1Right
nums2Left 与 nums2Right

因为数组本身有序，这两条关系天然成立。

七、如何处理分割线位于数组边界

如果分割线左边没有元素，就把这一侧的最大值看作负无穷：

int nums1Left = (partition1 == 0)
                    ? INT_MIN
                    : nums1[partition1 - 1];

如果分割线右边没有元素，就把这一侧的最小值看作正无穷：

int nums1Right = (partition1 == m)
                     ? INT_MAX
                     : nums1[partition1];

第二个数组同理。

这样就不用为以下情况分别写大量判断：

  • 某个数组为空；
  • 某个数组的元素全部在左半部分；
  • 某个数组的元素全部在右半部分。

INT_MIN 和 INT_MAX 只是用于比较的哨兵值，不是真的向数组中添加元素。

八、二分移动方向

情况 1：nums1Left > nums2Right

nums1: [ ... 较大的值 | ... ]
nums2: [ ... | 较小的值 ... ]

说明 nums1 左边选得太多，partition1 太靠右，需要向左移动：

right = partition1 - 1;

情况 2：nums2Left > nums1Right

说明 nums1 左边选得太少，partition1 太靠左，需要向右移动：

left = partition1 + 1;

情况 3：两条交叉关系都成立

nums1Left <= nums2Right && nums2Left <= nums1Right

说明当前分割合法，可以直接计算中位数。

九、示例推演

示例 1：总长度为奇数

nums1 = [1,3]
nums2 = [2]

为了在较短数组中二分，交换后：

A = [2]，m = 1
B = [1,3]，n = 2
leftCount = (1 + 2 + 1) / 2 = 2

第一轮

partition1 = 0
partition2 = 2

A_Left  = -∞
A_Right = 2
B_Left  = 3
B_Right = +∞

检查：

B_Left <= A_Right
3 <= 2 ？不成立

说明 A 左边选得太少，分割线右移。

第二轮

partition1 = 1
partition2 = 1

A_Left  = 2
A_Right = +∞
B_Left  = 1
B_Right = 3

两条交叉关系都成立：

2 <= 3
1 <= +∞

总长度为奇数，中位数是左半部分最大值：

max(2, 1) = 2

示例 2：总长度为偶数

nums1 = [1,2]
nums2 = [3,4]
leftCount = 2

合法分割为：

nums1: [1,2 | ]
nums2: [ | 3,4]

所以：

左半部分最大值 = 2
右半部分最小值 = 3
中位数 = (2 + 3) / 2.0 = 2.5

十、C++ 完整代码

class Solution {
public:
    double findMedianSortedArrays(vector<int>& nums1,
                                  vector<int>& nums2) {
        // 始终在较短的数组中二分
        if (nums1.size() > nums2.size()) {
            return findMedianSortedArrays(nums2, nums1);
        }

        int m = nums1.size();
        int n = nums2.size();

        // 合并意义下，左半部分需要包含的元素总数
        int leftCount = (m + n + 1) / 2;

        // 二分的是分割位置，因此范围是 [0, m]
        int left = 0;
        int right = m;

        while (left <= right) {
            // nums1、nums2 左边分别选取多少个元素
            int partition1 = left + (right - left) / 2;
            int partition2 = leftCount - partition1;

            // 分割线位于边界时，用正负无穷作为哨兵值
            int nums1Left = (partition1 == 0)
                                ? INT_MIN
                                : nums1[partition1 - 1];

            int nums1Right = (partition1 == m)
                                 ? INT_MAX
                                 : nums1[partition1];

            int nums2Left = (partition2 == 0)
                                ? INT_MIN
                                : nums2[partition2 - 1];

            int nums2Right = (partition2 == n)
                                 ? INT_MAX
                                 : nums2[partition2];

            // 找到合法分割
            if (nums1Left <= nums2Right &&
                nums2Left <= nums1Right) {
                int maxLeft = max(nums1Left, nums2Left);

                // 总长度为奇数：左半部分比右半部分多一个元素
                if ((m + n) % 2 == 1) {
                    return static_cast<double>(maxLeft);
                }

                // 总长度为偶数：取中间两个数的平均值
                int minRight = min(nums1Right, nums2Right);
                return (static_cast<double>(maxLeft) + minRight) / 2.0;
            }

            if (nums1Left > nums2Right) {
                // nums1 左边选得太多，分割线左移
                right = partition1 - 1;
            } else {
                // nums1 左边选得太少，分割线右移
                left = partition1 + 1;
            }
        }

        // 根据题目条件，两个数组不会同时为空，一定存在合法分割
        return 0.0;
    }
};

十一、变量含义

变量 含义
m 较短数组 nums1 的长度
n 较长数组 nums2 的长度
leftCount 合并意义下左半部分需要包含的元素总数
partition1 nums1 左边选取的元素个数
partition2 nums2 左边选取的元素个数
nums1Left nums1 分割线左边的最大值
nums1Right nums1 分割线右边的最小值
nums2Left nums2 分割线左边的最大值
nums2Right nums2 分割线右边的最小值

十二、容易出错的地方

1. C++ 变量名不能包含空格

错误：

int left count = (m + n + 1) / 2;

正确：

int leftCount = (m + n + 1) / 2;

2. 分割位置的二分范围是 [0, m]

int left = 0;
int right = m;

这里二分的是“左边选多少个元素”，不是元素下标，因此必须允许选 0 个或选全部 m 个。

3. 分割线左边使用 partition - 1

nums1Left = nums1[partition1 - 1];
nums1Right = nums1[partition1];

因为 partition1 表示左边元素的数量。

4. 必须先保证第一个数组更短

否则 partition2 可能超出第二个数组的分割范围，边界处理会变复杂。

5. 偶数长度要使用浮点除法

推荐写法：

return (static_cast<double>(maxLeft) + minRight) / 2.0;

这样既能得到小数，也能避免先进行整数加法带来的潜在溢出问题。

6. 奇数长度取的是左半部分最大值

因为 (m+n+1)/2 已经让左半部分在奇数情况下多放一个元素：

return max(nums1Left, nums2Left);

十三、复杂度

设较短数组长度为 m：

  • 时间复杂度：O(log(min(m,n)))
  • 空间复杂度：O(1)

递归交换数组最多发生一次，不会改变整体复杂度。

十四、方法归纳

这道题不是在二分查找某一个具体数，而是在二分查找一个分割位置。

记忆步骤：

1. 保证 nums1 是较短数组
2. 左边总数 leftCount = (m+n+1)/2
3. 在 [0,m] 中二分 partition1
4. partition2 = leftCount - partition1
5. 检查两条交叉关系
6. 根据奇偶性计算中位数

核心口诀：

短数组上找分割，左边数量先固定；交叉边界都合法，奇取左大，偶取两边平均。

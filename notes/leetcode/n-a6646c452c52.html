本笔记整理 LeetCode 1、49、128。共同核心是利用哈希表或哈希集合，将查找、分组和判存在的平均时间降为 O(1)。

相关笔记：双指针专题（283、15、42）

一、哈希结构的选择

需求 推荐结构 保存内容
根据一个值找它之前出现的位置 unordered_map 元素值 -> 下标
根据统一特征把数据分组 unordered_map 分组特征 -> 一组原数据
去重并快速判断某个值是否存在 unordered_set 不重复的元素值

需要注意：

  • unordered_map 和 unordered_set 都是无序的，遍历顺序不固定；
  • 它们不能像 vector 一样使用 0、1、2... 表示“第几个元素”；
  • 哈希结构的插入和查询平均为 O(1)。

二、1. 两数之和

1. 题意

给定整数数组 nums 和目标值 target，找出两个不同位置的元素，使得：

nums[i] + nums[j] == target

返回两个下标。题目保证存在唯一答案。

2. 核心思路：边遍历边寻找补数

遍历到 nums[i] 时，需要寻找：

need = target - nums[i]

用哈希表记录此前出现过的元素：

元素值 -> 元素下标

如果 need 已经存在，就找到了答案；否则再记录当前元素。

关键顺序是：

先查补数，再存当前元素

这样能够避免把同一个元素使用两次。例如 nums = [3,3]、target = 6 时，第一个 3 先存入，第二个 3 才能与它配对。

3. 示例推演

nums = [2,7,11,15], target = 9
  • i = 0：当前值为 2，需要 7；哈希表中没有，记录 2 -> 0；
  • i = 1：当前值为 7，需要 2；找到 2 -> 0，返回 [0,1]。

4. C++ 代码

class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        // key：已经遍历过的元素值
        // value：该元素的下标
        unordered_map<int, int> indexOf;

        for (int i = 0; i < static_cast<int>(nums.size()); i++) {
            int need = target - nums[i];

            if (indexOf.count(need)) {
                return {indexOf[need], i};
            }

            // 先查后存，避免当前元素与自己配对
            indexOf[nums[i]] = i;
        }

        return {};
    }
};

5. 复杂度

  • 时间复杂度：平均 O(n)；
  • 空间复杂度：O(n)。

6. 方法归纳

当前元素 + 需要的补数 = 目标值
             ↓
用哈希表判断补数是否在此前出现

记忆：

两数之和：计算补数，先查后存。

三、49. 字母异位词分组

1. 题意

将互为字母异位词的字符串分到同一组。字母异位词使用的字母及其出现次数完全相同，只是排列顺序不同。

例如：

"eat"、"tea"、"ate"

排序后都得到：

"aet"

2. 核心思路：排序结果作为分组特征

使用：

unordered_map<string, vector<string>> groups;

其中：

  • key：原字符串排序后的结果；
  • value：所有具有该排序结果的原字符串。

例如：

"aet" -> ["eat", "tea", "ate"]
"ant" -> ["tan", "nat"]
"abt" -> ["bat"]

排序后的字符串相当于每一组的统一“身份证”。

3. 为什么要复制一份字符串

string key = str;
sort(key.begin(), key.end());

str 要保留原始内容并加入答案，所以只对复制出来的 key 排序。

4. unordered_map 的正确遍历方式

错误写法：

for (int i = 0; i < mp.size(); i++) {
    ans.push_back(mp[i]);
}

这里 mp 的键类型是 string，而且哈希表不存在“第 i 个元素”的数组下标语义。

正确写法：

for (auto& entry : mp) {
    ans.push_back(entry.second);
}

其中：

  • entry.first 是排序后的字符串；
  • entry.second 是该组所有原字符串。

5. C++ 代码

class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> groups;

        for (const string& str : strs) {
            string key = str;
            sort(key.begin(), key.end());
            groups[key].push_back(str);
        }

        vector<vector<string>> answer;

        for (auto& entry : groups) {
            answer.push_back(entry.second);
        }

        return answer;
    }
};

空字符串排序后仍为空字符串，因此 strs = [""] 会自然得到 [[""]]，不需要特殊处理。

6. 复杂度

设字符串数量为 n，每个字符串的最大长度为 k：

  • 平均时间复杂度：O(n · (1 + k log(k+1)))，包含空串处理；通常在 k ≥ 2 时写作 O(nk log k)。
  • 额外空间：O(n(k+1))，保存哈希表的键与分组字符串；当前复制分组到答案的写法，返回结果也占 O(n(k+1)) 空间。

本次补充：计数与分组不是同一件事

将 unordered_map<char,int> ssmp 放在字符串循环外，持续执行 ssmp[c]++，会把所有单词的字符次数混在一起。即使每轮清空，也只得到了当前单词的计数，还需要用完整特征寻找对应分组。

主模板使用 unordered_map<string, vector<string>>，含义是“排序后的字符串 → 一组原字符串”。排序同时保留字符种类和次数，所以 abb 与 ab 不会误分到同组。

string key = str;
sort(key.begin(), key.end());
groups[key].push_back(str);

groups[key] 在键不存在时自动创建空 vector<string>，然后追加原单词。与整数映射默认插入 0 的规则一致，只是值类型不同。不能把排序后的 key 当作原单词加入答案，也不能用集合去掉重复输入。

空字符串可直接分组，["a","a"] 应保留两个 a；组的返回顺序不固定，符合题意。const string& 只读原字符串，key 是可排序副本，详见 C++基础。

口诀：排序作键，原词入组，最后收集。

7. 方法归纳

原数据 → 提取统一特征 → 哈希表按特征分组

记忆：

异位词排序后相同：排序结果作 key，原字符串进入对应分组。

四、128. 最长连续序列

1. 题意

给定未排序整数数组，返回最长数值连续序列的长度。连续指数字连续，不要求它们在原数组中的位置连续。

例如：

nums = [100,4,200,1,3,2]

最长连续序列是：

[1,2,3,4]

答案为 4。

2. 核心思路：哈希集合 + 只从起点扩展

先把所有数字放入哈希集合：

unordered_set<int> numSet(nums.begin(), nums.end());

哈希集合可以自动去重，并平均 O(1) 判断一个数字是否存在。

对于数字 num，只有当 num - 1 不存在时，它才是一段连续序列的起点：

if (!numSet.count(num - 1))

例如序列 [1,2,3,4]：

  • 4 的前面有 3，不是起点；
  • 3 的前面有 2，不是起点；
  • 2 的前面有 1，不是起点；
  • 1 的前面没有 0，从 1 开始向后统计。

3. 为什么不依赖遍历顺序

unordered_set 的遍历顺序不固定。即使先检查 4，也只会因为 3 存在而跳过；以后检查到 1 时，仍会完整找到：

1 → 2 → 3 → 4

算法要求的是“只有起点才向后扩展”，不是“必须先遍历到最小数字”。

4. 为什么应该遍历集合，而不是原数组

推荐：

for (int num : numSet)

不推荐：

for (int num : nums)

如果原数组中有很多重复的序列起点，遍历原数组会从同一起点反复向后统计，可能失去严格的线性保证。遍历去重后的集合，可确保每个起点只处理一次。

5. C++ 代码

class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> numSet(nums.begin(), nums.end());
        int longest = 0;

        for (int num : numSet) {
            // num - 1 不存在，num 才是序列起点
            if (!numSet.count(num - 1)) {
                int currentNum = num;
                int currentLength = 1;

                while (numSet.count(currentNum + 1)) {
                    currentNum++;
                    currentLength++;
                }

                longest = max(longest, currentLength);
            }
        }

        return longest;
    }
};

6. 为什么含有 while 仍是 O(n)

如果从每个数字都向后查找，最坏会产生大量重复操作。加入起点判断后，每一段连续序列只会从起点完整扩展一次，中间数字不会重复向后扩展。

7. 复杂度

  • 时间复杂度：平均 O(n)；
  • 空间复杂度：O(n)。

8. 方法归纳

集合去重并判存在
        ↓
没有前一个数才是起点
        ↓
只从起点不断寻找下一个数

记忆：

最长连续序列：没有前驱才起步，从起点一直向后找。

题目 哈希结构 键/元素的含义 核心操作

统一思考方式：

先确定需要快速回答的问题是“在哪里”“属于哪组”还是“是否存在”，再选择 unordered_map 或 unordered_set。

77. 组合

力扣原题

简短题意

给定整数 n、k，返回从 1..n 中选出 k 个不同数的全部组合，组合内部顺序不形成新答案。

思路解析

path 保存已选择的数，start 表示下次可选的最小数，每次选择 i 后只从 i+1 往后选，天然避免排列重复。当 path 长度为 k 时收集。需要 need 个数时，起点不能大于 n-need+1，这是保证剩余候选足够的边界。

C++ 主模板

class Solution {
    // 后续只选更大的数，避免同一组合产生不同排列。
    vector<vector<int>> answer;
    vector<int> path;
    void dfs(int start, int n, int k) {
        if (static_cast<int>(path.size()) == k) { answer.push_back(path); return; }
        int need = k - path.size();
        for (int i = start; i <= n - need + 1; i++) {
            path.push_back(i);
            dfs(i + 1, n, k);
            path.pop_back();
        }
    }
public:
    vector<vector<int>> combine(int n, int k) {
        answer.clear(); path.clear(); dfs(1,n,k); return answer;
    }
};

示例与复杂度

n=4、k=2，得到 [1,2]、[1,3]、[1,4]、[2,3]、[2,4]、[3,4]。

时间 O(k×C(n,k))，包含复制结果的成本；额外空间 O(k)，输出 O(k×C(n,k))。

易错点与一类题总结

递归下一起点是 i+1，不是 start+1；回退弹出当前选择；和全排列的 used 模板不同，组合只需单向选数。

组合问题用 start 限制后续选择范围；固定长度时，结合剩余需求设置枚举上界。

52. N皇后II

力扣原题

简短题意

在 n×n 棋盘上放 n 个皇后，使任意两皇后不同列、不同斜线，返回合法摆放方案的数量，不需要返回棋盘布局。

思路解析

每层递归固定一行，在所有未冲突列中放皇后。列编号 col，两种斜线编号 row-col+n-1 和 row+col。放置后标记占用，下一行完成后撤销；当 row=n 时计数加一，每种摆法对应唯一的逐行选择路径。

C++ 主模板

class Solution {
    // 每层放一行皇后，递归返回后撤销三类占用标记。
    vector<bool> column, diagonal1, diagonal2;
    int answer = 0;
    void dfs(int row, int n) {
        if (row == n) { answer++; return; }
        for (int col = 0; col < n; col++) {
            int d1 = row - col + n - 1, d2 = row + col;
            if (column[col] || diagonal1[d1] || diagonal2[d2]) continue;
            column[col] = diagonal1[d1] = diagonal2[d2] = true;
            dfs(row + 1, n);
            column[col] = diagonal1[d1] = diagonal2[d2] = false;
        }
    }
public:
    int totalNQueens(int n) {
        column.assign(n,false); diagonal1.assign(2*n-1,false); diagonal2.assign(2*n-1,false);
        answer = 0; dfs(0,n); return answer;
    }
};

示例与复杂度

n=4 有 2 种方案；n=1 为 1；n=2、3 都为 0。

按每个状态枚举 n 列计，时间上界 O(n×n!)，额外空间 O(n)。

易错点与一类题总结

斜线编号范围为 0..2n-2；负差值加 n-1 平移。三个占用标记都必须撤销。

与 N 皇后 51 共用逐行回溯，输出从棋盘列表换为计数即可；冲突判断是题目的必要约束。

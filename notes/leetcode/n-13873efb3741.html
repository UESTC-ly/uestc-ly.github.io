71. 简化路径

题型与核心思路

栈 + 字符串分割。按 / 分割绝对路径，普通目录入栈，.. 删除最近进入的目录。每处理完一段，栈里保存的就是从根目录到当前位置的有效目录。

分割得到的字符串 操作
空串或 . 跳过，位置不变
.. 栈非空则出栈；根目录不能再向上
其他字符串 作为普通目录名入栈

只有恰好等于 .、.. 才有特殊含义，...、a.. 都是普通名称。

C++ 模板

#include <sstream>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string simplifyPath(string path) {
        vector<string> stk;
        stringstream ss(path);
        string part;

        while (getline(ss, part, '/')) {
            if (part.empty() || part == ".") {
                continue;
            } else if (part == "..") {
                if (!stk.empty()) {
                    stk.pop_back();
                }
            } else {
                stk.push_back(part);
            }
        }

        string ans;
        for (const auto& dir : stk) {
            ans += '/';
            ans += dir;
        }
        return ans.empty() ? "/" : ans;
    }
};

示例与追问

/a//b/./../c/ 忽略空段后依次处理 a、b、.、..、c：

[a] → [a,b] → [a,b] → [a] → [a,c]
答案：/a/c

为什么用 vector 而不是 stack？ 两者都能实现后进先出，但最终要从栈底到栈顶顺序拼接。vector 能直接遍历；stack 只能访问栈顶，依次弹出得到的顺序相反，还要调整顺序。算法仍然是栈，只是用 vector 实现。

getline 怎么分割？ getline(ss, part, '/') 读取到下一个 /，将内容放入 part；分隔符会被消耗但不放入结果。空段跳过即可。相关接口见 C++基础。

边界、复杂度与迁移

  • /、/../ 最终都是 /；栈为空时不能 pop。
  • 每个目录前加一个 /，自然避免连续斜杠和末尾多余斜杠；没有目录时单独返回根目录。
  • 路径长度为 n：时间 O(n)，额外空间 O(n)，输出空间 O(n)。

识别信号：后面的操作需要撤销最近一次有效操作。先分割、再分类、用栈保存有效状态。口诀：空和点跳过，两点退一步，目录入栈。

162. 寻找峰值

力扣原题

简短题意

给定数组 nums，相邻元素不相等，找一个严格大于相邻元素的峰值并返回下标。两端外侧视为负无穷，可返回任意峰值，要求 O(log n)。

思路解析

比较 nums[mid] 与 nums[mid+1]。若上坡，右半边一定存在峰：继续上涨最终在末尾遇到负无穷，或途中转为下坡。若下坡，左半边含 mid 一定存在峰。因此只保留必含某个峰的一半，闭区间缩到单点。

C++ 主模板

class Solution {
    // 根据 mid 到 mid+1 的上坡或下坡，保留必含峰的一侧。
public:
    int findPeakElement(vector<int>& nums) {
        int left = 0, right = static_cast<int>(nums.size()) - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < nums[mid + 1]) left = mid + 1;
            else right = mid;
        }
        return left;
    }
};

示例与复杂度

[1,2,3,1]：中间处上坡，保留右半边；随后下坡，定位到下标 2。

时间 O(log n)，额外空间 O(1)。

易错点与一类题总结

不是寻找全局最大值；left<right 保证 mid+1<=right，才不会越界。相邻不相等是判断方向的题目条件。

二分不一定要求整体有序；如果局部趋势能证明某半边必含答案，也能做保留候选区间的二分。

69. x的平方根

力扣原题

简短题意

给定非负整数 x，返回其平方根向下取整的整数结果，不使用 pow 或其他内置指数函数。

思路解析

在 [0,x] 二分，找最大的 mid 使 mid²<=x。满足条件就保存并尝试更大，不满足就缩小上界。平方随非负 mid 单调增大，所以候选判断具备单调性。

C++ 主模板

class Solution {
    // 二分找最大的平方不超过 x 的整数。
public:
    int mySqrt(int x) {
        int left = 0, right = x, answer = 0;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            long long square = 1LL * mid * mid;
            if (square <= x) {
                answer = mid;
                left = mid + 1;
            } else right = mid - 1;
        }
        return answer;
    }
};

示例与复杂度

x=8：2²<=8、3²>8，返回 2；x=0 返回 0。

时间 O(log(x+1))，额外空间 O(1)。

易错点与一类题总结

平方必须先转 long long；中点用 left+(right-left)/2；不是四舍五入。

求最大可行整数：建立单调可行条件，闭区间二分并保存最后满足条件的位置。

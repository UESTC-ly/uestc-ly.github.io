一、437. 路径总和 III

1. 题意

统计二叉树中节点值之和等于 targetSum 的路径数量。

路径要求：

  • 不一定从根节点开始；
  • 不一定在叶子节点结束；
  • 必须连续；
  • 方向只能从父节点到子节点。

经典示例中 targetSum = 8：

          10
         /  \
        5   -3
       / \    \
      3   2    11
     / \   \
    3  -2   1

合法路径有：

5 → 3
5 → 2 → 1
-3 → 11

共 3 条。

2. 核心思路：前缀和 + DFS + 回溯

设从根到当前节点的前缀和是 currentSum，某个祖先位置的前缀和是 previousSum。

两者之间的路径和为：

currentSum - previousSum

若它等于目标值：

currentSum - previousSum = targetSum

则：

previousSum = currentSum - targetSum

所以访问当前节点时，查询：

prefixCount[currentSum - targetSum]

其出现次数就是“以当前节点为终点”的合法路径数量。

3. 递归函数返回什么

定义：

int dfs(TreeNode* node, ...)

返回：

当前节点 node 所在子树中，路径和等于 targetSum 的所有向下路径数量。

递推关系：

dfs(node)
= 以 node 为终点的合法路径数
+ dfs(node->left)
+ dfs(node->right)

注意，返回的不是路径和，也不是必须从 node 开始的路径数量。

4. C++ 代码

class Solution {
private:
    int dfs(
        TreeNode* node,
        long long currentSum,
        int targetSum,
        unordered_map<long long, int>& prefixCount
    ) {
        if (node == nullptr) {
            return 0;
        }

        currentSum += node->val;

        // 统计以当前节点为终点的合法路径
        int pathCount = prefixCount[currentSum - targetSum];

        // 当前前缀和对后代节点可用
        ++prefixCount[currentSum];

        pathCount += dfs(
            node->left,
            currentSum,
            targetSum,
            prefixCount
        );

        pathCount += dfs(
            node->right,
            currentSum,
            targetSum,
            prefixCount
        );

        // 回溯：离开当前分支，撤销当前前缀和
        --prefixCount[currentSum];

        return pathCount;
    }

public:
    int pathSum(TreeNode* root, int targetSum) {
        unordered_map<long long, int> prefixCount;

        // 允许统计从根开始且路径和恰好等于 targetSum 的路径
        prefixCount[0] = 1;

        return dfs(root, 0, targetSum, prefixCount);
    }
};

5. 关键细节

prefixCount[0] = 1

表示访问任何节点之前存在一个和为 0 的空前缀。

当从根到当前节点的和恰好等于目标值时：

currentSum - targetSum = 0

这条从根开始的路径就能被统计。

为什么存“出现次数”

同一个前缀和可能在当前路径上出现多次，每次出现都对应一个不同的路径起点，所以不能只保存“是否出现”。

为什么必须回溯

--prefixCount[currentSum];

保证哈希表只记录当前根到当前节点这条递归路径上的前缀和。

左子树中的前缀和不能带入右子树，否则可能把不同分支错误拼成一条路径。

为什么先查询再加入

正确顺序：

先查询历史前缀和
再加入当前前缀和
递归左右子树
最后撤销当前前缀和

若先加入当前前缀和，当 targetSum == 0 时可能让当前前缀和与自身匹配，错误统计空路径。

为什么使用 long long

多个节点值连续累加可能超出 int 范围，因此前缀和及哈希表键使用 long long。

6. 复杂度

  • 时间复杂度：平均 O(n)；
  • 空间复杂度：O(h)，最坏 O(n)。

二、236. 二叉树的最近公共祖先

1. 题意

在普通二叉树中，找到节点 p 和 q 深度最大的公共祖先。

一个节点可以是它自己的祖先。因此，如果 p 是 q 的祖先，答案可以是 p。

2. 递归函数返回什么

lowestCommonAncestor(root, p, q)

返回当前子树中的有效结果：

  • nullptr：当前子树没有找到 p 或 q；
  • p 或 q：找到其中一个目标节点；
  • 其他节点：当前子树中已经确定的最近公共祖先。

3. 核心判断

分别递归左右子树：

TreeNode* leftResult = lowestCommonAncestor(root->left, p, q);
TreeNode* rightResult = lowestCommonAncestor(root->right, p, q);

情况如下：

左右都非空：p、q 分别位于两侧，当前 root 是最近公共祖先；
只有左边非空：返回左边结果；
只有右边非空：返回右边结果；
左右都为空：返回 nullptr。

4. C++ 代码

class Solution {
public:
    TreeNode* lowestCommonAncestor(
        TreeNode* root,
        TreeNode* p,
        TreeNode* q
    ) {
        if (root == nullptr || root == p || root == q) {
            return root;
        }

        TreeNode* leftResult =
            lowestCommonAncestor(root->left, p, q);

        TreeNode* rightResult =
            lowestCommonAncestor(root->right, p, q);

        if (leftResult != nullptr && rightResult != nullptr) {
            return root;
        }

        return leftResult != nullptr ? leftResult : rightResult;
    }
};

5. 常见代码错误

若当前节点参数名是 root，递归时必须写：

lowestCommonAncestor(root->left, p, q);
lowestCommonAncestor(root->right, p, q);

不能误写为未定义的变量：

lowestCommonAncestor(node->left, p, q);  // node 未定义

另外，应比较节点指针：

root == p || root == q

而不是只比较节点值。

6. 为什么找到 p 或 q 就直接返回

如果当前节点等于 p：

  • q 在其他分支时，上层会通过左右结果确定公共祖先；
  • q 在 p 的子树中时，题目保证两节点存在，此时 p 自身就是最近公共祖先。

7. 复杂度

  • 时间复杂度：O(n)；
  • 递归栈空间：O(h)，最坏 O(n)。

三、124. 二叉树中的最大路径和

1. 题意

求二叉树中任意合法路径的最大节点值之和。

路径：

  • 至少包含一个节点；
  • 相邻节点之间必须有边；
  • 同一节点最多出现一次；
  • 不一定经过整棵树的根节点；
  • 可以从左子树经过某个节点，再走到右子树。

例如：

    1
   / \
  2   3

最大路径：

2 → 1 → 3

最大路径和为 6。

2. 必须区分两个值

经过当前节点的完整路径

用于更新全局答案：

root->val + leftGain + rightGain

它可以同时使用左右两边，因为当前节点是这条路径的最高连接点。

当前节点向父节点返回的贡献

root->val + max(leftGain, rightGain)

只能选择一边。若同时返回左右两边，父节点再接入后会形成 Y 形分叉，不再是一条路径。

3. 递归函数返回什么

int dfs(TreeNode* root)

返回：

从当前节点 root 出发，只向下选择一条分支时，可以提供给父节点的最大路径和。

关键词：

必须包含当前节点
只能向下
最多选择一个孩子方向

4. 舍弃负贡献

int leftGain = max(0, dfs(root->left));
int rightGain = max(0, dfs(root->right));

如果一棵子树只能提供负数，把它加入路径会让结果更小，因此用 0 表示“不选择该分支”。

当前节点本身不能舍弃，因为题目要求路径至少包含一个节点。

5. C++ 代码

class Solution {
private:
    // 所有递归调用共享同一个成员变量
    int answer = INT_MIN;

    int dfs(TreeNode* root) {
        if (root == nullptr) {
            return 0;
        }

        int leftGain = max(0, dfs(root->left));
        int rightGain = max(0, dfs(root->right));

        // 左右都可使用，只用于更新完整路径答案
        int currentPathSum = root->val + leftGain + rightGain;
        answer = max(answer, currentPathSum);

        // 返回父节点时只能选择一边
        return root->val + max(leftGain, rightGain);
    }

public:
    int maxPathSum(TreeNode* root) {
        // 防止同一个 Solution 对象被重复调用时保留旧结果
        answer = INT_MIN;
        dfs(root);
        return answer;
    }
};

6. 为什么 answer 没有作为参数传入也能更新

answer 是 Solution 类的成员变量，dfs 是该类的成员函数，因此：

answer = max(answer, currentPathSum);

等价于：

this->answer = max(this->answer, currentPathSum);

所有递归调用都属于同一个 Solution 对象，所以共享同一个 answer。

如果将 answer 定义为主函数局部变量，则必须通过引用传入：

int dfs(TreeNode* root, int& answer) {
    if (root == nullptr) {
        return 0;
    }

    int leftGain = max(0, dfs(root->left, answer));
    int rightGain = max(0, dfs(root->right, answer));

    answer = max(answer, root->val + leftGain + rightGain);

    return root->val + max(leftGain, rightGain);
}

成员变量写法更简洁，但每次调用主函数前应重新初始化。

7. 为什么 answer 初始化为 INT_MIN

不能初始化为 0，因为节点值可能全为负数。

例如只有一个节点：

-3

合法路径必须包含一个节点，正确答案是 -3，不是 0。

8. 示例推演

对于：

    1
   / \
  2   3

叶子节点返回：

dfs(2) = 2
dfs(3) = 3

在节点 1：

完整路径和 = 2 + 1 + 3 = 6
向父节点返回 = 1 + max(2,3) = 4

完整路径可以左右都要；向父节点返回只能选择一边。

9. 复杂度

  • 时间复杂度：O(n)；
  • 递归栈空间：O(h)，最坏 O(n)。

四、三道题的递归返回值对比

题目 dfs 或递归函数返回什么 额外状态
437. 路径总和 III 当前子树中的合法路径总数 当前路径的前缀和计数表，需要回溯
236. 最近公共祖先 当前子树找到的目标节点或已确定的 LCA 无
124. 最大路径和 当前节点向父节点提供的最大单边贡献 全局最大完整路径和 answer

统一思考框架

写二叉树递归前，先回答：

1. 这个函数处理哪棵子树？
2. 它要向父节点返回什么信息？
3. 空节点返回什么？
4. 当前节点如何组合左右子树的返回值？
5. 是否还需要一个不能直接向上传递的全局答案？
6. 修改了当前路径状态后，离开节点时是否需要回溯？

复习口诀：

437：当前和减目标，查历史前缀，进入加一，离开减一；
236：遇目标就返回，左右都有返回根，单边有效向上传；
124：负贡献不要，更新答案左右都要，返回父层只能一条。

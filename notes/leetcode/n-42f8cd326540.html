本目录整理图搜索与拓扑排序的基础题型。基础题解包括 LeetCode 200、994、207，新增题目见文末补充导航。

核心目标：根据问题问法，区分“连通块统计”“多源最短传播”和“依赖关系判环”。

一、题型对比

题目 图的形式 核心问题 主流方法 队列/递归中的含义
200. 岛屿数量 二维网格形成的隐式图 统计四方向连通块 DFS / BFS 从一块陆地访问整座岛
994. 腐烂的橘子 二维网格形成的隐式图 多个起点同时扩散的最短时间 多源 BFS 同一层表示同一分钟腐烂的橘子
207. 课程表 先修关系形成的有向图 判断依赖关系中是否有环 BFS 拓扑排序 当前所有入度为 0 的课程

二、如何选择方法

1. 统计连通区域

关键词：

  • 上下左右连通；
  • 有多少片区域；
  • 一次搜索标记一个完整区域。

优先考虑 DFS 或 BFS。外层遍历发现一个未访问目标格子时，答案加一，再标记整个连通块。

2. 多个起点同时扩散并求最短时间

关键词：

  • 每分钟传播一步；
  • 多个起点同时扩散；
  • 求全部传播完成的最少时间。

优先考虑多源 BFS：所有起点先同时入队，按层向外扩散。

3. 处理任务依赖与判环

关键词：

  • 先完成 A，才能完成 B；
  • 判断能否完成全部任务；
  • 判断依赖关系中是否存在循环。

优先考虑拓扑排序：不断处理入度为 0 的节点，最终比较已处理节点数与总节点数。

三、专题导航

  • 网格图搜索：岛屿数量与腐烂的橘子（200、994）
  • 拓扑排序与课程表（207）

四、复习口诀

连通块：发现一个起点，搜索并标记整个区域；
最短传播：所有源点一起入队，BFS 一层表示一步；
课程依赖：[a,b] 建边 b→a，入度为 0 才能学习；
拓扑结束后处理数量不足，说明有环。

最长回文子串长度：区间 DP 与中心扩展

来源：本次会话中的题目截图与代码讨论。
题目要求：给定一个仅含大小写字母和数字的字符串，求最长回文子串的长度；截图给出的长度范围为 1 ≤ s.size() ≤ 2500。

一、题意与关键区别

回文串指正读和反读都相同的字符串，例如：

"ABBA"、"ABA"、"A"、"123321"

要求的是最长回文子串：必须是原字符串中一段连续的字符。

例如：

s = "12HHHHHA"
最长回文子串 = "HHHHH"
答案 = 5

二、区间 DP 解法

1. 状态定义

dp[i][j]

表示子串 s[i...j] 是否为回文串：

  • true：是回文串；
  • false：不是回文串。

最终不需要单独的 dp 答案位置：遍历所有区间时，维护所有回文区间中的最大长度即可。

2. 状态转移

要让 s[i...j] 成为回文串，需要：

  1. 两端字符相等：s[i] == s[j]；
  2. 若区间较长，则去掉两端后的中间部分 s[i + 1...j - 1] 也必须是回文串。
dp[i][j] = (s[i] == s[j]) && (j - i <= 2 || dp[i + 1][j - 1]);

其中 j - i <= 2 是短区间的边界：

区间长度 j - i 例子 为什么可直接判定
1 0 "A" 单个字符一定是回文串
2 1 "AA" 两端相同即可
3 2 "ABA" 两端相同，中间单字符一定是回文串

长度至少为 4 时，才需要查询 dp[i + 1][j - 1]。

3. 为什么按区间长度从小到大遍历？

计算：

dp[i][j]

可能依赖：

dp[i + 1][j - 1]

后者表示更短的中间子串。因此必须先计算短区间，再计算长区间，即按 len = 1, 2, ..., n 的顺序枚举。

三、示例推演："ABBA"

长度 1："A"、"B"、"B"、"A" 全是回文
长度 2："AB" 否，"BB" 是，"BA" 否
长度 3："ABB" 否，"BBA" 否
长度 4："ABBA"：两端都是 A，且中间 "BB" 是回文，因此为回文

所以最长长度为 4。

四、C++ 参考代码（区间 DP）

#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
    string s;
    getline(cin, s);

    int n = static_cast<int>(s.size());

    // dp[i][j]：子串 s[i...j] 是否为回文串。
    vector<vector<bool>> dp(n, vector<bool>(n, false));

    int maxLen = 1;

    // 按子串长度从小到大枚举，保证 dp[i + 1][j - 1] 已经求出。
    for (int len = 1; len <= n; ++len) {
        // i：当前子串左端点。
        for (int i = 0; i + len - 1 < n; ++i) {
            int j = i + len - 1;  // 当前子串右端点。

            // 两端相同，并且短区间可直接成立，或中间子串已是回文。
            if (s[i] == s[j] && (j - i <= 2 || dp[i + 1][j - 1])) {
                dp[i][j] = true;
                maxLen = max(maxLen, len);
            }
        }
    }

    cout << maxLen << '\n';
    return 0;
}

五、中心扩展法（同题的另一种主流解法）

除了 DP，还可以枚举回文中心后向两边扩展：

  • 奇数长度中心：left = i, right = i，如 "ABA"；
  • 偶数长度中心：left = i, right = i + 1，如 "ABBA"。

每个位置都要尝试这两种中心。

int expand(const string& s, int left, int right) {
    while (left >= 0 && right < static_cast<int>(s.size())
           && s[left] == s[right]) {
        --left;
        ++right;
    }

    // 循环结束时 [left + 1, right - 1] 才是有效回文区间。
    return right - left - 1;
}

DP 与中心扩展的选择

方法 时间复杂度 空间复杂度 适用理解
区间 DP O(n²) O(n²) 适合练习“区间状态 + 依赖更短区间”
中心扩展 O(n²) O(1) 代码更省空间，适合只求最长长度

本题 n ≤ 2500，两种做法都可行；若题目只要求最长长度，中心扩展的额外空间更少。若在学习动态规划，优先掌握本页的区间 DP 写法。

六、易错点

  1. 不要把子串和子序列混淆：本题要求连续。
  2. 只枚举奇数中心会漏掉偶数回文，如 "ABBA"。
  3. 区间 DP 的遍历顺序不能随意写：dp[i][j] 依赖 dp[i + 1][j - 1]，必须先算短区间。
  4. 短区间要处理好：j - i <= 2 时，只要两端相等即可。
  5. dp 数组下标范围是 0 ~ n - 1，区间右端点 j 不能越界。

七、方法归纳

遇到“判断一个区间是否满足某种对称性质”的题，可以考虑区间 DP：

1. 定义 dp[i][j] 表示区间 s[i...j] 是否满足性质
2. 找到缩小区间后的依赖状态，例如 dp[i + 1][j - 1]
3. 先处理长度 1、2、3 等边界
4. 按区间长度从小到大计算
5. 在满足条件的区间中更新答案

一句话记忆：

最长回文子串的区间 DP：两端字符相等，并且中间子串也是回文；按长度从小到大枚举区间。

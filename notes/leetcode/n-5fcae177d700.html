41. 缺失的第一个正数

简短题意

给定未排序的整数数组 nums，返回其中没有出现的最小正整数。数组可能包含负数、零和重复值；要求时间复杂度为 O(n)，额外空间为 O(1)。

题型与核心思路

数组原地归位。

长度为 n 的数组，答案一定在 [1,n+1]：如果 1..n 全部出现，答案就是 n+1；否则答案在 1..n 中。负数、零和大于 n 的数都不需要归位。

让数值 x 放到下标 x-1，即 1 放到 0、2 放到 1。归位完成后，从左向右找第一个 nums[i] != i+1 的位置，缺少的数就是 i+1。

为什么交换要用 while

把 nums[i] 交换到目标位置后，当前位置会换进另一个数，它也可能需要归位。因此必须持续处理当前位置，直到：

  1. 当前值不在 1..n 中；或
  2. 目标位置已经存着这个值，包括重复值或自己已经归位。

第二个条件防止重复数相互交换，形成死循环。读取 nums[nums[i]-1] 前，必须先检查数值范围，避免越界。

C++ 主模板

class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {
        int n = nums.size();

        for (int i = 0; i < n; i++) {
            while (nums[i] >= 1 && nums[i] <= n &&
                   nums[nums[i] - 1] != nums[i]) {
                int target = nums[i] - 1; // 先保存该数应在的位置
                swap(nums[i], nums[target]);
            }
        }

        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1; // 1..n 都在正确位置
    }
};

示例与正确性

输入：[3,4,-1,1]
i=0：把 3 放到下标 2 → [-1,4,3,1]，-1 不需要归位
i=1：把 4 放到下标 3 → [-1,1,3,4]
     把换入的 1 放到下标 0 → [1,-1,3,4]
检查：下标 0 有 1，下标 1 没有 2，因此答案为 2

每次交换都会把一个有效值放到正确位置。后续不会把它破坏：只有相同数值才会以该位置为目标，而“目标已等于当前值”的判断会阻止交换。因此，所有出现过的有效值最终都能归位；第一个未归位的位置对应最小缺失正数。

复杂度与易错点

虽然有两层循环，每次有效交换至少新增一个正确位置，最多发生 n 次交换，加上两次扫描，时间 O(n)，额外空间 O(1)。代码会修改原数组。

  • 目标下标是 x-1，不是 x。
  • 用 while 连续处理换入的值，不能只交换一次。
  • 必须判断目标位置是否已有同值，[1,1] 才不会死循环。
  • 全负数或全零返回 1；[1,2,3] 返回 4；[2] 返回 1。
  • 不能排序后直接声称满足要求：排序需要 O(n log n)；哈希集合则需要额外空间 O(n)。

一类题总结

识别信号：值与下标存在一一对应关系，且要求常数额外空间。把输入数组本身当作定位表，让有效值归位，再扫描异常位置。先确定有效范围、目标下标和重复值停止条件。

口诀：正数回家，x 到 x-1；首个错位，就是缺数。

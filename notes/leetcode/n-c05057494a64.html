383. 赎金信

力扣原题

简短题意

给定 ransomNote 和 magazine，判断能否使用 magazine 中的字符组成 ransomNote。每个字符最多使用一次，两串只含小写英文字母。

思路解析

先统计 magazine 的各字符库存，再逐字符消耗 ransomNote 的需求。任何一次库存不足都说明无法构造；全部消耗成功即存在合法分配。

C++ 主模板

class Solution {
    // 计数表是可用库存，每使用一个字符就减一。
public:
    bool canConstruct(string ransomNote, string magazine) {
        vector<int> stock(26, 0);
        for (char c : magazine) stock[c - 'a']++;
        for (char c : ransomNote) {
            if (stock[c - 'a'] == 0) return false;
            stock[c - 'a']--;
        }
        return true;
    }
};

示例与复杂度

ransomNote="aa"，magazine="ab"：第二个 a 没有库存，返回 false。

时间 O(|ransomNote|+|magazine|)，固定字符集空间 O(1)。

易错点与一类题总结

集合只记录存在，不能判断重复字符够不够；计数下标仅适用于题目限定的小写字母。

资源可重复但有次数限制时，用频次表表达库存，逐项消耗需求。

205. 同构字符串

力扣原题

简短题意

给定等长字符串 s、t，判断能否把 s 的每种字符固定替换为 t 的一种字符得到 t。同一字符映射必须一致，不同字符不能映射到同一个字符，允许映射到自身。

思路解析

同时维护 s→t 和 t→s 两张表。只检查正向表会错误接受两个源字符映射成同一个目标字符；双向一致才构成一一映射。

C++ 主模板

class Solution {
    // 正向和反向映射都一致，才能保证一一对应。
public:
    bool isIsomorphic(string s, string t) {
        unordered_map<char, char> forward, backward;
        for (int i = 0; i < static_cast<int>(s.size()); i++) {
            char a = s[i], b = t[i];
            if (forward.count(a) && forward[a] != b) return false;
            if (backward.count(b) && backward[b] != a) return false;
            forward[a] = b;
            backward[b] = a;
        }
        return true;
    }
};

示例与复杂度

egg→add 可以建立 e→a、g→d；foo→bar 的 o 同时对应 a、r，返回 false。

平均时间 O(n)，空间 O(Σ)，Σ 为出现字符种类数；固定字符集可视为常数。

易错点与一类题总结

ab→aa 正向看似能映射，反向冲突，必须拒绝。题目保证两串等长。

模式匹配中的一一对应关系，用双向映射同时检查一致性与唯一性。

290. 单词规律

力扣原题

简短题意

给定模式字符串 pattern 和空格分隔的单词串 s，判断模式字符与单词之间是否存在一一对应关系。每个模式字符对应一个完整单词。

思路解析

先用字符串流分词，词数必须等于模式长度，再对字符和单词维护双向映射。每个位置同时检查“同字符同词”和“同词同字符”。

C++ 主模板

class Solution {
    // 分词后，检查模式字符与完整单词的双向对应。
public:
    bool wordPattern(string pattern, string s) {
        istringstream input(s);
        vector<string> words;
        string word;
        while (input >> word) words.push_back(word);
        if (words.size() != pattern.size()) return false;
        unordered_map<char, string> forward;
        unordered_map<string, char> backward;
        for (int i = 0; i < static_cast<int>(pattern.size()); i++) {
            char c = pattern[i];
            const string& w = words[i];
            if (forward.count(c) && forward[c] != w) return false;
            if (backward.count(w) && backward[w] != c) return false;
            forward[c] = w; backward[w] = c;
        }
        return true;
    }
};

示例与复杂度

pattern="abba"，s="dog cat cat dog" 返回 true；"dog cat cat fish" 在最后一个 a 处冲突。

计入分词和字符串哈希，平均时间 O(|s|+|pattern|)，额外空间 O(|s|+|pattern|)。

易错点与一类题总结

必须比较词数；只检查正向映射会接受 ab 对应 dog dog。istringstream 需 。

将文本切成语义单位，再检查双射；本题的映射单位是单词而不是字符。

242. 有效的字母异位词

力扣原题

简短题意

给定只含小写英文字母的字符串 s、t，判断它们是否为字母异位词：每种字母的出现次数相同，顺序可以不同。

思路解析

用 26 个计数器，s 的字符加一、t 的字符减一，最后所有差值都为零就表示频次相同。长度不同可直接拒绝。

C++ 主模板

class Solution {
    // 两个串的字符分别加减，所有差值为零表示频次相同。
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) return false;
        vector<int> count(26, 0);
        for (char c : s) count[c - 'a']++;
        for (char c : t) count[c - 'a']--;
        for (int x : count) if (x != 0) return false;
        return true;
    }
};

示例与复杂度

anagram 和 nagaram 的所有频次差为零；rat 和 car 的差不为零。

时间 O(|s|+|t|)，固定字符集额外空间 O(1)。

易错点与一类题总结

字符种类相同不够，次数也要相同；若推广到其他字符集，要更换计数结构。

比较两个多重集合时，用加减计数表示差集；顺序无关，但 multiplicity（重复次数）有关。

202. 快乐数

力扣原题

简短题意

给定正整数 n，反复将它替换为各位数字平方和。若最终到达 1 则是快乐数；若陷入无法到达 1 的循环则不是。

思路解析

用集合记录已经出现的整数状态。确定性转换再次遇到同一状态，之后必定重复同一路径；到达 1 返回 true，重复状态返回 false。第一次转换后状态不超过 810，后续状态落在固定有限范围。

C++ 主模板

class Solution {
    // 重复整数状态意味着后续轨迹循环。
    int nextValue(int n) {
        int sum = 0;
        while (n > 0) {
            int digit = n % 10;
            sum += digit * digit;
            n /= 10;
        }
        return sum;
    }
public:
    bool isHappy(int n) {
        unordered_set<int> seen;
        while (n != 1 && !seen.count(n)) {
            seen.insert(n);
            n = nextValue(n);
        }
        return n == 1;
    }
};

示例与复杂度

19→82→68→100→1，返回 true；2 最终进入重复状态循环。

设访问 R 个状态，每状态最多 D 位，平均时间 O(RD)、空间 O(R)。本题为固定 32 位正整数，状态范围有固定上界。

易错点与一类题总结

记录完整整数状态，不是某一位数字；seen 和平方和每轮作用不同，不能混用。

确定性状态转换判断终止或循环：保存已访问状态，再次出现同状态就是循环；也可迁移到快慢指针判圈。

219. 存在重复元素II

力扣原题

简短题意

给定整数数组 nums 和整数 k，判断是否存在不同下标 i、j，使 nums[i]=nums[j] 且 |i-j|<=k。

思路解析

哈希表保存每个值最近出现的位置。对同一数值，最近位置与当前下标的距离最小，若它都不满足，更早位置也不会满足，因此只需要保留最近位置。

C++ 主模板

class Solution {
public:
    bool containsNearbyDuplicate(vector<int>& nums, int k) {
        unordered_map<int, int> last;
        for (int i = 0; i < static_cast<int>(nums.size()); i++) {
            auto it = last.find(nums[i]);
            if (it != last.end() && i - it->second <= k) return true;
            last[nums[i]] = i; // 覆盖为最近位置
        }
        return false;
    }
};

示例与复杂度

[1,2,3,1]，k=3：第二次 1 距上次 3，返回 true；k=2 则为 false。

平均时间 O(n)，额外空间 O(n)。

易错点与一类题总结

必须先检查再更新，否则距离总是 0；k=0 时不存在两个不同下标满足要求。

重复值附带距离条件时，哈希表应保存位置；选择最近或最早取决于目标要最小距离还是最大跨度。

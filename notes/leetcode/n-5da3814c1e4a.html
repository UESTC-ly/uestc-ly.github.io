一、94. 二叉树的中序遍历

1. 题意

给定二叉树根节点 root，返回它的中序遍历结果。

中序遍历的固定顺序是：

左子树 → 当前根节点 → 右子树

简称：

左 → 根 → 右

2. 核心思路：递归 DFS

对于当前节点：

  1. 递归遍历左子树；
  2. 把当前节点值加入答案；
  3. 递归遍历右子树。

空节点不需要处理：

if (root == nullptr) {
    return;
}

最关键的三行是：

inorder(root->left);
answer.push_back(root->val);
inorder(root->right);

“记录当前节点”的操作位于左右递归之间，所以这是中序遍历。

3. 示例推演

对于：

    1
     \
      2
     /
    3

输入的层序表示为：

[1,null,2,3]

递归过程：

inorder(1)
├── inorder(null)
├── 记录 1
└── inorder(2)
    ├── inorder(3)
    │   ├── inorder(null)
    │   ├── 记录 3
    │   └── inorder(null)
    ├── 记录 2
    └── inorder(null)

结果：

[1,3,2]

4. C++ 代码

class Solution {
private:
    vector<int> answer;

    void inorder(TreeNode* root) {
        // 空节点不需要访问
        if (root == nullptr) {
            return;
        }

        // 左 → 根 → 右
        inorder(root->left);
        answer.push_back(root->val);
        inorder(root->right);
    }

public:
    vector<int> inorderTraversal(TreeNode* root) {
        answer.clear();
        inorder(root);
        return answer;
    }
};

5. 复杂度

设节点数为 n，树高为 h：

  • 时间复杂度：O(n)，每个节点访问一次；
  • 递归栈空间：O(h)；最坏情况下树退化成链表，空间为 O(n)；
  • 返回结果需要 O(n) 空间。

6. 方法归纳

三种 DFS 遍历的名称，取决于“根节点”何时被访问：

前序遍历：根 → 左 → 右
中序遍历：左 → 根 → 右
后序遍历：左 → 右 → 根

注意：中序遍历并不一定得到升序数组；只有二叉搜索树的中序遍历才严格递增（本题组的 BST 不允许重复值）。

二、102. 二叉树的层序遍历

1. 题意

按照从上到下、每层从左到右的顺序访问二叉树，并返回每一层的节点值。

返回类型：

vector<vector<int>>
  • 外层数组：所有层；
  • 内层数组：当前层的节点值。

示例：

       3
      / \
     9   20
        /  \
       15   7

结果：

[[3], [9,20], [15,7]]

2. 核心思路：队列 BFS

队列具有先进先出的特点，适合按照层次处理节点：

  1. 根节点入队；
  2. 记录当前队列长度 levelSize；
  3. 取出本层的 levelSize 个节点；
  4. 保存节点值，并把它们的左右孩子入队；
  5. 将本层结果加入最终答案；
  6. 重复以上过程，直到队列为空。

3. 为什么必须固定 levelSize

进入一轮循环时，队列中正好是当前层的节点：

int levelSize = nodeQueue.size();

处理当前层时，还会不断把下一层节点加入队列，因此队列长度会变化。必须先保存本层节点数，再只处理这些节点：

for (int i = 0; i < levelSize; ++i) {
    // 只处理当前层
}

不要使用不断变化的 nodeQueue.size() 直接充当循环上界。

4. 示例推演

轮次 开始时队列 levelSize 本层结果 处理后队列
1 [3] 1 [3] [9,20]
2 [9,20] 2 [9,20] [15,7]
3 [15,7] 2 [15,7] []

最终结果：

[[3], [9,20], [15,7]]

5. C++ 代码

class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> answer;

        // 空树没有节点
        if (root == nullptr) {
            return answer;
        }

        queue<TreeNode*> nodeQueue;
        nodeQueue.push(root);

        while (!nodeQueue.empty()) {
            // 当前队列中的节点都属于本层
            int levelSize = static_cast<int>(nodeQueue.size());
            vector<int> currentLevel;

            // 只处理本层的 levelSize 个节点
            for (int i = 0; i < levelSize; ++i) {
                TreeNode* currentNode = nodeQueue.front();
                nodeQueue.pop();

                currentLevel.push_back(currentNode->val);

                // 先左后右入队，保证每层从左到右
                if (currentNode->left != nullptr) {
                    nodeQueue.push(currentNode->left);
                }
                if (currentNode->right != nullptr) {
                    nodeQueue.push(currentNode->right);
                }
            }

            answer.push_back(currentLevel);
        }

        return answer;
    }
};

6. 两层循环分别表示什么

while (!nodeQueue.empty())

每执行一轮，处理完整的一层。

for (int i = 0; i < levelSize; ++i)

处理当前层中的所有节点。

可以记成：

while：控制层；
for：处理一层中的节点。

7. 复杂度

设节点数为 n，最大宽度为 w：

  • 时间复杂度：O(n)，每个节点入队、出队各一次；
  • 队列空间：O(w)；
  • 若包含返回结果，整体还需要 O(n) 空间。

三、DFS 与 BFS 的选择

问法 优先方法 原因
前序、中序、后序遍历 DFS 递归结构与树结构一致
逐层输出、每层统计 BFS 队列天然维护同一层的访问顺序
求深度、直径等子树属性 DFS 需要先获得左右子树的信息
求离根最近的目标 BFS 按距离一层一层扩展

复习口诀：

中序遍历：左、根、右；
层序遍历：队列从左到右，levelSize 分开不同层。

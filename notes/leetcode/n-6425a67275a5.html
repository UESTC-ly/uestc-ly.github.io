67. 二进制求和

力扣原题

简短题意

给定两个非空二进制字符串 a、b，返回它们相加后的二进制字符串，不能依赖固定宽度整数保存整个大数。

思路解析

从两个串末尾模拟竖式加法，当前和为两个位加 carry，结果位是 sum%2，新进位为 sum/2。先逆序追加结果位，结束后翻转。

C++ 主模板

class Solution {
    // 从低位相加，sum%2 为结果位，sum/2 为进位。
public:
    string addBinary(string a, string b) {
        int i = static_cast<int>(a.size()) - 1, j = static_cast<int>(b.size()) - 1, carry = 0;
        string answer;
        while (i >= 0 || j >= 0 || carry != 0) {
            int sum = carry;
            if (i >= 0) sum += a[i--] - '0';
            if (j >= 0) sum += b[j--] - '0';
            answer += static_cast<char>('0' + sum % 2);
            carry = sum / 2;
        }
        reverse(answer.begin(),answer.end());
        return answer;
    }
};

示例与复杂度

11+1：从低位得到 0、0，最后进位 1，逆序后为 100。

时间 O(max(m,n))，额外结果缓冲 O(max(m,n))。

易错点与一类题总结

两个串读完后仍可能有进位；字符需减 '0' 才是数值；不能转成 int 后相加处理长输入。

任意进制竖式加法：结果位取 sum%base，进位取 sum/base。

190. 颠倒二进制位

力扣原题

简短题意

颠倒给定整数 n 的完整 32 位二进制位，返回颠倒后的整数。当前力扣接口为 int reverseBits(int n)，输入为非负偶数，保证颠倒结果仍在 int 范围内。

思路解析

固定处理 32 次，每次从原数低位取一位，先将答案左移一位，再将取出的位补到答案低位。原数右移，最终原低位依次成为结果高位。位操作使用 uint32_t，避免有符号移位问题。

C++ 主模板

class Solution {
    // 固定取出 32 个低位，依次推入结果高位方向。
public:
    int reverseBits(int n) {
        uint32_t bits = static_cast<uint32_t>(n), answer = 0;
        for (int i = 0; i < 32; i++) {
            answer = (answer << 1) | (bits & 1u);
            bits >>= 1;
        }
        return static_cast<int>(answer);
    }
};

示例与复杂度

43261596（00000010100101000001111010011100）反转后是 964176192。

固定 32 次，时间 O(1)，额外空间 O(1)。

易错点与一类题总结

必须保留前导零并处理整整 32 位，不能只循环到 n=0。uint32_t 需 ；一些旧题面使用无符号接口，提交时以当前编辑器声明为准。

固定宽度位串重排要区分有效数值位数与机器位宽；使用明确宽度的无符号类型做移位。

191. 位1的个数

力扣原题

简短题意

给定正整数 n，返回其二进制表示中值为 1 的位数，也称汉明重量。

思路解析

每次检查最低位 n&1，再将 n 右移一位，直到所有有效位处理完。计数只在最低位为 1 时增加。

C++ 主模板

class Solution {
    // 最低位为 1 时计数，再右移处理下一位。
public:
    int hammingWeight(int n) {
        uint32_t bits = static_cast<uint32_t>(n);
        int count = 0;
        while (bits != 0) {
            count += bits & 1u;
            bits >>= 1;
        }
        return count;
    }
};

示例与复杂度

11 的二进制为 1011，共三个 1；128 为 10000000，返回 1。

固定 32 位整数最多 32 次，时间和空间 O(1)。推广到 B 位为 O(B) 时间。

易错点与一类题总结

数值大小不等于置位数；用无符号值右移避免符号扩展；本题当前参数为 int。

逐位统计可以通过最低位提取加右移完成；先保证位宽和符号语义明确。

137. 只出现一次的数字II

力扣原题

简短题意

给定整数数组，只有一个数出现一次，其余每个数恰好出现三次。返回只出现一次的数，要求线性时间、常数额外空间，允许负数。

思路解析

逐个二进制位统计 1 的总次数，对 3 取余。出现三次的数在每一位贡献 0 或 3，都会消掉，余数就是唯一数在该位的值。用无符号形式提取 32 位，再把重建的二进制补码明确转换为对应有符号数。

C++ 主模板

class Solution {
    // 每一位的总计数对 3 取余，消掉出现三次的数。
public:
    int singleNumber(vector<int>& nums) {
        uint32_t answer = 0;
        for (int bit = 0; bit < 32; bit++) {
            int count = 0;
            for (int x : nums) count += (static_cast<uint32_t>(x) >> bit) & 1u;
            if (count % 3 != 0) answer |= uint32_t{1} << bit;
        }
        long long value = answer;
        if (answer & (uint32_t{1} << 31)) value -= (1LL << 32);
        return static_cast<int>(value);
    }
};

示例与复杂度

[2,2,3,2]：2 的各位贡献是 3 的倍数，取余后得到 3；[-2,-2,-2,-7] 同样得到 -7。

时间 O(32n)=O(n)，额外空间 O(1)。

易错点与一类题总结

最高符号位也要统计；不要写有符号 1<<31；普通异或只消掉偶数次，不能消掉三次。

除一个数外其余均出现固定 k 次时，可逐位计数对 k 取余，恢复唯一数。

201. 数字范围按位与

力扣原题

简短题意

给定非负整数 left、right，返回闭区间 [left,right] 内所有整数按位与的结果。

思路解析

区间中一旦某位发生过 0/1 变化，该位的与结果就是 0。结果只保留左右端点的公共二进制前缀。同步右移两端直到相等，记录移动位数，再把共同前缀移回高位，低位补零。

C++ 主模板

class Solution {
    // 同步右移找到公共前缀，再把低位补零。
public:
    int rangeBitwiseAnd(int left, int right) {
        int shift = 0;
        while (left < right) { left >>= 1; right >>= 1; shift++; }
        return static_cast<int>(static_cast<uint32_t>(left) << shift);
    }
};

示例与复杂度

5..7 为 101、110、111，公共前缀是 1，补回两位零得到 100，即 4。

固定 32 位下时间、空间 O(1)，最多移动 31 位。

易错点与一类题总结

区间长度很大，不能枚举所有数；left=right 返回自身，区间包含 0 则返回 0。

连续整数区间的位运算，关注公共高位前缀与低位变化范围。

目标：不是死记三个顺序，而是看见题目就能立刻反应出该怎么写、为什么这么写。

一、题型判断

这类题属于：

  • 二叉树遍历
  • 本质方法：DFS（深度优先搜索）
  • 常见考法：
  • 前序遍历
  • 中序遍历
  • 后序遍历
  • 层序遍历（这个是 BFS，和前三个不是一套）

看到题目出现这些字眼：

  • 前序
  • 中序
  • 后序
  • 遍历整棵树
  • 对每个节点都按某种固定顺序处理

就要马上想到：

这是二叉树遍历模板题，先想“根什么时候处理”。

二、先用一句话讲明白

二叉树遍历，本质就一件事：

对于每个节点，我都要处理三部分：左子树、当前节点、右子树。

三种遍历的区别，不在于你会不会递归，而在于：

当前节点是放在前面、中间，还是后面处理。

所以你只要盯住一个问题：

“根”是在左和右的前面，还是中间，还是后面？

三、为什么递归这么自然

因为树本身就是递归结构。

一个节点 root：

  • root->left 本身又是一棵树
  • root->right 本身又是一棵树

所以处理一棵树的方式就是：

  1. 先处理左边
  2. 再处理自己
  3. 再处理右边

或者换个顺序：

  1. 先处理自己
  2. 再处理左边
  3. 再处理右边

这就是前中后序的来源。

所以树遍历最标准的总模板永远是：

void dfs(TreeNode* node) {
    if (node == nullptr) return;

    // 在三个位置里选一个地方处理 node->val
}

四、一张图彻底记住三种遍历

假设树长这样：

      A
     / \
    B   C

你每次走到节点 A，其实会经历三个“时机”：

  1. 刚到 A
  2. 左子树处理完，准备去右子树之前
  3. 左右子树都处理完，准备离开 A

于是三种遍历本质就是：

1）前序遍历

在刚到当前节点时处理它。

顺序：

根 -> 左 -> 右

所以是：

A B C

2）中序遍历

在左子树处理完之后处理当前节点。

顺序：

左 -> 根 -> 右

所以是：

B A C

3）后序遍历

在左右子树都处理完之后处理当前节点。

顺序：

左 -> 右 -> 根

所以是：

B C A

五、真正好记的方法：不要背顺序，背“根放哪”

很多人记不住，是因为在背：

  • 前序：根左右
  • 中序：左根右
  • 后序：左右根

这样容易混。

更好记的方法是：

前序

根最先处理

中序

根夹在中间处理

后序

根最后处理

也就是：

  • 前序：根在前
  • 中序：根在中
  • 后序：根在后

这比硬背“根左右 / 左根右 / 左右根”更稳。

六、三种模板并排对照

1）前序遍历模板

void preorder(TreeNode* node, vector<int>& res) {
    if (node == nullptr) return;

    res.push_back(node->val);       // 根
    preorder(node->left, res);      // 左
    preorder(node->right, res);     // 右
}

口诀：

前序：一到节点先记自己。

2）中序遍历模板

void inorder(TreeNode* node, vector<int>& res) {
    if (node == nullptr) return;

    inorder(node->left, res);       // 左
    res.push_back(node->val);       // 根
    inorder(node->right, res);      // 右
}

口诀：

中序：左边看完，再看自己。

3）后序遍历模板

void postorder(TreeNode* node, vector<int>& res) {
    if (node == nullptr) return;

    postorder(node->left, res);     // 左
    postorder(node->right, res);    // 右
    res.push_back(node->val);       // 根
}

口诀：

后序：左右都完，最后记根。

七、三种模板怎么一口气写出来

推荐你脑子里固定成下面这一版：

void dfs(TreeNode* node, vector<int>& res) {
    if (node == nullptr) return;

    // 位置1：这里写，就是前序

    dfs(node->left, res);

    // 位置2：这里写，就是中序

    dfs(node->right, res);

    // 位置3：这里写，就是后序
}

你以后别把它当成三套代码。

你要把它理解成：

其实就是同一套代码，只是 res.push_back(node->val) 放的位置不同。

这一下就统一了。

八、为什么面试和题目里总爱考这三种

因为这三种遍历不是孤立知识点，而是很多树题的基础。

前序常见用途

  • 复制树
  • 序列化树
  • 输出“先看根再看孩子”的结构

识别信号：

题目强调“先处理当前节点，再处理子节点”。

中序常见用途

  • 二叉搜索树相关题
  • 判断 BST 是否有序
  • 输出从小到大的序列

识别信号：

题目和 BST（搜索树） 有关，大概率要想到中序。

因为 BST 的中序遍历结果天然有序。

后序常见用途

  • 先算左右子树，再汇总当前节点答案
  • 树的高度
  • 判断平衡树
  • 直径、路径和、子树信息汇总

识别信号：

当前节点答案依赖左右子树结果，就优先想后序。

因为你得先拿到左右子树答案，最后才能处理根。

九、一个核心升维：遍历顺序本质上决定“信息流方向”

这个点很重要。

前序

根先处理，信息从上往下传。

适合：

  • 路径记录
  • 参数传递
  • “父亲先决定，孩子再继续”

中序

根在中间，适合处理中间顺序关系。

最典型就是：

  • BST 有序输出

后序

左右先处理，信息从下往上汇总。

适合：

  • 子树高度
  • 子树节点数
  • 子树是否合法
  • 子树最值

所以很多“求某个树性质”的题，最后都会落到后序。

十、常见易错点

易错点 1：递归函数参数忘了传

比如你写：

void inorder(TreeNode* node, vector<int>& res)

那递归调用时必须写：

inorder(node->left, res);
inorder(node->right, res);

不能漏掉 res。

易错点 2：中序和后序总混

记法：

  • 中序：根在中间
  • 后序：根在最后

只盯“根在哪”，别死背整串顺序。

易错点 3：把层序遍历也当成 DFS

不是。

  • 前 / 中 / 后序：DFS
  • 层序遍历：BFS + 队列

它们不是同一套模板。

易错点 4：只会背遍历，不会判断什么时候用哪种

判断口诀：

  • 先处理根：前序
  • 中间处理根：中序
  • 最后处理根：后序
  • 一层一层扫：层序

十一、LeetCode 可直接提交的三份标准 C++ 模板

1）前序遍历

class Solution {
public:
    void preorder(TreeNode* node, vector<int>& res) {
        if (node == nullptr) return;

        res.push_back(node->val);
        preorder(node->left, res);
        preorder(node->right, res);
    }

    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> res;
        preorder(root, res);
        return res;
    }
};

2）中序遍历

class Solution {
public:
    void inorder(TreeNode* node, vector<int>& res) {
        if (node == nullptr) return;

        inorder(node->left, res);
        res.push_back(node->val);
        inorder(node->right, res);
    }

    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> res;
        inorder(root, res);
        return res;
    }
};

3）后序遍历

class Solution {
public:
    void postorder(TreeNode* node, vector<int>& res) {
        if (node == nullptr) return;

        postorder(node->left, res);
        postorder(node->right, res);
        res.push_back(node->val);
    }

    vector<int> postorderTraversal(TreeNode* root) {
        vector<int> res;
        postorder(root, res);
        return res;
    }
};

十二、复杂度分析

前序 / 中序 / 后序这三种递归遍历，复杂度都一样。

时间复杂度

O(n)

因为每个节点都会访问一次。

空间复杂度

O(h)

h 是树的高度，主要是递归栈空间。

最坏情况下树退化成链表，空间复杂度会变成：

O(n)

十三、记忆口诀

这一段最适合考前快速看一遍。

总口诀

二叉树遍历，只看根放哪。

分口诀

  • 前序：根在前，先记自己再递归
  • 中序：根在中，左边看完再看根
  • 后序：根在后，左右做完再汇总

判断用途口诀

  • 往下传信息，用前序
  • 看中间顺序，用中序
  • 向上汇总答案，用后序

十四、一类题总结

二叉树前中后序，不是三道题，而是一整类题的基础模型。

以后看到树题，你先不要急着写代码。

先问自己两个问题：

问题 1：当前节点的答案，依赖左右子树吗？

  • 如果依赖左右子树返回结果，优先想 后序
  • 如果是先处理自己再往下走，优先想 前序

问题 2：这题是否和 BST 的有序性有关？

  • 如果有关，优先想 中序

十五、最后压缩成复习版

题型

  • 二叉树遍历
  • DFS 模板题

核心思路

  • 树题递归本质：处理左子树、当前节点、右子树
  • 三种遍历的区别只是 根节点处理位置不同

三种顺序

  • 前序：根左 右
  • 中序：左根 右
  • 后序：左右 根

一眼识别

  • 先处理根：前序
  • 根在中间：中序
  • 先算左右再处理根：后序

口诀

二叉树遍历，只看根放哪。

通用模板

void dfs(TreeNode* node, vector<int>& res) {
    if (node == nullptr) return;

    // 这里放根：前序
    dfs(node->left, res);
    // 这里放根：中序
    dfs(node->right, res);
    // 这里放根：后序
}

一类题沉淀

  • 前序：适合从上往下传信息
  • 中序：适合 BST / 有序相关
  • 后序：适合从下往上汇总答案

十六、最短结论

如果你只想记一句：

前中后序不是三套东西，本质是同一个 DFS 模板里，根节点放的位置不同。

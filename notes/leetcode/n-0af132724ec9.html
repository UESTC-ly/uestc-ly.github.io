本笔记整理两类“路径依赖”回溯：

    1. 单词搜索：在二维网格中搜索一条不能重复使用格子的路径；
    1. 分割回文串：从左到右枚举切割位置，只保留回文子串。

总览：回溯算法专题

一、79. 单词搜索

1. 题意

给定字符网格 board 和字符串 word，判断能否通过上下左右相邻的格子依次拼出 word。

限制：

  1. 只能上下左右移动，不能斜着走；
  2. 同一个格子在一条搜索路径中不能重复使用；
  3. 单词可能从任意格子开始。

例如：

A B C E
S F C S
A D E E

ABCCED 可以按以下坐标找到：

(0,0) → (0,1) → (0,2) → (1,2) → (2,2) → (2,1)

2. 核心思路：枚举起点 + DFS + 回溯

定义：

dfs(board, word, row, col, index)

表示：

当前来到 (row, col)，尝试匹配 word[index] 以及后面的字符。

处理顺序：

1. 判断坐标是否越界；
2. 判断当前格子是否等于 word[index]；
3. 若已匹配最后一个字符，返回 true；
4. 临时标记当前格子已经使用；
5. 向上下左右匹配 index + 1；
6. 恢复当前格子。

3. 为什么要标记并恢复

同一个格子不能在当前路径中重复使用，因此进入后临时改成特殊字符：

char original = board[row][col];
board[row][col] = '#';

但该限制只针对当前路径，其他起点和其他分支仍然可以使用此格子，所以递归结束后必须恢复：

board[row][col] = original;

4. C++ 代码

class Solution {
private:
    int rows;
    int cols;

    bool dfs(vector<vector<char>>& board,
             const string& word,
             int row,
             int col,
             int index) {
        // 必须先判断越界，再访问 board[row][col]
        if (row < 0 || row >= rows ||
            col < 0 || col >= cols) {
            return false;
        }

        if (board[row][col] != word[index]) {
            return false;
        }

        // 当前字符已匹配，并且它就是最后一个字符
        if (index == word.size() - 1) {
            return true;
        }

        char original = board[row][col];
        board[row][col] = '#';

        bool found =
            dfs(board, word, row - 1, col, index + 1) ||
            dfs(board, word, row + 1, col, index + 1) ||
            dfs(board, word, row, col - 1, index + 1) ||
            dfs(board, word, row, col + 1, index + 1);

        // 即使某个方向成功，也要先恢复当前格子再返回
        board[row][col] = original;

        return found;
    }

public:
    bool exist(vector<vector<char>>& board, string word) {
        rows = board.size();
        cols = board[0].size();

        // 单词可能从任意格子开始
        for (int row = 0; row < rows; row++) {
            for (int col = 0; col < cols; col++) {
                if (dfs(board, word, row, col, 0)) {
                    return true;
                }
            }
        }

        return false;
    }
};

5. 本次代码纠错

越界条件必须使用 >=

原写法：

row > rows || col > cols

正确写法：

row >= rows || col >= cols

合法下标范围是：

行：0 ～ rows - 1
列：0 ～ cols - 1

因此 row == rows、col == cols 已经越界。

word 使用常量引用传递

推荐：

const string& word

避免每次 DFS 都复制字符串，同时保证函数不会修改它。

四个方向必须完整

row - 1, col  // 上
row + 1, col  // 下
row, col - 1  // 左
row, col + 1  // 右

6. 为什么不使用普通 DP

如果定义：

dp[index][row][col]

它只记录“当前位置和匹配下标”，没有记录当前路径已经使用了哪些格子。

反例：

网格：A B
单词：ABA

仅看位置转移，可能得到：

(0,0) → (0,1) → (0,0)

但这重复使用了第一个 A，正确答案应为 false。

相同的 (row, col, index)，如果历史路径使用过的格子不同，后续可走位置也不同。因此普通记忆化：

memo[row][col][index]

也不可靠。

理论上可以把访问集合加入状态：

位置 + index + usedMask

但若网格有 m × n 个格子，访问集合最多有 2^(m×n) 种，状态过大。DFS + 回溯只维护当前路径，更简单自然。

7. 复杂度

设网格为 m × n，单词长度为 L：

时间复杂度：O(m × n × 4^L)（易理解的上界）
额外空间复杂度：O(L)（递归深度）

由于不能立即走回已使用格子，后续分支数通常小于 4。

8. 记忆

枚举每个格子作为起点；当前格子匹配后临时标记，向四个方向搜索下一个字符，最后恢复。

二、131. 分割回文串

1. 题意

把字符串 s 分割成若干个连续子串，要求每个子串都是回文串，返回所有合法分割方案。

s = "aab"
答案：["a","a","b"]、["aa","b"]

2. 核心思路

使用 startIndex 表示当前未分割部分的起点，枚举当前子串的结束位置 end：

当前子串：s[startIndex...end]
下一段起点：end + 1

只有当前子串是回文串时，才加入 path 并继续递归。

完整答案的条件是：

startIndex == s.size()

表示整个字符串都已被切割完。

3. 回文判断

bool isPalindrome(const string& s, int left, int right) {
    while (left < right) {
        if (s[left] != s[right]) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

两端相等后必须移动指针，否则会死循环。

4. C++ 代码

class Solution {
private:
    vector<vector<string>> answer;
    vector<string> path;

    bool isPalindrome(const string& s, int left, int right) {
        while (left < right) {
            if (s[left] != s[right]) {
                return false;
            }

            left++;
            right--;
        }

        return true;
    }

    void backtrack(const string& s, int startIndex) {
        if (startIndex == s.size()) {
            answer.push_back(path);
            return;
        }

        // 枚举当前子串的结束位置
        for (int end = startIndex; end < s.size(); end++) {
            if (!isPalindrome(s, startIndex, end)) {
                continue;
            }

            // substr 的第二个参数是长度，不是结束下标
            path.push_back(
                s.substr(startIndex, end - startIndex + 1)
            );

            backtrack(s, end + 1);

            path.pop_back();
        }
    }

public:
    vector<vector<string>> partition(string s) {
        answer.clear();
        path.clear();

        backtrack(s, 0);
        return answer;
    }
};

5. 示例推演

s = "aab"

第一条路径：

"a" → "a" → "b"
startIndex：0 → 1 → 2 → 3
保存 ["a","a","b"]

第二条路径：

"aa" → "b"
startIndex：0 → 2 → 3
保存 ["aa","b"]

"aab" 不是回文串，因此对应分支被跳过。

6. 本次代码纠错

错误一：回文判断没有移动双指针

错误：

while (left < right) {
    if (s[left] != s[right]) {
        return false;
    }
    // 缺少 left++ 和 right--
}

修正：

left++;
right--;

否则判断 "aa" 时两端始终相等且指针不动，会无限循环。

错误二：终止条件比较了不同含义的长度

错误：

if (path.size() == s.size())
  • path.size()：已切出了几个子串；
  • s.size()：字符串有几个字符。

例如：

s = "aab"
path = ["aa","b"]

虽然整个字符串已经处理完，但 path.size() == 2、s.size() == 3。

正确条件：

if (startIndex == s.size())

错误三：非回文时不能 break

例如 s = "aba"：

"a"   是回文串
"ab"  不是回文串
"aba" 是回文串

较短子串不是回文串，不代表继续延长后也不是，因此要用 continue，不能用 break。

7. 复杂度

长度为 n 的字符串有 n - 1 个可能切割位置，每处都可以切或不切，搜索规模为指数级。当前实现还要逐次判断回文：

时间复杂度：可用 O(n² × 2^n) 表示宽松上界
额外空间复杂度：O(n)（不计返回结果）

8. 记忆

startIndex 表示当前段的起点，end 枚举当前段的终点；当前段是回文串才继续，startIndex == s.size() 时保存答案。

三、两题统一归纳

题目 路径是什么 如何防止非法路径 恢复什么
79. 单词搜索 网格中的坐标路径 越界、字符匹配、格子不可重复 被临时修改的网格字符
131. 分割回文串 从左到右选择的子串序列 当前子串必须为回文串 path 中最后一个子串

统一理解：

回溯不仅可以枚举数组元素，也可以枚举移动方向或字符串切割点。关键是只让合法状态进入下一层，并在返回时恢复当前路径造成的修改。

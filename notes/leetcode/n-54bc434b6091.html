53. 最大子数组和

简短题意

给定整数数组 nums，找出元素和最大的非空连续子数组，并返回这个最大和。子数组必须连续，且至少包含一个元素；数组全为负数时，也不能选择空数组。

  • 题型：动态规划（Kadane）
  • 核心状态：dp[i] 表示 以 nums[i] 结尾 的最大子数组和
  • 转移：
  • 自己重新开始：nums[i]
  • 接到前面后面：dp[i-1] + nums[i]
  • 所以：dp[i] = max(nums[i], dp[i-1] + nums[i])
  • 全局答案：所有 dp[i] 里的最大值
  • 空间优化：只依赖前一个状态，所以可用一个变量 cur 代替 dp[i]
  • 理解：前面有用就接，前面拖后腿就断掉重开
  • 口诀：定义“以当前位置结尾”的最优值

C++代码

class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int cur = nums[0]; // 以当前位置结尾的最大和
        int ans = nums[0]; // 全局最大值

        for (int i = 1; i < nums.size(); i++) {
            cur = max(nums[i], cur + nums[i]); // 前面有用就接，否则重开
            ans = max(ans, cur);
        }

        return ans;
    }
};

补充理解（合并区间）

  • intervals[i] = [starti, endi] 表示：第 i 个区间的左端点是 starti，右端点是 endi
  • 在 C++ 里通常是：vector<vector<int>> intervals
  • intervals[i][0]：当前区间左端点
  • intervals[i][1]：当前区间右端点

为什么 sort(intervals.begin(), intervals.end()) 能按左端点排序

因为 intervals 的每个元素是 vector<int>，而 vector<int> 默认按字典序比较： 1. 先比第 0 个元素 2. 如果相同，再比第 1 个元素

所以区间 [start, end] 排序时就变成：

先按左端点 start 排；左端点相同，再按右端点 end 排

一句话记忆：

vector<int> 默认按字典序比较，所以 [start, end] 会先按 start 排，再按 end 排

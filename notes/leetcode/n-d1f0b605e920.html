题目来源：牛客合唱队形
相关专题：动态规划专题

一、题意

有 n 位同学排成一列，每位同学有一个身高 h[i]。老师可以从队伍中删除一些同学，但必须满足：

删除后，剩下同学的相对顺序不能改变。

目标：

删除尽可能少的同学，使剩下的同学形成"先严格递增，再严格递减"的队形。

例如：

160 < 170 < 180 < 190 > 175 > 160

其中 190 是最高点，也叫"峰值"。

题目要求：

  • 峰值位置 i 满足 1 < i < k，即峰值左右都必须至少有一个同学；
  • 左侧部分严格递增；
  • 右侧部分严格递减。

二、问题转化：删除最少 = 保留最多

假设原来有 n 位同学，最后保留 k 位同学，那么删除数量就是：

\[ n - k \]

所以：

删除最少数量 = 保留最多数量

因此问题转化为：

在原数组中找一个最长的、保持原顺序的"先递增后递减"子序列。

这种子序列叫：

最长双调子序列，或者最长山峰子序列。

三、什么是子序列？

子序列和子数组不同。

例如原数组：

186 186 150 200 160 130 197 200

选择下标 1, 4, 5, 6 得到：

186 200 160 130

虽然删除了一些同学，但剩下的同学顺序没有改变，所以这是一个合法子序列。

不能把剩下的同学重新排序。

四、核心思路：枚举峰值 + 左右最长子序列

可以把一个合法队形拆成两部分：

左边：严格递增
右边：严格递减

假设第 i 位同学是最高点：

h[...] < ... < h[i] > ... > h[...]

我们需要计算：

  1. 以 i 结尾的最长严格递增子序列长度 left[i]；
  2. 以 i 开始的最长严格递减子序列长度 right[i]。

最后把两部分拼接起来：

\[ \text{以 }i\text{ 为峰值的队形长度} = left[i] + right[i] - 1 \]

其中 -1 是因为峰值 h[i] 被左右两部分各计算了一次。

五、状态一：最长递增子序列 left[i]

定义：

left[i]

表示：

在原数组的 0 ~ i 范围内，以第 i 位同学作为最后一个人时，最长严格递增子序列的长度。

状态转移：

left[i] = 1;  // 至少可以只选择自己

for (int j = 0; j < i; ++j) {
    if (height[j] < height[i]) {
        left[i] = max(left[i], left[j] + 1);
    }
}

含义：

如果 height[j] < height[i]，
那么可以把 height[i] 接到以 height[j] 结尾的递增序列后面。

注意必须使用严格小于 <，因为题目要求严格递增。

六、状态二：最长递减子序列 right[i]

定义：

right[i]

表示：

从第 i 位同学开始，向右选择同学，能够得到的最长严格递减子序列长度。

状态转移：

right[i] = 1;  // 至少可以只选择自己

for (int j = i + 1; j < n; ++j) {
    if (height[j] < height[i]) {
        right[i] = max(right[i], right[j] + 1);
    }
}

含义：

如果 height[j] < height[i]，
那么可以把 height[j] 接在 height[i] 后面，
形成严格递减序列。

为什么要从右往左计算？

right[i] 依赖后面的位置 right[j]（其中 j > i）。

因此计算 right[i] 时，后面的 right[j] 必须已经计算完成。

所以要：

for (int i = n - 1; i >= 0; --i)

也就是从右往左。

类似地：

  • left[i] 依赖前面的位置，所以从左往右；
  • right[i] 依赖后面的位置，所以从右往左。

七、合并左右两部分

假设第 i 位同学是峰值。

left[i]   // 包含峰值 height[i]
right[i]  // 也包含峰值 height[i]

如果直接相加：

left[i] + right[i]

峰值会被计算两次。

因此需要减去一次：

int length = left[i] + right[i] - 1;

这就是以 i 为峰值时，能够形成的队形长度。

八、峰值必须在中间

题目要求：

1 < i < k

也就是说，最高点的左边和右边都必须至少有一个同学。

因此峰值不能是队伍的第一个人，也不能是最后一个人。

在 C++ 的 0 下标中，峰值位置应该满足：

1 <= i <= n - 2

因此枚举峰值时：

for (int i = 1; i < n - 1; ++i)

九、完整 C++ 代码

#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<int> height(n);

    for (int i = 0; i < n; ++i) {
        cin >> height[i];
    }

    /*
        left[i]：
        以第 i 位同学结尾的最长严格递增子序列长度。
    */
    vector<int> left(n, 1);

    /*
        从左到右计算最长递增子序列。
    */
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < i; ++j) {
            /*
                如果前面的同学 h[j] 比当前同学 h[i] 矮，
                那么 h[i] 可以接在以 j 结尾的递增序列后面。
            */
            if (height[j] < height[i]) {
                left[i] = max(left[i], left[j] + 1);
            }
        }
    }

    /*
        right[i]：
        以第 i 位同学开头的最长严格递减子序列长度。
    */
    vector<int> right(n, 1);

    /*
        从右到左计算最长递减子序列。
    */
    for (int i = n - 1; i >= 0; --i) {
        for (int j = i + 1; j < n; ++j) {
            /*
                如果后面的同学 h[j] 比当前同学 h[i] 矮，
                那么 h[j] 可以接在 h[i] 后面，
                形成严格递减序列。
            */
            if (height[j] < height[i]) {
                right[i] = max(right[i], right[j] + 1);
            }
        }
    }

    int maxChoirLength = 0;

    /*
        枚举峰值位置。

        由于题目要求峰值左右都要有人，
        所以峰值不能在第一个或最后一个位置。
    */
    for (int i = 1; i < n - 1; ++i) {
        /*
            left[i] 和 right[i] 都包含 height[i]，
            所以合并时要减去 1。
        */
        int currentLength = left[i] + right[i] - 1;

        maxChoirLength = max(maxChoirLength, currentLength);
    }

    /*
        删除最少人数
        = 总人数 - 最多保留人数
    */
    cout << n - maxChoirLength << '\n';

    return 0;
}

十、示例推演

输入：

8
186 186 150 200 160 130 197 200

计算 left（最长递增长度）：

下标：  0    1    2    3    4    5    6    7
left：  1    1    1    2    2    1    3    4

计算 right（最长递减长度）：

下标：   0    1    2    3    4    5    6    7
right：  3    3    2    3    2    1    1    1

枚举峰值（下标 1 到 6）：

i = 1: left[1] + right[1] - 1 = 1 + 3 - 1 = 3
i = 2: left[2] + right[2] - 1 = 1 + 2 - 1 = 2
i = 3: left[3] + right[3] - 1 = 2 + 3 - 1 = 4
i = 4: left[4] + right[4] - 1 = 2 + 2 - 1 = 3
i = 5: left[5] + right[5] - 1 = 1 + 1 - 1 = 1
i = 6: left[6] + right[6] - 1 = 3 + 1 - 1 = 3

最大队形长度为 4。

最少删除人数：

8 - 4 = 4

输出：4。

可以保留的队形之一：

186, 200, 160, 130

十一、常见错误

1. 不能排序

不能将身高排序后再处理，因为题目要求：

不改变同学的相对位置。

所以只能在原数组中选择子序列。

2. 必须使用严格大小关系

递增部分：

height[j] < height[i]

递减部分：

height[j] < height[i]

不能写成 <=，因为相同身高不能构成严格递增或严格递减。

3. 合并时要减一

错误：

left[i] + right[i]

正确：

left[i] + right[i] - 1

因为峰值被左右两部分各计算了一次。

4. right 要从右往左计算

right[i] 表示从 i 开始向右的递减序列，依赖后面的 right[j]，因此要从右向左计算：

for (int i = n - 1; i >= 0; --i)

5. 变量未初始化

C++ 局部变量不初始化时值不确定：

错误：

int ans;

正确：

int ans = 0;

6. right[i] 更新时写错变量

错误：

right[i] = max(height[i], height[j] + 1);

这是在比较身高值，不是序列长度。

正确：

right[i] = max(right[i], right[j] + 1);

十二、复杂度分析

两次动态规划都是两层循环：

for (int i = 0; i < n; ++i) {
    for (int j = 0; j < i; ++j) {
        ...
    }
}

时间复杂度：

\[ O(n^2) \]

空间复杂度：

\[ O(n) \]

题目中 n <= 3000，因此 3000² = 9,000,000，可以正常通过。

十三、方法归纳

这道题的核心可以记成：

最长合唱队形 = 枚举峰值 + 左侧最长递增子序列 + 右侧最长递减子序列。

步骤：

原队伍
  ↓
求每个位置左侧的最长递增长度
  ↓
求每个位置右侧的最长递减长度
  ↓
枚举每个位置作为最高点
  ↓
left[i] + right[i] - 1
  ↓
取最大队形长度
  ↓
n - 最大队形长度

核心公式：

\[ \text{以 }i\text{ 为峰值的队形长度} = left[i] + right[i] - 1 \]

最终答案：

\[ \text{最少删除人数} = n - \max_i(left[i] + right[i] - 1) \]

一句话记忆：

双调子序列 = 最长递增 + 最长递减 - 峰值重复计数。

130. 被围绕的区域

力扣原题

简短题意

给定只含 X、O 的网格，将被 X 完全包围的 O 区域改成 X。四方向连通；与边界上的 O 连通的区域不会被包围，直接修改原网格。

思路解析

从边界 O 出发 BFS，将所有能通到边界的 O 标成 #。扫描全网格：未标记 O 是被围住的，改成 X；# 恢复成 O。反向寻找必定保留的区域，比逐块判断是否被包围更统一。

C++ 主模板

class Solution {
    // 先保留与边界连通的 O，再翻转剩余 O。
public:
    void solve(vector<vector<char>>& board) {
        if (board.empty()) return;
        int rows = board.size(), cols = board[0].size();
        queue<pair<int,int>> q;
        auto mark = [&](int r, int c) {
            if (board[r][c] == 'O') { board[r][c] = '#'; q.push({r,c}); }
        };
        for (int r = 0; r < rows; r++) { mark(r,0); mark(r,cols-1); }
        for (int c = 0; c < cols; c++) { mark(0,c); mark(rows-1,c); }
        int dr[4] = {-1,1,0,0}, dc[4] = {0,0,-1,1};
        while (!q.empty()) {
            auto [r,c] = q.front(); q.pop();
            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols) mark(nr,nc);
            }
        }
        for (auto& row : board) for (char& c : row) {
            if (c == 'O') c = 'X';
            else if (c == '#') c = 'O';
        }
    }
};

示例与复杂度

边界 (3,1) 的 O 保留；内部与边界不连通的 (1,1)、(1,2)、(2,2) 全改成 X。

时间 O(mn)，队列最坏空间 O(mn)。

易错点与一类题总结

入队立即标记，避免重复入队；单行或单列时所有 O 都连通边界，全部保留。

“不与边界相连”的区域问题可以反向从边界做多源搜索，再取未访问区域。

133. 克隆图

力扣原题

简短题意

给定连通无向图中一个节点 node，每节点有值和邻居列表，返回整张图的深拷贝。新图结构相同，但节点对象与原图独立；输入也可能为空。

思路解析

哈希表映射原节点地址到新节点。DFS 首次遇到原节点时，先创建副本并登记，再递归复制邻居。先登记才能在环中再次遇到节点时复用已创建副本，而不会无限递归。

C++ 主模板

class Solution {
    unordered_map<Node*, Node*> copied;
    Node* clone(Node* node) {
        if (node == nullptr) return nullptr;
        if (copied.count(node)) return copied[node];
        Node* result = new Node(node->val);
        copied[node] = result; // 在处理邻居之前登记，截断环
        for (Node* neighbor : node->neighbors) result->neighbors.push_back(clone(neighbor));
        return result;
    }
public:
    Node* cloneGraph(Node* node) { copied.clear(); return clone(node); }
};

示例与复杂度

1 与 2 互为邻居：先登记 1 的副本，再复制 2；从 2 回到 1 时直接使用已登记的副本。

平均时间 O(V+E)，映射与递归栈空间 O(V)，新图输出 O(V+E)。

易错点与一类题总结

不能只复制值或把原邻居指针接到新图；映射键应为原节点地址。Node 的 neighbors 定义由力扣提供。

含环结构的深拷贝：先建点并登记地址映射，再连边；随机链表复制也使用相同思想。

399. 除法求值

力扣原题

简短题意

给定若干等式 A/B=value 和查询 C/D，返回各查询结果。关系无法推导或变量未出现时返回 -1.0；已知输入没有矛盾。

思路解析

建立带权图：A→B 权值 value，B→A 权值 1/value。每次查询从 C 做 BFS，状态同时保存 C/当前节点的积。沿边相乘即可推导比值；先检查两个变量都存在，未知 x/x 也必须返回 -1。

C++ 主模板

class Solution {
    // 路径上的边权连乘，未知变量不能自动赋值为 1。
public:
    vector<double> calcEquation(vector<vector<string>>& equations, vector<double>& values,
                                vector<vector<string>>& queries) {
        unordered_map<string, vector<pair<string,double>>> graph;
        for (int i = 0; i < static_cast<int>(equations.size()); i++) {
            string a = equations[i][0], b = equations[i][1];
            graph[a].push_back({b,values[i]});
            graph[b].push_back({a,1.0 / values[i]});
        }
        vector<double> ans;
        for (const auto& query : queries) {
            string start = query[0], target = query[1];
            if (!graph.count(start) || !graph.count(target)) { ans.push_back(-1.0); continue; }
            queue<pair<string,double>> q; q.push({start,1.0});
            unordered_set<string> seen; seen.insert(start);
            double result = -1.0;
            while (!q.empty()) {
                auto [node,product] = q.front(); q.pop();
                if (node == target) { result = product; break; }
                for (const auto& [next,weight] : graph[node]) {
                    if (seen.insert(next).second) q.push({next,product * weight});
                }
            }
            ans.push_back(result);
        }
        return ans;
    }
};

示例与复杂度

a/b=2、b/c=3，则 a/c=6、b/a=0.5；已知 a/a=1，未知 x/x=-1。

忽略题目中固定长度变量名的字符串成本，平均时间 O(E+Q(V+E))，额外空间 O(V+E)，输出 O(Q)。

易错点与一类题总结

反向边必须取倒数；seen 每个查询独立；这不是带权最短路，权值表示乘法关系而非路径成本。

可传递的比值关系转为带权图，用沿路径连乘回答连通分量中的关系查询。

本笔记整理自本次会话中学习的 3 道 LeetCode 题： - 35. 搜索插入位置 - 34. 在排序数组中查找元素的第一个和最后一个位置 - 74. 搜索二维矩阵

核心主题：二分查找的边界写法、lower_bound / upper_bound 思想、二维矩阵中的二分搜索。

一、35. 搜索插入位置

1. 题意

给定一个严格升序数组 nums 和目标值 target：

  • 如果 target 存在，返回它的下标；
  • 如果不存在，返回它按顺序插入后的位置。

题目要求时间复杂度为 O(log n)，因此应使用二分查找。

2. 核心思路：找第一个 >= target 的位置

这题本质上不是“找某个值是否存在”，而是：

找到数组中第一个大于或等于 target 的位置。

为什么这样就够了？

  • 如果该位置上的值正好等于 target，它就是答案；
  • 如果该位置上的值大于 target，说明 target 应插入到这里；
  • 如果所有元素都小于 target，答案就是 nums.size()。

这正是 lower_bound 的思想。

3. 二分区间设计

使用左闭右开区间：

[left, right)

初始化：

int left = 0;
int right = nums.size();

循环条件：

while (left < right)

转移规则：

  • nums[mid] < target：答案在右边，left = mid + 1
  • nums[mid] >= target：mid 可能就是答案，right = mid

4. C++ 代码

class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size();

        while (left < right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        return left;
    }
};

5. 复杂度

时间复杂度：O(log n)
空间复杂度：O(1)

补充：闭区间写法与“相等为何不直接返回”

本次会话使用闭区间 [left, right] 检查尚未分类的元素；原有左闭右开模板也正确，保留原模板，不混用边界更新。

class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0;
        int right = static_cast<int>(nums.size()) - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return left;
    }
};

不变量：left 左边都小于 target，right 右边都大于等于 target。结束时 left == right + 1，两片已确定区域接起来，left 正是第一个大于等于 target 的位置；不存在时为 n。

相等已经包含在 else 中。 例如 [1,3,5,6] 查找 5：先将 left 更新为 2，再在 mid=2 命中相等时令 right=1，最终仍返回 left=2。排除 mid 的后续检查，不等于丢失分界位置；它已被归入右侧满足条件的区域。

如果只需要任意一个匹配位置，相等时可以直接返回；要保证找第一个匹配位置，就应继续向左收缩。时间 O(log n)，额外空间 O(1)。

6. 记忆

35 题本质：找第一个 >= target 的位置。

二、34. 在排序数组中查找元素的第一个和最后一个位置

1. 题意

给定一个按非递减顺序排列的数组 nums 和目标值 target，返回 target 的：

  • 第一个出现位置；
  • 最后一个出现位置。

如果不存在，返回 [-1, -1]。

题目要求时间复杂度为 O(log n)。

2. 核心思路：两次二分查找边界

普通二分查找只能保证“找到一个 target”，不能保证找到最左或最右。

这题要拆成两个边界问题：

  • 左边界：第一个 >= target 的位置；
  • 右边界：第一个 > target 的位置，再减 1。

也就是：

first = lowerBound(nums, target)
last  = upperBound(nums, target) - 1

3. lowerBound 与 upperBound 的区别

lowerBound(nums, target)

寻找第一个满足下面条件的位置：

nums[i] >= target

写法：

if (nums[mid] < target) {
    left = mid + 1;
} else {
    right = mid;
}

upperBound(nums, target)

寻找第一个满足下面条件的位置：

nums[i] > target

写法：

if (nums[mid] <= target) {
    left = mid + 1;
} else {
    right = mid;
}

可以这样记：

找第一个 >= target：跳过所有 <  target 的数
找第一个 >  target：跳过所有 <= target 的数

4. 本题最容易犯的错误

错误写法：

int last = upperBound(nums, target);
return {first, last};

错因：upperBound(nums, target) 返回的是“第一个大于 target 的位置”，不是“最后一个等于 target 的位置”。

正确写法：

int last = upperBound(nums, target) - 1;

例如：

nums = [5,7,7,8,8,10], target = 8
upperBound(nums, 8) = 5
最后一个 8 的位置 = 5 - 1 = 4

5. C++ 代码

class Solution {
private:
    int lowerBound(const vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size();

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }

    int upperBound(const vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size();

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] <= target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }

public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int first = lowerBound(nums, target);

        if (first == nums.size() || nums[first] != target) {
            return {-1, -1};
        }

        int last = upperBound(nums, target) - 1;
        return {first, last};
    }
};

补充：闭区间模板怎样找右端点

若沿用上面闭区间版本，两次二分均初始化 left=0, right=n-1，循环条件均为 left <= right，右移/左移仍使用 mid + 1 / mid - 1：

要找的分界 向右排除的条件 循环结束
第一个 >= target nums[mid] < target start = left
第一个 > target nums[mid] <= target end = left - 1

第一次二分后先检查 start == n || nums[start] != target，不存在就返回 {-1, -1}；短路求值也能保护空数组。第二次重新初始化搜索范围。

为什么 end 要减一已在上文示例解释：第二次 left 越过了所有等于 target 的位置。即使没有更大的值也成立，例如 [5,8,8] 查找 8，第二次 left=3，最后一个 8 的位置是 2。

不要找到一个 target 后再向两侧线性扫描，重复值很多时会退化为 O(n)。

6. 与 35 题的联系

35 题本质上就是：

lowerBound(nums, target)

34 题是在 35 题的基础上，再多找一个：

upperBound(nums, target)

7. 复杂度

时间复杂度：O(log n)
空间复杂度：O(1)

8. 记忆

左边界 = 第一个 >= target 的位置；右边界 = 第一个 > target 的位置减一。

三、74. 搜索二维矩阵

1. 题意

给定一个 m x n 的矩阵，满足：

  • 每一行从左到右非递减（允许相等）；
  • 每一行的第一个元素大于前一行的最后一个元素。

给定 target，判断它是否在矩阵中。

2. 核心思路一：把矩阵看成有序的一维数组

因为矩阵满足“行内递增 + 下一行整体接在上一行后面”，所以整个矩阵可以逻辑上看成一个升序数组。

例如：

1   3   5   7
10  11  16  20
23  30  34  60

可以看成：

[1,3,5,7,10,11,16,20,23,30,34,60]

此时直接对长度为 m * n 的“虚拟数组”做二分查找即可。

3. 一维下标如何映射回二维坐标

如果矩阵有 n 列，则一维下标 mid 对应：

int row = mid / n;
int col = mid % n;

然后访问：

matrix[row][col]

4. C++ 代码（虚拟一维数组）

class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        if (matrix.empty() || matrix[0].empty()) {
            return false;
        }

        int m = matrix.size();
        int n = matrix[0].size();
        int left = 0;
        int right = m * n - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            int row = mid / n;
            int col = mid % n;
            int value = matrix[row][col];

            if (value == target) {
                return true;
            } else if (value < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return false;
    }
};

5. 补充：不转化为一维数组，也可以做

如果不想记“下标映射”，也可以做两次二分：

  1. 先在所有行中二分，找到 target 可能所在的那一行；
  2. 再在该行中做普通二分查找。

判断某一行是否可能包含 target，只需看这一行的首尾：

matrix[midRow][0] <= target <= matrix[midRow][n - 1]

C++ 代码（两次二分）

class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        if (matrix.empty() || matrix[0].empty()) {
            return false;
        }

        int m = matrix.size();
        int n = matrix[0].size();

        int top = 0;
        int bottom = m - 1;
        int targetRow = -1;

        while (top <= bottom) {
            int midRow = top + (bottom - top) / 2;

            if (target < matrix[midRow][0]) {
                bottom = midRow - 1;
            } else if (target > matrix[midRow][n - 1]) {
                top = midRow + 1;
            } else {
                targetRow = midRow;
                break;
            }
        }

        if (targetRow == -1) {
            return false;
        }

        int left = 0;
        int right = n - 1;

        while (left <= right) {
            int midCol = left + (right - left) / 2;

            if (matrix[targetRow][midCol] == target) {
                return true;
            } else if (matrix[targetRow][midCol] < target) {
                left = midCol + 1;
            } else {
                right = midCol - 1;
            }
        }

        return false;
    }
};

6. 两种写法的关系

  • 虚拟一维数组：代码更统一，本质是对全部元素做一次二分；
  • 两次二分：更直观，先找行，再找列。

时间复杂度本质相同：

O(log(mn)) = O(log m + log n)

7. 记忆

74 题要先判断矩阵是否“整体有序”；若整体有序，可直接当成一维数组二分，或者先二分找行、再二分找列。

四、三道题的统一归纳

题目 本质 关键写法
35. 搜索插入位置 找第一个 >= target 的位置 lowerBound
34. 查找第一个和最后一个位置 找左边界 + 找右边界 lowerBound + upperBound - 1
74. 搜索二维矩阵 在整体有序结构中做二分 虚拟一维 / 两次二分

1. 常用边界模板

模板 A：找第一个 >= target

int left = 0;
int right = nums.size();

while (left < right) {
    int mid = left + (right - left) / 2;
    if (nums[mid] < target) {
        left = mid + 1;
    } else {
        right = mid;
    }
}

return left;

模板 B：找第一个 > target

int left = 0;
int right = nums.size();

while (left < right) {
    int mid = left + (right - left) / 2;
    if (nums[mid] <= target) {
        left = mid + 1;
    } else {
        right = mid;
    }
}

return left;

2. 做题自检

  1. 这题找的是“某个值”，还是“某个边界”？
  2. 当 nums[mid] == target 时，应该继续向左找，还是向右找？
  3. 用的是左闭右开区间 [left, right)，还是闭区间 [left, right]？
  4. upperBound 的返回值是否还需要减 1？
  5. 二维矩阵映射时，是否记住：row = mid / 列数，col = mid % 列数？

3. 一句话归纳

二分查找最重要的不是“会不会二分”，而是先想清楚：你到底在找哪个边界，遇到相等时应该把答案压向哪一边。

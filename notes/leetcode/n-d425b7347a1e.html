160. 相交链表

题目给两个单链表头节点 headA 和 headB，要求返回两个链表开始相交的节点；如果不相交，返回 nullptr。

注意：相交不是节点值相等，而是两个指针指向同一个内存节点。

pA == pB

才表示相交，不能用：

pA->val == pB->val

因为值相同的两个节点可能是不同节点。

核心思路是双指针走等长路。设链表 A 独有部分长度为 a，链表 B 独有部分长度为 b，公共部分长度为 c。

链表 A 长度：

a + c

链表 B 长度：

b + c

让两个指针同时走：

pA = headA
pB = headB

当 pA 走完 A，就去走 B；当 pB 走完 B，就去走 A：

pA 走过：a + c + b
pB 走过：b + c + a

总路程一样。如果相交，它们会在第一个公共节点相遇；如果不相交，它们会同时走到 nullptr。

代码：

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */

class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        ListNode* pA = headA;
        ListNode* pB = headB;

        while (pA != pB) {
            pA = pA == nullptr ? headB : pA->next;
            pB = pB == nullptr ? headA : pB->next;
        }

        return pA;
    }
};

循环结束有两种情况：

pA == pB == 相交节点

或者：

pA == pB == nullptr

所以直接返回：

return pA;

复杂度：

时间复杂度：O(m + n)
空间复杂度：O(1)

易错点：比较的是指针地址，不是节点值；不能修改链表结构；三目运算要先判断是否为空，不能在 nullptr 上访问 next；while (pA != pB) 最后可能在相交节点停止，也可能在 nullptr 停止。

记忆：

A 指针走完 A 去走 B
B 指针走完 B 去走 A
两人总路程一样，相交则相遇，不相交则同时为 null

模板：

while (pA != pB) {
    pA = pA ? pA->next : headB;
    pB = pB ? pB->next : headA;
}
return pA;

206. 反转链表

题目关键词

  • 单链表
  • 原地反转
  • 三指针
  • 链表指针修改

题意速记

给定单链表头节点 head，把链表整体反转，并返回反转后的新头节点。

例子：

1 -> 2 -> 3 -> 4 -> 5
反转后：
5 -> 4 -> 3 -> 2 -> 1

核心思路：三指针迭代

用三个指针边遍历边反转：

  • prev：已经反转部分的头节点，初始为 nullptr
  • cur：当前正在处理的节点
  • next：临时保存 cur->next，防止断链

每一轮固定四步：

ListNode* next = cur->next;
cur->next = prev;
prev = cur;
cur = next;

记忆口诀

先存后继，再反指向；
prev 跟上，cur 前进。

也就是：

存 next -> 改 next -> prev 前进 -> cur 前进

易错点

  1. 一定要先保存 next = cur->next，否则 cur->next = prev 后会丢失后面的链表。
  2. 循环结束条件是 cur == nullptr。
  3. 最后返回的是 prev，不是 head。
  4. 空链表和单节点链表都可以被同一套迭代逻辑自然处理。

C++ 代码：迭代写法

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* cur = head;

        while (cur != nullptr) {
            ListNode* next = cur->next; // 保存后继
            cur->next = prev;           // 反转指向
            prev = cur;                 // prev 前进
            cur = next;                 // cur 前进
        }

        return prev;
    }
};

模板追问：返回 prev，以及为什么必须保存原后继

prev 始终指向已反转部分的头，cur 指向未处理部分的头。反转 2 → 3 → 4 时：

已处理节点数 prev 指向的已反转部分 cur 指向
0 nullptr 2
1 2 → nullptr 3
2 3 → 2 → nullptr 4
3 4 → 3 → 2 → nullptr nullptr

结束时 prev 是新头 4，原 head 仍指向旧头 2（现在是尾），cur 为 nullptr，因此返回 prev。

本次代码错误：保存了 nextNode，却在改过连接后写 cur = cur->next。第一次反转时 cur->next 已改为 nullptr，这会让循环提前结束。

ListNode* nextNode = cur->next;
cur->next = prev;
prev = cur;
cur = nextNode; // 沿原后继前进，而不是沿改过的 next 前进

末尾节点仍是有效节点，读取其 next 只是得到 nullptr；只有 cur 本身为空时访问成员才非法。循环先判断 cur 非空即可。相关基础：C++基础。

此模板可独立为函数，供 反转链表 II（92） 和 链表进阶（2、25、138、148、146） 调用。

递归写法理解

先递归反转 head->next 后面的链表，再让后一个节点指回当前节点：

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (head == nullptr || head->next == nullptr) {
            return head;
        }

        ListNode* newHead = reverseList(head->next);
        head->next->next = head;
        head->next = nullptr;

        return newHead;
    }
};

复杂度

  • 时间复杂度：O(n)
  • 空间复杂度：
  • 迭代：O(1)
  • 递归：O(n)，递归调用栈

复习时重点看

  • 反转链表最常用模板就是四行：
next = cur->next;
cur->next = prev;
prev = cur;
cur = next;
  • 返回新头节点 prev。

234. 回文链表

题目关键词

  • 单链表
  • 回文判断
  • 快慢指针
  • 反转后半段
  • 双指针比较

题意速记

给定单链表头节点 head，判断链表中的值是否构成回文序列。

例子：

1 -> 2 -> 2 -> 1    true
1 -> 2              false

回文：从前往后读和从后往前读一样。

核心思路：快慢指针 + 反转后半段

链表不能从后往前遍历，所以把后半段链表反转，再和前半段逐个比较。

步骤：

  1. 用快慢指针找到链表中点。
  2. 从中点开始反转后半段。
  3. 用两个指针分别从 head 和反转后的后半段头节点开始比较。
  4. 只要后半段指针走完，且一路相等，就是回文链表。

快慢指针找中点

ListNode* slow = head;
ListNode* fast = head;

while (fast != nullptr && fast->next != nullptr) {
    slow = slow->next;
    fast = fast->next->next;
}

循环结束后：

  • 偶数长度：slow 在后半段第一个节点。
  • 奇数长度：slow 在中间节点。

奇数长度时，从中间节点开始反转也没问题，因为中间节点和自己比较，不影响结果。

反转后半段模板

直接复用反转链表四步：

ListNode* next = cur->next;
cur->next = prev;
prev = cur;
cur = next;

C++ 代码

class Solution {
public:
    bool isPalindrome(ListNode* head) {
        if (head == nullptr || head->next == nullptr) {
            return true;
        }

        // 1. 快慢指针找中点
        ListNode* slow = head;
        ListNode* fast = head;

        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }

        // 2. 反转后半段
        ListNode* secondHalf = reverseList(slow);

        // 3. 前半段和反转后的后半段逐个比较
        ListNode* p1 = head;
        ListNode* p2 = secondHalf;

        while (p2 != nullptr) {
            if (p1->val != p2->val) {
                return false;
            }
            p1 = p1->next;
            p2 = p2->next;
        }

        return true;
    }

private:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* cur = head;

        while (cur != nullptr) {
            ListNode* next = cur->next;
            cur->next = prev;
            prev = cur;
            cur = next;
        }

        return prev;
    }
};

复杂度

  • 时间复杂度：O(n)
  • 空间复杂度：O(1)

易错点

  1. 快慢指针条件写成：
while (fast != nullptr && fast->next != nullptr)

避免访问空指针。

  1. 比较时循环条件用 p2 != nullptr，因为只需要比较反转后的后半段长度。
  2. 最后判断成功后返回 true。
  3. 这份代码没有恢复链表结构；LeetCode 通常不要求。如果面试官要求，可以比较完后再把后半段反转回来。

记忆口诀

快慢找中点，
反转后半边，
两头一起比，
不同就 false。

复习时重点看

这题是两个模板组合：

  1. 快慢指针找链表中点。
  2. 反转链表。

核心代码骨架：

// 找中点
while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;
}

// 反转 slow 后面的链表
ListNode* secondHalf = reverseList(slow);

// 比较
while (secondHalf) {
    if (head->val != secondHalf->val) return false;
    head = head->next;
    secondHalf = secondHalf->next;
}
return true;

141. 环形链表

题目关键词

  • 单链表
  • 判断是否有环
  • 快慢指针
  • Floyd 判圈算法
  • 龟兔赛跑

题意速记

给定单链表头节点 head，判断链表中是否存在环。

如果某个节点的 next 指针指向链表前面的某个节点，就形成了环。

例子：

3 -> 2 -> 0 -> -4
     ^         |
     |_________|

这里 -4 指回节点 2，所以返回 true。

注意：题目里的 pos 只是 LeetCode 内部用来描述尾节点连接到哪里，不会作为函数参数传入。

核心思路：快慢指针

使用两个指针：

  • slow：每次走 1 步
  • fast：每次走 2 步

判断逻辑：

  • 如果无环，fast 会先走到 nullptr。
  • 如果有环，fast 和 slow 进入环后，fast 每轮都会比 slow 多走一步，最终一定会追上 slow。

一旦出现：

slow == fast

说明链表有环。

为什么一定会相遇

把环想象成操场：

  • slow 是乌龟，每次走一步。
  • fast 是兔子，每次走两步。

进入环后，兔子每轮比乌龟多走一步，相对距离不断缩小，所以一定会在环中相遇。

C++ 代码

class Solution {
public:
    bool hasCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;

        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;

            if (slow == fast) {
                return true;
            }
        }

        return false;
    }
};

复杂度

  • 时间复杂度：O(n)
  • 空间复杂度：O(1)

易错点

  1. 判断是否相遇时，比较的是节点地址，不是节点值：
if (slow == fast)

不要写成：

if (slow->val == fast->val)

因为链表中可能有重复值。

  1. 循环条件必须防止空指针：
while (fast != nullptr && fast->next != nullptr)

因为后面要执行：

fast = fast->next->next;
  1. pos 不作为参数传入，函数签名通常是：
bool hasCycle(ListNode *head)
  1. 可以不单独特判空链表或单节点链表，循环条件会自然处理。

记忆口诀

慢走一步，快走两步；
无环快到空，有环必相逢。

复习时重点看

快慢指针判环模板：

ListNode* slow = head;
ListNode* fast = head;

while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;

    if (slow == fast) return true;
}

return false;

这类题的本质：

链表是否有环 = 快慢指针是否会在链表内部相遇。

142. 环形链表 II

题目关键词

  • 单链表
  • 找入环点
  • 快慢指针
  • Floyd 判圈算法
  • 二次相遇

题意速记

给定单链表头节点 head，如果链表中有环，返回链表开始入环的第一个节点；如果无环，返回 nullptr。

例子：

3 -> 2 -> 0 -> -4
     ^         |
     |_________|

尾节点 -4 指回节点 2，所以入环点是节点 2。

注意：题目里的 pos 只是 LeetCode 内部用来构造链表，不作为参数传入。

和 141. 环形链表的区别

  • 141：只判断有没有环，返回 true / false。
  • 142：不仅要判断有环，还要返回入环的第一个节点。

核心思路：快慢指针 + 二次相遇

分两步：

  1. 用快慢指针判断是否有环，并找到第一次相遇点。
  2. 如果有环，让一个指针从 head 出发，另一个指针从第一次相遇点出发，它们都每次走一步，最终相遇的位置就是入环点。

为什么二次相遇点是入环点

设：

head 到入环点距离 = a
入环点到第一次相遇点距离 = b
第一次相遇点回到入环点距离 = c

链表结构：

head ---- a ---- 入环点 ---- b ---- 相遇点
                         ^          |
                         |---- c ---|

第一次相遇时：

slow 走了：a + b
fast 走了：a + b + k(b + c)

因为 fast 速度是 slow 的 2 倍：

a + b + k(b + c) = 2(a + b)

整理得到：

a = (k - 1)(b + c) + c

含义：

  • 从 head 走 a 步到入环点。
  • 从第一次相遇点继续走 c 步，也能到入环点；多绕几圈仍然到入环点。

所以从 head 和第一次相遇点同时每次走一步，最终会在入环点相遇。

C++ 代码

class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;

        // 1. 快慢指针找第一次相遇点
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;

            if (slow == fast) {
                // 2. 一个从 head 出发，一个从相遇点出发
                ListNode* p1 = head;
                ListNode* p2 = slow;

                while (p1 != p2) {
                    p1 = p1->next;
                    p2 = p2->next;
                }

                return p1; // 入环点
            }
        }

        return nullptr; // 无环
    }
};

复杂度

  • 时间复杂度：O(n)
  • 空间复杂度：O(1)

易错点

  1. slow 和 fast 一定要初始化：
ListNode* slow = head;
ListNode* fast = head;

不要只声明不赋值：

ListNode* slow;
ListNode* fast;

这样会产生野指针，后面执行：

while (fast && fast->next)

就是未定义行为，可能崩溃或结果随机。

  1. 第一次相遇判断比较的是节点地址：
if (slow == fast)

不是比较节点值。

  1. 第二阶段两个指针都每次走一步，不要再让 fast 走两步：
p1 = p1->next;
p2 = p2->next;
  1. 如果无环，快指针会走到空，最后返回：
return nullptr;
  1. 题目要求不修改链表，本解法只移动指针，不改变 next。

记忆口诀

先快慢相遇，
再头遇相遇；
二次相遇点，
就是入环口。

复习时重点看

模板核心：

ListNode* slow = head;
ListNode* fast = head;

while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;

    if (slow == fast) {
        ListNode* p1 = head;
        ListNode* p2 = slow;

        while (p1 != p2) {
            p1 = p1->next;
            p2 = p2->next;
        }

        return p1;
    }
}

return nullptr;

本次代码审查记忆点

你写的主体逻辑是对的，但出现了一个高频 C++ 指针错误：

ListNode* slow;
ListNode* fast;

必须改成：

ListNode* slow = head;
ListNode* fast = head;

链表题里的指针只声明不初始化，几乎一定会出错。

21. 合并两个有序链表

题目关键词

  • 单链表
  • 两个升序链表
  • 双指针
  • 虚拟头节点 dummy
  • 归并思想

题意速记

给定两个升序链表 list1 和 list2，把它们合并成一个新的升序链表，并返回合并后的头节点。

例子：

list1 = 1 -> 2 -> 4
list2 = 1 -> 3 -> 4

合并后：
1 -> 1 -> 2 -> 3 -> 4 -> 4

核心思路：双指针 + 虚拟头节点

两个链表本身已经有序，所以每次比较当前两个节点：

list1->val
list2->val

谁更小，就把谁接到结果链表后面。

使用虚拟头节点 dummy 可以避免单独处理结果链表第一个节点。

ListNode dummy(0);
ListNode* cur = &dummy;

含义：

  • dummy：虚拟头节点，不是真正答案的一部分。
  • cur：始终指向结果链表的尾节点。
  • 最后返回：dummy.next。

合并模板

每轮固定做三件事：

  1. 比较 list1->val 和 list2->val。
  2. 把较小节点接到 cur->next。
  3. 接谁，谁前进；cur 也前进。
if (list1->val <= list2->val) {
    cur->next = list1;
    list1 = list1->next;
} else {
    cur->next = list2;
    list2 = list2->next;
}
cur = cur->next;

循环结束后，至少有一个链表为空，直接接上剩余链表：

cur->next = list1 != nullptr ? list1 : list2;

C++ 代码：推荐迭代写法

class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode dummy(0);
        ListNode* cur = &dummy;

        while (list1 != nullptr && list2 != nullptr) {
            if (list1->val <= list2->val) {
                cur->next = list1;
                list1 = list1->next;
            } else {
                cur->next = list2;
                list2 = list2->next;
            }

            cur = cur->next;
        }

        cur->next = list1 != nullptr ? list1 : list2;

        return dummy.next;
    }
};

C++ 代码：递归写法

递归含义：较小节点作为当前头节点，后面接两个剩余链表的合并结果。

class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        if (list1 == nullptr) return list2;
        if (list2 == nullptr) return list1;

        if (list1->val <= list2->val) {
            list1->next = mergeTwoLists(list1->next, list2);
            return list1;
        } else {
            list2->next = mergeTwoLists(list1, list2->next);
            return list2;
        }
    }
};

复杂度

设两个链表长度分别为 m 和 n：

  • 时间复杂度：O(m + n)
  • 空间复杂度：
  • 迭代：O(1)
  • 递归：O(m + n)，递归调用栈

易错点

  1. 接上哪个链表的节点，哪个链表指针就必须前进：
cur->next = list1;
list1 = list1->next;

或者：

cur->next = list2;
list2 = list2->next;
  1. cur 也要前进：
cur = cur->next;
  1. 循环结束后不要忘记接剩余链表：
cur->next = list1 ? list1 : list2;
  1. 推荐用栈上虚拟头节点：
ListNode dummy(0);
ListNode* cur = &dummy;

比 new ListNode(0) 更简单，不用手动 delete。

本次代码审查记忆点：为什么会 TLE

错误代码的核心问题是：接了节点，但没有移动 list1 或 list2。

错误写法：

if (list1->val <= list2->val) {
    cur->next = list1;
} else {
    cur->next = list2;
}
cur = cur->next;

少了：

list1 = list1->next;
// 或
list2 = list2->next;

后果：

  1. list1 / list2 不前进，while (list1 && list2) 可能永远不结束。
  2. 更严重时，如果连续选择同一个节点，可能执行出类似：
cur->next = cur;

形成自环，导致死循环或 TLE。

记忆口诀

两个指针比大小，
小的接到 dummy 后；
接谁谁前进，
尾指针也前进；
谁剩下整体接上。

复习时重点看

核心模板：

ListNode dummy(0);
ListNode* cur = &dummy;

while (list1 && list2) {
    if (list1->val <= list2->val) {
        cur->next = list1;
        list1 = list1->next;
    } else {
        cur->next = list2;
        list2 = list2->next;
    }
    cur = cur->next;
}

cur->next = list1 ? list1 : list2;
return dummy.next;

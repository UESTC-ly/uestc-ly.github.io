双指针

151. 反转字符串中的单词

题型与核心思路

字符串分词：提取单词 → 倒序遍历 → 单空格连接。

反转的是单词顺序，单词内部字符保持不变；结果首尾没有空格，单词之间只有一个空格。

输入："  hello   world  "
提取：["hello", "world"]
输出："world hello"

主解法：字符串流分词

stringstream ss(s) 将字符串作为输入流；ss >> word 每次跳过空白并读取一个单词，读不到时循环结束。前导、尾部及连续空格自然被跳过。

拼接规则：第一个单词直接放，后续单词先放空格再放内容。 不需要最后删除空格。

class Solution {
public:
    string reverseWords(string s) {
        stringstream ss(s);
        string word;
        vector<string> words;
        while (ss >> word) {
            words.push_back(word);
        }

        string ans;
        for (int i = static_cast<int>(words.size()) - 1; i >= 0; i--) {
            if (!ans.empty()) {
                ans += ' ';
            }
            ans += words[i];
        }
        return ans;
    }
};

本地编译需要 <sstream>、<string>、<vector>，并使用 std:: 或 using namespace std;。

手写分词：双指针边界模板

用于理解分词过程，也用于不能直接按空白读取的场景：

  1. left 跳过空格，定位单词起点。
  2. right 扫过非空格字符，停在单词后一个位置。
  3. 提取 [left, right)，长度为 right - left。
  4. 令 left = right，继续寻找下一个单词。
class Solution {
public:
    string reverseWords(string s) {
        vector<string> words;
        int n = s.size();
        int left = 0;

        while (left < n) {
            while (left < n && s[left] == ' ') {
                left++;
            }
            if (left == n) {
                break;
            }

            int right = left;
            while (right < n && s[right] != ' ') {
                right++;
            }
            words.push_back(s.substr(left, right - left));
            left = right;
        }

        string ans;
        for (int i = static_cast<int>(words.size()) - 1; i >= 0; i--) {
            if (!ans.empty()) {
                ans += ' ';
            }
            ans += words[i];
        }
        return ans;
    }
};

例如 " hello world "，第一个单词的 left = 2、right = 7，提取 substr(2, 5) 得到 "hello"。最后一个单词后即使没有空格，right 也会走到 n，仍然能完整提取。

正确性与复杂度

分词保留所有单词和内部字符顺序；倒序遍历颠倒单词顺序；仅在已有结果后补空格，保证空格只出现在两个单词之间。

两种写法时间均为 O(n)，额外空间均为 O(n)，结果空间为 O(n)。双指针扫描不会反复从头查找，所有单词提取和拼接的总字符数为 O(n)。

本次代码中的易错点

原写法或逻辑 问题 正确处理
temp.push_back(起始迭代器, 结束迭代器) string::push_back 只接受一个字符 用 substr(left, 长度) 提取子串
temp.reverse() string 没有该成员方法，且本题无需反转单词内部 保留单词内容，倒序遍历单词数组
ans.push_back(temp) 不能用它拼接整个字符串 ans += temp
只在遇到空格时处理单词 末尾没有空格时漏掉最后一个单词 扫描到空格或 n 都结束当前单词
不跳过连续空格 把空白间隔当作单词，可能产生 right < left 先跳过空格，再找单词
ans.pop() string 没有 pop() 非空时可用 pop_back()；本题用条件加空格避免删除

迭代器区间为左闭右开。如果 right 表示最后一个字符，结束迭代器应为 s.begin() + right + 1。本题统一让 right 表示单词后的位置，更容易计算长度。

一类题总结

  • 拆分 → 处理 → 拼接：片段可以是单词或其他有意义的单位，处理可以是倒序、排序或筛选。
  • 手写分段扫描：跳过分隔符 → 标记起点 → 扫到片段末尾 → 提取 [left, right) → 继续扫描。
  • 统一分隔符拼接：结果非空时先补分隔符，再补当前元素。
  • stringstream >> word 按空白分词；逗号分隔或需要保留原始空格时，应调整拆分方式。

记忆口诀：先拆单词再倒序，非空结果先补空格。

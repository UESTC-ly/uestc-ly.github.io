总览：二叉树专题｜基础：二叉树遍历基础（94、102）

一、二叉树递归的统一模型

递归处理二叉树时，先明确辅助函数的含义：

这个函数接收哪个节点？
它要完成什么任务？
它向父节点返回什么信息？
空节点应该返回什么？

常见后序递归框架：

ReturnType dfs(TreeNode* root) {
    if (root == nullptr) {
        return 空节点结果;
    }

    ReturnType leftResult = dfs(root->left);
    ReturnType rightResult = dfs(root->right);

    // 左右子树处理完后，计算当前节点
    return 当前结果;
}

二、104. 二叉树的最大深度

1. 题意

二叉树的最大深度是从根节点到最远叶子节点的最长路径上的节点数。

空树深度 = 0
只有根节点的树，深度 = 1

示例：

       3
      / \
     9   20
        /  \
       15   7

最长路径为 3 → 20 → 15 或 3 → 20 → 7，包含 3 个节点，因此最大深度为 3。

2. 核心思路

先递归得到左右子树的最大深度：

int leftDepth = maxDepth(root->left);
int rightDepth = maxDepth(root->right);

当前树的最大深度为：

max(leftDepth, rightDepth) + 1

其中 +1 表示加上当前节点这一层。

3. C++ 代码

class Solution {
public:
    int maxDepth(TreeNode* root) {
        // 空树的深度为 0
        if (root == nullptr) {
            return 0;
        }

        int leftDepth = maxDepth(root->left);
        int rightDepth = maxDepth(root->right);

        // 更深的子树加上当前节点
        return max(leftDepth, rightDepth) + 1;
    }
};

4. 复杂度

设节点数为 n、树高为 h：

  • 时间复杂度：O(n)；
  • 递归栈空间：O(h)，最坏为 O(n)。

5. 记忆

当前树最大深度 = 左右子树深度的较大值 + 当前这一层

三、226. 翻转二叉树

1. 题意

翻转二叉树，就是对树中的每一个节点交换左右子树，并返回翻转后的根节点。

示例：

翻转前：              翻转后：
        4                    4
      /   \                /   \
     2     7              7     2
    / \   / \            / \   / \
   1   3 6   9          9   6 3   1

不能只交换根节点的两个孩子，所有节点都要递归处理。

2. 核心思路

对于当前非空节点：

  1. 交换它的左右孩子；
  2. 递归翻转交换后的左子树；
  3. 递归翻转交换后的右子树；
  4. 返回当前根节点。

节点本身没有被重新创建，只修改了 left 和 right 指针，所以最后仍返回原来的 root。

3. C++ 代码

class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) {
            return nullptr;
        }

        // 修改当前节点的左右结构
        swap(root->left, root->right);

        // 继续翻转两棵子树
        invertTree(root->left);
        invertTree(root->right);

        return root;
    }
};

也可以先递归翻转原来的两棵子树，再重新连接：

TreeNode* invertedLeft = invertTree(root->left);
TreeNode* invertedRight = invertTree(root->right);
root->left = invertedRight;
root->right = invertedLeft;

两种写法都正确。

4. 复杂度

  • 时间复杂度：O(n)，每个节点交换一次；
  • 递归栈空间：O(h)。

5. 记忆

翻转二叉树 = 每个节点都交换左右孩子

翻转两次会恢复成原来的二叉树。

四、101. 对称二叉树

1. 题意

判断一棵二叉树是否关于根节点所在的中轴线左右对称。

本质是判断：

根节点的左子树和右子树是否互为镜像

示例：

        1
      /   \
     2     2
    / \   / \
   3   4 4   3

外侧的 3 对应 3，内侧的 4 对应 4，所以返回 true。

2. 递归函数含义

定义：

bool isMirror(TreeNode* left, TreeNode* right)

表示判断以 left、right 为根的两棵树是否互为镜像。

空节点和节点值的判断顺序：

  1. 两个节点都为空：当前位置对称，返回 true；
  2. 只有一个为空：结构不对称，返回 false；
  3. 两个节点值不同：返回 false；
  4. 当前值相同：继续交叉比较下一层。

3. 为什么要交叉比较

镜像位置是：

left 的左孩子  ↔ right 的右孩子（外侧）
left 的右孩子  ↔ right 的左孩子（内侧）

因此递归条件是：

isMirror(left->left, right->right) &&
isMirror(left->right, right->left)

如果按“左对左、右对右”比较，判断的是结构相同，而不是镜像对称。

4. C++ 代码

class Solution {
private:
    bool isMirror(TreeNode* left, TreeNode* right) {
        // 两个位置都没有节点，仍然对称
        if (left == nullptr && right == nullptr) {
            return true;
        }

        // 只有一个位置有节点，结构不对称
        if (left == nullptr || right == nullptr) {
            return false;
        }

        // 镜像位置的值必须相等
        if (left->val != right->val) {
            return false;
        }

        // 外侧对外侧，内侧对内侧
        return isMirror(left->left, right->right) &&
               isMirror(left->right, right->left);
    }

public:
    bool isSymmetric(TreeNode* root) {
        if (root == nullptr) {
            return true;
        }

        return isMirror(root->left, root->right);
    }
};

5. 复杂度

  • 时间复杂度：O(n)；
  • 递归栈空间：O(h)。

6. 记忆

对称二叉树：外侧对外侧，内侧对内侧。

五、543. 二叉树的直径

1. 题意

二叉树的直径是树中任意两个节点之间最长路径的长度，并且长度按边数计算。

需要注意：最长路径可能经过根节点，也可能完全位于某棵子树中。

例如：

        1
       / \
      2   3
     / \
    4   5

最长路径可以是：

4 → 2 → 1 → 3

共有 4 个节点、3 条边，所以直径是 3。

2. 核心思路：求深度时更新直径

定义：

int getDepth(TreeNode* root)

它向父节点返回以 root 为根的子树最大深度。

假设：

int leftDepth = getDepth(root->left);
int rightDepth = getDepth(root->right);

那么经过当前节点的候选直径是：

leftDepth + rightDepth

当前子树向父节点返回的深度是：

max(leftDepth, rightDepth) + 1

这里必须区分两种信息：

递归返回值：当前子树的最大深度；
全局答案：遍历中遇到的最大直径。

3. 为什么直径不加 1

辅助函数返回的深度按子树中的节点数计算。对于当前节点：

  • 左子树深度恰好等于当前节点走到左侧最深节点的边数；
  • 右子树深度恰好等于当前节点走到右侧最深节点的边数。

两段相加就是路径的边数，因此：

leftDepth + rightDepth

不需要再加当前节点。

4. 为什么每个节点都要更新答案

最长路径不一定经过整棵树的根节点，但一定存在一个路径中位置最高的“转折节点”。

枚举每个节点作为转折点，并执行：

answer = max(answer, leftDepth + rightDepth);

就不会漏掉真正的直径。

5. 示例推演

对于：

        1
       / \
      2   3
     / \
    4   5
  • 叶子 4、5、3 返回深度 1；
  • 节点 2：候选直径 1 + 1 = 2，返回深度 2；
  • 节点 1：候选直径 2 + 1 = 3，返回深度 3；
  • 全局最大直径为 3。

6. C++ 代码

class Solution {
private:
    int answer = 0;

    // 返回当前子树的最大深度
    int getDepth(TreeNode* root) {
        if (root == nullptr) {
            return 0;
        }

        int leftDepth = getDepth(root->left);
        int rightDepth = getDepth(root->right);

        // 当前节点作为路径最高转折点时的候选直径
        answer = max(answer, leftDepth + rightDepth);

        // 向父节点返回当前子树的最大深度
        return max(leftDepth, rightDepth) + 1;
    }

public:
    int diameterOfBinaryTree(TreeNode* root) {
        answer = 0;
        getDepth(root);
        return answer;
    }
};

7. 复杂度

  • 时间复杂度：O(n)；
  • 递归栈空间：O(h)。

8. 记忆

向上返回最大深度；
遍历过程中，用左深度 + 右深度更新直径。

六、四道题的统一归纳

题目 递归函数负责什么 当前节点如何处理 返回值

设计递归时最重要的不是先背代码，而是先说清楚：

函数返回什么？
父节点为什么需要这个返回值？
当前节点应当怎样组合左右子树的信息？

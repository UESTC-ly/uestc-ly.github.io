56. 合并区间

简短题意

给定若干闭区间 intervals，其中每个区间为 [start, end]。合并所有重叠区间，返回一组互不重叠、覆盖范围与原区间集合相同的区间；共享端点也算重叠。

题型与核心思路

排序 + 区间扫描。共享端点也要合并，例如 [1,4] 和 [4,5] 合并为 [1,5]。

先按左端点排序，使可能重叠的区间集中到一起。随后只需要比较当前区间与答案中的最后一个区间：

  • 当前左端点大于最后区间的右端点：不重叠，加入新段。
  • 否则：重叠，保留最后区间的左端点，右端点取两者最大值。

intervals 的类型是 vector<vector<int>>。默认 sort 按字典序比较：先比较 [0] 左端点，相同再比较 [1] 右端点，符合这里的排序要求。原来的表示与排序说明保留在 最大子数组和（53）。

C++ 主模板

class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end()); // 按左端点升序
        vector<vector<int>> ans;

        for (const auto& interval : intervals) {
            if (ans.empty() || interval[0] > ans.back()[1]) {
                ans.push_back(interval); // 与最后一段不重叠
            } else {
                // 重叠或包含：右端点只能扩张，不能缩小
                ans.back()[1] = max(ans.back()[1], interval[1]);
            }
        }
        return ans;
    }
};

示例与正确性

[[1,3],[2,6],[8,10],[15,18]]：先加入 [1,3]；遇到 [2,6]，因为 2<=3，更新为 [1,6]；8>6，加入 [8,10]；最后加入 [15,18]。

扫描过程中，答案始终表示“已经处理的区间合并后的结果”，且按左端点有序、互不重叠。当前区间的左端点不会小于已处理区间的左端点，所以只能与最后一段发生合并；更早的段已经结束。按是否重叠处理，就能维持这个性质。

复杂度与易错点

  • 排序时间 O(n log n)，扫描时间 O(n)；std::sort 的辅助空间通常为 O(log n)，输出空间 O(n)。
  • 右端点必须取 max。[1,10] 包含 [2,3] 时，不能把右端点改成 3。
  • 不重叠判断用 >，不能用 >=，共享端点也要合并。
  • 原输入无序，要先排序；该代码会修改原数组的排列顺序。
  • 一个区间原样返回；多个相同区间会合并成一个；空数组也能返回空结果。

一类题总结

识别信号：无序区间集合，需要按重叠关系归并。先排序，再维护当前合并段，比较新起点与当前终点。插入区间（57） 的原区间已经有序且互不重叠，可以直接分段扫描。

口诀：起点先排序，不交另开段，相交扩右端。

滑动窗口

76. 最小覆盖子串

简短题意

给定字符串 s 和 t，返回 s 中覆盖 t 所有字符的最短连续子串。重复字符也必须达到 t 要求的次数，且区分大小写；没有合法子串时返回空字符串。

题型与核心思路

可变长度滑动窗口 + 字符计数。

右指针向右扩展直到覆盖 t；覆盖成立后，左指针不断右移，尝试缩短窗口；覆盖失效时，再继续扩展右侧。

状态和更新条件

变量 含义
need[c] t 需要字符 c 的次数
window[c] 当前窗口包含字符 c 的次数
required t 中不同字符的种类数
formed 当前窗口次数已经达标的所需字符种类数
bestStart、bestLen 已找到的最短合法窗口

formed == required 表示覆盖成立。formed 数的是种类，不是字符总数。

加入字符 c 时，仅当它是所需字符，且次数刚好达到 need[c]，才将 formed 加一。移除所需字符 d 时，次数降到 need[d] 以下，才将 formed 减一。多余的重复字符不会增加已达标种类数。

C++ 主模板

class Solution {
public:
    string minWindow(string s, string t) {
        if (t.empty()) return "";

        unordered_map<char, int> need;
        unordered_map<char, int> window;
        for (char c : t) need[c]++;

        int required = need.size();
        int formed = 0;
        int left = 0;
        int bestStart = 0;
        int bestLen = static_cast<int>(s.size()) + 1;

        for (int right = 0; right < static_cast<int>(s.size()); right++) {
            char c = s[right];
            window[c]++;
            if (need.count(c) && window[c] == need[c]) {
                formed++;
            }

            // 覆盖已经成立，记录答案并尝试继续缩短
            while (formed == required) {
                int len = right - left + 1;
                if (len < bestLen) {
                    bestLen = len;
                    bestStart = left;
                }

                char d = s[left];
                window[d]--;
                if (need.count(d) && window[d] < need[d]) {
                    formed--;
                }
                left++;
            }
        }

        if (bestLen == static_cast<int>(s.size()) + 1) return "";
        return s.substr(bestStart, bestLen);
    }
};

示例与正确性

s="ADOBECODEBANC"，t="ABC"：第一次覆盖的窗口是 ADOBEC，记录长度 6；移除首字符 A 后覆盖失效，再扩展右侧。最后到达结尾，可以依次移除多余字符，缩成 BANC，答案长度为 4。

如果 t="AABC"，则 required=3，但 A 必须出现至少两次才能算这一种字符达标，只有一个 A 的 ABC 不合法。

固定右端点时，左端不断右移会让窗口变短；只要仍然覆盖，就记录这个合法候选。第一次失效后，继续右移左端也无法补回缺少字符，因此结束收缩。左右指针只向右移动，遍历过程中能找到全局最短窗口。

复杂度与易错点

哈希操作平均为常数时间，左右指针各移动至多 |s| 次，时间 O(|s|+|t|)；计数表额外空间 O(Σ)，Σ 为出现的字符种类数。题目字符集为英文字母，计数空间可视为常数；返回字符串另占 O(bestLen)。

  • 收缩必须用 while，一次右移后可能连续丢掉多个多余字符。
  • 先记录合法答案，再移除左侧字符；移除后窗口可能已经不合法。
  • 新增字符达标时用 ==，不能用 >=，否则同一种字符会被反复计数。
  • need.count(c) 确保只统计目标字符；字符区分大小写。
  • 无解返回空字符串；s="a", t="aa" 无解；s="aa", t="aa" 返回 aa。

一类题总结

识别信号：寻找满足计数要求的最短连续区间。右侧扩张补条件，条件满足后左侧收缩求更短答案。遇到重复需求，使用频次表，不能只用集合判断“出现过”。

口诀：右扩补需求，满足就左缩，缩前记最优。

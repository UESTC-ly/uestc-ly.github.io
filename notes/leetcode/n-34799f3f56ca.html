427. 建立四叉树

力扣原题

简短题意

给定 n×n 的 0/1 网格，n 为 2 的幂。用四叉树表示网格：同值区域为叶子，否则分成左上、右上、左下、右下四块递归构造，返回根节点。

思路解析

递归函数接收区域左上坐标 r、c 和边长 size。先扫描区域是否全部同值，是则创建叶子；否则按 size/2 划分四块，分别构造四个孩子。每次子区域无重叠且覆盖原区域，所以返回树恰好表示原网格。

C++ 主模板

class Solution {
    Node* build(vector<vector<int>>& grid, int r, int c, int size) {
        bool same = true;
        for (int i = r; i < r + size; i++) {
            for (int j = c; j < c + size; j++) {
                if (grid[i][j] != grid[r][c]) same = false;
            }
        }
        if (same) return new Node(grid[r][c] == 1, true);
        int half = size / 2;
        Node* root = new Node(false, false); // 非叶子的 val 不影响表示
        root->topLeft = build(grid,r,c,half);
        root->topRight = build(grid,r,c+half,half);
        root->bottomLeft = build(grid,r+half,c,half);
        root->bottomRight = build(grid,r+half,c+half,half);
        return root;
    }
public:
    Node* construct(vector<vector<int>>& grid) { return build(grid,0,0,grid.size()); }
};

示例与复杂度

[[0,1],[1,0]]：根非叶子，四个孩子依次是值 0、1、1、0 的叶子；全 1 方阵只产生一个叶子。

每层扫描总区域面积 n²，深度 O(log n)，时间 O(n² log n)，递归栈 O(log n)，输出树 O(n²)。

易错点与一类题总结

四个孩子位置不能颠倒；Node(bool val,bool isLeaf) 为力扣提供；边长 1 时必然同值，递归自然终止。

区域具有递归分块结构时，用“同值就整块结算，否则划分”为主模板；二维前缀和可优化同值判断，但不必取代直观版本。

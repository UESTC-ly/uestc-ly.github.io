150. 逆波兰表达式求值

题型与核心思路

栈。逆波兰表达式把运算符放在操作数之后，例如 (2 + 1) * 3 写成 2 1 + 3 *。运算次序已由排列顺序确定，无需另行处理优先级和括号。

数字入栈，符号计算；先右后左，结果回栈。

栈保存已经读入、尚未被后续运算使用的数值（包括子表达式结果）。每遇到一个运算符，就将最近两个操作数替换为一个计算结果。题目保证表达式合法，最后恰好剩下一个结果。

C++ 模板

class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        stack<int> element;

        for (const auto& c : tokens) {
            if (c != "+" && c != "-" && c != "*" && c != "/") {
                element.push(stoi(c));
            } else {
                // 先弹右，再弹左
                int right = element.top();
                element.pop();
                int left = element.top();
                element.pop();

                if (c == "+") {
                    element.push(left + right);
                } else if (c == "-") {
                    element.push(left - right);
                } else if (c == "*") {
                    element.push(left * right);
                } else {
                    element.push(left / right);
                }
            }
        }
        return element.top();
    }
};

示例

["4","13","5","/","+"]，栈按栈底到栈顶展示：

4   → [4]
13  → [4,13]
5   → [4,13,5]
/   → 先弹 right=5，再弹 left=13，13/5=2 → [4,2]
+   → 4+2=6 → [6]

本次代码纠错

  • 栈保存的是整数和计算结果，用 stack<int>，不能用 stack<string> 后直接当整数运算。
  • c 是 string，没有 c.isdigit() 这个成员函数；判断它是否恰好等于四种运算符，其余按数字处理，能正确区分 "-" 和 "-11"。
  • 转整数用 stoi(c)，支持多位数和负数；c - '0' 只适用于已知为单个数字字符的 char，不适用于 string。
  • 先弹出的是右操作数。 减法必须写 left - right，除法必须写 left / right。命名为 left/right 后仍要核对算式，不能写成 right - left。加法、乘法也统一左在前。
  • C++ 整数除法向零截断，-7 / 3 == -2，符合题意。题目保证无除零，答案及中间结果可用 32 位整数表示。
  • 最后返回 element.top()，不能漏写 return。

复杂度与迁移

设 token 数为 n，题目整数范围固定时，时间 O(n)，额外空间 O(n)，返回值空间 O(1)。

识别信号：运算符消费最近两个未使用的值。用栈存操作数及中间结果，每次弹出、计算、压回。这一直接模板用于合法后缀表达式，中缀表达式不能直接照搬。

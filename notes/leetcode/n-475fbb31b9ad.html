239. 滑动窗口最大值

简短题意

给定整数数组 nums 和窗口大小 k，长度为 k 的窗口从数组最左端开始，每次向右移动一位。按窗口出现的顺序，返回每个窗口中的最大值；1 <= k <= nums.size()。

题型与核心思路

固定长度滑动窗口 + 单调队列。

每个窗口重新扫描 k 个数，需要 O(nk)。窗口右移时，只增加一个元素、移除一个元素，可以用双端队列保存仍有可能成为最大值的候选。

队列保存下标：从队首到队尾，下标递增，对应的数值严格递减。队首就是当前窗口最大值的下标。

两种删除，各有原因

  • 从队首删除过期下标：窗口右端为 right 时，左端为 right-k+1，下标 <= right-k 的元素已经离开窗口。
  • 从队尾删除较小或相等的值：新元素更大或相等，而且下标更靠右、过期更晚。只要旧元素仍在未来窗口中，新元素也一定在，因此旧元素不再有成为最大值的必要。

每轮按照“删除过期候选 → 删除被新值淘汰的候选 → 加入新下标 → 窗口凑满后记录答案”处理。

C++ 主模板

class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        deque<int> candidates;
        vector<int> ans;

        for (int right = 0; right < static_cast<int>(nums.size()); right++) {
            // 当前窗口左端为 right - k + 1
            while (!candidates.empty() && candidates.front() <= right - k) {
                candidates.pop_front();
            }
            // 新值更大或相等，旧队尾不再需要
            while (!candidates.empty() && nums[candidates.back()] <= nums[right]) {
                candidates.pop_back();
            }
            candidates.push_back(right);

            if (right >= k - 1) {
                ans.push_back(nums[candidates.front()]);
            }
        }
        return ans;
    }
};

示例推演

nums = [1,3,-1,-3,5,3,6,7]，k = 3。下表的队列同时写出下标和对应值。

right 当前窗口 候选队列：下标(值) 最大值
2 [1,3,-1] 1(3), 2(-1) 3
3 [3,-1,-3] 1(3), 2(-1), 3(-3) 3
4 [-1,-3,5] 4(5) 5
5 [-3,5,3] 4(5), 5(3) 5
6 [5,3,6] 6(6) 6
7 [3,6,7] 7(7) 7

答案为 [3,3,5,5,6,7]。加入 5 时，旧的 3 已过期，-1、-3 又被新值淘汰，队列只剩下 5。

复杂度与易错点

每个下标入队一次，最多出队一次，所有 while 的总工作量仍是 O(n)。额外空间 O(k)，输出空间 O(n-k+1)。

  • 队列存下标，才能判断过期；读取最大值时写 nums[candidates.front()]。
  • pop_front 处理过期，pop_back 维护单调性，不能混淆。
  • 凑满 k 个数以后才输出；题目保证 1 <= k <= n。
  • k=1 时输出原数组；全相等时保留最新的相等值；全负数也正常比较。

一类题总结

识别信号：窗口持续移动，反复询问最大值或最小值。用单调队列维护尚未过期且未被更优新元素淘汰的候选。最大值维护递减队列，最小值维护递增队列。

口诀：队首清过期，队尾清弱者，队首报答案。

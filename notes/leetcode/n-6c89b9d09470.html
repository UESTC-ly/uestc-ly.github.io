本笔记整理五种基础回溯模型：

  • 46：从所有未使用元素中选择；
  • 78：只从当前位置之后选择；
  • 17：从每个位置对应的候选集合中选择；
  • 39：按顺序选择且允许重复使用当前元素；
  • 22：只生成满足约束的合法序列。

总览：回溯算法专题

一、回溯的基础结构

void backtrack() {
    if (结束条件) {
        保存答案;
        return;
    }

    for (当前层的每个选择) {
        if (选择不可用) {
            continue;
        }

        做选择;
        backtrack();
        撤销选择;
    }
}

关键不在于背模板，而在于明确：

一层递归负责什么？
下一层从哪里开始？
哪个状态需要恢复？

二、46. 全排列

1. 题意

给定一个不含重复数字的数组 nums，返回所有可能的全排列。

nums = [1,2,3]
排列数量 = 3! = 6

排列考虑顺序，因此 [1,2] 和 [2,1] 不同。

2. 核心思路

每层递归填写排列中的一个位置，并从所有尚未使用的数字中选择。

使用：

used[i]

表示 nums[i] 是否已经出现在当前排列中。

完成条件：

path.size() == nums.size()

3. C++ 代码

class Solution {
private:
    vector<vector<int>> answer;
    vector<int> path;
    vector<bool> used;

    void backtrack(const vector<int>& nums) {
        if (path.size() == nums.size()) {
            answer.push_back(path);
            return;
        }

        for (int i = 0; i < nums.size(); i++) {
            if (used[i]) {
                continue;
            }

            used[i] = true;
            path.push_back(nums[i]);

            backtrack(nums);

            path.pop_back();
            used[i] = false;
        }
    }

public:
    vector<vector<int>> permute(vector<int>& nums) {
        answer.clear();
        path.clear();
        used.assign(nums.size(), false);

        backtrack(nums);
        return answer;
    }
};

4. 复杂度

时间复杂度：O(n × n!)
额外空间复杂度：O(n)（不计返回结果）

5. 记忆

排列问题每层都从全部元素中选，因此需要 used 判断当前路径中哪些元素已经使用。

三、78. 子集

1. 题意

返回元素互不相同的数组 nums 的所有子集，包括空集。

长度为 n 的集合共有：

2^n

个子集。

2. 核心思路

回溯树上的每一个节点都是一个合法子集，所以每次进入递归函数都收集：

answer.push_back(path);

使用 startIndex 限制下一层只能向后选择，避免同时生成：

[1,2]
[2,1]

选中下标 i 后，下一层从 i + 1 开始，因为当前元素不能重复使用。

3. C++ 代码

class Solution {
private:
    vector<vector<int>> answer;
    vector<int> path;

    void backtrack(const vector<int>& nums, int startIndex) {
        // 当前路径本身就是一个子集；第一次会收集空集
        answer.push_back(path);

        for (int i = startIndex; i < nums.size(); i++) {
            path.push_back(nums[i]);

            // 当前元素不能重复使用
            backtrack(nums, i + 1);

            path.pop_back();
        }
    }

public:
    vector<vector<int>> subsets(vector<int>& nums) {
        answer.clear();
        path.clear();

        backtrack(nums, 0);
        return answer;
    }
};

4. 易错点

下一层必须传：

backtrack(nums, i + 1);

不能写成：

backtrack(nums, startIndex + 1);

因为本轮实际选择的是下标 i。

5. 复杂度

时间复杂度：O(n × 2^n)
额外空间复杂度：O(n)

6. 记忆

子集问题的每个递归节点都要收集；用 startIndex 保证元素只向后选择。

四、17. 电话号码的字母组合

1. 题意

数字 2～9 与字母的映射如下：

数字 字母
2 abc
3 def
4 ghi
5 jkl
6 mno
7 pqrs
8 tuv
9 wxyz

每个输入数字都必须选择一个对应字母。

2. 核心思路

第 index 层只负责为：

digits[index]

选择一个字母。

这不是从同一个数组中选元素，所以不需要 used 或 startIndex。处理完当前数字后，固定进入：

index + 1

3. C++ 代码

class Solution {
private:
    vector<string> answer;
    string path;

    const vector<string> phone = {
        "", "", "abc", "def", "ghi",
        "jkl", "mno", "pqrs", "tuv", "wxyz"
    };

    void backtrack(const string& digits, int index) {
        if (index == digits.size()) {
            answer.push_back(path);
            return;
        }

        int digit = digits[index] - '0';
        const string& letters = phone[digit];

        for (char letter : letters) {
            path.push_back(letter);
            backtrack(digits, index + 1);
            path.pop_back();
        }
    }

public:
    vector<string> letterCombinations(string digits) {
        if (digits.empty()) {
            return {};
        }

        answer.clear();
        path.clear();

        backtrack(digits, 0);
        return answer;
    }
};

4. 易错点

若用 i 枚举当前数字对应的字母，递归仍应传：

index + 1

不能传 i + 1。index 表示输入数字的位置，i 只表示当前映射字符串中的字母下标。

空输入要直接返回 {}，否则初始状态就会把空字符串加入答案。

5. 复杂度

若最终组合数量为 R，输入长度为 n：

时间复杂度：O(n × R)
最坏情况：O(n × 4^n)
额外空间复杂度：O(n)

6. 记忆

一层固定处理一个数字，从它对应的候选字母集合中选择一个。

五、39. 组合总和

1. 题意

从元素互不相同的 candidates 中选数，使总和等于 target。同一个数字可以重复选择，但不同顺序不算不同组合。

candidates = [2,3,6,7], target = 7
答案：[2,2,3]、[7]

2. 核心思路

使用：

  • startIndex：限制只能按下标不下降的顺序选择，避免 [2,3,2]、[3,2,2]；
  • remain：表示距离目标值还差多少；
  • 下一层传 i：允许当前数字继续被选择。
backtrack(candidates, i, remain - candidates[i]);

若传 i + 1，当前数字就只能使用一次。

3. 排序与剪枝

排序后，如果：

candidates[i] > remain

当前数字无法选择，后面的数字也只会更大，因此可以直接 break。

这个剪枝依赖候选数为正且数组已经排序。

4. C++ 代码

class Solution {
private:
    vector<vector<int>> answer;
    vector<int> path;

    void backtrack(const vector<int>& candidates,
                   int startIndex,
                   int remain) {
        if (remain == 0) {
            answer.push_back(path);
            return;
        }

        for (int i = startIndex; i < candidates.size(); i++) {
            if (candidates[i] > remain) {
                break;
            }

            path.push_back(candidates[i]);

            // 传 i：当前数字可以重复使用
            backtrack(candidates, i, remain - candidates[i]);

            path.pop_back();
        }
    }

public:
    vector<vector<int>> combinationSum(vector<int>& candidates,
                                       int target) {
        answer.clear();
        path.clear();

        sort(candidates.begin(), candidates.end());
        backtrack(candidates, 0, target);

        return answer;
    }
};

5. 本次代码纠错

for 的三部分使用分号

- for (int i = startIdx, i < candidates.size(); i++)
+ for (int i = startIdx; i < candidates.size(); i++)

函数实参使用逗号

- backtrack(candidates, 0; target);
+ backtrack(candidates, 0, target);

6. 复杂度

搜索树规模与候选数和 target 有关，最坏为指数级。若最小候选数是 m，递归深度最多约为：

target / m

7. 记忆

startIndex 防止不同顺序形成重复组合；下一层传 i 允许当前数字重复使用；remain == 0 时收集答案。

六、22. 括号生成

1. 题意

生成 n 对括号的所有有效组合。

有效括号的任意前缀都必须满足：

右括号数量 <= 左括号数量

2. 核心思路

使用：

  • open：已使用的左括号数量；
  • close：已使用的右括号数量。

放置规则：

open < n       // 左括号没用完，可以放 '('
close < open   // 存在未匹配左括号，才能放 ')'

右括号条件必须是严格小于，不能写成 close <= open。

3. C++ 代码

class Solution {
private:
    vector<string> answer;
    string path;

    void backtrack(int n, int open, int close) {
        if (open == n && close == n) {
            answer.push_back(path);
            return;
        }

        if (open < n) {
            path.push_back('(');
            backtrack(n, open + 1, close);
            path.pop_back();
        }

        if (close < open) {
            path.push_back(')');
            backtrack(n, open, close + 1);
            path.pop_back();
        }
    }

public:
    vector<string> generateParenthesis(int n) {
        answer.clear();
        path.clear();

        backtrack(n, 0, 0);
        return answer;
    }
};

4. 为什么不需要最后检查合法性

算法在构造过程中就禁止非法前缀，因此不会生成以 ')' 开头或某一前缀右括号更多的字符串。相比先枚举 2^(2n) 个序列再判断，回溯提前剪掉了无效分支。

5. 复杂度

合法方案数量为第 n 个卡特兰数 C_n：

时间复杂度：O(n × C_n)
额外空间复杂度：O(n)

6. 记忆

左括号没用完就能放；只有存在未匹配的左括号时，才能放右括号。

七、五题统一归纳

题目 关键状态 下一层如何变化 为什么不重复
46 used 继续枚举全部未使用元素 已使用元素不能再选
78 startIndex i + 1 只能向后选
17 index index + 1 每层固定处理一个数字
39 startIndex、remain i、减少 remain 下标不下降，但当前数可重复
22 open、close 对应计数加一 只进入合法前缀

一句话归纳：

先定义“一层递归代表什么”，再决定用 used、startIndex、固定 index，还是合法性计数来限制选择。

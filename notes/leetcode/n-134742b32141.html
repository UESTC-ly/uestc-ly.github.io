100. 相同的树

力扣原题

简短题意

给定二叉树 p、q 的根节点，判断它们是否结构相同，且每个对应位置的节点值也相同。

思路解析

对应节点一起递归：都为空说明这一位置相同；只有一棵为空或值不同则失败；否则左右子树都必须相同。返回值直接表达“当前两棵子树是否相同”。

C++ 主模板

class Solution {
    // 先比较当前位置，再同时比较左右两对对应子树。
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if (p == nullptr || q == nullptr) return p == q;
        if (p->val != q->val) return false;
        return isSameTree(p->left, q->left) && isSameTree(p->right, q->right);
    }
};

示例与复杂度

[1,2,3] 与 [1,2,3] 相同；[1,2] 与 [1,null,2] 值相同但结构不同。

最坏时间 O(n+m)，实际访问在首次不匹配处可结束；递归栈 O(h)，h 为同时递归的深度。

易错点与一类题总结

不能只比较遍历值序列，缺少空节点信息时不同结构也可能产生相同序列。

比较树结构时，递归参数同时携带两棵对应子树，空节点与值判断先于子树递归。

106. 从中序与后序遍历序列构造二叉树

力扣原题

简短题意

给定同一棵二叉树的中序 inorder、后序 postorder，节点值互不相同，构造并返回原二叉树。

思路解析

后序最后一个值是根，根在中序中的位置把左右子树分开。用 index 从后序末尾倒着取根；倒序后序的顺序是“根、右、左”，因此必须先构造右子树，再构造左子树。递归参数是当前子树在中序中的闭区间。

C++ 主模板

class Solution {
    unordered_map<int, int> position;
    int index;
    TreeNode* build(vector<int>& postorder, int left, int right) {
        if (left > right) return nullptr;
        int value = postorder[index--];
        int mid = position[value];
        TreeNode* root = new TreeNode(value);
        root->right = build(postorder, mid + 1, right); // 倒序后序先右后左
        root->left = build(postorder, left, mid - 1);
        return root;
    }
public:
    TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder) {
        position.clear();
        for (int i = 0; i < static_cast<int>(inorder.size()); i++) position[inorder[i]] = i;
        index = static_cast<int>(postorder.size()) - 1;
        return build(postorder, 0, static_cast<int>(inorder.size()) - 1);
    }
};

示例与复杂度

inorder=[9,3,15,20,7]，postorder=[9,15,7,20,3]：取 3 为根，中序右区间先构造以 20 为根的子树，再构造左节点 9。

哈希操作平均下时间 O(n)，哈希表和递归栈额外空间 O(n)，结果树另占 O(n)。

易错点与一类题总结

共享后序 index 时不能先左后右；left>right 是空子树。TreeNode 由力扣提供，创建的新节点组成返回树。

由遍历还原树：选根、用中序拆区间、按消耗另一遍历序列的方向递归；前序正读先左，后序倒读先右。

117. 填充每个节点的下一个右侧节点指针II

力扣原题

简短题意

给定普通二叉树，其节点额外带有 next 指针。让每个节点的 next 指向同一层右边的相邻节点；本层最后节点指向 nullptr，返回根节点。树不保证完美。

思路解析

使用 BFS 逐层处理。固定层大小，prev 保存这一层刚处理的节点，处理当前节点时令 prev->next=current。层末将最后一个节点的 next 清空。队列入队顺序为左孩子、右孩子，因此连接顺序正确。

C++ 主模板

class Solution {
public:
    Node* connect(Node* root) {
        if (root == nullptr) return root;
        queue<Node*> q; q.push(root);
        while (!q.empty()) {
            int size = q.size();
            Node* previous = nullptr;
            for (int i = 0; i < size; i++) {
                Node* current = q.front(); q.pop();
                if (previous != nullptr) previous->next = current;
                previous = current;
                if (current->left != nullptr) q.push(current->left);
                if (current->right != nullptr) q.push(current->right);
            }
            previous->next = nullptr; // 不跨层连接
        }
        return root;
    }
};

示例与复杂度

[1,2,3,4,5,null,7] 的连接为 1→null、2→3→null、4→5→7→null。

时间 O(n)，额外空间 O(w)，w 为最大层宽。此主模板使用队列；常数空间属于进阶要求，可借助已建立的 next 遍历每层。

易错点与一类题总结

不能假设每个节点都有两个孩子；previous 每层重置，层大小必须在入队下一层之前固定。Node 由力扣提供。

同层相邻关系可用 BFS 加“上一节点”变量维护；将层边界与普通队列循环明确分开。

112. 路径总和

力扣原题

简短题意

给定二叉树 root 和整数 targetSum，判断是否存在一条从根到叶子的路径，节点值之和等于 targetSum。叶子指左右孩子都为空的节点。

思路解析

递归携带剩余目标值，每经过当前节点减去它的值。只有到叶子时剩余目标恰好等于当前节点值才成功；中途和相等不能当作答案，因为路径必须结束在叶子。

C++ 主模板

class Solution {
    // 只有叶子才结算根到叶子的路径。
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        if (root == nullptr) return false;
        if (root->left == nullptr && root->right == nullptr) return root->val == targetSum;
        int remain = targetSum - root->val;
        return hasPathSum(root->left, remain) || hasPathSum(root->right, remain);
    }
};

示例与复杂度

根 5→左 4→左 11→右叶子 2，总和为 22，因此 targetSum=22 时返回 true。

时间 O(n)，递归栈 O(h)。

易错点与一类题总结

空树没有根到叶子路径，即使目标为 0 也返回 false；负数存在时，不能按剩余值小于零剪枝。

路径必须有规定起止点时，终止条件要检查节点身份；根到叶子与任意起点路径不能混用模板。

129. 求根节点到叶节点数字之和

力扣原题

简短题意

二叉树每个节点值为 0..9，从根到每个叶子的路径按顺序组成十进制数，返回所有这些数的总和。

思路解析

DFS 参数 prefix 表示进入当前节点之前已经组成的数字，更新为 prefix×10+val。叶子返回这个完整数字，内部节点返回左右子树的数字和。每条根到叶子路径恰好被一个叶子结算。

C++ 主模板

class Solution {
    // 路径数字用 prefix*10+当前位扩展。
    int dfs(TreeNode* root, int prefix) {
        if (root == nullptr) return 0;
        int current = prefix * 10 + root->val;
        if (root->left == nullptr && root->right == nullptr) return current;
        return dfs(root->left, current) + dfs(root->right, current);
    }
public:
    int sumNumbers(TreeNode* root) { return dfs(root, 0); }
};

示例与复杂度

[1,2,3] 形成 12 和 13，总和为 25。

时间 O(n)，递归栈 O(h)；题目保证结果适合 32 位整数。

易错点与一类题总结

拼接数字用乘 10 加当前位，不是直接累加节点值；prefix 按值传递，每条分支互不污染。

从根向下累计信息时，参数携带“到父节点为止的前缀状态”，在叶子结算路径结果。

222. 完全二叉树的节点个数

力扣原题

简短题意

给定完全二叉树 root，返回节点总数。除最后一层外各层全满，最后一层节点从左到右连续排列；进阶希望快于 O(n) 遍历。

思路解析

沿当前子树最左路径与最右路径计算节点层数。如果两者相等，完全二叉树的这棵子树就是满二叉树，节点数为 2^h-1。否则递归统计左右子树再加根。完全性保证每次只有一侧可能继续不满，因此每层仅一条分支继续深递归。

C++ 主模板

class Solution {
    // 完全树的同高两侧边界对应满子树，可整块计数。
public:
    int countNodes(TreeNode* root) {
        if (root == nullptr) return 0;
        int leftHeight = 0, rightHeight = 0;
        for (TreeNode* p = root; p != nullptr; p = p->left) leftHeight++;
        for (TreeNode* p = root; p != nullptr; p = p->right) rightHeight++;
        if (leftHeight == rightHeight) return static_cast<int>((1LL << leftHeight) - 1);
        return 1 + countNodes(root->left) + countNodes(root->right);
    }
};

示例与复杂度

[1,2,3,4,5,6]：根的两条边界高度不同，左子树为满树可直接得 3，右子树统计为 2，总共 6。

时间 O(log² n)，递归栈 O(log n)，空树为 O(1)。

易错点与一类题总结

最左与最右同高推出满树的依据是“输入完全”；普通二叉树不能这样判断。公式的 h 按节点层数计，不是边数。

特殊结构的树计数，先识别可整块结算的完整子树，只递归处理不完整部分。

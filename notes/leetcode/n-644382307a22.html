N 皇后：逐行选择与冲突集合（51）

LeetCode 51 的核心是：每层递归处理一行，为这一行选择一个不冲突的列，并用三个集合记录列和两类对角线是否已被占用。

总览：回溯算法专题

一、题意

在 n × n 棋盘中放置 n 个皇后，使任意两个皇后都不在：

同一行、同一列或同一条斜线

返回所有合法棋盘，其中：

'Q'：皇后
'.'：空位

n = 4 时有两种解：

.Q..    ..Q.
...Q    Q...
Q...    ...Q
..Q.    .Q..

二、核心思路：一层处理一行

规定第 row 层递归只在第 row 行放置一个皇后：

第 0 层：为第 0 行选择一列
第 1 层：为第 1 行选择一列
……
第 n 层：所有行处理完成，保存棋盘

这样同一行天然只会有一个皇后，不需要额外记录行占用状态。

当前行枚举所有列：

for (int col = 0; col < n; col++)

如果当前列和两条对角线都没有皇后，就执行：

放置并标记 → 递归下一行 → 移除并恢复标记

三、如何编号两类对角线

1. 列

columns[col]

表示第 col 列是否已经有皇后。

2. \ 方向对角线

同一条 \ 对角线满足：

row - col 相同

例如：

(0,0)、(1,1)、(2,2)

row - col 可能为负数，所以整体加 n - 1：

row - col + n - 1

3. / 方向对角线

同一条 / 对角线满足：

row + col 相同

例如：

(0,3)、(1,2)、(2,1)、(3,0)

编号直接使用：

row + col

4. 为什么长度是 2n - 1

两类对角线编号范围都是：

0 ～ 2n - 2

因此各需要长度为 2n - 1 的状态数组。

四、合法性判断

当前位置 (row, col) 的两个对角线编号：

int mainIndex = row - col + n - 1;  // \ 对角线
int antiIndex = row + col;          // / 对角线

任意状态已被占用时，当前位置不能放皇后：

if (columns[col] ||
    mainDiagonal[mainIndex] ||
    antiDiagonal[antiIndex]) {
    continue;
}

可以把这三个数组理解为三类 used：

columns：列的 used
mainDiagonal：\ 对角线的 used
antiDiagonal：/ 对角线的 used

五、示例推演：n = 4

一条成功路径是：

第 0 行选第 1 列：.Q..
第 1 行选第 3 列：...Q
第 2 行选第 0 列：Q...
第 3 行选第 2 列：..Q.

完整棋盘：

.Q..
...Q
Q...
..Q.

当递归进入：

row == n

说明第 0～n-1 行都已放置皇后，可以保存当前棋盘。

六、C++ 代码

class Solution {
private:
    vector<vector<string>> answer;
    vector<string> board;

    vector<bool> columns;
    vector<bool> mainDiagonal;  // \：row - col + n - 1
    vector<bool> antiDiagonal;  // /：row + col

    void backtrack(int row, int n) {
        // 所有行都已经放置完成
        if (row == n) {
            answer.push_back(board);
            return;
        }

        // 为当前行枚举所有列
        for (int col = 0; col < n; col++) {
            int mainIndex = row - col + n - 1;
            int antiIndex = row + col;

            if (columns[col] ||
                mainDiagonal[mainIndex] ||
                antiDiagonal[antiIndex]) {
                continue;
            }

            // 1. 放置皇后并标记冲突集合
            board[row][col] = 'Q';
            columns[col] = true;
            mainDiagonal[mainIndex] = true;
            antiDiagonal[antiIndex] = true;

            // 2. 处理下一行
            backtrack(row + 1, n);

            // 3. 移除皇后并恢复所有状态
            board[row][col] = '.';
            columns[col] = false;
            mainDiagonal[mainIndex] = false;
            antiDiagonal[antiIndex] = false;
        }
    }

public:
    vector<vector<string>> solveNQueens(int n) {
        answer.clear();

        board.assign(n, string(n, '.'));
        columns.assign(n, false);
        mainDiagonal.assign(2 * n - 1, false);
        antiDiagonal.assign(2 * n - 1, false);

        backtrack(0, n);
        return answer;
    }
};

七、变量含义

变量 含义
row 当前准备放置皇后的行
col 当前尝试的列
board 当前棋盘
columns[col] 第 col 列是否被占用
mainDiagonal[row-col+n-1] 当前 \ 对角线是否被占用
antiDiagonal[row+col] 当前 / 对角线是否被占用

八、常见错误

1. 直接用 row - col 作下标

当 row < col 时会得到负数。必须平移：

row - col + n - 1

2. 混淆两类对角线

\ 方向：row - col 相同
/ 方向：row + col 相同

3. 只恢复棋盘，没有恢复占用数组

下面四个状态描述同一次选择，必须同步恢复：

board[row][col] = '.';
columns[col] = false;
mainDiagonal[mainIndex] = false;
antiDiagonal[antiIndex] = false;

4. 完成条件写成 row == n - 1

row == n - 1 表示正准备处理最后一行，最后一个皇后尚未放置。正确条件是：

row == n

九、复杂度

搜索规模通常用：

O(n!)

表示；对角线限制会剪掉大量分支。每保存一个解还需要复制 n × n 棋盘。

不计算返回结果：

当前棋盘：O(n²)
递归与三个占用数组：O(n)

十、方法归纳

N 皇后可以理解为：

每一行必须选择一个列的排列问题，同时增加两条对角线约束。

模板：

void backtrack(int row) {
    if (row == n) {
        保存棋盘;
        return;
    }

    for (int col = 0; col < n; col++) {
        if (列或对角线冲突) {
            continue;
        }

        放皇后并标记;
        backtrack(row + 1);
        移除皇后并恢复标记;
    }
}

记忆口诀：

一层一行，循环选列；
列不能重，两斜线不能撞；
row 到 n 收答案；
棋盘和标记必须一起恢复。

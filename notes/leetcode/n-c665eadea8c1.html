一、230. 二叉搜索树中第 K 小的元素

1. 题意

给定一棵二叉搜索树和整数 k，返回其中第 k 小的节点值，k 从 1 开始计数。

示例：

      3
     / \
    1   4
     \
      2

中序遍历结果为：

1 → 2 → 3 → 4

因此：

第 1 小 = 1
第 2 小 = 2
第 3 小 = 3
第 4 小 = 4

2. 核心思路

二叉搜索树满足：

左子树节点值 < 当前节点值 < 右子树节点值

所以中序遍历：

左子树 → 当前节点 → 右子树

得到的节点值是严格升序的。

不需要保存完整序列。每访问一个节点，就把 k 减 1；当 k == 0 时，当前节点就是答案。

3. 递归函数的执行顺序

1. 递归左子树；
2. 访问当前节点，让 k--；
3. k == 0 时记录答案；
4. 否则递归右子树。

找到答案后应立即停止后续递归，避免无意义遍历，也防止 k 继续减成负数。

4. C++ 代码

class Solution {
private:
    int answer = 0;

    // k 使用引用传递，所有递归调用共享同一个计数器
    void inorder(TreeNode* root, int& k) {
        // 节点为空，或者已经找到答案，直接结束
        if (root == nullptr || k == 0) {
            return;
        }

        // 左
        inorder(root->left, k);

        // 答案可能已经在左子树中找到
        if (k == 0) {
            return;
        }

        // 根
        --k;
        if (k == 0) {
            answer = root->val;
            return;
        }

        // 右
        inorder(root->right, k);
    }

public:
    int kthSmallest(TreeNode* root, int k) {
        answer = 0;
        inorder(root, k);
        return answer;
    }
};

5. 为什么 k 要使用引用

参数写成：

int& k

表示所有递归调用修改的是同一个 k。

如果按值传递：

void inorder(TreeNode* root, int k)

每层递归都会得到一份独立副本，左子树访问过多少个节点无法正确传递给父层和右子树。

6. 示例推演

对于：

      3
     / \
    1   4
     \
      2

当 k = 1：

从 3 进入左子树 1
1 没有左孩子
访问 1：k 从 1 变为 0
记录 answer = 1
提前结束递归

7. 复杂度

设节点数为 n、树高为 h：

  • 时间复杂度：最坏 O(n)；提前结束时可理解为约 O(h + k)；
  • 递归栈空间：O(h)，最坏为 O(n)。

8. 方法归纳

BST + 第 k 小
      ↓
中序遍历得到升序序列
      ↓
每访问一个节点就让 k--
      ↓
k == 0 时记录并提前返回

本笔记整理 LeetCode 199、114、105：分别对应按层观察二叉树、原地改变指针结构，以及根据遍历序列递归构造二叉树。

总览：二叉树专题｜遍历基础：二叉树遍历基础（94、102）｜递归路径题：二叉树递归返回值与路径专题（437、236、124）

一、199. 二叉树的右视图

1. 题意

返回从二叉树右侧观察时，从上到下能看到的节点值。

本质是：

找到每一层最右侧的节点。

例如：

       1
      / \
     2   3
      \   \
       5   4

每层最右侧节点为：

第 0 层：1
第 1 层：3
第 2 层：4

答案为：

[1,3,4]

注意，右视图节点不一定都是右孩子。如果某层右子树没有节点，左子树中的节点也可能被看到。

2. 主流解法：层序遍历 BFS

层序遍历天然按层处理。若每层从左到右访问，那么每层最后一个节点就是右视图节点。

class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> answer;
        if (root == nullptr) {
            return answer;
        }

        queue<TreeNode*> nodes;
        nodes.push(root);

        while (!nodes.empty()) {
            // 必须先固定当前层节点数
            int levelSize = static_cast<int>(nodes.size());

            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = nodes.front();
                nodes.pop();

                // 从左到右访问时，当前层最后一个节点属于右视图
                if (i == levelSize - 1) {
                    answer.push_back(node->val);
                }

                if (node->left != nullptr) {
                    nodes.push(node->left);
                }
                if (node->right != nullptr) {
                    nodes.push(node->right);
                }
            }
        }

        return answer;
    }
};

为什么必须保存 levelSize

处理当前层时，还会把下一层节点加入队列，队列大小不断变化。不能直接把变化中的 queue.size() 当作当前层边界。

正确方式：

int levelSize = nodes.size();

然后只弹出固定的 levelSize 个节点。

3. 递归 DFS 写法

按下面的顺序递归：

根 → 右 → 左

这样每一层第一次访问到的节点，就是该层最靠右的节点。

class Solution {
private:
    void dfs(TreeNode* root, int depth, vector<int>& answer) {
        if (root == nullptr) {
            return;
        }

        // 当前深度还没有记录过节点
        if (depth == static_cast<int>(answer.size())) {
            answer.push_back(root->val);
        }

        dfs(root->right, depth + 1, answer);
        dfs(root->left, depth + 1, answer);
    }

public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> answer;
        dfs(root, 0, answer);
        return answer;
    }
};

两种方法的记忆：

BFS：从左到右，每层最后一个；
DFS：先右后左，每层第一个。

复杂度：

  • BFS：时间 O(n)，队列空间 O(w)，w 为最大宽度；
  • DFS：时间 O(n)，递归栈 O(h)，h 为树高。

二、114. 二叉树展开为链表

1. 题意

将二叉树原地展开为只使用 right 指针的单链表：

  • 节点顺序与原树的先序遍历相同；
  • 每个节点的 left 必须为 nullptr；
  • 不创建一套新的链表节点。

例如：

        1
       / \
      2   5
     / \   \
    3   4   6

先序遍历是：

1 → 2 → 3 → 4 → 5 → 6

展开后：

1 → 2 → 3 → 4 → 5 → 6

所有箭头都是 right 指针，所有 left 都为 nullptr。

2. 递归函数含义

定义：

TreeNode* flattenTree(TreeNode* root)

含义是：

将 root 子树原地展开，并返回展开后链表的尾节点。

返回尾节点是为了让父层可以把原右子树接到左链表末尾。

3. 拼接规则

先递归展开左右子树。假设得到：

左链表：L1 → L2 → L3
右链表：R1 → R2 → R3

根据先序遍历，当前子树应该拼成：

root → L1 → L2 → L3 → R1 → R2 → R3

关键三步：

leftTail->right = root->right; // 左链表尾部接原右链表
root->right = root->left;      // 根的右边改为左链表
root->left = nullptr;          // 清空左指针

只有存在左子树时才需要重新拼接。

4. C++ 代码

class Solution {
private:
    // 展开当前子树，并返回链表尾节点
    TreeNode* flattenTree(TreeNode* root) {
        if (root == nullptr) {
            return nullptr;
        }

        TreeNode* leftTail = flattenTree(root->left);
        TreeNode* rightTail = flattenTree(root->right);

        if (leftTail != nullptr) {
            leftTail->right = root->right;
            root->right = root->left;
            root->left = nullptr;
        }

        // 原右子树存在时，最终尾节点来自右子树
        if (rightTail != nullptr) {
            return rightTail;
        }

        // 否则若存在左子树，尾节点来自左子树
        if (leftTail != nullptr) {
            return leftTail;
        }

        // 叶子节点的尾节点就是自己
        return root;
    }

public:
    void flatten(TreeNode* root) {
        flattenTree(root);
    }
};

5. 为什么能保证先序顺序

先序遍历的递归定义是：

preorder(root)
= [root]
+ preorder(root->left)
+ preorder(root->right)

递归先保证左右子树内部已经分别按先序展开，再把它们按：

根 → 左链表 → 右链表

连接，所以最终顺序就是整棵子树的先序遍历。

代码执行过程虽然是先处理左右子树、再处理根，类似后序计算，但最终链表顺序由指针拼接方式决定。

6. 为什么主函数不能写 return flattenTree(root)

题目固定的函数签名是：

void flatten(TreeNode* root)

而辅助函数返回：

TreeNode*

因此不能从一个 void 函数返回 TreeNode*：

void flatten(TreeNode* root) {
    return flattenTree(root); // 返回类型不匹配
}

正确写法是：

void flatten(TreeNode* root) {
    flattenTree(root);
}

最外层调用只需要树被原地修改，不需要尾节点。flattenTree 返回的尾节点只服务于父层递归的连接操作。

7. 复杂度

  • 时间复杂度：O(n)；
  • 递归栈空间：O(h)，最坏 O(n)。

三、105. 从前序与中序遍历序列构造二叉树

1. 题意

给定同一棵树的前序遍历 preorder 和中序遍历 inorder，还原二叉树并返回根节点。

前序：根 → 左 → 右
中序：左 → 根 → 右

因此：

  • 前序遍历负责确定当前根节点；
  • 中序遍历负责划分左右子树。

例如：

preorder = [3,9,20,15,7]
inorder  = [9,3,15,20,7]

前序第一个元素 3 是根；在中序中找到 3 后：

左区间：[9]
右区间：[15,20,7]

2. 递归函数含义

TreeNode* build(
    vector<int>& preorder,
    int left,
    int right
)

表示：

根据中序遍历闭区间 [left, right] 中的节点构造一棵子树，并返回其根节点。

另用 preorderIndex 指向前序数组中下一个尚未使用的根节点。

3. 为什么必须先构造左子树

取出当前根之后，前序数组接下来依次存放：

左子树节点 → 右子树节点

所以必须：

root->left = build(...);
root->right = build(...);

如果先构造右子树，preorderIndex 会把属于左子树的节点错误地用作右子树根节点。

4. C++ 代码

class Solution {
private:
    unordered_map<int, int> inorderPosition;
    int preorderIndex = 0;

    TreeNode* build(
        vector<int>& preorder,
        int left,
        int right
    ) {
        // 中序区间为空
        if (left > right) {
            return nullptr;
        }

        // 前序中尚未使用的第一个元素是当前根
        int rootValue = preorder[preorderIndex++];
        TreeNode* root = new TreeNode(rootValue);

        // 用中序位置划分左右子树
        int middle = inorderPosition[rootValue];

        root->left = build(preorder, left, middle - 1);
        root->right = build(preorder, middle + 1, right);

        return root;
    }

public:
    TreeNode* buildTree(
        vector<int>& preorder,
        vector<int>& inorder
    ) {
        inorderPosition.clear();
        preorderIndex = 0;

        for (int i = 0; i < static_cast<int>(inorder.size()); ++i) {
            inorderPosition[inorder[i]] = i;
        }

        return build(
            preorder,
            0,
            static_cast<int>(inorder.size()) - 1
        );
    }
};

5. 为什么只传中序区间就够了

preorderIndex：确定下一个根节点是谁；
[left, right]：确定当前子树包含哪些节点。

只要递归顺序严格遵守“先左后右”，前序下标就会自然按正确顺序向后移动。

6. 为什么使用哈希表

建立：

节点值 → 该节点在 inorder 中的下标

可以平均 O(1) 找到根节点位置。如果每次线性搜索中序数组，最坏时间会达到 O(n²)。

该方法依赖题目中节点值互不相同。

7. 复杂度

  • 时间复杂度：O(n)；
  • 哈希表空间：O(n)；
  • 递归栈：O(h)，最坏 O(n)。

四、统一归纳

题目 关键观察 方法
199. 右视图 每层最右侧节点 BFS 每层最后一个；或 DFS 先右后左
114. 展开为链表 最终顺序为根、左、右 递归返回尾节点并原地拼接
105. 前序与中序构造树 前序定根，中序分左右 前序指针 + 中序区间 + 哈希表

复习口诀：

右视图：按层取最后，或先右后左；
展开链表：左右先展开，右接左尾，左移到右；
构造二叉树：前序找根，中序切左右，先建左再建右。

502. IPO

力扣原题

简短题意

初始资本 w，最多做 k 个不同项目。capital[i] 是启动第 i 项目所需最低资本，完成后获得 profits[i] 的纯利润；资本门槛不扣除。返回最终最大资本。利润非负。

思路解析

按启动门槛排序，将当前资本能做的项目加入利润大顶堆。每轮选择可做项目中利润最高的；它获得的资本不少于任何其他可选项目，所以不会减少下一轮的可选范围。每项目只入堆一次，取出后不再使用。

C++ 主模板

class Solution {
    // 先解锁当前资本够用的项目，再取最大利润。
public:
    int findMaximizedCapital(int k, int w, vector<int>& profits, vector<int>& capital) {
        vector<pair<int,int>> projects;
        for (int i = 0; i < static_cast<int>(profits.size()); i++) projects.push_back({capital[i],profits[i]});
        sort(projects.begin(),projects.end());
        priority_queue<int> available;
        int index = 0;
        for (int step = 0; step < k; step++) {
            while (index < static_cast<int>(projects.size()) && projects[index].first <= w) {
                available.push(projects[index].second); index++;
            }
            if (available.empty()) break;
            w += available.top(); available.pop();
        }
        return w;
    }
};

示例与复杂度

k=2、w=0、profits=[1,2,3]、capital=[0,1,1]：先赚 1，随后选择赚 3，最终资本为 4。

时间 O(n log n+min(k,n) log(n+1))，额外空间 O(n)；题目保证最终资本适合 int。

易错点与一类题总结

capital 是门槛而非支出；没有可用项目就停止，最多 k 次不要求恰好 k 次；必须先加入所有当前可做项目，再选最大利润。

选择受门槛限制而收益可扩大选择范围：排序管理解锁，大顶堆管理当前最优收益。

373. 查找和最小的K对数字

力扣原题

简短题意

给定两个非递减数组 nums1、nums2，数对各取一个数组元素，返回和最小的 k 个数对。相同数值可以由不同下标产生多个数对。

思路解析

固定 nums1[i] 时，与 nums2[0..] 的数对和有序，视作一路有序流。小顶堆初始放各路的 (i,0)，每次取最小和，再从同路补 (i,j+1)。只需前 min(k,n1) 路，因为更后路的首项之前已有至少 k 个不更大的首项，足够组成前 k 个结果。

C++ 主模板

class Solution {
public:
    vector<vector<int>> kSmallestPairs(vector<int>& nums1, vector<int>& nums2, int k) {
        vector<vector<int>> ans;
        if (nums1.empty() || nums2.empty()) return ans;
        using Item = tuple<long long,int,int>; // 和、nums1 下标、nums2 下标
        priority_queue<Item,vector<Item>,greater<Item>> heap;
        for (int i = 0; i < min(k,static_cast<int>(nums1.size())); i++) {
            heap.push({1LL * nums1[i] + nums2[0],i,0});
        }
        while (k > 0 && !heap.empty()) {
            auto [sum,i,j] = heap.top(); heap.pop();
            ans.push_back({nums1[i],nums2[j]}); k--;
            if (j + 1 < static_cast<int>(nums2.size())) heap.push({1LL * nums1[i] + nums2[j+1],i,j+1});
        }
        return ans;
    }
};

示例与复杂度

nums1=[1,7,11]，nums2=[2,4,6]，k=3：依次取 [1,2]、[1,4]、[1,6]。

h=min(k,n1)，时间 O((h+k) log(h+1))，堆空间 O(h)，输出 O(k)。

易错点与一类题总结

每一路只沿 j 前进，避免重复生成同一下标对；不能按值去重；和用 long long，tuple 需 。

大量笛卡尔积候选若可拆成多路有序序列，就做堆归并，不必先生成所有候选。

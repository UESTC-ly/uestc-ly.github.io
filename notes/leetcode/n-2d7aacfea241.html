核心目标：掌握二叉树的 DFS/BFS 遍历、递归函数设计、树属性计算、结构修改，以及二叉搜索树的验证与构造。

二、二叉树递归的统一思考框架

设计递归函数时，依次回答下面四个问题：

  1. 函数的返回值表示什么？
  2. 空节点应该返回什么？
  3. 左右子树能为当前节点提供什么信息？
  4. 当前节点如何组合左右子树的信息？

典型框架：

ReturnType dfs(TreeNode* root) {
    if (root == nullptr) {
        return 空节点对应的结果;
    }

    ReturnType leftResult = dfs(root->left);
    ReturnType rightResult = dfs(root->right);

    // 使用左右子树的信息计算当前节点的结果
    return 当前结果;
}

根据“处理当前节点”的位置，可以对应不同遍历顺序：

前序：根 → 左 → 右
中序：左 → 根 → 右
后序：左 → 右 → 根

三、如何选择 DFS 或 BFS

1. 优先考虑 DFS 递归

常见问法：

  • 求树的深度、高度或直径；
  • 判断两棵子树的关系；
  • 修改每个节点的左右结构；
  • 构造一棵树；
  • 按前序、中序、后序访问。

2. 优先考虑 BFS 队列

常见问法：

  • 逐层访问；
  • 每层单独保存结果；
  • 求某一层的信息；
  • 求距离根节点最近的目标。

层序遍历中：

队列保证从左到右；
levelSize 把不同层分开。

四、最容易混淆的概念

1. 最大深度与直径

最大深度：根节点到最远叶子节点的节点数
直径：任意两个节点之间最长路径的边数

对应公式：

// 当前子树的最大深度
max(leftDepth, rightDepth) + 1

// 经过当前节点的候选直径
leftDepth + rightDepth

当 leftDepth、rightDepth 按子树节点数计算时，它们也恰好分别等于“当前节点沿该方向走到最深节点”的边数，所以候选直径不需要再加 1。

2. 二叉搜索树不能只比较父子节点

BST 要求的是：

左子树的所有节点 < 当前节点
右子树的所有节点 > 当前节点

不是只要求直接左孩子和右孩子满足大小关系。验证 BST 时，可以利用“中序遍历严格递增”的整体性质。

3. 对象与指针

TreeNode root(value);                 // root 是节点对象
TreeNode* root = new TreeNode(value); // root 是指向节点的指针

new TreeNode(...) 返回 TreeNode*，所以必须用指针接收。递归建树需要返回函数结束后依然存在的节点，不能返回局部对象的地址。

六、复习口诀

遍历顺序：看根节点在左、右递归的什么位置；
层序遍历：队列从左到右，levelSize 分隔层；
最大深度：左右取大再加一；
翻转二叉树：每个节点交换左右孩子；
对称二叉树：外侧对外侧，内侧对内侧；
二叉树直径：向上返回深度，左右深度之和更新答案；
验证 BST：中序遍历必须严格递增；
有序数组建平衡 BST：每次取中点当根。

210. 课程表II

力扣原题

简短题意

共有 numCourses 门课，[a,b] 表示学习 a 之前必须先学 b。返回一种能学完全部课程的顺序，若依赖有环则返回空数组。

思路解析

建立 b→a 的边并统计入度。入度为零的课不再有未完成前置条件，放入队列；每取出一门课就加入答案，并递减后续课程入度。最终答案数量不足课程总数，说明剩余课程互相依赖形成环。

C++ 主模板

class Solution {
    // 入度为零才可输出课程，完成后递减后续课程入度。
public:
    vector<int> findOrder(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> graph(numCourses);
        vector<int> indegree(numCourses, 0);
        for (const auto& edge : prerequisites) {
            graph[edge[1]].push_back(edge[0]); indegree[edge[0]]++;
        }
        queue<int> q;
        for (int i = 0; i < numCourses; i++) if (indegree[i] == 0) q.push(i);
        vector<int> order;
        while (!q.empty()) {
            int course = q.front(); q.pop(); order.push_back(course);
            for (int next : graph[course]) if (--indegree[next] == 0) q.push(next);
        }
        if (static_cast<int>(order.size()) != numCourses) return {};
        return order;
    }
};

示例与复杂度

4 门课，依赖 [[1,0],[2,0],[3,1],[3,2]]，一种顺序为 [0,1,2,3]。

时间 O(V+E)，额外空间 O(V+E)，输出 O(V)。

易错点与一类题总结

依赖边方向为前置课→后续课；顺序不唯一，只要满足所有依赖即可；无依赖时所有课程都应出现在结果中。

拓扑排序既能判断有向图是否有环，也能生成满足先后约束的顺序；与课程表 207 共用入度消除模板。

本目录用于系统学习与实践 Retrieval-Augmented Generation（检索增强生成）的完整链路。

学习主线

数据接入 → 文档解析 → 清洗与元数据管理 → Chunk → Embedding
→ 向量检索 / BM25 → 混合检索 → Query Rewrite / 意图识别
→ Rerank → 上下文压缩与去重 → 引用溯源
→ 权限与多租户 → 评测 → 增量更新与索引一致性 → 端到端实践

核心知识范围

  • 数据接入：PDF、Word、网页、图片和数据库；
  • 文档解析：OCR、表格和复杂版面；
  • 数据清洗与元数据管理；
  • Chunk：固定长度、递归、语义和父子块；
  • Embedding 模型、向量维度、向量索引和相似度检索；
  • BM25、混合检索与多路召回；
  • Query Rewrite、意图识别和 Rerank；
  • 上下文压缩、去重与引用溯源；
  • 文档权限与多租户隔离；
  • 检索评测与生成评测；
  • 增量更新、删除与索引一致性。

向量存储选型

  • PostgreSQL + pgvector；
  • Milvus；
  • Elasticsearch / OpenSearch；
  • Qdrant；
  • FAISS（适合本地实验）。

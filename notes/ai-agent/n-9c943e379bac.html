环境

Python 3.12.10；FastAPI 0.141.1；Pydantic 2.13.5；Starlette 1.6.0；SQLModel 0.0.42；HTTPX 0.28.1；pytest 9.1.1。

依赖安装在临时虚拟环境中，没有修改系统 Python。完整版本见 requirements-verified.txt。如需按本次环境复现，在虚拟环境中执行 python -m pip install -r requirements-verified.txt。版本快照来自 macOS / Python 3.12，其他平台优先使用 requirements.txt 让安装器选择适配依赖。

讲解扩写版检查结果

本轮由三个子 agent 分别扩写 01—04、05—08、09—12 章，主 agent 统一校对学习地图、速查表、代码说明和运行方式。

12 章正文现在各保留一个 Python 最小示例。正文全部围栏代码块（包括旧版的 shell 与目录树）从 324 行减少为 179 行，约减少 45%；非代码块文本字符数从 13,434 增至 36,001，约为原来的 2.7 倍。该统计不含学习地图、速查表和独立配套文件。

从新版 Markdown 中直接提取 12 个 Python 代码块，在临时目录逐一加载，并使用 TestClient 验证实际行为，全部通过。检查包含参数校验、请求体默认值、响应字段过滤、404、分页依赖、流式最终内容、路由前缀、数据库创建与读取、有效及无效凭证、文件上传、计时响应头，以及第 12 章测试函数中的成功与失败断言；12 个应用的 OpenAPI 也均可生成。

数据库正文示例在临时工作目录运行，未在笔记目录创建 tasks.db。流式验证只检查完整内容，不验证真实网络的分块时机。正文示例语法和所有 Markdown 内部文件链接也已检查通过。

原 demos/ 文件未修改，保留为可选练习。下面 24 项测试的记录对应原配套代码，与本轮正文示例验证分开记录。

第一版配套文件检查结果

运行 python -m pytest -q demos/test_demos.py，结果：24 passed。

覆盖：参数默认值与边界、请求体校验、响应字段过滤、404、分页依赖、异步响应和流式内容、路由前缀、数据库 CRUD、鉴权、文件上传、中间件、CORS 预检、lifespan、后台任务、环境变量，以及 12 个应用的 OpenAPI 生成。

数据库测试使用独立的内存 SQLite，引擎被临时替换，不访问练习用数据库。流式测试只检查响应内容，不证明真实网络中每一段到达的时机。本次未进行公网部署或性能压测。

第一版还检查了当时 13 个 Python 代码块的语法、12 章代码与配套 demo 的一致性，以及笔记内部文件链接，均通过。扩写版正文已经精简，正文与配套文件不再要求一致，不能用这一旧记录代替新版正文验证。

依赖提示

本次出现两条第三方依赖弃用警告，测试仍全部通过：

  • Starlette 提示当前 TestClient 的 HTTPX 后端未来应迁移到 httpx2。
  • Starlette 内部使用的 AnyIO BlockingPortal 旧别名被标记弃用。

笔记保留本次可运行且与 FastAPI 测试教程一致的 HTTPX 用法；升级测试依赖后应重新运行测试确认兼容性。

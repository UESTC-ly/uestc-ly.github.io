06-03 章节摘要：IVF 与乘积量化

← 返回专题下载 Markdown ↓
  • 本章新增知识： IVF 先把向量分到由中心代表的列表，查询时只搜索部分列表；PQ 把子向量映射为短码字编号，用近似距离换取存储与内存收益。
  • 新术语： 倒排文件索引（Inverted File Index，IVF）、乘积量化（Product Quantization，PQ）、码本、量化误差。
  • 新代码接口： 本批次不实现 IVF/PQ 训练或压缩；伪实现、原始向量重排和基准仍是计划项。
  • 后续必须知道： IVF 的分区误差与 PQ 的量化误差会叠加，应以 Flat、IVF、IVF+PQ 分层比较；中心、码本和训练数据必须版本化。
  • 与其他章节的关联： 以 06-01 的精确结果为基线，为 06-04 的本地索引组合建立算法边界。
  • 未解决问题： 分区数量、搜索列表数、编码粒度和是否保留原向量需要由实际数据与资源目标决定。

本章增量

  1. 秘密、用户输入、知识库文本、系统指令、输出和日志必须保持边界。
  2. 检索文本是不可信数据，不能因为进入 Prompt 就升级为系统指令。
  3. 密钥不进入代码、文档、截图和日志；暴露后先撤销或轮换，不能只删除当前文件。
  4. 文档权限需要贯穿索引、检索、缓存、重排、引用、输出和删除流程。
  5. Prompt 分隔只是纵深防御的一部分，不能单独彻底解决 Prompt Injection。
  6. 接入外部服务前要核查数据、保留、区域、权限、费用版本和离线替代。

一句话复述

安全基线的核心是最小权限、数据与指令分离、减少敏感数据，并诚实记录剩余风险。

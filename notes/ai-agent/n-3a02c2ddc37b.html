这一部分不要求你已经学过人工智能、机器学习或 RAG。它只做三件事：帮助你选对学习 路线，确认当前环境足以完成后续练习，并建立最基本的安全与诚实边界。

你会在这里完成什么

章节 你要解决的问题 完成标志
00-01 如何使用本教程 先读什么、什么时候动手、怎样判断自己真的学会了 能为自己选一条主线，并说清每一步要留下什么证据
00-02 能力、范围与诚实边界 哪些结论可以相信，哪些仍需核查 能区分事实、工程经验、建议和推测
00-03 学习准备度检查 Python、命令行、JSON/HTTP 或数学基础不足时怎么办 能找到自己的缺口和对应补救路线
00-04 环境冒烟测试 电脑是否能运行后续离线示例 能用 Python 3.11+ 完成一次无网络、无付费的最小检查
00-05 安全基线 密钥、输入、知识库和日志应该怎样处理 能指出一次练习中的秘密、非可信数据和权限边界

建议路线

第一次学习时，按 00-01 → 00-02 → 00-03 → 00-04 → 00-05 阅读。完成前言后再进入 基础知识和 RAG 原理，不必先安装向量数据库、在线模型 SDK 或任何付费服务。

如果你已经熟悉 Python，也不要跳过 00-02 和 00-05。会写代码不等于知道某个结论的 证据等级，也不等于自动具备安全默认值。如果环境检查失败，先回到 00-03 选择补救 路线，不要一次性安装大量工具来“碰碰运气”。

本批次的诚实状态

本目录当前交付的是教学正文。规划中的学习路线图、准备度分流图、环境流程图、安全 信任边界图和统一冒烟脚本尚未在本批次实现。正文会明确标注这些待交付项，不会把 “计划存在”写成“已经验证”。

每章都有独立摘要，索引见章节摘要。摘要用于复习，不能 替代第一次阅读和亲手检查。

本章增量

  1. 冒烟测试只检查仓库位置、Python 3.11+、虚拟环境和 UTF-8 文件读写。
  2. 打印 sys.executable 可以确认实际解释器，而不只依赖终端提示符或安装名称。
  3. 直接调用 .venv 内的 Python 能减少激活脚本和 shell 差异造成的困惑。
  4. 本章不需要网络、付费 API、RAG 框架或向量数据库。
  5. 失败记录至少包含操作系统、终端、版本、解释器路径、完整命令和第一条错误。

一句话复述

先证明最小本地环境能工作，再引入依赖和网络，排错会更可靠。

自检

  • 我的 Python 版本和真实解释器路径是什么？
  • 虚拟环境中的解释器路径是什么？

  • UTF-8 临时文件是否成功读回并清理？

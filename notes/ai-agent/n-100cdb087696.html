完成本章后，你应该能够：

  • 为一次小实验固定语料、查询、相关性标签和配置；
  • 手算 Hit@K 与 Recall@K，并说明 K 和标签怎样影响结果；
  • 分开记录检索质量、回答质量、延迟与成本；
  • 一次只改变一个主要因素，保留失败样本，而不是只展示最好结果。

为什么“看起来不错”不够

你修改了切分方法，随手问一个问题，答案读起来更自然。能否据此判断修改有效？不能。

可能是问题刚好简单，模型随机输出不同，检索结果其实更差，或者回答只是更流畅。没有 固定输入和记录，就无法区分改动效果与偶然波动，也无法让别人复查。

最小测量纪律不是建立完整评估平台，而是让第一次实验就具备可比较的证据。

固定四样东西

一次可比较的检索实验至少固定：

  1. 语料：候选文档或文本块集合，记录版本或内容快照。
  2. 查询：一组真实或代表性问题，不在看到结果后只保留容易的问题。
  3. 相关性标签：对每个查询，哪些候选被认为相关；标签来自明确规则或人工判断。
  4. 配置：切分、检索方法、K 值、模型和关键参数。

如果修改语料、查询和算法后只比较一个总分，即使分数变化，也不知道由哪项导致。

Hit@K：有没有命中至少一个

对某个查询，系统返回前 K 个候选。如果其中至少一个被标记为相关，Hit@K 记为 1；否则 记为 0。

假设问题“怎样重置密码”有三个相关块：A、B、C。系统返回前两个候选 A、X，那么：

  • Hit@2 = 1，因为 A 相关；
  • 这个指标没有说明 B、C 是否也被找回。

多个查询的平均 Hit@K，是成功命中至少一个相关项的查询比例。它直观，但无法区分“只 找到一个”和“找全所有相关证据”。

Recall@K：相关项找回了多少

Recall@K 可以写成：

前 K 个结果中相关项数量 ÷ 全部已标记相关项数量

在上面的例子中，如果返回 A、B，则 Recall@2 = 2/3；如果返回 A、X，则 Recall@2 = 1/3。

边界要先约定：某个查询没有任何相关标签时，分母为零，不能直接计算。可以把这类查询 单独归为“无答案查询”，使用拒答或误报指标检查，而不是偷偷记为 0 或 1。

相关性标签也可能不完整或存在分歧。指标只反映“系统结果相对当前标签怎样”，不自动 代表绝对真相。

K 不是越大越好

增大 K 往往更容易包含相关项，但也可能带回更多噪声、冲突和无权限内容，并增加后续 处理成本。比较 Hit@K 或 Recall@K 时必须写明 K；Hit@1 与 Hit@10 不是同一个问题。

检索指标高也不保证最终回答正确。回答步骤可能忽略证据、混合冲突内容或超出来源。至少 应把下面几类结果分开记录：

  • 检索是否找到相关证据；
  • 回答是否由证据支持；
  • 引用是否真的指向支持结论的内容；
  • 证据不足时是否正确拒答。

延迟与成本也要有口径

同一系统可以记录总延迟，也可以拆成嵌入、检索、重排和生成时间。无论选择哪种，都要 说明测量起止点、运行环境、重复次数和统计方式。

成本也不能只写一个数字而不说明范围。可以记录调用次数、输入输出 Token、付费服务 账单或本地硬件时间。具体价格会变化，应在实际项目中注明服务、版本和核查日期；本章 不提供产品价格。

一次只改变一个主要因素

假设你想比较两种切分长度：

  1. 固定语料版本、查询集、标签、检索方法和 K；
  2. 运行方案 A，保存逐查询结果；
  3. 只改变切分长度得到方案 B；
  4. 使用同一计算方式比较；
  5. 检查平均值，也检查从成功变失败的个例；
  6. 记录环境、配置和已知限制。

如果同时更换模型、语料、查询和 K，结果可能更好，但不能把改进归因于某一个变化。

一张最小实验记录表

字段 示例
实验目的 比较两种切分长度对检索的影响
语料版本 handbook-v1，共 20 个候选块
查询集 10 个固定问题，含 2 个无答案问题
相关性标签 两人复核；分歧保留说明
变量 只改变切分长度
固定项 检索方法、K=3、运行环境
指标 Hit@3、Recall@3、无答案误报、延迟
逐条结果 保存查询、返回候选、分数和引用位置
限制 样本小，只用于早期方向判断

“样本小”不等于实验没有价值，但结论必须限定在当前数据与配置，不能泛化为所有语料、 模型或生产环境。

自测与实践

  1. 某查询有相关项 A、B、C，Top-2 返回 A、X。计算 Hit@2 与 Recall@2。
  2. 为什么平均分提升后仍要检查逐条失败样本？
  3. 如果一个查询没有相关项，为什么 Recall 的分母会成为问题？
  4. 设计 A/B 实验时，列出一个要改变的变量和四个要固定的因素。
  5. 为什么检索 Recall 高不能直接证明最终回答正确？

本章小结

最小实验需要固定语料、查询、标签和配置。Hit@K 检查是否至少命中一个相关项，Recall@K 检查找回了多少已标记相关项；它们都依赖 K 和标签。检索、回答、延迟和成本应分开记录， 结论只适用于明确的数据与条件。

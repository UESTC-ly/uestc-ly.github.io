01-02 摘要：Token、上下文窗口与提示词

← 返回专题下载 Markdown ↓
本篇目录
  • 核心结论
  • 必须保留的边界

核心结论

  • Token 是模型处理的离散单位，不固定等于汉字、英文单词或字节；精确计数依赖目标 tokenizer。
  • 上下文窗口由规则、问题、历史、检索资料、工具结果和回答空间共同使用。
  • Prompt 应拆成规则、任务、数据与输出要求；检索文本属于待核对数据，不能自动变成系统 指令。
  • 内容能放进窗口不代表模型会正确使用；截断、摘要和压缩都应是明确、可观察的决策。

必须保留的边界

长上下文不等于无信息损失，分隔指令与数据也不能单独解决权限、投毒或所有提示注入问题。

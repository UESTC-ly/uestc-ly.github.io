Rust所有权、移动与借用

常见问法：Rust如何不用GC管理对象；借用检查器解决什么问题。

Rust 用所有权与借用规则约束值的使用：值由相应所有者负责生命周期，移动可以把所有权转交给另一个绑定，借用则允许暂时访问而不取得所有权。编译器据此排除许多悬空引用、重复释放和不合规别名访问。

共享借用与独占可变借用的约束，重点是某段使用期间能否存在冲突访问，而不只是变量声明时有没有 mut。内部可变性和智能指针也有各自协议；它们允许表达更复杂关系，却不取消相应的运行时或同步要求。借用检查保守地拒绝某些难以证明的代码，不意味着所有被拒程序必然会在运行时出错。

参考资料：规范或原始文档校核。

Rust生命周期标注

常见问法：生命周期标注会延长对象寿命吗；返回引用怎样保证不会悬空。

生命周期参数描述引用之间必须成立的有效期关系，让编译器验证返回值或结构体借用是否仍有效；它不会在运行时替对象增加寿命，也不会把已经销毁的局部对象变成可安全返回的引用。

一个函数若返回输入对象中的引用，需要让调用方看清返回引用依赖哪个输入。多数简单关系可以省略并由规则推断，存在多个可能来源时才需要显式表达。设计 API 时，应先决定返回拥有值还是借用值，再写生命周期关系，不能把随意加一个 'static 当作修复所有生命周期错误的方法。

参考资料：规范或原始文档校核。

Rust的String与str借用

常见问法：String和str有什么区别；为什么字符串不能随便按字节下标取字符。

String 是拥有存储的 UTF-8 字符串类型；str 表示 UTF-8 字符序列，通常通过 &str 等借用形式访问。借用不转移底层字符串所有权，所以适合接受来自 String、字面量或切片的只读文本。

UTF-8 的字符编码长度不固定，字节偏移不等于字符序号；按不合法边界切片会出问题。需要按字节、Unicode 标量或用户可见字素处理时，应先明确目标。把 &str 转成 String 通常意味着创建拥有副本，是否值得这次分配取决于是否需要长期保存或修改。

参考资料：规范或原始文档校核。

Rust的泛型、trait与动态分派

常见问法：泛型与trait对象有什么区别；什么时候使用dyn Trait。

trait 描述类型能够提供的行为，泛型参数配合 trait 约束允许编译器检查操作并常以静态分派实现；trait 对象则通过动态分派，让运行时选择一个满足接口的具体实现。二者在类型可见性、代码生成与运行时灵活性上取舍。

不是所有 trait 都能以任意方式作为 trait 对象使用，需满足相应的动态兼容规则。对性能敏感、类型在编译期可确定的路径可优先考虑泛型；需要在同一个集合中容纳运行时不同实现时，trait 对象可能更直接。动态分派成本不应脱离实际调用量与对象布局讨论。

参考资料：规范或原始文档校核。

Rust的Option、Result与panic边界

常见问法：错误为什么用Result而不是全部panic；Option怎样避免空值遗漏。

Option 把“有值或无值”表达进类型，Result 把“成功值或错误”表达进返回协议，调用方需要匹配、转换或传播。这样失败路径成为接口的一部分，而不是只依赖约定的特殊值或忽略空指针。

panic 适用于无法按当前接口继续的失败，不应代替所有可预期输入与外部操作错误。unwrap 会把失败转成 panic，只有前提确实由程序保证时才合理。错误传播还要保留有助定位的上下文；简单包一层通用字符串可能丢失具体原因和恢复方式。

参考资料：规范或原始文档校核。

Rust的Send、Sync与共享所有权

常见问法：Send和Sync分别保证什么；Arc为什么不自动让内部对象线程安全。

Send 表达值可安全跨线程转移，Sync 表达共享引用可安全跨线程使用；二者约束的是不同的访问关系。Rc 使用非原子的引用计数，不能按普通方式直接跨线程共享；Arc 通过原子引用计数支持相应的共享所有权场景。

Arc 只处理共享所有权的计数与寿命，不会自动把内部可变状态变成安全并发对象。需要修改时仍应使用满足相应约束的锁、原子或其他同步类型。手工实现这些 unsafe 标记 trait 是在向其他代码承诺不变量，不能为了让编译通过而随意添加。

参考资料：规范或原始文档校核。

Rust的unsafe与异步运行时边界

常见问法：unsafe是否关闭全部安全检查；Rust是否内置统一异步运行时。

unsafe 允许执行某些编译器无法直接验证的低层操作，但普通类型检查、借用规则和必须维持的内存安全前提仍然存在；责任转为由实现者证明。安全抽象的价值在于把少量受审查的 unsafe 限制在边界内，对外暴露不会轻易破坏约束的接口。

async 函数生成可由执行器推进的 Future，并不意味着调用后就自行在后台运行。语言提供异步构造与协议，具体调度、I/O 驱动和计时等由所选运行时提供，不能把某个第三方运行时当成所有 Rust 程序唯一的内置标准。

7B规模模型使用GRPO训练时的显存占用开销及优化方式

回答：

GRPO 的核心优势是相对 PPO 省掉独立 value/critic model，用同一 prompt 下的多条采样构成 group，通过组内 reward 标准化估计 advantage。因此它比 PPO 更省显存，但并不等于便宜。7B 模型做 GRPO 时，显存主要花在策略模型参数、梯度、优化器状态、reference model 或 KL 计算、rollout 生成的 KV cache、group samples 的 token 激活以及 reward 计算上。

粗略估算：7B 参数如果用 BF16，仅权重约 14GB；训练还需要梯度和优化器状态，Adam 全参训练会让显存显著上升，常规单卡很难承受。如果采用 LoRA/QLoRA，只训练低秩适配器，可以把可训练参数、梯度和优化器状态压下来。GRPO 还需要一次 prompt 采样多个回答，group size 越大，rollout token 和 KV cache 开销越高；如果回答很长，显存和吞吐压力会迅速增加。

优化方式包括：第一，用 LoRA/QLoRA、ZeRO/FSDP、gradient checkpointing、activation recomputation 降低训练显存；第二，用 vLLM 或高效推理引擎做 rollout，把生成和训练解耦；第三，控制 group size、最大生成长度和 prompt packing，避免无效长链路；第四，使用 flash attention、paged attention、GQA/MQA 和 KV cache 管理降低注意力开销；第五，reference model 可以共享权重、延迟计算或使用 KL 近似；第六，reward 尽量规则化和批处理，避免 reward model 成为瓶颈。

面试里要说清楚：GRPO 省的是 critic/value model 的训练成本，但 RL 训练的真实瓶颈往往在 rollout 生成、长序列、group 采样和 reward 评估。

Adapter 的优点是什么？

Adapter 的主要优点包括：

  • 训练参数少：只训练新增 Adapter 模块，不需要更新全部模型参数。
  • 模块化强：不同任务可以保存不同 Adapter，推理时按需加载。
  • 适合多任务切换：同一个底座模型可以搭配多个 Adapter，用于不同任务或领域。
  • 底座模型稳定：原始预训练模型参数被冻结，降低灾难性遗忘风险。
  • 表达能力较好：相比 Prompt Tuning 这类只在输入侧添加软提示的方法，Adapter 插入到模型中间层，通常具有更强的适配能力。

Adapter 的基本原理是什么？

Adapter 是一种典型的参数高效微调方法。它的基本思路是：冻结预训练模型的大部分参数，只在 Transformer 层中插入少量可训练的小型模块，通过训练这些新增模块来适配下游任务。

Adapter 通常插入在 Transformer 的注意力层或前馈网络层之后，其结构一般是一个瓶颈网络：

hidden → down projection → non-linear activation → up projection → residual

也就是说，Adapter 会先把 hidden state 从高维压缩到低维，再经过非线性变换，最后升维回原来的 hidden size，并通过残差连接加回原表示。

Adapter 不直接改原模型的大部分权重，而是在模型内部插入一些“小插件”，让这些插件学习特定任务或领域的适配能力。

Adapter 的缺点是什么？

Adapter 的局限主要包括：

  • 会改变模型结构：需要在 Transformer 层中插入额外模块。
  • 运行时有额外开销：每层都要经过 Adapter 模块，增加额外计算。
  • 适配器管理较复杂：模型结构与任务版本必须一同管理。
  • 现代大语言模型微调中使用频率低于 LoRA：LoRA 可以合并到原权重中，部署更方便，因此在大语言模型业务微调中更常见。

AIGC 数字人为什么越来越强调多条件混合训练？

数字人不是单条件任务。真实视频中的动作同时受文本语义、音频节奏、情绪、身份、姿态、镜头、场景和交互对象影响。

多条件混合训练的价值：

  1. 扩大可用数据

严格的音频-姿态-身份全标注数据很少，但单独的图像、视频、音频、姿态数据很多。混合训练可以利用更多弱条件数据。

  1. 提升泛化能力

模型同时见过文本生成、图像动画、音频驱动、姿态控制，更容易适应不同输入组合。

  1. 减少条件过拟合

如果只训练音频到视频，模型可能只会动嘴；加入姿态/文本/视频条件能学习更完整的人体动态。

  1. 支持产品灵活性

同一个模型可以支持只给音频、给音频+姿态、给参考视频、给文本脚本等多种使用方式。

  1. 增强鲁棒性

某个条件缺失或质量差时，模型仍能借助其他条件生成合理结果。

训练难点：

  • 不同条件强度不一致，容易互相冲突。
  • 数据质量和标注粒度不同。
  • 需要条件 dropout、任务采样比例、条件路由和损失平衡。

失败轨迹不是天然的 SFT 正样本。首先要保留完整上下文：用户输入、版本化 Prompt、模型输出、工具 schema、工具参数、Observation、环境状态、错误码、最终结果、人工修改和评测信息，并对隐私字段脱敏。然后将失败归因到具体层：意图识别、检索、规划、参数生成、执行器、上下文压缩、模型知识、评测标准或产品交互。

一个完整的回流链路是：

  1. 采集与去重： 统一 trace ID，过滤重复重试和无效日志，保护敏感数据。
  2. 分类与归因： 由规则、工具错误码和人工标注联合确定 failure type，并记录置信度。
  3. 构造修复信号： 客观错误可生成正确工具调用、拒答或格式样本；规划错误可由专家重写计划；检索错误可补充相关文档、hard negative 和查询改写样本。
  4. 选择优化手段： Prompt/Schema/工具描述修复适合协议问题；检索和索引修复适合证据问题；规则或 Workflow 修复适合确定性约束；SFT 适合稳定、可复现的行为模式；DPO/偏好优化适合多个候选中有明确偏好；奖励或 Agentic RL 适合有可验证环境反馈的长轨迹策略。
  5. 离线验证和回归： 在原 badcase、相邻场景、对抗样本和通用能力集上做单变量消融，确认修复没有引入过拟合、长度偏置或安全回退。
  6. 灰度与监控： 通过版本化配置、小流量灰度和回滚开关观察线上成功率、成本、延迟和副作用。

直接把失败轨迹做 SFT 有几个问题：失败动作会被模型模仿；一条长轨迹包含大量错误前缀，训练信号定位不清；线上用户输入可能含隐私；重复样本会让模型过拟合；只学习“怎么答”而不学习“何时拒绝或调用工具”。更可靠的做法是把失败轨迹当诊断材料，从中提取经过验证的修复片段，必要时保留失败轨迹作为负样本、偏好对或 verifier 的测试样本。

BF16与FP32精度差异、训练选型；训练推理精度一致性问题

答：FP32 是 32 位浮点数，包含 1 位符号位、8 位指数位、23 位尾数位。BF16 是 16 位浮点数，包含 1 位符号位、8 位指数位、7 位尾数位。也就是说，BF16 和 FP32 的指数位一样，动态范围接近，但尾数位少很多，精度更低。

这带来一个重要结论：BF16 比 FP16 更适合大模型训练。FP16 的指数位更少，容易 overflow/underflow，通常需要 loss scaling；BF16 保留了 FP32 的动态范围，训练稳定性更好，尤其适合 Transformer 中 attention、softmax、LayerNorm、梯度更新等数值范围变化较大的场景。

训练选型上，如果硬件支持 BF16，主流大模型训练通常优先 BF16 mixed precision。常见配置是：前向和反向大部分矩阵乘用 BF16，部分敏感算子如 LayerNorm、softmax、loss、梯度规约或 optimizer state 使用 FP32。优化器状态通常保留 FP32 master weights 或 FP32 moment，以保证更新稳定性。

FP32 的优点是精度最高、数值最稳，适合小模型验证、敏感科学计算或 debug；缺点是显存和带宽成本高。BF16 的优点是显存低、吞吐高、动态范围大；缺点是尾数精度低，极小差异可能被舍入。

训练推理精度一致性问题主要有几类：

  1. 训练用 BF16，推理用 FP16/INT8/INT4，输出可能变化。量化后尤其容易出现长尾 token 概率变化、数学推理退化、格式遵循下降。

  2. 训练和推理 kernel 不同，例如训练用 PyTorch attention，推理用 FlashAttention、vLLM、TensorRT-LLM，不同 kernel 的累加顺序和近似实现会造成微小差异。

  3. 训练时 dropout 开启、推理时关闭，这是正常差异；但如果 LayerNorm、RoPE scaling、tokenizer、chat template、position ids 不一致，就可能造成明显退化。

  4. 多卡推理或不同 batch size 下，浮点规约顺序不同，也可能导致非完全 deterministic。

解决思路是：尽量让训练和推理使用一致的 tokenizer、chat template、RoPE 参数、视觉 processor、精度配置和 attention 实现；量化前后做回归评测；对数值敏感任务保留 BF16/FP16；对线上部署模型固定推理框架版本和 kernel 配置。面试里可以强调，大模型不要求 bit-level 完全一致，但要求业务指标和关键能力在精度切换后稳定。

BLIP 的三个预训练目标（ITC/ITM/LM）各自承担什么作用？

难度评分：⭐⭐⭐ (3/5) | 考察频率：⭐⭐⭐⭐⭐ (5/5)

BLIP 预训练时同时优化三个目标，分别对应 MED 的三种模式，从粗到细、从理解到生成：

  1. ITC（Image-Text Contrastive，图文对比）：作用于单模态编码器。和 CLIP 一样用 InfoNCE 拉近匹配的图文对、推远不匹配的，学全局对齐，让图文向量进入同一空间，给后两个目标打基础。BLIP 还沿用 ALBEF 的做法，引入动量编码器和软标签[3]，缓解网络数据里"负样本其实也匹配"的噪声。

  2. ITM（Image-Text Matching，图文匹配）：作用于图像引导的文本编码器，是一个二分类任务，判断图文对是否匹配。文本经逐层 cross-attention 融合了图像信息，ITM 学到的是细粒度对齐，能分辨 ITC 难以区分的难负样本（hard negative，语义相近但细节不符的图文）。BLIP 按 ITC 相似度挖掘难负样本，同一 batch 里对比相似度越高的负样本，被选中的概率越大[4]。

  3. LM（Language Modeling，语言建模）：作用于图像引导的文本解码器，用因果自注意力自回归地逐词生成图像的 caption，优化交叉熵损失（带 0.1 的标签平滑）。它给模型带来生成能力，也是 CapFilt 中 Captioner 的基础。BLIP 用的是 LM，没有用 BERT 式的 MLM（遮词预测），论文认为 LM 能让模型把视觉信息转成连贯的描述[4]。

三个目标覆盖了对齐、匹配判别和生成这条能力链，ITC 打底，ITM 学细粒度交互，LM 把对齐转成生成。三者共享 MED 的大部分参数，同一套权重既能检索、问答，也能写描述。CLIP 只有 ITC，所以只会判别，ITM 和 LM 是 BLIP 超出 CLIP 的能力来源。

面试速答：ITC 在单模态编码器上做对比学习，学全局对齐，并用动量编码器缓解噪声；ITM 在带 cross-attention 的编码器上判断图文是否匹配，配合难负样本学细粒度对齐；LM 在解码器上逐词生成 caption，带来生成能力。CLIP 只有 ITC，另外两个目标是 BLIP 多出来的能力。

难度评分：⭐⭐⭐⭐ (4/5) | 考察频率：⭐⭐⭐⭐⭐ (5/5)

两条路线的分歧在于视觉能力在什么时候进入语言模型，是语言模型训完之后接上去，还是在联合继续预训练阶段与语言数据一起优化：

  1. BLIP-2 走事后改装（retrofit）路线。 冻结现成的视觉编码器和 LLM，只训练中间约 188M 参数的 Q-Former[25]，分视觉-语言表示学习和视觉到语言的生成学习两个阶段（见 5.3.9.2）。LLM 在预训练里从没接触过视觉，视觉信息以软提示的形式注入，也就是拼在 LLM 输入前面的一组连续向量。

  2. InternVL3 走联合继续预训练路线（论文称 native multimodal pre-training）。 它保留 ViT-MLP-LLM 结构，中间是一个随机初始化的两层 MLP，LLM 用预训练好的基座模型（Qwen2.5 系列和 InternLM3-8B）初始化[12]。区别在训练方式，InternVL3 把语言预训练和多模态对齐合并进同一个预训练阶段，LLM 参与训练，不另设对齐阶段，视觉能力在这一联合继续预训练阶段与语言数据一起优化（论文称 native multimodal pre-training）[12]。

CFG dropout、EMA、timestep sampling 和 loss weighting 分别解决什么问题？

难度评分：⭐⭐⭐⭐ (4/5) | 考察频率：⭐⭐⭐⭐⭐ (5/5)

这四个机制作用在不同位置：CFG dropout 构造无条件分支，EMA 保存平滑后的评估权重，timestep sampling 决定哪些时间位置被抽到，loss weighting 决定这些位置产生多大梯度。把它们都归为“稳定训练技巧”，很容易调错方向。

CFG dropout：让同一模型学会条件与无条件预测。 训练时以一定概率把条件替换为空条件，推理时才能组合两路输出：

f_{\mathrm{cfg}}
=f_\theta(x_t,t,\varnothing)
+s\left[f_\theta(x_t,t,c)-f_\theta(x_t,t,\varnothing)\right]

其中 \(c\) 表示生成条件，\(\varnothing\) 表示空条件；\(f_\theta\) 可以是当前参数化下的噪声、速度或其他预测，\(s\) 是 guidance scale。dropout 太少，无条件分支可能不可靠；太多则会减少条件样本的训练曝光。多条件系统还要区分“全部条件一起丢弃”和“每种条件独立丢弃”，两者训练出的可组合能力不同。验证时应画出 guidance scale 扫描曲线，同时看文本遵循、运动、伪影和多样性。

EMA：提供一份参数的滑动平均副本。

\bar{\theta}\leftarrow \beta\bar{\theta}+(1-\beta)\theta

EMA 不参与当前参数 \(\theta\) 的梯度更新，因此不能用来修复 loss 爆炸或错误梯度。它主要用于评估或发布更平滑的权重，并带来额外参数存储。衰减过大时会明显滞后于当前模型，阶段切换后尤其要比较原始权重与 EMA 权重，避免把滞后误判成训练回退。

timestep sampling：决定训练数据在时间轴上的曝光分布。 若从分布 \(q(t)\) 非均匀采样并加入正确的重要性修正，可以估计原目标；不做修正时，实际优化目标就被改变。它主要影响训练方差、收敛速度以及模型更常看到哪些噪声或路径区间。

loss weighting：直接改变不同训练项的梯度贡献。 权重可以按 SNR、时间步、帧、区域、任务或样本规格设置。它必须与预测参数化和 loss 归一化一起设计；照搬另一种参数化下的权重，可能让某些时间区间主导训练。

timestep sampling 与 loss weighting 会共同决定有效梯度分布。若时间位置按 \(q(t)\) 抽样、loss 使用 \(w(t)\)，未做其他修正时，该位置的相对贡献与 \(q(t)w(t)\) 有关。因此两者不宜同时改完再看总 loss，至少要记录分时间步 loss、梯度范数和生成切片，逐项做消融。

面试速答：CFG dropout 训练条件与无条件两路预测，为推理时的 CFG 提供基础；EMA 只维护平滑权重副本，不会修复当前训练的数值发散；timestep sampling 决定时间位置出现的频率，loss weighting 决定出现后贡献多大梯度。后二者的有效作用相互耦合，必须结合预测参数化和分时间步统计调节。

CLIP 的对比预训练目标与传统 ImageNet 监督分类有何本质区别？

难度评分：⭐⭐⭐ (3/5) | 考察频率：⭐⭐⭐⭐ (4/5)

ImageNet 监督分类学的是图像到固定标签的映射，CLIP 学的是图像和自然语言的对齐，两者的差别主要体现在三个方面：

  1. 监督信号的形态不同。 ImageNet 预训练用 128 万张图、1000 个离散类别[5]，标签是人工标注的 one-hot 向量，模型最后一层是 1000 维的分类头。CLIP 用 4 亿网络图文对，监督信号是整句自然语言，没有分类头，靠图文向量的余弦相似度衡量匹配程度。

  2. 可迁移性不同，这是差别最大的地方。 ImageNet 模型的分类头和 1000 个类绑定，迁移到新任务要换掉分类头重新微调，训练时没见过的类别没法直接识别。CLIP 没有固定分类头，做新任务时把候选类别名写成文本送进文本编码器，就能零样本分类。论文里 ViT-L/14@336px 在 ImageNet 上的零样本 Top-1 准确率是 76.2%，没用 ImageNet 的 128 万张训练图，就追平了原版有监督 ResNet-50[1]。

  3. 分布偏移下更稳。 在 ImageNet-A、ImageNet-R、ImageNet-Sketch 等自然分布偏移测试集上，有监督 ResNet 的准确率掉得很厉害，CLIP 掉得少得多[1]。常见的解释是 CLIP 学到的是用语言锚定的语义概念，对单一数据集纹理的过拟合较少。

代价是不够专精。在和训练分布完全一致的封闭任务上，专门用 ImageNet 训练的模型仍可能胜过 CLIP 的零样本结果。CLIP 的长处是开放词表、迁移能力强和抗分布偏移。

面试速答：ImageNet 监督分类学图像到 1000 个固定标签的映射，有分类头，换任务要重新微调；CLIP 学图像和整句文本的对齐，没有分类头，换类别名就能零样本分类。ViT-L/14@336px 不用 ImageNet 训练图，零样本准确率 76.2%，追平有监督 ResNet-50，在分布偏移测试集上也更稳。

CLIP 预训练范式存在哪些固有局限？

难度评分：⭐⭐⭐ (3/5) | 考察频率：⭐⭐⭐⭐ (4/5)

CLIP 擅长对齐和迁移，双塔加全局对比的做法也带来几类绕不开的局限，面试中常被追问：

  1. 细粒度理解弱。 图文只在最后做全局向量点积，局部细节建模不足。计数（"图里有几只猫"）、空间关系（"杯子在书的左边"）、属性绑定（"红色的车和蓝色的房子"容易混淆）都做不好。这是双塔晚融合结构带来的问题，单靠加数据很难完全解决。

  2. 训练数据有噪声和偏见。 4 亿图文对主要来自互联网 alt-text，质量参差，网络数据里的性别、种族刻板印象也会被模型继承，OpenAI 在原论文里专门讨论了这类风险[1]。BLIP 提出 CapFilt 清洗数据，直接动机是数据噪声[4]。

  3. 零样本结果对 prompt 敏感。 同一个类别，用 "dog" 和 "A photo of a dog." 做类别文本，结果不一样。论文报告，只加这一个模板，ImageNet 准确率就提高 1.3%[1]，要结果稳定，往往还得做 prompt 集成（见 5.3.3.2）。

  4. 文本端能力有限。 文本编码器只有 63M 参数，上下文长度 77 个 token[1]，处理不了长文本和复杂的语义推理。它更像一个标签编码器，BLIP-2、LLaVA 后来改用 LLM 做语言侧，原因之一在此。

  5. 不能生成。 CLIP 只能做匹配、检索、分类这些判别任务，生成 caption、回答开放问题要外接解码器或 LLM。

这些局限推动了后面的演进，BLIP 补上生成能力，BLIP-2 接入 LLM，LLaVA 补上指令跟随。对比学习路线本身也有改进版，代表是 SigLIP（2023）和 SigLIP 2（2025）。SigLIP 用 sigmoid 损失替代 softmax 对比损失，每个图文对单独算二分类，不再需要跨 GPU 做全局归一化，batch 更容易放大[6]；SigLIP 2 改用 Google 的多语言 Gemma 分词器（词表 256K），还推出了保持原始长宽比、支持多种分辨率的 NaFlex 变体[7]。PaliGemma、LLaVA-OneVision 等模型都用 SigLIP 做视觉编码器[8,9]。

面试速答：CLIP 的局限有五类。细粒度理解弱，计数、空间关系、属性绑定做不好；网络数据有噪声和偏见；零样本结果对 prompt 敏感；文本编码器只有 63M 参数、77 个 token；只能判别，不能生成。对比路线上的改进版是 SigLIP 和 SigLIP 2。

CLIP/InfoNCE 对比学习损失如何实现图文对齐？

给定 batch 中 \(N\) 对图文样本，图像编码为 \(v_i\)，文本编码为 \(t_i\)，通常做归一化：

\[ \|v_i\|_2=1,\quad \|t_i\|_2=1 \]

相似度：

\[ s_{ij}=\frac{v_i^Tt_j}{\tau} \]

其中 \(\tau\) 是温度系数。

图到文损失：

\[ L_{i2t}=-\frac{1}{N}\sum_i\log\frac{\exp(s_{ii})}{\sum_j\exp(s_{ij})} \]

文到图损失：

\[ L_{t2i}=-\frac{1}{N}\sum_i\log\frac{\exp(s_{ii})}{\sum_j\exp(s_{ji})} \]

总损失：

\[ L=\frac{1}{2}(L_{i2t}+L_{t2i}) \]

数学直觉：

正样本对 \((v_i,t_i)\) 被拉近，batch 内其他图文组合被推远。温度 \(\tau\) 控制分布尖锐程度，越小越强调 hard negatives。

CogVideoX 如何通过渐进训练、frame pack 与数据管线提升训练效果？

这三项分别解决“先学什么”“batch 怎么装”“监督信号是否可靠”，共同决定有限算力能否转成有效梯度。

  • 渐进训练：先在较低分辨率和较短视频上学习语义与基础运动，再提高分辨率和时长。它降低早期计算成本，但阶段切换可能造成遗忘或分布突变，需要用重叠数据和验证切片检查。

DDPM 的训练目标为什么可以化简为预测噪声 MSE？

DDPM 反向过程学习：

\[ p_{\theta}(x_{t-1}|x_t)=\mathcal{N}(x_{t-1};\mu_{\theta}(x_t,t),\sigma_t^2I) \]

变分下界中包含真实后验和模型反向分布之间的 KL：

\[ D_{KL}(q(x_{t-1}|x_t,x_0)\|p_{\theta}(x_{t-1}|x_t)) \]

两个高斯分布方差固定时，KL 关于均值的部分等价于加权 MSE：

\[ \|\tilde{\mu}_t(x_t,x_0)-\mu_{\theta}(x_t,t)\|_2^2 \]

真实后验均值可写为 \(x_t\) 和 \(x_0\) 的函数，而 \(x_0\) 又可由噪声表达：

\[ x_0=\frac{x_t-\sqrt{1-\bar{\alpha}_t}\epsilon}{\sqrt{\bar{\alpha}_t}} \]

因此模型预测均值可以重参数化为预测噪声：

\[ \mu_{\theta}(x_t,t)= \frac{1}{\sqrt{\alpha_t}} \left( x_t-\frac{\beta_t}{\sqrt{1-\bar{\alpha}_t}}\epsilon_{\theta}(x_t,t) \right) \]

忽略与时间步相关的权重后，得到简化目标：

\[ L_{\text{simple}}= \mathbb{E}_{t,x_0,\epsilon} \left[ \|\epsilon-\epsilon_{\theta}(x_t,t)\|_2^2 \right] \]

结论：

DDPM 不是随意选择预测噪声，而是因为高斯后验 KL 在特定参数化下可以化简为噪声预测 MSE，训练稳定且效果好。

Decoder-Only和Encoder-Decoder模型相比有什么优势？在训练和推理效率上有什么区别？

Decoder-Only模型：结构较为简洁，通常只由一个解码器组成。模型参数较少，相比于Encoder-Decoder模型在训练和推理上可能更高效。在自回归生成任务中表现优异，比如语言模型生成文本。

训练效率：

Decoder-Only 模型：在训练过程中，由于模型仅处理解码器部分，参数较少，训练效率较高。

Encoder-Decoder 模型：由于需要同时训练编码器和解码器部分，模型的参数量通常较大，因此训练效率相对较低。

推理效率： Decoder-Only 模型：推理过程中模型依赖先前生成的标记，因此推理时间较长，尤其在生成长文本时。

Encoder-Decoder 模型：推理时编码器只需处理一次输入，但解码器部分的推理仍然逐步进行，因此总的来说推理时间也较长，但对于复杂任务而言，效率可能更好。

Diffusion 与 Flow Matching 在工程训练上各有什么关注点？

难度评分：⭐⭐⭐⭐⭐ (5/5) | 考察频率：⭐⭐⭐⭐ (4/5)

Diffusion 与 Flow Matching 都可以训练网络把噪声分布连接到数据分布，差别主要在概率路径、监督目标和采样动力学。二者并非完全互斥：Flow Matching 可以使用扩散概率路径，Rectified Flow 则是更具体的一类路径设计。

Diffusion 先定义加噪过程，例如：

x_t=\alpha(t)x_0+\sigma(t)\epsilon,
\qquad \epsilon\sim\mathcal{N}(0,I)

其中 \(x_0\) 是干净视频 latent，\(x_t\) 是时间 \(t\) 的带噪状态，\(\alpha(t)\) 和 \(\sigma(t)\) 控制信号与噪声强度。网络可以预测噪声 \(\epsilon\)、干净样本 \(x_0\)、速度参数化 \(v\) 或其他等价目标，不能把 Diffusion 限定为“预测噪声”。训练表现会受到噪声调度、输入预条件、预测参数化、时间步采样和 loss weighting 的共同影响；推理时还要让 sampler 与训练时的参数化和噪声定义一致。

Flow Matching 选定连接两端分布的概率路径，并回归该路径上的条件速度场：

\mathcal{L}_{\text{fm}}=
\mathbb{E}_{t,x_t}
\left[
w(t)\lVert v_\theta(x_t,t,c)-u_t(x_t)\rVert_2^2
\right]

其中 \(x_t\) 从选定的概率路径采样，\(c\) 是文本等生成条件，\(u_t\) 是目标路径在时间 \(t\) 的条件速度，\(v_\theta\) 是模型预测，\(w(t)\) 是可选权重。工程上要关注路径与样本配对、时间参数化、速度场尺度，以及 ODE 求解器的步数、离散方式和误差。路径更直不等于任意模型都能稳定少步生成，最终效果仍受网络逼近误差和求解器影响。

在视频训练里，两条路线还共享相同的基础风险：VAE latent 尺度不一致、不同视频规格的 loss 归一化不一致、时间采样覆盖失衡，以及训练目标改善但运动质量没有同步提升。公平比较时应固定数据、VAE、backbone、训练算力和采样网络调用次数，再分别观察收敛速度、数值异常率、单帧质量、运动与时序质量。只更换目标函数却同时更换模型和 sampler，无法判断收益来自哪里。

面试速答：Diffusion 先定义加噪过程，可预测噪声、\(x_0\) 或 \(v\) 等目标；Flow Matching 直接回归选定概率路径上的速度场。FM 可以采用扩散路径，因此两者不是简单对立。Diffusion 侧重噪声调度、预条件、预测参数化和 sampler 对齐，FM 侧重路径、时间参数化与 ODE 求解；谁更稳定或更适合少步采样，必须在固定数据、主干和计算预算下实测。

DPO Loss 如何从 KL 约束优化目标推导？

RLHF 的理想目标可以写成在 KL 约束下最大化奖励：

\[ \max_{\pi} \mathbb{E}_{y\sim\pi(\cdot|x)}[r(x,y)] - \beta D_{KL}(\pi(\cdot|x)\|\pi_{\text{ref}}(\cdot|x)) \]

该目标的最优策略满足：

\[ \pi^*(y|x)=\frac{1}{Z(x)}\pi_{\text{ref}}(y|x)\exp\left(\frac{1}{\beta}r(x,y)\right) \]

两边取对数并整理：

\[ r(x,y)= \beta\log\frac{\pi^*(y|x)}{\pi_{\text{ref}}(y|x)} + \beta\log Z(x) \]

对于同一个 prompt 下的两个回答 \(y_w,y_l\)，归一化项 \(\log Z(x)\) 抵消：

\[ r(x,y_w)-r(x,y_l) = \beta \left[ \log\frac{\pi^*(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \log\frac{\pi^*(y_l|x)}{\pi_{\text{ref}}(y_l|x)} \right] \]

偏好模型使用 Bradley-Terry 形式：

\[ P(y_w \succ y_l|x)=\sigma(r(x,y_w)-r(x,y_l)) \]

用当前策略 \(\pi_{\theta}\) 近似 \(\pi^*\)，得到 DPO 损失：

\[ L_{\text{DPO}} = -\log\sigma \left( \beta \left[ \log\frac{\pi_{\theta}(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \log\frac{\pi_{\theta}(y_l|x)}{\pi_{\text{ref}}(y_l|x)} \right] \right) \]

一句话：

DPO 把 KL 约束 RL 问题转成了偏好对上的二分类问题，避免显式训练 reward model 和在线 PPO。

DPO 如何把偏好学习转化为分类式损失？

DPO（Direct Preference Optimization）不显式训练 reward model，也不跑 PPO，而是从 KL 约束下的偏好优化推导出直接损失。

给定 prompt \(x\)，偏好回答 \(y_w\)，劣选回答 \(y_l\)，DPO 损失：

\[ L_{\text{DPO}}=-\log\sigma\left(\beta\left[\log\frac{\pi_{\theta}(y_w|x)}{\pi_{\text{ref}}(y_w|x)}-\log\frac{\pi_{\theta}(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right]\right) \]

直觉：

  • 提高模型相对参考模型生成偏好回答的概率。
  • 降低模型相对参考模型生成劣选回答的概率。
  • \(\beta\) 控制偏离参考模型的强度。

优势：

  • 训练流程简单稳定。
  • 不需要在线 RL 采样。
  • 适合偏好数据充足的对齐场景。

DPO训练造成模型分布尖锐后，是否可以接续开展GRPO训练？

回答：

可以接续，但先要修正一个前提：DPO 并不必然让分布尖锐。分布是否低熵，取决于偏好数据一致性、训练步数、参考模型、KL 约束强度、实现中的 \(\beta\) 约定以及采样温度。若同一类偏好被反复强化、训练过度或有效约束过弱，模型确实可能把概率集中到少数模式上。

DPO 后接 GRPO 在算法上没有障碍。DPO 提供较好的偏好初始化，GRPO 再让当前策略在线采样多个候选，并按组内相对奖励构造优势：

\[ A_i=\frac{r_i-\operatorname{mean}(r_1,\ldots,r_G)} {\operatorname{std}(r_1,\ldots,r_G)+\epsilon} \]

问题在于，如果 DPO 后策略过于尖锐，同一输入采出的 \(G\) 个结果几乎相同，组内奖励方差接近零，GRPO 就失去有效学习信号；模型也难以探索 DPO 未覆盖的更优轨迹。

因此接续训练时要恢复“可控探索”。可以提高 rollout 温度或 top-p，设置熵奖励或最低熵约束，降低学习率，并持续监控输出多样性与组内奖励方差。KL 参考模型的选择也很关键：若参考 DPO 检查点，GRPO 主要在 DPO 策略附近局部改进；若参考原 SFT 模型，约束会把策略往更宽的基础分布拉回，但优化张力也更大。

还应混入 SFT/DPO 回放样本，防止格式能力、通用能力和安全边界在 RL 阶段漂移；奖励需要同时覆盖任务正确性、格式、过程合法性和安全性，否则 GRPO 可能通过投机行为拿高分。训练前最好先在离线样本上检查奖励是否能正确区分好坏轨迹。

结论是：SFT -> DPO -> GRPO 是合理链路，但 DPO 负责把策略推到一个较好区域，GRPO 需要足够的采样多样性才能继续搜索。若策略已经塌缩，直接接 GRPO 往往只是在原模式附近自我强化。

Flow Matching、Rectified Flow 与传统扩散模型的训练目标有什么差异？

Flow Matching 直接学习一个连续速度场 \(v_{\theta}(x_t,t)\)，把简单分布 \(p_0\) 传输到数据分布 \(p_1\)。

若采用线性插值路径：

\[ x_t=(1-t)x_0+tx_1 \]

目标速度为：

\[ u_t=x_1-x_0 \]

训练目标：

\[ L=\mathbb{E}_{t,x_t}\left[\|v_{\theta}(x_t,t)-u_t(x_t)\|_2^2\right] \]

Rectified Flow 也学习从噪声到数据的速度场，强调把生成路径“拉直”，使少步采样更有效。

与 DDPM 的差异：

  • DDPM 常学习噪声、score 或 \(x_0\) 预测。
  • Flow Matching 学习速度场。
  • DDPM 采样通常是逐步去噪；Flow/Rectified Flow 更像求解 ODE 轨迹。
  • 现代图像生成模型中，Flow Matching/Rectified Flow 因少步采样效率和稳定性受到重视。

GRPO 与 PPO 的数学差异是什么？为什么适合推理模型训练？

GRPO（Group Relative Policy Optimization）使用同一 prompt 下的一组候选回答作为比较组，用组内相对奖励估计 advantage，减少对单独 value model 的依赖。

对同一问题采样多个回答：

\[ \{y_1,...,y_G\} \]

得到奖励：

\[ \{r_1,...,r_G\} \]

组内标准化 advantage：

\[ A_i=\frac{r_i-\text{mean}(r_1,...,r_G)}{\text{std}(r_1,...,r_G)} \]

再用类似 PPO 的 clipped ratio 目标更新策略，并加入 KL 约束。

GRPO 为什么适合推理能力训练？

GRPO 对同一道题采样多个回答，并用规则、验证器（verifier）、单元测试或奖励模型打分。它用组内平均奖励替代价值作为 baseline，学习“同题下哪些推理轨迹更好”。

  • 优势：保留采样探索，同时省掉 value / critic，工程成本低于 PPO；
  • 风险：奖励稀疏、组内样本差异过小或 verifier 有偏时，advantage 信号会变弱，长推理还可能存在逐 token 计算不够精细的问题。

GRPO 和 PPO 的区别在哪?GRPO 的优化目标函数怎么写?

回答：

PPO 通常用价值网络估计优势，配合重要性比率裁剪限制更新；GRPO 对同一问题从旧策略采样一组回答，用组内奖励的相对高低构造优势，省去独立 critic。省去 critic 不代表没有 rollout 成本或参考策略。

对问题 $q$ 采样 $G$ 条回答 $o_i$，一种原始 GRPO 形式的结果级优势是：

\hat A_i=\frac{r_i-\mathrm{mean}(r_1,\ldots,r_G)}{\mathrm{std}(r_1,\ldots,r_G)+\delta}

令 token 级概率比率 $\rho_{i,t}=\pi_\theta(o_{i,t}\mid q,o_{i,\lt t})/\pi_{old}(o_{i,t}\mid q,o_{i,\lt t})$。一个常见的原始目标表达为：

J(\theta)=\mathbb E\left[\frac1G\sum_{i=1}^G\frac1{|o_i|}\sum_{t=1}^{|o_i|}\left(\min\left(\rho_{i,t}\hat A_i,\mathrm{clip}(\rho_{i,t},1-\epsilon,1+\epsilon)\hat A_i\right)-\beta D_{i,t}\right)\right]

其中 $D_{i,t}$ 是当前策略相对参考策略 KL 的估计，$\beta$ 控制约束；$\pi_{old}$ 是采样策略，$\pi_{ref}$ 是参考策略，两者角色不同。若用过程奖励，token 优势构造会变化；后续 GRPO 变体对长度归一化、KL 和组内标准化也可能不同，应明确实现版本。

组内奖励相同会缺少相对信号，标准差很小时要数值保护；长度归一化和奖励稀疏也会引入偏置。比较 PPO/GRPO 应同时报告任务成功、采样预算、训练稳定性与总成本。

GRPO 的训练目标通常包含什么？

GRPO 仍然属于策略优化方法。实际训练中，它通常会包含：

  • 策略比率项：比较新策略和旧策略生成当前回答的概率（例：如果这个回答是高分回答，新模型有没有适当提高它的概率？）；
  • 裁剪项：限制策略更新幅度，避免一次更新过大；
  • 组内优势值：用组内相对奖励衡量回答好坏；
  • KL 正则：约束当前模型不要偏离 reference model 太远。

可以简化理解为：

同一 prompt 多采样
→ verifier / reward model 打分
→ 组内归一化得到 advantage
→ 用策略优化目标强化高 advantage 回答
→ 用 KL 约束控制模型偏移

LLaVA 的两阶段训练（特征对齐预训练 + 指令微调）目标分别是什么？

LLaVA 分两阶段训练，先解决视觉和语言的对齐，再学按指令完成任务，各阶段冻结和训练的模块如图 3-5 所示。两个阶段都用自回归语言建模损失（预测下一个 token），只在回答部分计算损失，和 CLIP、BLIP 的对比损失不同[21]。两个阶段的目标、数据和训练设置分别如下：

阶段一：特征对齐预训练（Feature Alignment Pre-training）

（1）目标：让投影器学会把 CLIP 视觉特征映射到 LLM 的词嵌入空间，建立视觉 token 和语言的初步对齐。

（2）数据：从 CC3M 过滤出的约 595K 图文对[21,24]，每条组织成单轮对话，问题是请模型简要描述图像，答案是原始 caption。

（3）训练设置：冻结视觉编码器和 LLM，只训练投影器。论文把这一步看作给冻结的 LLM 训练一个兼容的视觉分词器[21]。

阶段二：端到端指令微调（Visual Instruction Tuning）

（1）目标：让模型理解多样的视觉指令，进行多轮对话和复杂推理，LLaVA 的主要创新在这一步。

（2）数据：约 158K 条 GPT-4 合成的多模态指令数据[21]。

（3）训练设置：视觉编码器仍冻结，LLM 和投影器一起训练。模型从只会描述图片，变成能按各种指令完成视觉任务的助手。

分两阶段的原因是，一开始就用指令数据端到端训练，投影器还没建立基本对齐，视觉 token 对 LLM 来说接近噪声，复杂指令更学不会。先用大量简单图文对把投影器校准好，再用少而精的指令数据教复杂能力，先对齐、后对话，训练更稳。BLIP-2 的 Q-Former 两阶段训练也遵循先建立对齐、再面向任务的顺序。

LLaVA评估中跨模态一致性度量MIR如何计算？其如何指导训练数据选择？

跨模态一致性度量MIR（Modality Integration Rate）计算如下：

  1. 特征提取：对图文对 \((I,T)\)，提取视觉特征 \(f_v(I)\) 与文本特征 \(f_t(T)\) 。

  2. 相似度计算： \(s(I,T) = \frac{f_v(I)^T f_t(T)}{\|f_v(I)\|\|f_t(T)\|}\) 。

  3. 分布对齐： MIR = \(\mathbb{E}_{(I,T)}[s(I,T)] - \mathbb{E}_{I,T'}[s(I,T')]\) ，其中 \(T'\) 为负样本。高MIR值表示更好对齐。实验显示，MIR与VQA准确率相关性达0.91，可用于筛选高质量训练数据（如CC3M中MIR>0.6的样本）。

LLM SFT训练常用的Loss函数及适用场景

回答：

LLM SFT 最常用的是自回归语言模型的 token-level cross entropy。给定输入和目标输出，模型预测下一个 token，训练目标是最大化目标 token 的似然，等价于最小化负对数似然：

\[ \mathcal{L}_{CE}=-\sum_t \log p_\theta(y_t|x,y_{<t}) \]

在指令微调里，通常只对 assistant answer 部分计算 loss，对 user prompt、system prompt、工具返回等上下文做 mask。这样模型学习“如何回答”，而不是学习复述用户问题。多轮对话也要仔细处理 loss mask，否则模型可能学会生成用户消息。

结构化抽取任务可以继续用 cross entropy 训练 JSON 或 schema 输出，但要配合格式校验和字段级评估。如果某些字段更关键，可以做 token/field 加权 loss。分类任务可以接分类头用 cross entropy，也可以转成生成式标签。排序或偏好类任务更适合 DPO、pairwise ranking loss、contrastive loss，而不是普通 SFT。

对于 Thinking/Reasoning 数据，如果训练完整推理链，loss 会覆盖中间思考和最终答案；如果只希望模型输出短答案，可以对 reasoning 部分 mask 或蒸馏成简洁解释。选择 loss 的原则不是越复杂越好，而是训练目标要和线上输出、评测指标、可控性一致。

LLM 如何将原始语料组织成 token 序列、训练样本和上下文窗口？

难度评分：⭐⭐⭐⭐ (4/5) | 考察频率：⭐⭐⭐⭐⭐ (5/5)

大语言模型的训练通常按 token 消耗算力，上下文窗口更长，padding 浪费更明显，因此原始语料不能直接进入训练，而要经过文本规范化、tokenization、添加特殊 token、截断或拼接、padding 或 packing，以及构造 attention mask、causal mask 和 loss mask 等步骤，最终生成 input_ids、labels、mask 等训练张量。

预训练阶段通常将清洗后的文档转成 token 序列，再按照固定上下文窗口切分或 packing 成训练样本，并对所有有效 token 做 next token prediction。多个无关文档拼接时通常需要插入 EOS 或文档分隔 token，避免模型把不相关内容误学成连续上下文。

不同训练阶段的 loss mask 不同。预训练通常让所有有效 token 参与 loss；SFT 阶段则通常只让 assistant 输出部分参与 loss, system 和 user 内容作为条件输入。

LLM 预训练数据质量如何评估？为什么质量比单纯规模更重要？

难度评分：⭐⭐⭐⭐ (4/5) | 考察频率：⭐⭐⭐⭐ (4/5)

大语言模型预训练数据质量评估的特殊之处在于：模型训练按 token 消耗算力，低质量 token 不仅浪费训练预算，还可能让模型学习到错误事实、垃圾网页模式、模板化表达、隐私泄露模式或不安全内容。

因此，大语言模型预训练数据质量评估的核心，不只是判断文本是否“干净”，而是判断样本能否提供 有效训练信号。高质量数据通常具有信息密度高、表达自然、结构完整、事实相对可靠、重复度低、与目标能力匹配等特点。相比单纯扩大数据规模，提高有效 token 密度往往能更直接地提升训练效率和模型能力。

通常结合规则、分类器、困惑度评估、强模型打分和人工抽检进行质量评估，而不是依赖单一指标。

注：困惑度需要特别谨慎：困惑度过高可能说明文本是乱码、异常字符或低质量采集内容，也可能只是因为它属于代码、论文、医学术语、法律条文、数学公式或少数语言；困惑度过低则可能说明文本高度模板化、重复严重，甚至存在训练集泄露或评测集污染。

LLM 预训练语料清洗与传统数据清洗有什么不同？

难度评分：⭐⭐⭐ (3/5) | 考察频率：⭐⭐⭐⭐⭐ (5/5)

大语言模型预训练语料清洗的不同在于：数据规模很大，来源包括网页、书籍、论文、代码、社区问答、多语种语料和领域文档，清洗目标不只是让数据“干净”，还要提高训练集中的有效 token 密度，减少乱码、广告、模板页、重复文本、低质回答、隐私信息、有害内容和评测集污染对训练的干扰。

  • 有效 token 密度：在相同训练算力下，让模型看到更多有信息量、可学习、与目标能力匹配的 token。大语言模型训练成本很高，低质量 token 不仅浪费算力，还可能让模型学习到错误事实、模板化表达、垃圾网页模式、隐私泄露模式或不安全内容。

标准流程通常是：

原始数据采集 → 格式解析 → 语言识别 → 编码修复 → 乱码/空文本过滤 → 正文抽取 → 去重 → 质量过滤 → 隐私与敏感信息处理 → 安全过滤 → 评测污染检测 → 版权与许可证审查 → 人工抽检与版本入库

清洗强度不能简单越强越好。过弱会保留噪声、重复和风险内容，过强则可能误删长尾知识、少数语言、代码片段、公式、法律条文、医学术语、口语表达和领域文档，导致模型知识覆盖变窄、风格单一或领域能力下降。

实际工程中更常用分层过滤 + 质量打分 + 加权采样：高质量数据提高权重，中等质量数据降权，低质量或高风险数据删除，特殊领域数据使用领域规则单独处理。

LoRA 为什么可以用低秩矩阵近似权重更新？

原始线性层：

\[ y=Wx \]

微调时不直接更新 \(W\)，而是学习低秩增量：

\[ W'=W+\Delta W,\quad \Delta W=BA \]

其中：

\[ B \in \mathbb{R}^{d_{out}\times r},\quad A \in \mathbb{R}^{r\times d_{in}},\quad r \ll \min(d_{out},d_{in}) \]

前向：

\[ y=Wx+\frac{\alpha}{r}BAx \]

数学假设：

下游任务所需的参数更新 \(\Delta W\) 近似低秩，即主要变化集中在少数方向上。

优势：

  • 可训练参数量从 \(d_{out}d_{in}\) 降到 \(r(d_{out}+d_{in})\)。
  • 原模型权重冻结，便于多任务切换。
  • 推理时可将 LoRA 权重 merge 回原权重。

LoRA 为什么能低成本适配大模型？

难度评分：⭐⭐⭐⭐ (4/5) | 考察频率：⭐⭐⭐⭐⭐ (5/5)

LoRA 的核心假设是：模型适配时的权重更新具有低秩结构。

原始线性层：

\[ y = Wx \]

LoRA 冻结 \(W\)，只训练低秩更新：

\[ W' = W + \Delta W,\quad \Delta W = BA \]

其中 \(A\) 和 \(B\) 是低秩矩阵，rank 很小。

优点：

  • 可训练参数少。
  • 显存占用低。
  • 多任务只需保存 LoRA 权重。
  • 推理时可与原权重合并，不增加额外延迟。

适用场景：

  • 垂直领域问答。
  • 文风适配。
  • 多模态模型微调。
  • 文生图风格 LoRA。
  • 企业私有数据适配。

局限：

  • rank 太小可能表达不足。
  • 数据质量差仍会过拟合。
  • 对复杂能力提升不一定等同全量微调。

LoRA 如何减少显存开销？

LoRA 节省显存的关键是：（1）可训练参数少。LoRA 的可训练参数量为：

\[ r \times k + d \times r = r(d+k) \]

当 $r$ 远小于 $d$ 和 $k$ 时，训练参数量会大幅下降。

（2）底座模型权重被冻结。在全量微调中，需要为全部模型参数保存模型权重，梯度， 优化器状态（例如 Adam 的一阶动量和二阶动量）以及训练过程中的激活值。而在 LoRA 中，底座模型参数不更新，因此主要只需要为 LoRA 参数保存梯度和优化器状态。

但 LoRA 并不会让训练成本按参数减少比例等比例下降。因为训练时仍然要经过底座模型做前向计算和反向传播，激活显存也仍然存在。

LoRA 的参数量和计算量如何推导？

原始线性层：

\[ y=Wx \]

其中：

\[ W\in\mathbb{R}^{d_{out}\times d_{in}} \]

原始参数量：

\[ d_{out}d_{in} \]

LoRA 冻结 \(W\)，学习：

\[ \Delta W=BA \]
\[ B\in\mathbb{R}^{d_{out}\times r},\quad A\in\mathbb{R}^{r\times d_{in}} \]

LoRA 可训练参数量：

\[ rd_{out}+rd_{in}=r(d_{out}+d_{in}) \]

当 \(r\ll \min(d_{out},d_{in})\) 时，参数量大幅减少。

前向计算：

\[ y=Wx+\frac{\alpha}{r}BAx \]

LoRA 分支计算量：

  1. 先算 \(Ax\)：约 \(rd_{in}\)。
  2. 再算 \(B(Ax)\)：约 \(d_{out}r\)。

总额外计算量：

\[ O(r(d_{in}+d_{out})) \]

而完整更新矩阵的计算量为：

\[ O(d_{in}d_{out}) \]

面试结论：

LoRA 的高效来自低秩假设：下游任务所需权重变化 \(\Delta W\) 位于低维子空间。

LoRA低秩适配的底层原理

回答：

LoRA 冻结预训练权重，只训练一个低秩增量，基于任务适配所需的有效权重变化可以由较低秩表示近似这一经验假设。对于采用列向量输入的线性层：

W'=W+\frac{\alpha}{r}BA,\quad
W\in\mathbb{R}^{d_{\mathrm{out}}\times d_{\mathrm{in}}},\quad
A\in\mathbb{R}^{r\times d_{\mathrm{in}}},\quad
B\in\mathbb{R}^{d_{\mathrm{out}}\times r}.

因此增量的秩最多为 r，可训练参数量为 r(d_in+d_out)，而全量更新该矩阵需要 d_in·d_out 个参数。α/r 是标准 LoRA 常见的缩放方式，变体可能采用不同缩放。常见初始化令 A 随机、B 为零，使初始增量为零且底座输出不变；若 A、B 同时初始化为零，初始梯度可能无法推动两者更新。

训练时底座权重不更新，A、B 通过普通反向传播优化。它主要减少可训练参数、梯度和优化器状态，不能按相同比例减少全部激活显存或计算。注入哪些注意力投影或 MLP 层、rank 和学习率取决于任务，rank 越高并不必然越好。

在兼容精度和布局下，可以将增量合并进底座权重，避免保留额外低秩分支；多个适配器动态切换时可能选择不合并。QLoRA 还结合量化底座等机制，不能直接等同于 LoRA。量化后合并与重新量化也可能产生误差，需要重新验证。

面试可补充选型边界：LoRA 适合资源受限的任务适配，持续变化的外部知识不一定适合写入权重。评测需对比底座、提示词或 RAG 基线、不同 rank 与训练步数，同时检查目标任务提升、通用能力退化和数据泄漏。

回答：

LoRA 假设适配任务所需的权重变化可以用较低秩矩阵近似，在冻结底座权重的同时，训练两个小矩阵形成增量。对于线性层：

W'=W+\Delta W,\qquad \Delta W=\frac{\alpha}{r}BA,
\quad A\in\mathbb{R}^{r\times d_{\mathrm{in}}},
\quad B\in\mathbb{R}^{d_{\mathrm{out}}\times r}.

可训练参数为 r×(d_in+d_out)，而全量训练该矩阵需要 d_in×d_out 个参数。rank 控制增量表示容量，α/r 是标准 LoRA 的缩放；rank 更大不必然效果更好，也可能增加成本和过拟合。常见初始化令一个矩阵为零，另一个为随机值，使模型初始函数与底座一致；两个矩阵同时为零会妨碍初始梯度更新。

目标模块可以选择注意力中的若干投影层，也可以扩展到 MLP，具体取决于架构和任务。训练时底座参数不更新，但前向传播与必要的激活和反向链路仍存在，因此显存节省主要来自可训练参数、梯度和优化器状态减少，不等于总显存按参数比例下降。

在兼容精度与布局下，可将低秩增量合并到基础权重以部署；动态切换多个适配器时则可能保留额外计算。QLoRA 还引入量化底座等技术，不能简单解释为“LoRA 就是量化”。调参应固定数据划分，比较 rank、目标层、学习率与训练步数，并检查目标任务和通用能力。

补充说明

LoRA 冻结预训练权重 \(W_0\)，把任务更新限制为低秩增量：

\[ W=W_0+\Delta W,\qquad \Delta W=BA, \]

其中 \(A\in\mathbb R^{r\times d}\)、\(B\in\mathbb R^{k\times r}\)，\(r\ll\min(k,d)\)。训练时只更新 \(A,B\)，推理时可合并到线性层，也可保留 Adapter 动态切换。

它有效是经验性低内在秩假设：下游任务通常只需在预训练表示附近沿少数重要方向调整，不代表所有任务更新都低秩。关键超参包括 rank、alpha、dropout、学习率、target modules、数据质量和训练步数。LoRA 不能自动解决数据错误、任务冲突、灾难性遗忘或基础能力不足；复杂任务可能需要更高秩、DoRA、全量微调或继续预训练。量化 LoRA 要区分基座权重存储精度、激活精度、Adapter 精度和反向计算精度。

LoRA和Ptuning与传统fine-tuning的区别

  • 参数更新数量：LoRA和Ptuning都旨在减少参数更新的数量。LoRA通过低秩分解技术更新少量参数，而Ptuning仅优化输入提示的嵌入向量。相比之下，传统fine-tuning需要更新模型中的大部分或全部参数。

  • 计算资源和存储需求：由于LoRA和Ptuning仅更新少量参数，它们通常需要更少的计算资源和存储空间。传统fine-tuning则需要更多的计算资源，尤其是在处理大规模模型时。

  • 模型性能：LoRA和Ptuning旨在在不牺牲模型性能的前提下，减少微调的计算负担。传统fine-tuning可能会导致模型过拟合，尤其是在训练数据有限的情况下。

LoRA和Ptuning通过其独特的微调策略，为大型模型的微调提供了新的解决方案，特别是在计算资源和时间有限的情况下。然而，选择哪种微调方法应根据具体任务需求、资源限制和期望的灵活性来决定。

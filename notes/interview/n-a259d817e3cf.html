复杂度、均摊分析与输入规模

时间复杂度描述操作次数随输入规模增长的趋势，空间复杂度描述额外空间如何增长。分析应先定义 \(n\)、数据表示和基本操作；嵌套循环的次数不一定机械相乘，循环边界是否互相依赖才是关键。

均摊分析把一串操作的总成本分摊到每次操作，例如动态数组偶尔扩容复制，并不意味着每次追加都线性。最坏、平均和均摊是不同保证，面试回答要说明假设；常数、缓存与 I/O 仍影响工程性能，渐进更优也不保证所有小输入都更快。

参考资料：WeThinkIn/AIGC-Interview-Book 原文。

数组、链表与局部性

数组以连续存储支持按下标定位，链表通过节点引用组织顺序。已知节点后插删可较便宜，不等于链表按位置查找也快；数组中间插入可能移动元素，但连续访问通常具有更好的局部性。

选择时应同时考虑查找方式、插删位置、分配开销、迭代器或指针失效以及额外指针空间。反转链表要在改变当前节点的下一指针前保存后继，否则会丢失未处理链；这体现的是状态更新顺序，而不是需要背一长段代码。

参考资料：WeThinkIn/AIGC-Interview-Book 原文。

哈希表、冲突与扩容

哈希表将键映射到桶，再处理落入同一桶的冲突。常见方式包括链式组织和开放寻址；哈希函数、装载因子与键分布共同影响性能。期望常数时间依赖条件，不能写成任何输入下都严格 O(1)。

扩容通常涉及重新组织元素或迁移桶，因此需要考虑单次延迟、内存峰值和并发访问。键的相等判断必须与哈希规则一致；可变键在入表后改变相关字段，可能破坏查找。若需要有序遍历或范围查询，平衡树等结构可能更合适。

参考资料：WeThinkIn/AIGC-Interview-Book 原文；WeThinkIn/AIGC-Interview-Book 原文。

栈、队列、堆与操作目标

栈按后进先出组织，适合嵌套解析、回退和显式模拟递归；队列按先进先出组织，适合逐层遍历和任务排队；堆维护局部有序以快速获取优先级最高或最低的元素，不保证整体遍历有序。

选择应由要支持的操作决定。大小为 K 的小顶堆可维护最大的 K 个数，根结点是当前候选中最小者，便于判断新元素是否需要替换；每次更新通常为 O(log K)。若只需要一次选择，也可考虑分治选择等办法，不能认为所有 Top K 都必须排序全部输入。

参考资料：WeThinkIn/AIGC-Interview-Book 原文；WeThinkIn/AIGC-Interview-Book 原文。

搜索树、平衡树与有序查询

二叉搜索树利用左右子树的键序关系缩小查找范围，操作成本取决于树高；若退化成链，搜索仍可能线性。平衡树通过额外不变量和旋转等操作控制高度，以换取稳定的对数级查找、插入和删除保证。

堆只保证父子关系，不能据此进行普通搜索树式二分；哈希表也不自然支持按键范围遍历。面试比较时应说明是点查、范围查询、取极值还是顺序输出，避免只记各种树“查询很快”。

参考资料：WeThinkIn/AIGC-Interview-Book 原文。

DFS、BFS 与图遍历状态

DFS 沿一条路径深入再回溯，适合枚举、连通性和递归结构；BFS 按层扩展，在无权图或单位边权图中可用于求最少边数路径。一般带权最短路不能直接用普通 BFS 代替。

图可能有环和多条到达路径，应明确何时标记已访问，以及“当前路径状态”与“全局已访问”是否相同。BFS 通常在入队时标记，避免同一节点重复排队；回溯枚举则可能在返回时撤销路径状态。状态定义不清是重复访问或漏解的常见原因。

参考资料：WeThinkIn/AIGC-Interview-Book 原文。

二分查找的不变量与边界

二分查找利用有序或单调判定，每轮排除不可能的区间。实现前应决定维护的是闭区间还是半开区间，并写清目标是否一定存在；更新边界与终止条件必须与这一选择一致。

查找第一个满足条件的位置，可将问题统一为“左侧不满足、右侧满足”的边界搜索；查找值、lower bound 和 upper bound 也可据此区分。二分答案还需要证明判定的单调性。仅把循环模板套到非单调函数上，无法得到正确结果。

参考资料：WeThinkIn/AIGC-Interview-Book 原文。

双指针、滑动窗口与可维护条件

双指针用两个位置协作推进，避免反复扫描；滑动窗口维护一个连续区间及其状态，通过扩张和收缩寻找满足条件的区间。能否线性移动取决于状态是否可增量维护，以及条件是否支持相应移动策略。

例如窗口内计数可用频次表增减；但含负数的区间和问题不一定具有正数场景的单调性，不能照搬“和过大就缩左边”。面试中应先说明窗口不变量与移动依据，再写代码，并验证重复元素、空窗口和边界位置。

参考资料：WeThinkIn/AIGC-Interview-Book 原文。

回溯、剪枝与解空间

回溯按选择—递归—撤销的顺序遍历解空间，适合组合、排列和约束枚举。撤销操作恢复的是进入本层前的状态，使其他分支不受前一分支污染。

剪枝必须依据能证明该分支不可能产生所需答案的条件，而不是因为某种情况“看起来少见”。排序后去重、上下界和可行性检查各有适用前提；求全部解、计数或只找一个解，也会改变可以采用的剪枝。应从状态、选择集合、终止条件和重复定义出发设计。

参考资料：WeThinkIn/AIGC-Interview-Book 原文。

动态规划的状态、转移与空间优化

动态规划把问题分解为相互依赖的子问题，并保存结果避免重复计算。关键不是先画表，而是定义状态代表什么、哪些信息足以决定后续，以及转移如何覆盖全部合法选择。

还需确定初始条件与计算顺序，保证读取的子状态已可用。滚动数组只保留仍需读取的状态；压成一维后，遍历方向可能决定使用的是本轮还是上一轮结果。例如不同背包问题的循环方向不能互换。空间优化应在二维依赖关系清楚之后进行，而不是靠记忆方向替代理解。

参考资料：WeThinkIn/AIGC-Interview-Book 原文。

贪心选择与正确性证明

贪心在每一步选择当前看起来最有利的方案，只有当局部选择能够保留某个全局最优解时才可靠。常见证明可通过交换论证、结构性质或不变量说明，不能仅凭样例通过推断正确。

与动态规划相比，贪心通常保留更少的候选状态，因此可能更高效，也更依赖问题结构。先考虑是否存在容易构造的反例，再寻找可证明的选择规则；如果当前选择会改变未来代价而无法消除后效性，就需要更完整状态或其他方法。

参考资料：WeThinkIn/AIGC-Interview-Book 原文。

排序稳定性、复杂度与使用场景

稳定排序保持等价键元素原有相对顺序，适合已有次级顺序需要保留的场景。排序算法还应比较最坏时间、额外空间、是否原地，以及输入是否接近有序；“平均 O(n log n)”不能覆盖所有保证。

快速排序要注意选主元与退化情况，归并排序通常需要额外空间但便于稳定合并，堆排序提供不同的空间和最坏界限。实际工程库可能组合多种策略。若只需去重、找极值或 Top K，应先判断是否真的需要完整排序。

参考资料：WeThinkIn/AIGC-Interview-Book 原文。

最大正方形：状态边长与返回面积

把 dp[i][j] 定义为“以第 i-1 行、第 j-1 列为右下角，且全部由 1 构成的最大正方形边长”。当前格子为 0 时状态为 0；为 1 时，能扩大的边长受左、上、左上三个已有正方形中最短者限制，因此状态是三个邻居的最小值加 1。额外增加一行、一列 0 作为边界，就能用同一转移处理第一行、第一列和单格矩阵。

这里必须区分边长和题目要求的面积。先维护最大边长 best，最后返回 best * best。常见错误包括转移下标缺项、直接返回边长，以及漏算第一行或第一列。用零边界统一转移，并在最后计算面积，可以避免这些问题。

#include <algorithm>
#include <vector>

int maximalSquareArea(const std::vector<std::vector<char>>& a) {
    if (a.empty() || a[0].empty()) return 0;
    int rows = static_cast<int>(a.size());
    int cols = static_cast<int>(a[0].size());
    std::vector<std::vector<int>> dp(rows + 1,
                                   std::vector<int>(cols + 1, 0));
    int best = 0;
    for (int i = 1; i <= rows; ++i) {
        for (int j = 1; j <= cols; ++j) {
            if (a[i - 1][j - 1] == '1') {
                dp[i][j] = 1 + std::min({dp[i - 1][j], dp[i][j - 1],
                                        dp[i - 1][j - 1]});
                best = std::max(best, dp[i][j]);
            }
        }
    }
    return best * best;
}

代码中的矩阵元素按题目约定使用字符 '0' 和 '1'。单个 1 返回 1，两个相邻的 1 仍只能形成面积 1 的正方形，2×2 全 1 才返回 4；不能把只要求连通或矩形面积的问题套到这个状态上。时间和空间复杂度均为 \(O(mn)\)，空间压到一行时还需保存被覆盖前的左上状态。

参考资料：Datawhale 原问答及原代码；力扣 221 官方题目与返回面积要求。

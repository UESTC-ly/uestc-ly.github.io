## 9. 回文数

[力扣原题](https://leetcode.cn/problems/palindrome-number/)

### 简短题意

给定整数 x，判断从左往右与从右往左读是否相同。负数不是回文数。

### 思路解析

主解法转成十进制字符串，再从两端比较字符，直观且不会遇到反转整个整数的溢出问题。不转换字符串属于进阶，可通过反转后半部分完成。

### C++ 主模板

```cpp
class Solution {
    // 负数直接拒绝，其余转成字符串从两端比较。
public:
    bool isPalindrome(int x) {
        if (x < 0) return false;
        string digits = to_string(x);
        int left = 0, right = static_cast<int>(digits.size()) - 1;
        while (left < right) {
            if (digits[left] != digits[right]) return false;
            left++; right--;
        }
        return true;
    }
};
```

### 示例与复杂度

121 返回 true；-121 因负号返回 false；10 对应 10，反向 01，不相同。

D 为十进制位数，时间 O(D)，额外空间 O(D)。

### 易错点与一类题总结

0 是回文数；本模板主动使用字符串，没有声称满足不转换字符串的进阶版本。

数字题若本质是字符顺序，可先转换表示再复用字符串模板，另按要求考虑数值优化。

## 66. 加一

[力扣原题](https://leetcode.cn/problems/plus-one/)

### 简短题意

非负整数以数组 digits 保存，每格为一位，最高位在前，无多余前导零。返回该整数加一后的数字数组。

### 思路解析

从末位开始处理进位。当前位不是 9 就加一并返回；是 9 则置零，进位传到左侧。全部为 9 时，需要增加一个最高位 1。

### C++ 主模板

```cpp
class Solution {
    // 遇到 9 置零并继续进位，其他位加一后结束。
public:
    vector<int> plusOne(vector<int>& digits) {
        for (int i = static_cast<int>(digits.size()) - 1; i >= 0; i--) {
            if (digits[i] < 9) { digits[i]++; return digits; }
            digits[i] = 0;
        }
        digits.insert(digits.begin(),1);
        return digits;
    }
};
```

### 示例与复杂度

[1,2,9]→[1,3,0]；[9,9]→[1,0,0]；[0]→[1]。

时间 O(n)；算法工作空间 O(1)，数组扩容和返回结果可能占 O(n) 存储。会修改输入 digits。

### 易错点与一类题总结

只能在进位结束时返回；全部为 9 时不能遗漏最高位；不要先把长数组转 int。

逐位进位算法从低位向高位传播，遇到非最大位即可停止。

## 172. 阶乘后的零

[力扣原题](https://leetcode.cn/problems/factorial-trailing-zeroes/)

### 简短题意

给定非负整数 n，返回 n! 的十进制表示末尾连续零的数量。

### 思路解析

末尾每个零来自一对 2×5，阶乘中因子 2 比 5 多，所以统计因子 5 的数量即可。每个 5 的倍数贡献一次，每个 25 的倍数多贡献一次，以此类推。反复 n/=5 并累加，相当于 n/5+n/25+…。

### C++ 主模板

```cpp
class Solution {
    // n/5、n/25 等分别统计每一层因子 5。
public:
    int trailingZeroes(int n) {
        int answer = 0;
        while (n > 0) { n /= 5; answer += n; }
        return answer;
    }
};
```

### 示例与复杂度

25! 有 floor(25/5)+floor(25/25)=5+1=6 个末尾零。

时间 O(log_5(n+1))，额外空间 O(1)。

### 易错点与一类题总结

只数 5 的倍数会漏掉 25、125 的额外因子；不需要实际算阶乘，后者会迅速溢出；0!=1，答案为 0。

乘积末尾零转化为进制因子的配对数量，先找限制配对数的稀缺因子。

## 50. Pow(x,n)

[力扣原题](https://leetcode.cn/problems/powx-n/)

### 简短题意

实现 x 的整数 n 次幂，n 可以为负。负指数表示倒数，题目保证输入有定义且结果在规定浮点范围内。

### 思路解析

指数按二进制拆分，base 每轮平方，指数最低位为 1 时将 base 乘入答案。循环保持“答案×base^剩余指数”等于目标值。负指数先将 base 变为 1/x，再把指数取正；指数要先转 long long，才能处理 INT_MIN。

### C++ 主模板

```cpp
class Solution {
    // 指数每轮减半，底数每轮平方，最低位为 1 才乘入答案。
public:
    double myPow(double x, int n) {
        long long exponent = n;
        if (exponent < 0) { x = 1.0 / x; exponent = -exponent; }
        double answer = 1.0;
        while (exponent > 0) {
            if (exponent & 1) answer *= x;
            x *= x;
            exponent >>= 1;
        }
        return answer;
    }
};
```

### 示例与复杂度

2^10 用 10=8+2 的分解，仅将对应 2^8、2^2 乘入答案；2^-2=0.25。

时间 O(log(|n|+1))，额外空间 O(1)。

### 易错点与一类题总结

不能先写 -n 再转换 long long；n=0 返回 1；浮点结果存在正常舍入误差，不应用严格相等检查任意小数。

重复乘法的次数可通过指数二进制拆分降为对数级，适用于快速幂与矩阵幂。

## 149. 直线上最多的点数

[力扣原题](https://leetcode.cn/problems/max-points-on-a-line/)

### 简短题意

给定坐标互不相同的平面点 points，返回同一直线上的最大点数。

### 思路解析

逐个固定锚点，将其他点按相对斜率分组，同组点与锚点共线。用整数 (dy,dx) 表示斜率，以 gcd 约分并统一方向：dx>0，垂线统一 dy>0。不用浮点除法，避免近似误差；只看锚点后面的点也足够，因为任意最优直线都有一个下标最小的点作为锚点。

### C++ 主模板

```cpp
class Solution {
public:
    int maxPoints(vector<vector<int>>& points) {
        int n = points.size(), answer = 1;
        for (int i = 0; i < n; i++) {
            unordered_map<string,int> count;
            for (int j = i + 1; j < n; j++) {
                int dx = points[j][0] - points[i][0];
                int dy = points[j][1] - points[i][1];
                int divisor = gcd(abs(dx),abs(dy));
                dx /= divisor; dy /= divisor;
                if (dx < 0 || (dx == 0 && dy < 0)) { dx = -dx; dy = -dy; }
                string key = to_string(dy) + "/" + to_string(dx);
                answer = max(answer,++count[key] + 1); // 别忘锚点本身
            }
        }
        return answer;
    }
};
```

### 示例与复杂度

[[1,1],[2,2],[3,3]] 对首点都约分为斜率 1/1，答案为 3；垂线用 1/0 表示。

坐标绝对值<=10^4，gcd 和键长度有固定界，平均时间 O(n²)，额外空间 O(n)。一般坐标幅度 C 下可计 O(n² log C)。

### 易错点与一类题总结

必须统一符号，让相反方向落到同组；水平线归一成 0/1；题目无重复点，否则 gcd(0,0) 需要单独处理。gcd 需 <numeric>。

精确比值分组用整数约分代替浮点数，以归一化方向向量表示斜率。

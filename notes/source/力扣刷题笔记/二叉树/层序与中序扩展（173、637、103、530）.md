## 173. 二叉搜索树迭代器

[力扣原题](https://leetcode.cn/problems/binary-search-tree-iterator/)

### 简短题意

实现 BSTIterator，初始化时接收二叉搜索树。next 返回中序遍历的下一个最小值，hasNext 判断是否还有值；next 调用保证有效，要求 next 平均 O(1)、空间 O(h)。

### 思路解析

栈存储尚待访问的左侧路径。初始化把根到最左节点压栈；next 弹出栈顶后，把它右子树的左侧路径压栈。左子树已访问，当前节点弹出，然后准备右子树，正好遵守中序顺序。

### C++ 主模板

```cpp
class BSTIterator {
    // 栈顶始终是下一个中序节点；访问后准备右子树左链。
    stack<TreeNode*> pending;
    void pushLeft(TreeNode* root) {
        while (root != nullptr) { pending.push(root); root = root->left; }
    }
public:
    BSTIterator(TreeNode* root) { pushLeft(root); }
    int next() {
        TreeNode* current = pending.top(); pending.pop();
        pushLeft(current->right);
        return current->val;
    }
    bool hasNext() { return !pending.empty(); }
};
```

### 示例与复杂度

[7,3,15,null,null,9,20] 依次输出 3、7、9、15、20。

初始化 O(h)；单次 next 最坏 O(h)，完整遍历中每节点入栈、出栈各一次，摊还 O(1)；hasNext O(1)，空间 O(h)。

### 易错点与一类题总结

若先把全部中序结果存数组，会占 O(n)，不满足题目指定空间；next 不是每一次都严格 O(1)。TreeNode 由题目提供。

需要逐个产出遍历结果时，用显式栈保存“尚待执行的递归路径”，构造惰性迭代器。

## 637. 二叉树的层平均值

[力扣原题](https://leetcode.cn/problems/average-of-levels-in-binary-tree/)

### 简短题意

给定二叉树 root，返回从上到下每一层节点值的平均数，结果用浮点数表示。

### 思路解析

按层 BFS，固定当前层节点数并累计这一层的 sum，层末用 sum/size 得到平均值。sum 使用 double，避免多个大整数累加溢出。

### C++ 主模板

```cpp
class Solution {
    // 固定层大小，先累加再做浮点除法。
public:
    vector<double> averageOfLevels(TreeNode* root) {
        vector<double> ans;
        if (root == nullptr) return ans;
        queue<TreeNode*> q; q.push(root);
        while (!q.empty()) {
            int size = q.size(); double sum = 0;
            for (int i = 0; i < size; i++) {
                TreeNode* node = q.front(); q.pop(); sum += node->val;
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
            ans.push_back(sum / size);
        }
        return ans;
    }
};
```

### 示例与复杂度

[3,9,20,null,null,15,7] 的层平均为 [3,14.5,11]。

时间 O(n)，队列 O(w)，输出 O(h)。

### 易错点与一类题总结

层大小在开始时固定；sum 使用浮点类型，不能先做整数除法再转换。

层级统计可在普通层序模板中替换“收集值”为求和、计数、最大值等聚合。

## 103. 二叉树的锯齿形层序遍历

[力扣原题](https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal/)

### 简短题意

给定二叉树，第一层从左到右，第二层从右到左，之后交替方向，返回按层分组的锯齿形遍历结果。

### 思路解析

BFS 仍始终按左孩子、右孩子入队；将本层值收集完后，按方向决定是否反转。将树的扫描顺序与展示顺序分开，避免改变队列后破坏层次关系。

### C++ 主模板

```cpp
class Solution {
    // 队列保持正常层序，展示方向通过反转本层结果实现。
public:
    vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
        vector<vector<int>> ans;
        if (root == nullptr) return ans;
        queue<TreeNode*> q; q.push(root);
        bool leftToRight = true;
        while (!q.empty()) {
            int size = q.size(); vector<int> layer;
            for (int i = 0; i < size; i++) {
                TreeNode* node = q.front(); q.pop(); layer.push_back(node->val);
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
            if (!leftToRight) reverse(layer.begin(), layer.end());
            ans.push_back(layer);
            leftToRight = !leftToRight;
        }
        return ans;
    }
};
```

### 示例与复杂度

[3,9,20,null,null,15,7] 返回 [[3],[20,9],[15,7]]。

时间 O(n)，额外工作空间 O(w)，输出 O(n)。

### 易错点与一类题总结

第二层开始反转，方向每层只切换一次；reverse 所有层的总成本仍为 O(n)。

展示顺序与访问顺序不同，可先用稳定的遍历模板收集，再对本组结果做局部转换。

## 530. 二叉搜索树的最小绝对差

[力扣原题](https://leetcode.cn/problems/minimum-absolute-difference-in-bst/)

### 简短题意

给定至少两个节点的二叉搜索树，返回任意两个不同节点值之差的最小绝对值。

### 思路解析

二叉搜索树中序结果有序。有序数列的最小差一定出现在相邻元素之间，因为跨越多个元素的差不小于其中任意相邻差。中序时仅保存前一个值，并更新当前差。

### C++ 主模板

```cpp
class Solution {
    // 中序有序，最小差只需比较相邻访问值。
    bool hasPrevious = false;
    int previous = 0, answer = INT_MAX;
    void inorder(TreeNode* root) {
        if (root == nullptr) return;
        inorder(root->left);
        if (hasPrevious) answer = min(answer, root->val - previous);
        previous = root->val; hasPrevious = true;
        inorder(root->right);
    }
public:
    int getMinimumDifference(TreeNode* root) {
        hasPrevious = false; answer = INT_MAX;
        inorder(root);
        return answer;
    }
};
```

### 示例与复杂度

[4,2,6,1,3] 的中序为 [1,2,3,4,6]，相邻差最小为 1。

时间 O(n)，递归栈 O(h)。

### 易错点与一类题总结

必须保存前一个已访问节点，不是仅比较父子；hasPrevious 明确表示尚无前值，避免使用与合法值冲突的哨兵。

BST 问题先转化为中序有序序列，再复用有序数组的相邻关系。

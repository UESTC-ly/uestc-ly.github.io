# 6. Z 字形变换

## 题型与核心思路

**模拟：每行一个字符串，行号上下往返，最后逐行拼接。**

题目按 Z 字形放入字符，再从上到下逐行读取。最终只需要各行字符的顺序，因此不必存储具体列位置和空白。

用 `vector<string> rows(numRows)` 存储每一行，维护两个状态：

- `row`：当前字符应放入的行号，初始为 0。
- `step`：下一步方向，1 向下，-1 向上。

三行时行号依次为：

```text
0 → 1 → 2 → 1 → 0 → 1 → 2 → 1 → ...
```

每一步固定为：**放字符 → 到边界时调整方向 → 移动行号。**

## 例子手推

输入 `s = "PAYPALISHIRING"`，`numRows = 3`：

| 字符 | 放入行号 | 放入后的该行 | 下一步方向 |
|---|---|---|---|
| P | 0 | P | 向下 |
| A | 1 | A | 向下 |
| Y | 2 | Y | 向上 |
| P | 1 | AP | 向上 |
| A | 0 | PA | 向下 |
| L | 1 | APL | 向下 |
| I | 2 | YI | 向上 |

全部处理后：

```text
rows[0] = "PAHN"
rows[1] = "APLSIIG"
rows[2] = "YIR"
结果 = "PAHNAPLSIIGYIR"
```

## C++ 主模板

```cpp
class Solution {
public:
    string convert(string s, int numRows) {
        // 一行时没有上下移动
        if (numRows == 1) {
            return s;
        }

        vector<string> rows(numRows);
        int row = 0;
        int step = 1;

        for (char c : s) {
            rows[row] += c;  // 把字符追加到当前行末尾

            if (row == 0) {
                step = 1;
            } else if (row == numRows - 1) {
                step = -1;
            }
            row += step;
        }

        string ans;
        for (const string& line : rows) {
            ans += line;
        }
        return ans;
    }
};
```

本地编译需要 `<string>`、`<vector>`，并使用 `std::` 或 `using namespace std;`。

`for (char c : s)` 依次取出每个字符；`for (const string& line : rows)` 依次读取每行，通过引用避免复制字符串。

## 追问：`rows[row] += c` 是什么意思

`rows` 是字符串数组，`rows[row]` 是其中一整个字符串，`+= c` 把字符追加到这个字符串末尾；等价于 `rows[row].push_back(c)`。

可以把 rows 想成几张纸条：row 选中一张纸条，再在末尾写一个字符。更完整的类型区分和示例见 [[基础与模板/C++基础#字符串数组与追加字符|字符串数组与追加字符]]。

## 正确性、复杂度与易错点

行号在顶部与底部间往返，保证每个字符进入正确的行；按输入顺序追加，保证同一行内的先后顺序正确；最后逐行拼接得到答案。

设字符串长度为 n、行数为 r：时间 O(n + r)，额外空间 O(n + r)，结果空间另占 O(n)。行字符串共保存 n 个字符，并存在 r 个字符串对象。

- `numRows == 1` 必须单独处理，否则行号移动后可能越界。
- 最后一行下标是 `numRows - 1`。
- 先放字符，再调整下一步方向，最后移动；到边界后不要继续向外走。
- 行数大于字符数时，字符依次落入不同的行，拼接仍得到原字符串。

## 一类题总结

**识别信号：按固定路线移动，到边界改变方向。**

先提炼“当前位置、移动方向、转向条件”，再按输出需求保存必要信息。本题位置是 row，方向是 step，边界是 0 与 numRows - 1；输出按行组织，所以只保存每行字符串。

记忆口诀：**字符入当前行，到顶到底换方向，最后逐行拼起来。**

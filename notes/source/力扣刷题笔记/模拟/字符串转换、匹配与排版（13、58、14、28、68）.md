## 13. 罗马数字转整数

[力扣原题](https://leetcode.cn/problems/roman-to-integer/)

### 简短题意

给定合法罗马数字字符串 s，将其转成整数。通常较大的符号在前；较小符号放在较大符号之前时表示相减，例如 IV=4、IX=9。

### 思路解析

逐字符扫描：若当前值小于后一个字符的值，就减去当前值，否则加上当前值。合法输入中，减法组合恰好符合这个相邻大小关系；无需枚举整个字符串的特殊分支。

### C++ 主模板

```cpp
class Solution {
    // 较小符号在较大符号前时取负，其余符号取正。
public:
    int romanToInt(string s) {
        unordered_map<char, int> value = {{'I',1},{'V',5},{'X',10},{'L',50},
                                          {'C',100},{'D',500},{'M',1000}};
        int ans = 0;
        for (int i = 0; i < static_cast<int>(s.size()); i++) {
            int current = value[s[i]];
            if (i + 1 < static_cast<int>(s.size()) && current < value[s[i + 1]]) ans -= current;
            else ans += current;
        }
        return ans;
    }
};
```

### 示例与复杂度

MCMXCIV：1000-100+1000-10+100-1+5=1994。

时间 O(n)，固定符号表额外空间 O(1)。

### 易错点与一类题总结

题目保证罗马数字合法；这段代码不是格式校验器。最后一个字符没有后继，应直接加上。

编码中的局部特殊组合，可先寻找能统一解释组合的相邻关系；转换与验证是不同任务。

## 58. 最后一个单词的长度

[力扣原题](https://leetcode.cn/problems/length-of-last-word/)

### 简短题意

给定包含英文字母和空格的字符串 s，返回最后一个单词的长度。单词是由非空格字符组成的连续片段，题目保证至少有一个单词。

### 思路解析

从末尾先跳过空格，再向左统计连续非空格字符。这样不必分割整个字符串，前面的单词对答案没有影响。

### C++ 主模板

```cpp
class Solution {
    // 先跳过末尾空格，再统计最后一段字符。
public:
    int lengthOfLastWord(string s) {
        int i = static_cast<int>(s.size()) - 1;
        while (i >= 0 && s[i] == ' ') i--;
        int len = 0;
        while (i >= 0 && s[i] != ' ') { len++; i--; }
        return len;
    }
};
```

### 示例与复杂度

"  fly me   to   the moon  "：跳过两个末尾空格，统计 moon，答案为 4。

最坏时间 O(n)，额外空间 O(1)。

### 易错点与一类题总结

先用 int 转换 size，再减 1，避免无符号下溢；检查 i>=0 后再读字符。

只关心最后一个片段时，倒序扫描常比构造所有片段更直接。

## 14. 最长公共前缀

[力扣原题](https://leetcode.cn/problems/longest-common-prefix/)

### 简短题意

给定字符串数组 strs，返回所有字符串共有的最长前缀。不存在公共前缀时返回空字符串。

### 思路解析

把第一个字符串作为初始前缀，逐个与后续字符串比较，从头数出匹配长度，再将前缀缩短。处理完每个字符串后，prefix 都是当前所有已处理字符串的最长公共前缀。

### C++ 主模板

```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        if (strs.empty()) return "";
        string prefix = strs[0];
        for (int i = 1; i < static_cast<int>(strs.size()); i++) {
            int j = 0;
            while (j < static_cast<int>(prefix.size()) &&
                   j < static_cast<int>(strs[i].size()) && prefix[j] == strs[i][j]) j++;
            prefix.resize(j); // 只保留当前共同前缀
        }
        return prefix;
    }
};
```

### 示例与复杂度

["flower","flow","flight"]：prefix 从 flower 缩为 flow，再缩为 fl。

时间 O(S)，S 为所有字符串长度之和；工作字符串空间 O(L)，L 为首字符串长度。

### 易错点与一类题总结

有空字符串时答案必为空；公共前缀只从下标 0 开始，不能把公共子串当成前缀。

多个对象共享的性质，可以维护已处理对象的共同结果，再逐个收缩候选范围。

## 28. 找出字符串中第一个匹配项的下标

[力扣原题](https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/)

### 简短题意

给定字符串 haystack 和 needle，返回 needle 在 haystack 中第一次完整出现的起始下标；不存在则返回 -1。

### 思路解析

使用 KMP。先算 needle 的前缀函数 pi[i]：前缀 needle[0..i] 的最长相等真前后缀长度。匹配失败时将匹配长度 j 回退到 pi[j-1]，保留仍可能有效的前缀，不回退文本指针。每次回退都缩短候选，且之前已匹配后缀与新前缀相等，因此不会漏掉首次匹配。

### C++ 主模板

```cpp
class Solution {
    // 失配时只回退模式串的已匹配长度，文本位置不回退。
public:
    int strStr(string haystack, string needle) {
        int m = needle.size();
        if (m == 0) return 0;
        vector<int> pi(m, 0);
        for (int i = 1, j = 0; i < m; i++) {
            while (j > 0 && needle[i] != needle[j]) j = pi[j - 1];
            if (needle[i] == needle[j]) j++;
            pi[i] = j;
        }
        int j = 0;
        for (int i = 0; i < static_cast<int>(haystack.size()); i++) {
            while (j > 0 && haystack[i] != needle[j]) j = pi[j - 1];
            if (haystack[i] == needle[j]) j++;
            if (j == m) return i - m + 1;
        }
        return -1;
    }
};
```

### 示例与复杂度

needle="abab" 的 pi 为 [0,0,1,2]；在 haystack="abacabab" 中，遇到 c 回退后继续扫描，首次完整匹配起点为 4。

时间 O(n+m)，额外空间 O(m)。

### 易错点与一类题总结

真前后缀不能包含整个字符串；回退写 pi[j-1]，不能写 j-- 或 pi[j]；找到完整匹配后立即返回，避免读取 needle[m]。

字符串匹配的重复工作来自重试已知相等部分。前缀函数保存可复用的相等边界，适用于匹配、周期和重复结构。

## 68. 文本左右对齐

[力扣原题](https://leetcode.cn/problems/text-justification/)

### 简短题意

给定单词数组 words 和行宽 maxWidth，每行贪心装入尽可能多的单词，再分配空格使行长恰好为 maxWidth。普通多单词行左右对齐，多余空格优先分给左侧间隔；最后一行和单词行左对齐，右侧补空格。

### 思路解析

先确定一行装哪些词：单词总长加最少间隔数不能超过行宽。普通行有 gaps 个间隔，总空格为 maxWidth-letters，先每个分 total/gaps，再给前 total%gaps 个间隔各加一。最后行按单空格连接，随后补齐右侧；选词与排版分成两步，边界更清楚。

### C++ 主模板

```cpp
class Solution {
    // 先装词确定一行，再分别处理普通行和末行的空格。
public:
    vector<string> fullJustify(vector<string>& words, int maxWidth) {
        vector<string> ans;
        int n = words.size(), left = 0;
        while (left < n) {
            int right = left, letters = 0;
            while (right < n && letters + static_cast<int>(words[right].size()) + right - left <= maxWidth) {
                letters += words[right].size();
                right++;
            }
            int gaps = right - left - 1;
            string line;
            if (right == n || gaps == 0) {
                for (int i = left; i < right; i++) {
                    if (i > left) line += ' ';
                    line += words[i];
                }
                line += string(maxWidth - line.size(), ' ');
            } else {
                int spaces = maxWidth - letters;
                int base = spaces / gaps, extra = spaces % gaps;
                for (int i = left; i < right; i++) {
                    line += words[i];
                    if (i < right - 1) line += string(base + (i - left < extra), ' ');
                }
            }
            ans.push_back(line);
            left = right;
        }
        return ans;
    }
};
```

### 示例与复杂度

words=["This","is","an","example","of","text","justification."]，宽 16：结果是 "This    is    an"、"example  of text"、"justification.  "。

时间 O(S+R×maxWidth)，S 为输入字符总数，R 为结果行数；额外工作空间 O(maxWidth)，输出空间 O(R×maxWidth)。

### 易错点与一类题总结

单词行 gaps=0，不能做除法；最后一行不均匀分配内部空格。题目保证每个词长度不超过行宽，right 才能至少前进一步。

排版题先确定分组，再处理组内布局；将普通行和特殊行分开，避免一个公式兼顾所有边界。

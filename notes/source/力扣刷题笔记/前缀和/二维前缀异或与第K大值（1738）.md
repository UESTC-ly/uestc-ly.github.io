# 1738. 找出第 K 大的异或坐标值

> 整理自源笔记《力扣刷题笔记2.md》；已排除目标库中已有的同题旧稿。

## 1738. 找出第 K 大的异或坐标值

- 题型：二维前缀异或 + Top K / 小顶堆
- 核心：先算出每个坐标 `(i, j)` 的左上角矩形异或值，再在所有坐标值中找第 `k` 大
- 坐标值含义：坐标 `(a, b)` 的值是 `matrix[0][0]` 到 `matrix[a][b]` 这个矩形区域内所有元素的异或结果
- 比较套路：
  - 矩阵左上区域值 -> 二维前缀
  - 第 `k` 大 -> 小顶堆维护前 `k` 大

### 二维前缀异或

定义：

```cpp
pre[i][j]
```

表示：

```text
matrix[0][0] 到 matrix[i - 1][j - 1] 的区域异或值
```

也就是说，`pre` 比 `matrix` 整体往右下偏移一格。

二维前缀异或公式：

```cpp
pre[i][j] = pre[i - 1][j]
          ^ pre[i][j - 1]
          ^ pre[i - 1][j - 1]
          ^ matrix[i - 1][j - 1];
```

### 为什么 `pre[i][j]` 从 `[1][1]` 开始

因为 `pre` 多开了一圈：

```cpp
vector<vector<int>> pre(m + 1, vector<int>(n + 1, 0));
```

第一行和第一列都当作空区域：

```cpp
pre[0][j] = 0;
pre[i][0] = 0;
```

这样计算第一行、第一列时不会访问到 `pre[-1][j]` 或 `pre[i][-1]`，就不用写边界特判。

对应关系：

```text
pre[1][1] 对应 matrix[0][0]
pre[1][2] 对应 matrix[0][0] 到 matrix[0][1]
pre[2][1] 对应 matrix[0][0] 到 matrix[1][0]
pre[2][2] 对应 matrix[0][0] 到 matrix[1][1]
```

一句话记：

> `pre` 多开一圈，从 `1` 开始算，是为了让第一行第一列不用特判。`pre[i][j]` 对应 `matrix[i - 1][j - 1]`。

### 小顶堆找第 k 大

堆里始终只保留目前最大的 `k` 个数：

```cpp
heap.push(x);
if (heap.size() > k) heap.pop();
```

最后堆顶就是第 `k` 大。

原因：

- 小顶堆堆顶是堆里最小的
- 堆里保留的是最大的 `k` 个
- 所以堆顶就是这 `k` 个大数里最小的，也就是整体第 `k` 大

### C++代码

```cpp
class Solution {
public:
    int kthLargestValue(vector<vector<int>>& matrix, int k) {
        int m = matrix.size();
        int n = matrix[0].size();

        // pre[i][j] 表示 matrix[0][0] 到 matrix[i - 1][j - 1] 的异或值
        vector<vector<int>> pre(m + 1, vector<int>(n + 1, 0));

        // 小顶堆，维护当前最大的 k 个坐标值
        priority_queue<int, vector<int>, greater<int>> heap;

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                pre[i][j] = pre[i - 1][j]
                          ^ pre[i][j - 1]
                          ^ pre[i - 1][j - 1]
                          ^ matrix[i - 1][j - 1];

                heap.push(pre[i][j]);

                // 只保留最大的 k 个
                if (heap.size() > k) {
                    heap.pop();
                }
            }
        }

        return heap.top();
    }
};
```

### 复杂度

- 时间复杂度：`O(mn log k)`
- 空间复杂度：`O(mn + k)`

### 记忆口诀

> 左上矩形求异或，二维前缀来帮忙。  
> `pre` 多开一圈，从 `1` 开始防越界。  
> 所有坐标值算出来，小顶堆留前 `k` 大。

### 一类题总结

- 看到“从 `(0,0)` 到 `(i,j)` 的区域值”，先想二维前缀
- 看到“第 `k` 大 / 前 `k` 大”，先想 Top K
- 这题就是：**二维前缀异或 + 小顶堆 Top K**

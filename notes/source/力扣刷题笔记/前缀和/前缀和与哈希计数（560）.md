# 前缀和与哈希计数：和为 K 的子数组（560）

> 本笔记整理 LeetCode 560。核心目标是掌握如何使用 **前缀和 + 哈希表计数**，在线性时间内统计“和为目标值的连续子数组数量”。

---

# 一、560. 和为 K 的子数组

## 1. 题意

给定整数数组 `nums` 和整数 `k`，统计其中有多少个**连续、非空子数组**的元素和等于 `k`。

例如：

```text
nums = [1,1,1], k = 2
```

符合条件的子数组有：

```text
下标 [0,1]：[1,1]
下标 [1,2]：[1,1]
```

因此答案为 `2`。

需要注意：

- 子数组必须连续；
- 不同位置上的子数组分别计数；
- 数组中可能包含正数、负数和 `0`。

## 2. 为什么普通滑动窗口不适用

题目允许：

```text
-1000 <= nums[i] <= 1000
```

因此数组中可能出现负数。普通滑动窗口通常依赖下面的单调关系：

```text
扩大窗口 → 窗口和变大
缩小窗口 → 窗口和变小
```

有负数时，这个规律不成立。例如：

```text
nums = [2,-1,2]
```

加入 `-1` 后窗口变长，但窗口和反而减小，所以无法只根据“当前和大于还是小于 `k`”决定移动哪一侧。

因此，本题的主流基础解法是：

> **前缀和 + 哈希表计数。**

## 3. 前缀和公式

设：

```text
prefix[i] = nums[0] + nums[1] + ... + nums[i]
```

如果某个连续子数组从下标 `j + 1` 开始，在下标 `i` 结束，那么它的区间和为：

```text
prefix[i] - prefix[j]
```

希望这个区间和等于 `k`：

```text
prefix[i] - prefix[j] = k
```

移项得到：

```text
prefix[j] = prefix[i] - k
```

所以，当当前前缀和为 `sum` 时，只需查询：

```text
以前出现过多少次 sum - k
```

它出现了几次，就有几个以当前位置为右端点、元素和为 `k` 的子数组。

## 4. 哈希表保存什么

定义：

```cpp
unordered_map<long long, int> prefixCount;
```

含义是：

```text
前缀和 → 该前缀和在当前位置之前出现的次数
```

不能只用 `unordered_set`，因为同一个前缀和可能出现多次，而每次出现都可能形成一个不同的合法子数组。

例如，数组中存在若干个 `0` 时，同一个前缀和可能被重复得到，必须保留其出现次数。

## 5. 关键初始化：空前缀

遍历前必须初始化：

```cpp
prefixCount[0] = 1;
```

它表示：

> 还没有读取任何元素时，前缀和为 `0`，并且出现过一次。

这样才能统计从下标 `0` 开始、和为 `k` 的子数组。

例如：

```text
nums = [1,2,3], k = 3
```

遍历到 `2` 时：

```text
sum = 3
sum - k = 0
```

查询到预先保存的空前缀 `0`，于是能够统计子数组 `[1,2]`。

## 6. 示例推演

以：

```text
nums = [1,1,1], k = 2
```

为例。

初始状态：

```text
sum = 0
answer = 0
prefixCount = {0: 1}
```

| 当前数字 | 当前前缀和 `sum` | 查找 `sum - k` | 以前出现次数 | `answer` |
|---:|---:|---:|---:|---:|
| `1` | `1` | `-1` | `0` | `0` |
| `1` | `2` | `0` | `1` | `1` |
| `1` | `3` | `1` | `1` | `2` |

最终答案为 `2`。

## 7. 处理顺序

遍历每个数字时，依次执行：

```text
1. 把当前数字加入前缀和；
2. 查询以前出现过多少次 sum - k；
3. 将这些次数加入答案；
4. 记录当前前缀和 sum。
```

对应代码：

```cpp
sum += num;
answer += prefixCount[sum - k];
prefixCount[sum]++;
```

必须**先查询、后记录当前前缀和**。

如果先记录，并且 `k == 0`，当前前缀和就可能与自己匹配，相当于错误统计一个长度为 `0` 的空子数组。

记忆：

> **只用以前的前缀和匹配当前前缀和，所以先查再存。**

## 8. C++ 代码

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        // prefixCount[x]：前缀和 x 在当前位置之前出现的次数
        unordered_map<long long, int> prefixCount;

        // 空前缀的和为 0，用来统计从下标 0 开始的合法子数组
        prefixCount[0] = 1;

        long long sum = 0; // 当前前缀和
        int answer = 0;    // 和为 k 的连续子数组数量

        for (int num : nums) {
            // 1. 更新当前前缀和
            sum += num;

            // 2. 如果以前出现过 sum - k，
            //    那些位置之后到当前位置的子数组和都等于 k
            auto it = prefixCount.find(sum - k);
            if (it != prefixCount.end()) {
                answer += it->second;
            }

            // 3. 当前前缀和供后面的位置使用
            prefixCount[sum]++;
        }

        return answer;
    }
};
```

查询部分也可以简写为：

```cpp
answer += prefixCount[sum - k];
```

当键不存在时，`operator[]` 会创建该键并将值初始化为 `0`，因此结果仍然正确。使用 `find` 则不会为仅用于查询但不存在的前缀和创建新键，语义更明确。

## 9. 复杂度

设数组长度为 `n`：

- 时间复杂度：平均 `O(n)`；
- 空间复杂度：`O(n)`。

每个元素只遍历一次；哈希表的查询与插入平均为 `O(1)`。

## 10. 易错点总结

### 易错点一：把“子数组”理解成不连续的子序列

本题只统计连续区间，不能跳过中间元素。

### 易错点二：数组有负数却套用普通滑动窗口

负数会破坏窗口和的单调性，应改用前缀和。

### 易错点三：哈希表只记录是否出现

本题统计的是子数组数量，同一个前缀和可能出现多次，所以必须记录出现次数。

### 易错点四：忘记初始化 `prefixCount[0] = 1`

这样会漏掉所有从下标 `0` 开始、和为 `k` 的子数组。

### 易错点五：先记录当前前缀和，再统计答案

当 `k == 0` 时可能把当前前缀和与自己匹配，错误统计空子数组。正确顺序是先查再存。

# 二、方法归纳

看到下面的题目特征时，可以考虑“前缀和 + 哈希表”：

- 研究连续子数组；
- 数组中可能包含负数；
- 需要统计区间和等于某个目标值的子数组数量。

核心公式：

```text
区间和 = 当前前缀和 - 以前的前缀和
```

若区间和需要等于 `k`：

```text
以前的前缀和 = 当前前缀和 - k
```

通用模板：

```cpp
unordered_map<long long, int> prefixCount;
prefixCount[0] = 1;

long long sum = 0;
int answer = 0;

for (int num : nums) {
    sum += num;
    answer += prefixCount[sum - k];
    prefixCount[sum]++;
}
```

复习口诀：

```text
连续区间求目标和，前缀作差找旧和；
旧和次数全加入，空前缀一先放入；
当前前缀先查询，随后再存防空集。
```

# 数组三等分切分：等和与每段含正数

> 来源：本次会话提供的题目图片、C++ 代码片段与数组下标讨论。题目编号和原题名未在材料中给出。
>
> 本笔记只整理本次新增会话中与该题相关的长期知识：前缀和建模、正数约束优化、C++ 实现细节，以及 0 下标与 1 下标的对应关系。

## 一、题意

给定长度为 `n` 的整数数组，需要在数组中切两刀，分成三个**连续且非空**的子数组，满足：

1. 三个子数组的元素和相等；
2. 每个子数组中至少存在一个严格大于 `0` 的整数；
3. 统计不同切分位置的数量。

约束：

- `3 ≤ n ≤ 2 × 10^5`；
- `-10^9 ≤ a[i] ≤ 10^9`。

示例：

```text
[3, 3, 3]
```

只能切成：

```text
[3] | [3] | [3]
```

答案为 `1`。

```text
[1, 1, 4, 5, 1, 4]
```

总和为 `16`，不能被 `3` 整除，答案为 `0`。

> “子数组中至少有一个正数”不等于“子数组的和必须为正数”。例如 `[1, -1]` 的和为 `0`，但其中有正数，仍满足正数条件。

## 二、切分位置与前缀和

为了方便，本题实现采用 **1 下标**保存数组：

```text
nums[1], nums[2], ..., nums[n]
```

设第一刀切在 `nums[i]` 后面，第二刀切在 `nums[j]` 后面，则三个子数组为：

```text
[1 ... i]
[i + 1 ... j]
[j + 1 ... n]
```

为了保证三段都非空，必须满足：

```text
1 ≤ i < j ≤ n - 1
```

定义前缀和：

```text
prefix[k] = nums[1] + nums[2] + ... + nums[k]
```

如果数组总和为 `total`，那么三段和分别为：

```text
第一段：prefix[i]
第二段：prefix[j] - prefix[i]
第三段：total - prefix[j]
```

设每段目标和为 `target`。三段和相等时：

```text
target = total / 3
```

因此两个切分位置必须满足：

```text
prefix[i] = target
prefix[j] = 2 * target
```

如果：

```cpp
total % 3 != 0
```

则总和不能平均分成三份，答案直接为 `0`。

## 三、如何处理“每段至少有一个正数”

定义：

```text
positiveCount[k]
```

表示前 `k` 个元素中正数的数量。

切分位置为 `i`、`j` 时：

### 1. 第一段 `[1, i]`

至少有一个正数的条件是：

```text
positiveCount[i] > 0
```

### 2. 第二段 `[i + 1, j]`

正数数量为：

```text
positiveCount[j] - positiveCount[i]
```

因此需要：

```text
positiveCount[j] - positiveCount[i] > 0
```

### 3. 第三段 `[j + 1, n]`

正数数量为：

```text
positiveCount[n] - positiveCount[j]
```

因此需要：

```text
positiveCount[n] - positiveCount[j] > 0
```

## 四、从 `O(n²)` 优化到 `O(n)`

如果枚举所有第一刀 `i` 和第二刀 `j`，时间复杂度是 `O(n²)`，无法处理 `n = 2 × 10^5`。

### 1. 预处理合法的第一刀

定义：

```text
firstCount[k]
```

表示在位置 `1...k` 中，有多少个位置可以作为第一刀。

位置 `i` 可以作为第一刀，需要满足：

```text
prefix[i] == target
positiveCount[i] > 0
```

所以：

```cpp
firstCount[i] = firstCount[i - 1];
if (prefix[i] == target && positiveCount[i] > 0) {
    firstCount[i]++;
}
```

### 2. 固定第二刀，寻找第一刀数量

固定第二刀位置 `j`，第二段 `[i + 1, j]` 必须包含正数。

维护：

```text
lastPositive
```

表示区间 `[1, j]` 中最后一个正数的位置。

要让第二段包含这个最后的正数，需要：

```text
i < lastPositive
```

也就是：

```text
i ≤ lastPositive - 1
```

因此，当前 `j` 对应的合法第一刀数量为：

```cpp
firstCount[lastPositive - 1]
```

当前第二刀 `j` 还必须满足：

```text
prefix[j] == 2 * target
```

以及第三段包含正数：

```text
positiveCount[n] - positiveCount[j] > 0
```

满足这些条件后，把对应的第一刀数量加入答案。

## 五、为什么 `j < 2` 要跳过？

当前代码使用 1 下标：

```text
nums[1], nums[2], ..., nums[n]
```

并且：

```cpp
j
```

表示第二刀切在 `nums[j]` 后面。

当 `j = 1` 时，切分形式是：

```text
nums[1] | nums[2] ... nums[n]
```

如果还要放置第一刀，就必须有：

```text
1 ≤ i < 1
```

这是不可能的。因此第二刀至少要在 `nums[2]` 后面，即 `j ≥ 2`。

所以代码中可以写：

```cpp
if (j < 2) {
    continue;
}
```

这里的 `nums[0]` 不是第一个真实元素，而是 1 下标实现中为前缀和保留的辅助位置：

```text
nums[0]：辅助位置，不属于题目数组
nums[1]：第一个真实元素
```

### 与 0 下标的对照

如果改用 0 下标：

```text
nums[0], nums[1], ..., nums[n - 1]
```

那么：

```text
nums[0] | nums[1] | nums[2] ...
```

确实是合法的三段切分形式。此时第二刀的下标 `j` 可以从 `1` 开始，循环范围通常写成：

```cpp
for (int j = 1; j <= n - 2; j++) {
    // j 表示切在 nums[j] 后面
}
```

因此要始终先确认：

> 当前代码是 0 下标还是 1 下标。不能把 0 下标的 `nums[0]` 和 1 下标实现中的辅助位置混为一谈。

## 六、完整 C++ 代码

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    // 使用 1 下标，nums[0] 作为辅助位置，不存放真实数组元素。
    vector<long long> nums(n + 1);

    // prefix[i]：nums[1] 到 nums[i] 的元素和。
    vector<long long> prefix(n + 1, 0);

    // positiveCount[i]：前 i 个元素中正数的数量。
    vector<int> positiveCount(n + 1, 0);

    for (int i = 1; i <= n; i++) {
        cin >> nums[i];

        prefix[i] = prefix[i - 1] + nums[i];

        positiveCount[i] = positiveCount[i - 1];
        if (nums[i] > 0) {
            positiveCount[i]++;
        }
    }

    long long total = prefix[n];

    // 总和不能被 3 整除，不可能分成三个和相等的子数组。
    if (total % 3 != 0) {
        cout << 0 << '\n';
        return 0;
    }

    long long target = total / 3;

    /*
     * firstCount[k]：位置 1...k 中合法第一刀的数量。
     * 合法第一刀 i 需要满足：
     * 1. prefix[i] == target；
     * 2. 第一段 [1, i] 中至少有一个正数。
     */
    vector<long long> firstCount(n + 1, 0);

    for (int i = 1; i <= n; i++) {
        firstCount[i] = firstCount[i - 1];

        if (prefix[i] == target && positiveCount[i] > 0) {
            firstCount[i]++;
        }
    }

    long long answer = 0;

    // 当前第二刀左侧最后一个正数的位置。
    int lastPositive = 0;

    // 第二刀必须不晚于 n - 1，否则第三段为空。
    for (int j = 1; j <= n - 1; j++) {
        if (nums[j] > 0) {
            lastPositive = j;
        }

        // 1 下标下，j = 1 时没有合法的第一刀 i < j。
        if (j < 2) {
            continue;
        }

        // prefix[j] 是前两段的总和，应等于 2 * target。
        if (prefix[j] != 2 * target) {
            continue;
        }

        // 第三段 [j + 1, n] 至少要有一个正数。
        if (positiveCount[n] - positiveCount[j] == 0) {
            continue;
        }

        /*
         * 第二段 [i + 1, j] 要包含正数，必须有 i < lastPositive。
         * firstCount[lastPositive - 1] 统计了所有符合条件的第一刀 i。
         */
        if (lastPositive > 0) {
            answer += firstCount[lastPositive - 1];
        }
    }

    cout << answer << '\n';
    return 0;
}
```

## 七、代码中的常见错误

### 1. 空 `vector` 不能直接用下标写入

错误：

```cpp
vector<int> nums;
for (int i = 0; i < n; i++) {
    cin >> nums[i];
}
```

`nums` 初始长度为 `0`，访问 `nums[i]` 会越界。

可以提前分配空间：

```cpp
vector<long long> nums(n + 1);
```

或者使用 `push_back`：

```cpp
vector<long long> nums;
for (int i = 0; i < n; i++) {
    long long x;
    cin >> x;
    nums.push_back(x);
}
```

### 2. 变量未初始化

错误：

```cpp
int sum;
sum += nums[i];
```

应当初始化：

```cpp
long long sum = 0;
```

### 3. 总和和答案不能使用 `int`

总和的绝对值可能达到约 `2 × 10^14`，切分方案数也可能达到约 `O(n²)`，所以至少以下变量应使用 `long long`：

```cpp
sum
prefix
target
answer
```

### 4. 不要只用 `sum / 3` 判断可行性

必须先检查：

```cpp
if (sum % 3 != 0)
```

否则不能平均分成三个整数和相等的部分。

## 八、正确性与复杂度

对于每个第二刀位置 `j`：

1. `prefix[j] == 2 * target` 保证第一段和第二段合计为两个目标和；
2. `firstCount` 中的第一刀满足 `prefix[i] == target`，因此第一段和为 `target`，第二段和也为 `target`；
3. 第一刀自身满足第一段含正数；
4. `i < lastPositive` 保证最后一个正数位于第二段中；
5. `positiveCount[n] - positiveCount[j] > 0` 保证第三段含正数；
6. `j ≤ n - 1` 保证第三段非空。

因此统计到的每一组切分都合法，所有合法切分也都会被统计。

复杂度：

- 时间复杂度：`O(n)`；
- 空间复杂度：`O(n)`。

### 方法归纳

> **三等分先用前缀和确定切刀位置：第一刀找 `target`，第二刀找 `2 × target`；正数条件用正数前缀计数和“当前位置左侧最后一个正数”处理。**

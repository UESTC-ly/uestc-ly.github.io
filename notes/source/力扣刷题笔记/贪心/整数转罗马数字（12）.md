# 12. 整数转罗马数字

## 题型与核心思路

**贪心 + 映射表：特殊组合先入表，从大到小反复减。**

把整数转换为符合规则的罗马数字。除了基本符号，还把 `4、9、40、90、400、900` 对应的组合当作完整单位，避免单独写大量特殊判断。

| 数值 | 1000 | 900 | 500 | 400 | 100 | 90 | 50 | 40 | 10 | 9 | 5 | 4 | 1 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 符号 | M | CM | D | CD | C | XC | L | XL | X | IX | V | IV | I |

从大到小遍历：只要剩余数字不小于当前数值，就拼接对应符号并减去该数值。

## 为什么成立

罗马数字按千、百、十、个位依次表示。以个位为例，按 `9、5、4、1` 尝试，正好覆盖合法规则：1～3 重复 I，4 用 IV，5 用 V，6～8 用 V 加 I，9 用 IX。十位、百位同理。

例如 `1994`：

```text
1994 - 1000 = 994 → M
 994 -  900 =  94 → MCM
  94 -   90 =   4 → MCMXC
   4 -    4 =   0 → MCMXCIV
```

## C++ 主模板

```cpp
class Solution {
public:
    string intToRoman(int num) {
        int values[] = {
            1000, 900, 500, 400, 100, 90, 50,
            40, 10, 9, 5, 4, 1
        };
        string symbols[] = {
            "M", "CM", "D", "CD", "C", "XC", "L",
            "XL", "X", "IX", "V", "IV", "I"
        };

        string ans;
        for (int i = 0; i < 13; i++) {
            // 当前符号能用几次，就用几次
            while (num >= values[i]) {
                ans += symbols[i];
                num -= values[i];
            }
        }
        return ans;
    }
};
```

## 复杂度与易错点

本题 `1 ≤ num ≤ 3999`，表大小、拼接次数及结果长度均有固定上限，因此时间、额外空间和结果空间均为 O(1)。

- 必须从大到小，否则可能先将数字拆成大量 I。
- 使用 `while` 而非 `if`，例如 300 需要三个 C。
- 数值和符号必须一一对应；特殊组合必须入表，否则 4、9 会被错误表示。

## 一类题总结

**识别信号：普通规则 + 少量固定特殊组合。** 可以先尝试将特殊组合纳入映射表，让所有情况走同一个循环。这适合固定编码、符号转换等问题。

“每次选最大的”必须有规则或正确性依据，不能推广到任意找零问题：面额 `1、3、4` 凑 6，贪心得到 `4+1+1`，但更优的是 `3+3`。

## 122. 买卖股票的最佳时机II

[力扣原题](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/)

### 简短题意

prices[i] 是第 i 天股价，可以多次买卖但同一时刻最多持有一股，也可以同一天卖出后再买入。求最大利润。

### 思路解析

把一次跨多天的收益拆成相邻日差值，下降的差值可以跳过，只累加所有正差值。连续上涨期间逐天买卖与一次持有到末尾收益相同，因此不会损失最优收益。

### C++ 主模板

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int ans = 0;
        for (int i = 1; i < static_cast<int>(prices.size()); i++) {
            ans += max(0, prices[i] - prices[i - 1]); // 收集所有上涨收益
        }
        return ans;
    }
};
```

### 示例与复杂度

[7,1,5,3,6,4]：收集 1→5 的 4 和 3→6 的 3，答案为 7。

时间 O(n)，额外空间 O(1)。

### 易错点与一类题总结

本题允许无限次交易；有次数限制、手续费或冷冻期时，不能直接累加正差值。

可自由拆分且没有额外成本的收益问题，尝试将总收益分解成局部增量；先确认所有局部选择可以同时实现。

## 134. 加油站

[力扣原题](https://leetcode.cn/problems/gas-station/)

### 简短题意

环形路线上第 i 站提供 gas[i] 的油，从第 i 站到下一站消耗 cost[i]。初始油箱为空、容量无限，返回能完整绕行一圈的起点；不存在则返回 -1，若有解则唯一。

### 思路解析

把每站净收益记为 gas[i]-cost[i]。总净收益为负必定无解。扫描时维护候选起点以来的余额 tank；在 i 处变负，则该起点到 i 的任何站都不能作起点，下一候选设为 i+1。此前各前缀非负，从中间出发只会减少到 i 时的余额。总和非负时，最后候选可完成环路。

### C++ 主模板

```cpp
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int total = 0, tank = 0, start = 0;
        for (int i = 0; i < static_cast<int>(gas.size()); i++) {
            int gain = gas[i] - cost[i];
            total += gain;
            tank += gain;
            if (tank < 0) {
                start = i + 1; // 排除整个失败区间的起点
                tank = 0;
            }
        }
        return total < 0 ? -1 : start;
    }
};
```

### 示例与复杂度

gas=[1,2,3,4,5]，cost=[3,4,5,1,2]：前三段失败，候选起点更新为 3；总净收益为 0，从 3 出发可绕一圈。

时间 O(n)，额外空间 O(1)。

### 易错点与一类题总结

total 记录全局，tank 只记录当前候选段，不能一起清零；比较用 tank<0，余额等于零仍能继续。

连续尝试的起点失败时，若能证明整段候选都失败，就整段排除；这是贪心跳过候选的依据。

## 135. 分发糖果

[力扣原题](https://leetcode.cn/problems/candy/)

### 简短题意

ratings 是一排孩子的评分。每人至少一颗糖，相邻两人中评分更高者必须拿更多糖，返回最少糖果总数。

### 思路解析

先每人分 1 颗。左到右满足比左邻评分高的要求；右到左再满足比右邻高的要求，并用 max 保留此前已经满足的左侧要求。两方向给出的都是必须达到的下界，取较大值恰好同时满足且最少。

### C++ 主模板

```cpp
class Solution {
    // 先满足左邻约束，再用 max 合并右邻约束。
public:
    int candy(vector<int>& ratings) {
        int n = ratings.size();
        vector<int> candies(n, 1);
        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) candies[i] = candies[i - 1] + 1;
        }
        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) {
                candies[i] = max(candies[i], candies[i + 1] + 1);
            }
        }
        return accumulate(candies.begin(), candies.end(), 0);
    }
};
```

### 示例与复杂度

[1,0,2]：先得 [1,1,2]，反向修正为 [2,1,2]，总数为 5。

时间 O(n)，额外空间 O(n)。

### 易错点与一类题总结

同分没有必须多分的要求；反向不能直接覆盖，要取 max；代码求和需 <numeric>。

同时受左右邻居影响且方向可分开的约束，可做两次方向扫描，再合并两边的下界。

## 452. 用最少数量的箭引爆气球

[力扣原题](https://leetcode.cn/problems/minimum-number-of-arrows-to-burst-balloons/)

### 简短题意

每个气球由闭区间 [start,end] 表示，箭在横坐标 x 处射出可引爆所有满足 start<=x<=end 的气球。返回引爆全部气球需要的最少箭数。

### 思路解析

按右端点排序，第一箭射在最早结束气球的右端点。对于必须覆盖该气球的一箭，移到其右端点不会丢掉其他尚未结束且与它同箭的气球，还尽量有利于后续气球。当前气球起点超过箭坐标才需要新箭。

### C++ 主模板

```cpp
class Solution {
public:
    int findMinArrowShots(vector<vector<int>>& points) {
        if (points.empty()) return 0;
        sort(points.begin(), points.end(), [](const auto& a, const auto& b) {
            return a[1] < b[1]; // 直接比较，避免相减溢出
        });
        int arrows = 1, position = points[0][1];
        for (int i = 1; i < static_cast<int>(points.size()); i++) {
            if (points[i][0] > position) {
                arrows++;
                position = points[i][1];
            }
        }
        return arrows;
    }
};
```

### 示例与复杂度

[[10,16],[2,8],[1,6],[7,12]]：排序后先在 6 射箭，再在 12 射箭，共 2 支。

时间 O(n log n)，排序辅助空间通常 O(log n)；会改变区间顺序。

### 易错点与一类题总结

共享端点能用同一箭，判断新箭用严格 >；坐标可能接近整数边界，比较器不要写 a[1]-b[1]。

最少点覆盖区间：按结束位置排序，尽量在最早结束区间的最右处选择覆盖点。

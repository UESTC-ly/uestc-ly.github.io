# 57. 插入区间

## 题型与核心思路

区间合并。原区间按起点升序排列且互不重叠，插入新区间后仍需有序且无重叠；共享端点也算重叠。

**左边直接放，中间合并，右边直接放。** 用 `for + if` 扫描，维护待插入区间 `[left, right]`，用 `added` 记录它是否已加入答案。

| 当前区间与待插入区间的关系 | 判断 | 操作 |
|---|---|---|
| 完全在左侧 | `interval[1] < left` | 原样加入 |
| 完全在右侧 | `interval[0] > right` | 若新区间未加入，先加入它；再加入当前区间 |
| 重叠 | 以上均不成立 | 起点取 min，终点取 max |

原区间有序且互不重叠，因此重叠部分连续。遇到完全在右侧的区间后，后续区间不可能再与合并区间重叠，可以确定合并结果并加入答案。

## C++ 模板

```cpp
class Solution {
public:
    vector<vector<int>> insert(vector<vector<int>>& intervals,
                               vector<int>& newInterval) {
        vector<vector<int>> ans;
        int left = newInterval[0];
        int right = newInterval[1];
        bool added = false;

        for (const auto& interval : intervals) {
            if (interval[1] < left) {
                ans.push_back(interval);
            } else if (interval[0] > right) {
                // 第一次遇到右侧区间时，先放合并后的新区间
                if (!added) {
                    ans.push_back({left, right});
                    added = true;
                }
                ans.push_back(interval);
            } else {
                left = min(left, interval[0]);
                right = max(right, interval[1]);
            }
        }
        // 没遇到右侧区间时，补上待插入区间
        if (!added) {
            ans.push_back({left, right});
        }
        return ans;
    }
};
```

## 示例与易错点

`[[1,2],[3,5],[6,7],[8,10],[12,16]]` 插入 `[4,8]`：先放 `[1,2]`；依次合并得到 `[3,8] → [3,8] → [3,10]`；遇到 `[12,16]` 时，先放 `[3,10]` 再放它。结果为 `[[1,2],[3,10],[12,16]]`。

- **为什么最后还要 `if (!added)`？** 循环中只有遇到右侧区间才会加入新区间。插在末尾、合并持续到末尾、原数组为空时，都需要最后补上。例如 `[[1,2]]` 插入 `[3,4]`，循环只加入 `[1,2]`；最后才能补上 `[3,4]`。判断 `!added` 防止重复添加。
- **不能加入原来的 `newInterval`。** 修改的是独立变量 `left`、`right`，原数组没有同步变化。例如 `[[1,3]]` 插入 `[2,5]` 后，应加入 `{1,5}`，而原 `newInterval` 仍是 `{2,5}`。两处都必须写 `ans.push_back({left, right})`。
- 共享端点算重叠，所以不重叠判断必须用严格的 `<`、`>`。

## 复杂度与迁移

时间 O(n)，除返回数组外额外空间 O(1)，输出空间 O(n)。

识别信号：**有序、互不重叠的区间中插入一个区间**。按左、中、右分类，在中间维护合并边界；无序输入不能直接套用此模板。三段 `while` 也能表达同一流程，本笔记采用 `for + if` 版本。

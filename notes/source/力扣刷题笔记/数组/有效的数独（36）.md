# 36. 有效的数独

- 题型：矩阵遍历 / 分组判重。
- 只检查已填数字是否冲突，不填空格，也不判断最终是否有解。
- 核心：为行、列、宫分别记录出现过的数字，先检查，再登记。

## 状态与宫编号

```cpp
bool rows[9][10] = {};
bool cols[9][10] = {};
bool boxes[9][10] = {};
```

`= {}` 把全部元素初始化为 `false`。例如 `rows[2][5]` 表示下标为 2 的行是否出现过数字 5。

第一维为 9，对应下标 `0～8` 的行、列或宫；第二维为 10，是因为数字 `1～9` 直接作下标，位置 0 不使用。若改为 `[9][9]`，需用 `c - '1'` 将数字映射到 `0～8`，否则访问下标 9 会越界。

默认宫编号：

```text
0 1 2
3 4 5
6 7 8
```

```cpp
int box = (row / 3) * 3 + col / 3;
```

`row / 3` 是宫的排号，`col / 3` 是宫的列号，每排有三个宫。整数除法会把连续三行或三列归为一组。例如 `(4,7)` 属于宫 `1*3+2=5`。

用户分支函数 `getBoxs` 使用的编号也正确：

```text
0 3 6
1 4 7
2 5 8
```

它等价于 `(col / 3) * 3 + row / 3`。**同宫编号相同，不同宫编号不同即可，编号不必固定。** 原分支均已返回，末尾的 `return -1` 不会执行。

## C++ 主模板

```cpp
class Solution {
public:
    bool isValidSudoku(vector<vector<char>>& board) {
        bool rows[9][10] = {};
        bool cols[9][10] = {};
        bool boxes[9][10] = {};

        for (int row = 0; row < 9; row++) {
            for (int col = 0; col < 9; col++) {
                char c = board[row][col];
                if (c == '.') continue; // 空格不参与判重
                int num = c - '0';
                int box = (row / 3) * 3 + col / 3;

                if (rows[row][num] || cols[col][num] || boxes[box][num]) {
                    return false;
                }
                // 先检查三个范围，再登记
                rows[row][num] = true;
                cols[col][num] = true;
                boxes[box][num] = true;
            }
        }
        return true;
    }
};
```

## 正确性、例子与复杂度

三个数组始终记录已遍历格子的数字。若有冲突，读到第二个相同数字时一定能发现。

例如 `(0,0)` 填 5 后，登记行 0、列 0、宫 0 的数字 5；再遇到 `(1,1)` 的 5，虽然行列不同，但 `boxes[0][5]` 已为真，所以无效。全空或只有一个数字都有效。

固定 `9×9` 棋盘最多检查 81 格，时间和额外空间均为 `O(1)`。

## 一类题总结

“每组内元素不重复” → 确定分组编号 → 查询该组是否出现过元素 → 冲突则返回，否则登记。

本题一个元素同时归属行、列、宫三个组。口诀：**空格跳过，行列宫判重，先查再记。**

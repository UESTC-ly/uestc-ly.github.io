## 88. 合并两个有序数组

[力扣原题](https://leetcode.cn/problems/merge-sorted-array/)

### 简短题意

两个数组 nums1、nums2 的有效部分分别有 m、n 个元素，均为非递减顺序。nums1 长度为 m+n，末尾预留空间；将 nums2 合并到 nums1 中，直接修改 nums1。

### 思路解析

从前往后写会覆盖 nums1 尚未使用的元素，因此从后往前合并。i、j 指向两段的末尾，write 指向最终数组末尾，每次放入较大的数。nums2 用完后，nums1 剩余前缀已经就位。

### C++ 主模板

```cpp
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int i = m - 1, j = n - 1, write = m + n - 1;
        while (j >= 0) {
            // 较大值放到结果尾部，避免覆盖尚未读取的元素
            if (i >= 0 && nums1[i] > nums2[j]) nums1[write--] = nums1[i--];
            else nums1[write--] = nums2[j--];
        }
    }
};
```

### 示例与复杂度

nums1=[1,2,3,0,0,0]，m=3，nums2=[2,5,6]：从尾部依次写入 6、5、3、2，最终为 [1,2,2,3,5,6]。

时间 O(m+n)，额外空间 O(1)。

### 易错点与一类题总结

预留的 0 不属于有效数据；m=0 时需要全部复制 nums2，n=0 时不修改。先检查 i>=0 再读取 nums1[i]。

原数组尾部有空位、要求原地归并时，倒序写入可以保护未读数据；每轮结果后缀都是已确定的最大元素。

## 27. 移除元素

[力扣原题](https://leetcode.cn/problems/remove-element/)

### 简短题意

给定数组 nums 和值 val，原地移除所有等于 val 的元素，返回剩余元素数量 k。前 k 个位置必须保存剩余元素，后面的内容无要求。

### 思路解析

read 扫描全部元素，write 表示已保留元素数量。遇到不等于 val 的元素就写到 nums[write]，再递增 write；write 始终不会超过 read，因而不影响后续读取。

### C++ 主模板

```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int write = 0;
        for (int read = 0; read < static_cast<int>(nums.size()); read++) {
            if (nums[read] != val) {
                nums[write] = nums[read]; // 只保留满足条件的元素
                write++;
            }
        }
        return write;
    }
};
```

### 示例与复杂度

[3,2,2,3]，val=3：两次保留 2，返回 2，有效前缀为 [2,2]。

时间 O(n)，额外空间 O(1)。

### 易错点与一类题总结

返回新长度，不要求 resize 或清空尾部；空数组返回 0，全部等于 val 也返回 0。

原地筛选模板：读指针遍历，写指针只在保留元素时前进；更换保留条件即可迁移到其他过滤题。

## 274. H指数

[力扣原题](https://leetcode.cn/problems/h-index/)

### 简短题意

citations[i] 是第 i 篇论文的引用次数。返回最大的整数 h，使至少 h 篇论文各自被引用至少 h 次。

### 思路解析

先将引用次数从大到小排序。若第 i 篇（从 0 计）仍有至少 i+1 次引用，就有 i+1 篇达到该门槛；首次不满足时，后续更小的引用次数也无法提高 h。

### C++ 主模板

```cpp
class Solution {
    // 降序排名 i+1 对应“至少 i+1 篇达到该引用次数”。
public:
    int hIndex(vector<int>& citations) {
        sort(citations.begin(), citations.end(), greater<int>());
        int h = 0;
        for (int i = 0; i < static_cast<int>(citations.size()); i++) {
            if (citations[i] >= i + 1) h = i + 1;
            else break;
        }
        return h;
    }
};
```

### 示例与复杂度

[3,0,6,1,5] 排成 [6,5,3,1,0]，前三篇都至少被引 3 次，第 4 篇不足 4 次，答案为 3。

时间 O(n log n)，排序辅助空间通常 O(log n)；会改变数组顺序。

### 易错点与一类题总结

h 是篇数与引用次数共同满足的阈值，不是最大引用次数；全部为零时返回 0。

寻找“至少 h 项达到 h”时，可先排序，将数量条件转成排名与数值的比较。

## 380. O(1)时间插入、删除和获取随机元素

[力扣原题](https://leetcode.cn/problems/insert-delete-getrandom-o1/)

### 简短题意

实现 RandomizedSet：insert 插入不存在的值，remove 删除已有值，两者返回操作是否成功；getRandom 等概率返回一个现有元素。三个操作的平均时间均要求 O(1)，随机操作时集合非空。

### 思路解析

数组便于随机下标访问，哈希表保存值到下标的映射。删除中间元素时，把末尾元素搬到该位置、更新其下标，再弹出末尾，避免移动整段数组。随机数使用均匀整数分布。

### C++ 主模板

```cpp
class RandomizedSet {
    vector<int> data;
    unordered_map<int, int> index;
    mt19937 rng;
public:
    RandomizedSet() : rng(random_device{}()) {}
    bool insert(int val) {
        if (index.count(val)) return false;
        index[val] = data.size();
        data.push_back(val);
        return true;
    }
    bool remove(int val) {
        auto it = index.find(val);
        if (it == index.end()) return false;
        int pos = it->second;
        int last = data.back();
        data[pos] = last;       // 尾部补洞，不必搬动其他元素
        index[last] = pos;
        data.pop_back();
        index.erase(val);
        return true;
    }
    int getRandom() {
        uniform_int_distribution<int> pick(0, static_cast<int>(data.size()) - 1);
        return data[pick(rng)];
    }
};
```

### 示例与复杂度

集合数组为 [10,20,30]，删除 20：用 30 补到下标 1，再弹出原末尾，得到 [10,30]。

插入、删除为平均/摊还 O(1)，随机访问 O(1)；空间 O(n)。

### 易错点与一类题总结

搬入的末尾元素必须同步更新映射；删除的正好是末尾也可用同一模板。代码需标准头文件 <random>；vector、unordered_map 同样由标准库提供。

不要求保留顺序的动态集合，可用“数组存值 + 哈希定位 + 尾部补洞”；不同值占据不同下标，均匀下标对应均匀元素。

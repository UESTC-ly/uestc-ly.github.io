## 228. 汇总区间

[力扣原题](https://leetcode.cn/problems/summary-ranges/)

### 简短题意

给定严格递增、无重复的整数数组 nums，将连续数值汇总为最少的区间字符串。单元素输出 "a"，多个连续值输出 "a->b"，按原顺序返回。

### 思路解析

每段从 start 开始，只要下一值等于当前值加一，就继续向后扩展。遇到断点就确定这一段，下一段从断点后重新开始。每个最大连续段只能用一个区间表达，且不能跨越缺失数值。

### C++ 主模板

```cpp
class Solution {
    // 每次把当前最大连续数段汇总为一个区间。
public:
    vector<string> summaryRanges(vector<int>& nums) {
        vector<string> ans;
        int i = 0, n = nums.size();
        while (i < n) {
            int start = i;
            while (i + 1 < n && static_cast<long long>(nums[i + 1]) - nums[i] == 1) i++;
            string range = to_string(nums[start]);
            if (start != i) range += "->" + to_string(nums[i]);
            ans.push_back(range);
            i++;
        }
        return ans;
    }
};
```

### 示例与复杂度

[0,1,2,4,5,7] 返回 ["0->2","4->5","7"]。

固定 32 位数值下时间 O(n)，额外空间 O(1)，输出空间 O(n)。

### 易错点与一类题总结

用 long long 做相邻差，避免 INT_MAX+1 或 INT_MIN 相减溢出；空数组返回空列表。

有序数据的连续分段：保存段起点，扩展到不满足连续条件的位置，再输出一段。

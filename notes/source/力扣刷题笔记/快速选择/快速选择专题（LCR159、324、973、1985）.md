## LCR 159. 库存管理 III

### 题型判断

这题属于：**快速选择 / Top K 问题**。

题目要我们找出数组中**最小的 cnt 个数**，并且明确说“返回顺序不限”。

一看到：

- 找最小的 k 个
- 找最大的 k 个
- 找第 k 大 / 第 k 小
- 不要求整体有序

就要想到：**不用完整排序，可以用快速选择。**

### 题目白话

给你一个库存数组 `stock`，每个数表示某个商品的库存量。

现在要找出库存最少的 `cnt` 个商品。

比如：

```cpp
stock = [2,5,7,4], cnt = 1
```

库存最少的是 `2`，所以返回 `[2]`。

再比如：

```cpp
stock = [0,2,3,6], cnt = 2
```

最小的两个数是 `0` 和 `2`，返回 `[0,2]` 或 `[2,0]` 都可以。

### 为什么想到快速选择

最直接的做法是排序：

```cpp
sort(stock.begin(), stock.end());
```

然后取前 `cnt` 个。

这样能做，但时间复杂度是 `O(n log n)`。

可是这题并不要求前 `cnt` 个数内部有序，只要它们是最小的 `cnt` 个即可。

所以我们其实只需要做到：

> 数组前 cnt 个位置放的是最小的 cnt 个数，至于它们内部谁先谁后无所谓。

这正好是快速选择的目标。

快速选择借用了快速排序里的 `partition` 思想：

- 选一个基准值 `pivot`
- 把小于等于 `pivot` 的数放左边
- 把大于等于 `pivot` 的数放右边
- 最后 `pivot` 落到它排序后应该在的位置

如果 `partition` 返回的下标 `p` 正好是 `cnt - 1`，说明：

> 下标 `0 ~ cnt - 1` 这 cnt 个位置，就是最小的 cnt 个数。

### 核心思路拆解

我们要找的是最小的 `cnt` 个数，也就是让数组前 `cnt` 个位置满足条件。

设目标下标：

```cpp
target = cnt - 1;
```

每次做一次 `partition`，得到基准值最终位置 `p`：

- 如果 `p == target`：前 `cnt` 个数已经确定，直接返回
- 如果 `p > target`：说明目标位置在左半边，继续处理左边
- 如果 `p < target`：说明左边数量还不够，继续处理右边

注意：快速选择不是把整个数组排好序，而是不断缩小范围，直到第 `cnt` 个位置被放对。

### partition 怎么理解

以数组：

```cpp
[4, 2, 7, 5, 1, 3]
```

假设选 `4` 作为基准值。

partition 后可能变成：

```cpp
[3, 2, 1, 4, 5, 7]
```

此时 `4` 的下标是 `3`。

这说明：

- `4` 左边都不大于 `4`
- `4` 右边都不小于 `4`
- `4` 已经在排序后应该在的位置

但左右两边内部不一定有序。

这就够了，因为 Top K 问题只关心“边界位置”，不关心整体顺序。

这里返回的 `p` 不是“随便一个中间位置”，而是：

> 这次 `partition` 之后，pivot 最终应该落到的位置。

也就是说，`partition` 返回 `p` 后，满足：

- `nums[left ... p - 1] <= nums[p]`
- `nums[p + 1 ... right] >= nums[p]`

### C++ 代码实现

```cpp
class Solution {
public:
    vector<int> inventoryManagement(vector<int>& stock, int cnt) {
        if (cnt == 0) return {};
        if (cnt >= stock.size()) return stock;

        int left = 0, right = stock.size() - 1;
        int target = cnt - 1;

        while (left <= right) {
            int p = partition(stock, left, right);

            if (p == target) {
                break;
            } else if (p > target) {
                right = p - 1;
            } else {
                left = p + 1;
            }
        }

        return vector<int>(stock.begin(), stock.begin() + cnt);
    }

private:
    int partition(vector<int>& nums, int left, int right) {
        // 随机选 pivot，避免退化成最坏 O(n^2)
        int pivotIndex = left + rand() % (right - left + 1);
        swap(nums[left], nums[pivotIndex]);

        int pivot = nums[left];
        int i = left, j = right;

        // 交换法 partition：两边找错位元素，找到就交换
        while (i < j) {
            while (i < j && nums[j] >= pivot) j--;
            while (i < j && nums[i] <= pivot) i++;
            if (i < j) {
                swap(nums[i], nums[j]);
            }
        }

        // 最后把 pivot 放回最终位置
        swap(nums[left], nums[i]);
        return i;
    }
};
```

### 关键细节

#### 1. 为什么目标是 `cnt - 1`

因为数组下标从 `0` 开始。

如果要找最小的 `cnt` 个数，那么边界位置是：

```cpp
cnt - 1
```

比如 `cnt = 2`，只要下标 `0` 和 `1` 是最小的两个数即可。

#### 2. 为什么返回前 `cnt` 个就行

当 `partition` 让下标 `cnt - 1` 的位置确定后，前面一定有 `cnt` 个数不大于它。

题目不要求顺序，所以：

```cpp
vector<int>(stock.begin(), stock.begin() + cnt)
```

就是答案。

#### 3. 为什么这里改成随机 pivot

如果总是固定选最左边作为 pivot，遇到接近有序的数组时，快速选择可能退化。

所以这里先随机选一个 `pivotIndex`，再交换到 `left`，这样更稳。

#### 3. 为什么不用完整排序

完整排序会把每个元素的位置都排好。

但这题只需要知道最小的 `cnt` 个是谁，不关心它们之间的相对顺序。

所以快速选择更贴合题意。

### 复杂度分析

- 时间复杂度：平均 `O(n)`，最坏 `O(n^2)`
- 空间复杂度：`O(1)`

最坏情况出现在每次选到的基准值都特别偏，比如数组本来接近有序，且总是选最左边作为 `pivot`。

实际面试中可以说明：如果担心最坏情况，可以随机选择 `pivot` 来降低退化概率。

### 记忆口诀 / 一眼识别信号

口诀：

> 只要 Top K，不要全排序；找边界，用快选。

一眼识别信号：

- “最小的 k 个”
- “最大的 k 个”
- “第 k 大”
- “第 k 小”
- “返回顺序不限”

这些都是快速选择的典型信号。

### 一类题总结

快速选择解决的是：

> 不需要完整有序，只需要某个排名位置正确，或者只要排名前 k 的元素。

通用模板：

1. 明确目标下标
   - 最小的 k 个：`target = k - 1`
   - 第 k 小：`target = k - 1`
   - 第 k 大：`target = n - k`
2. 每次 `partition` 得到基准位置 `p`
3. 比较 `p` 和 `target`
4. 只递归 / 迭代进入可能包含答案的一边
5. 找到目标下标后，按题意返回结果

## 324. 摆动排序 II

### 题型判断

这题属于：**快速选择 / 中位数 / 三路划分 / 虚拟下标**。

题目要求把数组重新排列成：

```cpp
nums[0] < nums[1] > nums[2] < nums[3] ...
```

也就是：

- 奇数位放相对大的数，当“峰”
- 偶数位放相对小的数，当“谷”

### 题目白话

给你一个数组，不要求返回唯一答案，只要重新排列后满足：

```text
小 大 小 大 小 大 ...
```

比如：

```cpp
[1,5,1,1,6,4]
```

可以变成：

```cpp
[1,6,1,5,1,4]
```

因为：

```cpp
1 < 6 > 1 < 5 > 1 < 4
```

### 为什么不能只排序

如果简单排序后再交错放，重复元素容易挤在一起，导致相邻两个数相等。

但这题要求的是严格：

```cpp
nums[i] < nums[i + 1]
nums[i] > nums[i + 1]
```

所以难点不是排序，而是：

> 如何把大数稳定放到奇数位，小数稳定放到偶数位，并处理重复数字。

### 核心思路

先用快速选择找到中位数 `mid`。

然后把数组按 `mid` 分成三类：

- 大于 `mid`
- 等于 `mid`
- 小于 `mid`

目标是：

- 大于 `mid` 的数放到奇数位
- 小于 `mid` 的数放到偶数位
- 等于 `mid` 的数放在剩余位置

这一步不能直接按原下标做三路划分，而要用**虚拟下标**。

### 虚拟下标模板

虚拟下标公式：

```cpp
int newIdx(int index, int n) {
    return (1 + 2 * index) % (n | 1);
}
```

它的作用是让访问顺序变成：

```text
1, 3, 5, 0, 2, 4 ...
```

也就是：

> 先访问奇数位，再访问偶数位。

因为奇数位是“峰”，要优先放大数。

例如 `n = 6`：

```text
index:  0  1  2  3  4  5
newIdx: 1  3  5  0  2  4
```

### 三路划分模板

在虚拟下标顺序里做三路划分：

```cpp
if (nums[newIdx(i, n)] > mid) {
    swap(nums[newIdx(left, n)], nums[newIdx(i, n)]);
    left++;
    i++;
} else if (nums[newIdx(i, n)] < mid) {
    swap(nums[newIdx(i, n)], nums[newIdx(right, n)]);
    right--;
} else {
    i++;
}
```

记住：

- 大于中位数：放前面，也就是奇数位
- 小于中位数：放后面，也就是偶数位
- 等于中位数：先留在中间

这里的“前面”和“后面”指的是**虚拟下标顺序**，不是原数组顺序。

### C++ 代码实现

```cpp
class Solution {
public:
    void wiggleSort(vector<int>& nums) {
        int n = nums.size();

        // 找中位数：第 (n + 1) / 2 大
        int mid = findKthLargest(nums, (n + 1) / 2);

        int left = 0;
        int i = 0;
        int right = n - 1;

        // 按虚拟下标做三路划分
        while (i <= right) {
            if (nums[newIdx(i, n)] > mid) {
                // 大数放前面，对应真实数组中的奇数位
                swap(nums[newIdx(left, n)], nums[newIdx(i, n)]);
                left++;
                i++;
            } else if (nums[newIdx(i, n)] < mid) {
                // 小数放后面，对应真实数组中的偶数位
                swap(nums[newIdx(i, n)], nums[newIdx(right, n)]);
                right--;
            } else {
                // 等于中位数，留在中间
                i++;
            }
        }
    }

private:
    // 虚拟下标：先访问奇数位，再访问偶数位
    int newIdx(int index, int n) {
        return (1 + 2 * index) % (n | 1);
    }

    int findKthLargest(vector<int>& nums, int k) {
        int target = nums.size() - k;
        int left = 0;
        int right = nums.size() - 1;

        while (left <= right) {
            int p = partition(nums, left, right);

            if (p == target) {
                return nums[p];
            } else if (p > target) {
                right = p - 1;
            } else {
                left = p + 1;
            }
        }

        return -1;
    }

    int partition(vector<int>& nums, int left, int right) {
        int pivotIdx = left + rand() % (right - left + 1);
        int pivot = nums[pivotIdx];

        swap(nums[pivotIdx], nums[left]);

        int i = left;
        int j = right;

        while (i < j) {
            while (i < j && nums[j] >= pivot) j--;
            while (i < j && nums[i] <= pivot) i++;

            if (i < j) {
                swap(nums[i], nums[j]);
            }
        }

        swap(nums[left], nums[i]);
        return i;
    }
};
```

### 复杂度分析

- 时间复杂度：平均 `O(n)`，最坏 `O(n^2)`
- 空间复杂度：`O(1)`

快速选择平均 `O(n)`，三路划分 `O(n)`。

### 关键细节

#### 1. 为什么找第 `(n + 1) / 2` 大

这题要围绕中位数分组。

用：

```cpp
findKthLargest(nums, (n + 1) / 2)
```

可以找到偏小一侧的中位数，方便把数组分成：

- 大于中位数的一组
- 小于中位数的一组
- 等于中位数的一组

#### 2. 为什么小于 `mid` 时不 `i++`

代码里：

```cpp
swap(nums[newIdx(i, n)], nums[newIdx(right, n)]);
right--;
```

这里不能立刻 `i++`。

因为从 `right` 换过来的数还没有处理过，必须继续检查当前位置。

#### 3. 为什么大于 `mid` 时可以 `i++`

因为 `left` 到 `i` 之间都是已经检查过的区域。

当大数换到 `left` 后，当前位置换过来的数也已经属于处理过的区域，所以可以移动 `i`。

#### 4. `newIdx` 的写法容易错

函数调用要写：

```cpp
newIdx(i, n)
```

不能写成：

```cpp
newIdx[i, n]
```

函数定义要写：

```cpp
int newIdx(int index, int n)
```

不能写成：

```cpp
int newIdx = (int index, int n)
```

### 记忆口诀 / 一眼识别信号

口诀：

> 先找中位数，再虚拟下标三路划分。  
> 大数塞奇数位，小数塞偶数位，中位数夹中间。

虚拟下标口诀：

> 摆动排序先走奇数位：`(1 + 2 * i) % (n | 1)`。

一眼识别信号：

- 要求 `小 大 小 大` 摆动
- 要求原地 `O(1)` 额外空间
- 有重复数字
- 简单排序交错可能被相等元素卡住

### 一类题总结

这题的通用模型是：

> 需要把数组按特殊位置关系重新排列，并且重复元素会破坏简单排序结果。

常用套路：

1. 找一个分界值，比如中位数
2. 按分界值做三路划分
3. 如果原下标顺序不好放，就设计一个下标映射

可复用模块：

```cpp
int newIdx(int index, int n) {
    return (1 + 2 * index) % (n | 1);
}
```

```cpp
while (i <= right) {
    if (nums[newIdx(i, n)] > mid) {
        swap(nums[newIdx(left, n)], nums[newIdx(i, n)]);
        left++;
        i++;
    } else if (nums[newIdx(i, n)] < mid) {
        swap(nums[newIdx(i, n)], nums[newIdx(right, n)]);
        right--;
    } else {
        i++;
    }
}
```

## 973. 最接近原点的 K 个点

### 题型判断

这题属于：**Top K / 快速选择 / 自定义比较规则**。

题目要找的是：

> 离原点最近的 `k` 个点。

不要求这 `k` 个点内部有序，所以不用完整排序，优先想到快速选择。

### 题目白话

每个点是：

```cpp
[x, y]
```

它到原点 `(0, 0)` 的距离是：

```text
sqrt(x * x + y * y)
```

比较远近时不用真的开根号，因为平方距离大小关系不变。

所以只比较：

```cpp
x * x + y * y
```

### 为什么想到快速选择

如果完整排序：

```cpp
sort(points.begin(), points.end(), 按距离排序);
```

时间复杂度是 `O(n log n)`。

但这题只要最近的 `k` 个点，不要求前 `k` 个点内部有序。

所以目标只是：

> 让数组前 `k` 个位置放距离最小的 `k` 个点。

这正好是快速选择。

### 核心思路

把每个点看成一个“数”，这个数就是它到原点的距离平方：

```cpp
dist(point) = point[0] * point[0] + point[1] * point[1];
```

目标下标：

```cpp
target = k - 1;
```

每次 `partition` 后，pivot 点会落到按距离排序后的最终位置 `p`：

- `p == target`：前 `k` 个点已经是答案
- `p > target`：答案边界在左边
- `p < target`：答案边界在右边

最后返回：

```cpp
vector<vector<int>>(points.begin(), points.begin() + k)
```

### C++ 代码实现

```cpp
class Solution {
public:
    vector<vector<int>> kClosest(vector<vector<int>>& points, int k) {
        int left = 0;
        int right = points.size() - 1;
        int target = k - 1;

        while (left <= right) {
            int p = partition(points, left, right);

            if (p == target) {
                break;
            } else if (p > target) {
                right = p - 1;
            } else {
                left = p + 1;
            }
        }

        return vector<vector<int>>(points.begin(), points.begin() + k);
    }

private:
    // 比较距离时不用开根号，直接比较平方距离
    int dist(vector<int>& point) {
        return point[0] * point[0] + point[1] * point[1];
    }

    int partition(vector<vector<int>>& points, int left, int right) {
        int pivotIdx = left + rand() % (right - left + 1);
        swap(points[left], points[pivotIdx]);

        int pivot = dist(points[left]);
        int i = left;
        int j = right;

        while (i < j) {
            while (i < j && dist(points[j]) >= pivot) j--;
            while (i < j && dist(points[i]) <= pivot) i++;

            if (i < j) {
                swap(points[i], points[j]);
            }
        }

        swap(points[left], points[i]);
        return i;
    }
};
```

### 复杂度分析

- 时间复杂度：平均 `O(n)`，最坏 `O(n^2)`
- 空间复杂度：`O(1)`

快速选择平均只处理一边，所以平均是 `O(n)`。

### 关键细节

#### 1. 为什么不用开根号

距离公式是：

```text
sqrt(x * x + y * y)
```

但根号函数是单调递增的。

所以比较两个距离时，直接比较：

```cpp
x * x + y * y
```

结果一样，还更简单。

#### 2. 为什么目标是 `k - 1`

因为要让前 `k` 个位置成为最近的 `k` 个点。

下标从 `0` 开始，所以边界位置是：

```cpp
k - 1
```

#### 3. 为什么返回前 `k` 个

当 `partition` 找到下标 `k - 1` 后，说明：

```text
points[0 ... k - 1]
```

这 `k` 个点已经是距离最小的 `k` 个。

题目允许任意顺序，所以直接返回前 `k` 个。

### 记忆口诀 / 一眼识别信号

口诀：

> 点的远近看平方，最近 `k` 个不用全排。  
> 快选找 `k - 1`，前 `k` 个直接返回。

一眼识别信号：

- 最近的 `k` 个
- 最小的 `k` 个
- 前 `k` 个
- 不要求内部有序

### 一类题总结

这题是 Top K 的变形：

- 普通 Top K：比较数字大小
- 这题 Top K：比较点到原点的距离平方

本质还是：

> 不全排，只找边界。

可复用模块：

```cpp
int dist(vector<int>& point) {
    return point[0] * point[0] + point[1] * point[1];
}
```

```cpp
int target = k - 1;

while (left <= right) {
    int p = partition(points, left, right);

    if (p == target) {
        break;
    } else if (p > target) {
        right = p - 1;
    } else {
        left = p + 1;
    }
}
```

## 1985. 找出数组中的第 K 大整数

### 题型判断

这题属于：**快速选择 / 第 k 大 / 字符串大整数比较**。

题目给的是字符串数组，每个字符串表示一个非负整数。

关键点：

- 要找第 `k` 大
- 不要求完整排序
- 数字可能很大，不能转成 `int` 或 `long long`

所以这题本质还是快速选择，只是比较规则从普通整数比较变成了字符串大整数比较。

### 题目白话

给你一堆数字字符串：

```cpp
["3", "6", "7", "10"]
```

它们真正表示的是数字：

```text
3, 6, 7, 10
```

如果按数字从小到大排：

```cpp
["3", "6", "7", "10"]
```

第 `4` 大就是 `"3"`。

注意：不能用字符串字典序直接当数字大小。

比如：

```cpp
"9" > "10"   // 字符串比较为 true
```

但数字上：

```text
9 < 10
```

### 字符串大整数怎么比较

题目说没有前导零，所以比较两个数字字符串 `a` 和 `b`：

1. 先比长度，长度更长的数字更大
2. 长度一样，再用字符串字典序比较

模板：

```cpp
int cmp(const string& a, const string& b) {
    if (a.size() != b.size()) {
        return a.size() > b.size() ? 1 : -1;
    }

    if (a == b) return 0;
    return a > b ? 1 : -1;
}
```

返回含义：

- `1`：`a > b`
- `0`：`a == b`
- `-1`：`a < b`

### 为什么长度一样可以用 `a > b`

`string` 的 `>` 和 `<` 比较的是字典序。

对于长度相同、没有前导零的数字字符串，字典序和数字大小一致。

比如：

```cpp
"21" > "12"
```

第一位 `2 > 1`，所以数字上也是 `21 > 12`。

但长度不同时不能直接用字典序，所以必须先比长度。

### 核心思路

这题使用**升序快速选择**：

```text
左边 <= pivot
右边 >= pivot
```

因为第 `k` 大在升序数组里的下标是：

```cpp
target = nums.size() - k;
```

每次 `partition` 返回 pivot 最终位置 `p`：

- `p == target`：找到答案
- `p > target`：答案在左边
- `p < target`：答案在右边

### C++ 代码实现

```cpp
class Solution {
public:
    string kthLargestNumber(vector<string>& nums, int k) {
        int left = 0;
        int right = nums.size() - 1;

        // 升序中第 k 大的位置是 n - k
        int target = nums.size() - k;

        while (left <= right) {
            int p = partition(nums, left, right);

            if (p == target) {
                return nums[p];
            } else if (p > target) {
                right = p - 1;
            } else {
                left = p + 1;
            }
        }

        return "-1";
    }

private:
    int partition(vector<string>& nums, int left, int right) {
        int pivotIdx = left + rand() % (right - left + 1);
        string pivot = nums[pivotIdx];

        swap(nums[left], nums[pivotIdx]);

        int i = left;
        int j = right;

        // 升序 partition：左边 <= pivot，右边 >= pivot
        while (i < j) {
            while (i < j && cmp(nums[j], pivot) >= 0) j--;
            while (i < j && cmp(nums[i], pivot) <= 0) i++;

            if (i < j) {
                swap(nums[i], nums[j]);
            }
        }

        swap(nums[left], nums[i]);
        return i;
    }

    int cmp(const string& a, const string& b) {
        if (a.size() != b.size()) {
            return a.size() > b.size() ? 1 : -1;
        }

        if (a == b) return 0;
        return a > b ? 1 : -1;
    }
};
```

### 复杂度分析

- 时间复杂度：平均 `O(n * L)`，最坏 `O(n^2 * L)`
- 空间复杂度：`O(1)`

其中 `L` 是字符串平均长度，因为每次比较两个数字字符串需要看长度，长度相同还可能比较字典序。

### 关键细节

#### 1. 为什么不能用 `stoi`

数字字符串可能非常长，超过 `int` 或 `long long` 范围。

所以不能写：

```cpp
stoi(nums[i])
```

必须用字符串比较。

#### 2. 为什么 `target = nums.size() - k`

因为我们按升序做快速选择。

升序里：

- 第 `1` 大在下标 `n - 1`
- 第 `2` 大在下标 `n - 2`
- 第 `k` 大在下标 `n - k`

#### 3. 为什么 `pivot` 要提前保存

代码里先保存：

```cpp
string pivot = nums[pivotIdx];
```

再交换：

```cpp
swap(nums[left], nums[pivotIdx]);
```

这样后面比较时一直和原来的 pivot 值比较，不会因为数组交换导致 pivot 位置变化而出错。

### 记忆口诀 / 一眼识别信号

口诀：

> 字符串大整数，千万别 `stoi`。  
> 先比长度，长度一样比字典序。  
> 升序快选找第 `k` 大，目标下标 `n - k`。

一眼识别信号：

- 第 `k` 大
- 不要求完整排序
- 数字以字符串形式给出
- 数字可能超过整数范围

### 一类题总结

这题和 `215. 数组中的第 K 个最大元素` 是同一类：

> 第 `k` 大，按升序快选时，目标下标都是 `n - k`。

区别只在比较函数：

- 普通整数：直接用 `<`、`>`
- 字符串大整数：先比长度，长度相同再比字典序

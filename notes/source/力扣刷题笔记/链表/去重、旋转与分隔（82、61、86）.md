## 82. 删除排序链表中的重复元素II

[力扣原题](https://leetcode.cn/problems/remove-duplicates-from-sorted-list-ii/)

### 简短题意

给定升序链表 head，删除所有出现重复值的节点，只保留原链表中出现一次的值，返回结果头节点。重复组中的节点要全部删除。

### 思路解析

使用 dummy 统一头部重复的情况。pre 指向已确认保留前缀的尾部；若 cur 开始一个重复组，就向后越过整组，再令 pre->next 接到下一不同值。若 cur 的值只出现一次，pre 才能前进。

### C++ 主模板

```cpp
class Solution {
public:
    ListNode* deleteDuplicates(ListNode* head) {
        ListNode dummy(0); dummy.next = head;
        ListNode* pre = &dummy;
        ListNode* cur = head;
        while (cur != nullptr) {
            if (cur->next != nullptr && cur->val == cur->next->val) {
                int value = cur->val;
                while (cur != nullptr && cur->val == value) cur = cur->next;
                pre->next = cur; // 整组绕过，不保留组内第一点
            } else {
                pre = cur;
                cur = cur->next;
            }
        }
        return dummy.next;
    }
};
```

### 示例与复杂度

1→2→3→3→4→4→5 变为 1→2→5；1→1→1→2→3 变为 2→3。

时间 O(n)，额外空间 O(1)。

### 易错点与一类题总结

和“重复值保留一个”不同，本题重复组全部移除。模板仅断开连接，不手动释放题目输入节点；独立程序若拥有这些节点，应另行统一回收，避免误删共享或非堆内存。

有序链表中同值节点连续，可以整组判断；保留前驱是否前进由该组能否进入答案决定。

## 61. 旋转链表

[力扣原题](https://leetcode.cn/problems/rotate-list/)

### 简短题意

给定链表 head 和非负 k，将链表向右旋转 k 个位置，返回新头节点。末尾节点按次移动到最前面。

### 思路解析

先求长度 n，令 k%=n；右移 k 步后新尾是原第 n-k 个节点。暂时把旧尾接到旧头形成环，找到新尾，再断开其 next，新尾原来的后继就是新头。

### C++ 主模板

```cpp
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if (head == nullptr || head->next == nullptr) return head;
        int n = 1;
        ListNode* tail = head;
        while (tail->next != nullptr) { tail = tail->next; n++; }
        k %= n;
        if (k == 0) return head;
        tail->next = head; // 临时成环，方便寻找切断位置
        ListNode* newTail = head;
        for (int step = 1; step < n - k; step++) newTail = newTail->next;
        ListNode* newHead = newTail->next;
        newTail->next = nullptr;
        return newHead;
    }
};
```

### 示例与复杂度

1→2→3→4→5，k=2：新尾为第 3 个节点，新头为 4，得到 4→5→1→2→3。

时间 O(n)，额外空间 O(1)。

### 易错点与一类题总结

空链表不能先取模；从原头走 n-k-1 步才到新尾；成环后必须断开，防止返回循环链表。

循环移动可转成“确定新边界 + 连接头尾 + 在新边界切断”，先取模消除完整循环。

## 86. 分隔链表

[力扣原题](https://leetcode.cn/problems/partition-list/)

### 简短题意

给定链表 head 和值 x，将所有小于 x 的节点放在大于等于 x 的节点之前，且两部分各自保持原来的相对顺序。返回新头节点。

### 思路解析

创建两个虚拟头和两个尾指针，小值接入 small，大值接入 large。扫描时保存 next，再将当前节点从旧链表断开后尾插；最终 small 尾部连接 large 头部。各部分按扫描顺序追加，因此稳定。

### C++ 主模板

```cpp
class Solution {
public:
    ListNode* partition(ListNode* head, int x) {
        ListNode small(0), large(0);
        ListNode* smallTail = &small;
        ListNode* largeTail = &large;
        while (head != nullptr) {
            ListNode* next = head->next;
            head->next = nullptr; // 先保存后继，再断开旧连接
            if (head->val < x) { smallTail->next = head; smallTail = head; }
            else { largeTail->next = head; largeTail = head; }
            head = next;
        }
        smallTail->next = large.next;
        return small.next;
    }
};
```

### 示例与复杂度

1→4→3→2→5→2，x=3：small 为 1→2→2，large 为 4→3→5，连接后为 1→2→2→4→3→5。

时间 O(n)，额外空间 O(1)，复用原节点。

### 易错点与一类题总结

判定大值组用 >=x；若不断开旧 next，末尾可能残留旧连接甚至成环。任一组为空时 dummy 模板仍有效。

要求稳定分组的链表问题，用各组尾插维护顺序，最后拼接；不要通过交换节点值实现分组。

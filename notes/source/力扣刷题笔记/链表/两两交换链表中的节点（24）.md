# 24. 两两交换链表中的节点

## 简短题意

给定单链表头节点 `head`，将每两个相邻节点交换位置，返回交换后的头节点。必须修改节点连接，不能只交换节点值；奇数长度时，最后一个节点保持不变。

## 题型与核心思路

链表局部重连。

使用虚拟头节点 `dummy`，让 `pre` 始终指向待交换这一对的前驱。保存两个节点 `first、second`，把：

```text
pre → first → second → rest
```

改为：

```text
pre → second → first → rest
```

交换后，`first` 变成这一对的尾部，也就是下一对的前驱，所以执行 `pre = first`。

## C++ 主模板

力扣提供 `ListNode` 定义，以下代码可以直接放入题目编辑器。

```cpp
class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
        ListNode dummy(0);
        dummy.next = head;
        ListNode* pre = &dummy;

        while (pre->next != nullptr && pre->next->next != nullptr) {
            ListNode* first = pre->next;
            ListNode* second = first->next;

            first->next = second->next; // first 接到后面的剩余链表
            second->next = first;      // second 放到 first 前面
            pre->next = second;        // 前驱接到这一对的新头

            pre = first;               // 移到下一对的前驱
        }
        return dummy.next;
    }
};
```

## 示例、正确性与边界

`1→2→3→4→5`：`pre` 最初指向 `dummy`，交换 `1、2` 后得到 `2→1→3→4→5`；`pre` 移到 `1`，交换 `3、4` 后得到 `2→1→4→3→5`；只剩一个节点，停止。

每轮只修改这一对及其前驱的连接，后面的链表仍由 `first->next` 保存。交换后的前缀已经完成，`pre` 位于它的尾部；不断重复，就能处理所有完整的两节点分组。

- 空链表或单节点不进入循环，原样返回。
- 奇数长度末尾保持不变，偶数长度处理到最后一对。
- 三个指针赋值的顺序要与模板对应。先覆盖 `second->next`，再读取它作为剩余链表，会丢失原连接。
- 返回 `dummy.next`，因为原 `head` 在第一次交换后已经不是新头。
- 这里只移动原节点，不新建真实节点，也不删除节点；`dummy` 是局部对象。

时间 `O(n)`，额外空间 `O(1)`。

## 一类题总结

识别信号：固定大小分组，需要改变节点顺序。使用 `dummy + 分组前驱`，先确认这一组节点齐全，再保存节点、改连接，最后把前驱移到分组新尾部。[[链表/链表进阶（2、25、138、148、146）#25. K 个一组翻转链表]] 是更一般的分组翻转。

口诀：**先找一对，三步重连，前驱落在旧前点。**

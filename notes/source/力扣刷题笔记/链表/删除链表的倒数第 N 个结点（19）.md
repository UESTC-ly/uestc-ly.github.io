# 19. 删除链表的倒数第 N 个结点

## 简短题意

给定单链表头节点 `head` 和整数 `n`，删除链表中倒数第 `n` 个节点，返回删除后的头节点。倒数第 `1` 个是尾节点；题目保证 `1 <= n <= 链表长度`。

## 题型与核心思路

链表 + 两次遍历 + 删除前驱。先统计长度 len，把倒数位置转为正数位置，再找到前驱删除。主解法保留直观的两次遍历写法。

- 倒数第 n 个 = 正数第 len - n + 1 个。
- 前驱的位置 = len - n。
- dummy 看作第 0 个节点，pre 从 dummy 出发走 len - n 步。
- 题目中的 n 是有效倒数位置，即 1 <= n <= len。

## 样例手推

```text
1 → 2 → 3 → 4 → 5，n = 2，len = 5
目标位置：5 - 2 + 1 = 4
前驱位置：5 - 2 = 3
pre 指向 3，target 指向 4
让 3 连接 5，再释放 4，得到 1 → 2 → 3 → 5。
```

## C++ 代码

```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        int len = 0;
        ListNode* cur = head;
        while (cur != nullptr) {
            len++;
            cur = cur->next;
        }

        ListNode dummy(0);
        dummy.next = head;
        ListNode* pre = &dummy;
        for (int i = 0; i < len - n; i++) {
            pre = pre->next;
        }

        ListNode* target = pre->next; // 保存目标
        pre->next = target->next;    // 绕过目标
        delete target;              // 释放真实被删节点
        return dummy.next;
    }
};
```

## 正确性、边界与复杂度

统计长度后，pre 位于第 len - n 个位置，它的后继就是倒数第 n 个节点。绕过目标即可移除它，其他节点的顺序不变。

| 情况 | pre 的位置 | 结果 |
|---|---|---|
| 删除头节点，n = len | dummy，移动 0 步 | dummy.next 更新为原第二个节点 |
| 删除尾节点，n = 1 | 尾节点前驱，单节点时为 dummy | pre->next 变为 nullptr |
| 只有一个节点，n = 1 | dummy | 返回 nullptr |

- 时间 O(len)：两次遍历仍是线性时间；额外空间 O(1)。
- 先改连接再 delete，释放后不可再读取 target->next。
- dummy 是局部对象，不用 delete；delete target 释放的是题目要求移除的真实节点。
- 释放规则见 [[基础与模板/C++基础#插入与删除]]。

## 一类题总结

遇到倒数位置，可以先统计长度转为正数位置。删除单链表节点优先寻找前驱，再使用“保存目标 → 绕过目标 → 释放目标”的模板；dummy 统一处理删除头节点的情况。

口诀：**先数长度，再找前驱；绕过目标，释放返回。**

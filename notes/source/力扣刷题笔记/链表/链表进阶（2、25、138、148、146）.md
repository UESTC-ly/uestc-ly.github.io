## 2. 两数相加

- 题型：链表遍历 + 模拟加法 + 进位处理。
- 题意：两个非空链表逆序保存非负整数的各位，返回同样逆序保存的和。
- 识别信号：头节点就是个位，正好符合竖式加法从低位到高位的顺序，因此直接从头遍历。
- 核心：计算 `sum = x + y + carry`，用 `sum % 10` 保存当前位，用 `sum / 10` 更新进位；某条链表走完后按 `0` 处理。
- 循环条件：`l1 != nullptr || l2 != nullptr || carry != 0`，只要还有数字或进位就继续。
- 结果链表：`dummy` 是虚拟头节点，`tail` 始终指向结果末尾；每轮新建一个节点接到末尾，最后返回 `dummy.next`。

链表定义、遍历、尾插及 `.` / `->` 的区别见 [[基础与模板/C++基础#链表节点、指针与基本操作]]。

### 样例手推

`2 → 4 → 3` 表示 342，`5 → 6 → 4` 表示 465。

| 位 | x | y | 旧 carry | sum | 写入 sum % 10 | 新 carry |
|---|---:|---:|---:|---:|---:|---:|
| 个位 | 2 | 5 | 0 | 7 | 7 | 0 |
| 十位 | 4 | 6 | 0 | 10 | 0 | 1 |
| 百位 | 3 | 4 | 1 | 8 | 8 | 0 |

得到 `7 → 0 → 8`，表示 807。每轮都算对当前位，并把进位交给下一位；处理完全部数字和进位，结果就是完整的和。

### C++ 代码

力扣已提供 `ListNode` 定义。

```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode dummy(0);        // 虚拟头节点
        ListNode* tail = &dummy;  // 结果链表的尾指针
        int carry = 0;

        while (l1 != nullptr || l2 != nullptr || carry != 0) {
            int x = 0;
            int y = 0;

            // 缺位补 0，非空时才读取并前进
            if (l1 != nullptr) {
                x = l1->val;
                l1 = l1->next;
            }
            if (l2 != nullptr) {
                y = l2->val;
                l2 = l2->next;
            }

            int sum = x + y + carry;
            carry = sum / 10;
            tail->next = new ListNode(sum % 10);
            tail = tail->next;
        }

        return dummy.next;
    }
};
```

### 边界与复杂度

- 长度不同：缺位补零，例如 `[1] + [9,9] → [0,0,1]`。
- 最后仍有进位：`[9] + [1] → [0,1]`，不能在两条链表走完时直接结束。
- 两数都为零：`[0] + [0] → [0]`。
- 先判空再访问节点；添加节点后别忘记移动 `tail`。
- 每轮 `sum` 最大为 `9 + 9 + 1 = 19`，逐位计算不会产生整个整数转换的溢出问题。
- 设链表长度为 m、n：时间 `O(max(m, n))`；不计输出的额外空间 `O(1)`，结果链表空间 `O(max(m, n))`。

### 一类题总结

数字按低位到高位存储且需要加法时，可复用“缺位补零 → 当前位相加 → 取余留位 → 整除进位 → 处理剩余进位”的模板。若数字按高位到低位存储，不能直接照搬从头相加的顺序。

构建新链表可复用 `dummy + tail` 尾插模板，本题每次添加的是 `sum % 10`。

口诀：**逐位加，缺位零，取余留位，整除进位。**

## 25. K 个一组翻转链表

- 题型：链表 + 分组处理 + 独立反转模板。
- 题意：每 k 个节点反转一次，不足 k 个的最后一组保持原顺序；修改节点连接，不交换节点值。
- 核心：重复“找到区间 → 断尾 → 调用 reverseList → 接回”。
- `pre` 是当前组前一个节点，初始必须是 `&dummy`，不能是 nullptr；`dummy.next = head` 连接原链表。
- 每轮令 `end = pre`，向后走 k 步找到组尾。从 start 出发则只需 k - 1 步，不要混淆起点。
- 先判断 end 是否为空；不足 k 个时，在修改连接之前结束。
- 够一组才保存 `start = pre->next`、`after = end->next`，再令 `end->next = nullptr`。
- 接回后 `pre = start`：旧组头变成新组尾，也就是下一组的前驱。

### C++ 代码

```cpp
class Solution {
public:
    // 通用模板：反转整条链表，返回新头
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* cur = head;
        while (cur != nullptr) {
            ListNode* nextNode = cur->next; // 保存原后继
            cur->next = prev;
            prev = cur;
            cur = nextNode; // 不能使用已经改过的 cur->next
        }
        return prev;
    }

    ListNode* reverseKGroup(ListNode* head, int k) {
        ListNode dummy(0);
        dummy.next = head;
        ListNode* pre = &dummy;

        while (pre->next != nullptr) {
            ListNode* end = pre;
            for (int i = 0; i < k && end != nullptr; i++) {
                end = end->next;
            }
            if (end == nullptr) break; // 不足 k 个，不反转

            ListNode* start = pre->next;
            ListNode* after = end->next;
            end->next = nullptr;

            ListNode* newHead = reverseList(start);
            pre->next = newHead;
            start->next = after;
            pre = start; // 下一组的前驱
        }
        return dummy.next;
    }
};
```

### 手推、正确性与边界

```text
k = 2
初始：       1 → 2 → 3 → 4 → 5
第一组后：   2 → 1 → 3 → 4 → 5，pre 指向 1
第二组后：   2 → 1 → 4 → 3 → 5，pre 指向 3
剩余节点 5 不足一组，保持原样。
```

每轮开始时，pre 前面及 pre 所在的部分已经处理完成，pre->next 是未处理部分的头。反转完整一组并接回后，将 pre 移到新组尾，继续保持这个条件。

- k = 1：每组只有一个节点，顺序不变，pre 仍会前进。
- 长度恰好是 k 的倍数：最后 after 为 nullptr，接回后自然结束。
- 从末尾节点读取 next 得到 nullptr 是合法的；end 本身为空后不可再访问 end->next。
- 时间 O(n)：每组查找一次、反转一次，每个节点只被处理常数次；额外空间 O(1)。

### 一类题总结

固定长度分组处理：先确认够一组，再断开和处理，最后接回并推进前驱。与 [[链表/反转链表 II（92）]] 共用独立 reverseList 模板。

口诀：**先数够，再断尾；反转接回，pre 到旧头。**

## 138. 随机链表的复制

### 简短题意

给定链表头节点 `head`，每个节点除 `next` 外还有 `random` 指针，后者可指向链表中的任意节点或空指针。返回整条链表的深拷贝：新节点的值和指针关系与原链表对应，且所有指针都指向新链表节点或空指针，不能指向原节点。

- 题型：链表 + 深拷贝 + 哈希表
- 核心：复制的不是节点值，而是整套节点关系；用哈希表保存 `原节点 -> 新节点` 的映射
- 思路：
  - 第一遍遍历原链表，只创建新节点：`mp[cur] = new Node(cur->val)`
  - 第二遍遍历原链表，补上新节点的指针关系：
    - `mp[cur]->next = mp[cur->next]`
    - `mp[cur]->random = mp[cur->random]`
  - 最后返回 `mp[head]`
- 关键判断：
  - `head == nullptr` 时直接返回 `nullptr`
  - `random` 可能指向任意节点，也可能是 `nullptr`，所以必须先把所有节点创建出来
  - `unordered_map<Node*, Node*>` 存的是节点地址映射，不是节点值映射
- 为什么两遍：
  - 第一遍保证所有新节点都存在
  - 第二遍再连 `next` 和 `random`，就不用担心 `random` 指向的节点还没创建
- 口诀：**先建点，再连线；next 好连，random 靠映射**

### 地址映射与空指针

`unordered_map<Node*, Node*> mp` 的键是旧节点地址，值是对应的新节点地址。节点值可能重复，因此不能用 val 作为键。`mp[nullptr] = nullptr` 只添加“空 → 空”的记录，没有创建节点。

例如旧链表 A → B → C，复制后为 A' → B' → C'。若 A.random 指向 C，新节点 A'.random 必须指向 C'，不能直接写 `copy->random = cur->random`，否则会指向旧节点。

```cpp
Node* copy = mp[cur];            // 当前节点的副本
Node* oldTarget = cur->random;   // 原 random 目标
Node* newTarget = mp[oldTarget]; // 目标的副本
copy->random = newTarget;
// 等价于 mp[cur]->random = mp[cur->random];
```

当 cur->random 为空时，右边变成 `mp[nullptr]`，结果也是 nullptr。mp[cur] 的类型为 Node*，所以访问成员用箭头。

C++ 查询规则另见 [[基础与模板/C++基础#unordered_map 的查询与默认值]]。这里显式写空映射便于理解；即使省略，首次用 `mp[nullptr]` 访问缺失键也会插入值初始化后的 Node*，其值为 nullptr。

### C++代码
```cpp
class Solution {
public:
    Node* copyRandomList(Node* head) {
        if (head == nullptr) return nullptr;

        unordered_map<Node*, Node*> mp; // 原节点 -> 新节点
        mp[nullptr] = nullptr; // 空指针也映射到空指针

        // 第一遍：复制所有节点，只复制 val
        Node* cur = head;
        while (cur != nullptr) {
            mp[cur] = new Node(cur->val);
            cur = cur->next;
        }

        // 第二遍：补齐 next 和 random 指针
        cur = head;
        while (cur != nullptr) {
            mp[cur]->next = mp[cur->next];       // next 可能为空
            mp[cur]->random = mp[cur->random];   // random 可能为空
            cur = cur->next;
        }

        return mp[head]; // 返回复制链表头节点
    }
};
```

### 正确性、边界与复杂度

第一遍给每个旧节点建立唯一的同值副本；第二遍把每条旧连接换成副本之间的连接，因此保留原结构，且新链表不引用旧节点。

- 空链表返回 nullptr；random 为空、自指或指向前后任意节点，都由映射统一处理。
- 值重复仍按节点地址区分；遍历沿 next 前进，不沿 random 前进。
- 平均时间 O(n)，哈希表额外空间 O(n)，输出节点空间 O(n)。

- 一类题总结：
  - 这是典型的“复杂结构深拷贝”题
  - 只要看到节点之间有额外引用、随机引用、交叉引用，就优先想到：`旧节点 -> 新节点` 哈希映射
  - 通用套路：**先创建所有副本，再根据映射恢复关系**

## 148. 排序链表

### 简短题意

给定单链表头节点 `head`，按节点值的升序对链表排序，并返回排序后的头节点。链表可能为空，节点值可能重复；进阶要求为 `O(n log n)` 时间和常数额外空间。

- 题型：链表 + 归并排序
- 核心：链表不适合随机访问，但很适合“拆成两半 + 合并有序链表”，所以最经典做法就是归并排序
- 思路：
  - 终止条件：链表为空或只有一个节点，天然有序，直接返回
  - 用快慢指针找中点：`slow` 一步，`fast` 两步
  - 从中点断开链表，分成左右两半
  - 递归排序左半和右半
  - 最后合并两个有序链表
- 合并技巧：
  - 用 `dummy` 作为合并链表的哑节点，方便尾插
  - 逐个比较两个链表头部，把较小的接到结果链表后面
- 关键判断：
  - `slow` 位置决定拆分点
  - 递归前一定要 `slow->next = nullptr`，否则左右两边会互相串起来
  - 合并时剩余部分直接接到结果尾部
- 代码里的 `dummy.next`：
  - 这里的 `dummy` 是栈上局部变量，不是 `new` 出来的堆对象
  - 函数结束后会自动销毁，所以**不需要 delete**
  - 返回的是 `dummy.next` 指向的排序后链表头，不是 `dummy` 本身
- 口诀：**找中点，拆两半，递归排，最后合**

### C++代码
```cpp
class Solution {
public:
    ListNode* sortList(ListNode* head) {
        // 空链表或只有一个节点，天然有序
        if (head == nullptr || head->next == nullptr) {
            return head;
        }

        // 快慢指针找中点
        ListNode* slow = head;
        ListNode* fast = head->next;
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }

        // 从中点断开，分成左右两半
        ListNode* rightHead = slow->next;
        slow->next = nullptr;

        // 递归排序左右两边
        ListNode* left = sortList(head);
        ListNode* right = sortList(rightHead);

        // 合并两个有序链表
        return merge(left, right);
    }

private:
    ListNode* merge(ListNode* l1, ListNode* l2) {
        ListNode dummy(0); // 栈上哑节点，函数结束自动销毁
        ListNode* cur = &dummy;

        while (l1 != nullptr && l2 != nullptr) {
            if (l1->val <= l2->val) {
                cur->next = l1;
                l1 = l1->next;
            } else {
                cur->next = l2;
                l2 = l2->next;
            }
            cur = cur->next;
        }

        // 剩余部分直接接上
        cur->next = (l1 != nullptr) ? l1 : l2;

        return dummy.next;
    }
};
```

- 一类题总结：
  - 链表排序最常用的是归并排序
  - 模板就是：**快慢找中点 + 递归拆分 + 合并有序链表**
  - 如果看到“链表排序 + 要求稳定/高效”，优先想到归并，而不是快排

## 146. LRU 缓存

### 简短题意

实现容量为 `capacity` 的 LRU 缓存。`get(key)` 返回对应值，不存在则返回 `-1`；`put(key, value)` 插入或更新键值，超出容量时淘汰最久未使用的键。成功读取、插入或更新都算一次使用，两个操作的平均时间复杂度均要求为 `O(1)`。

- 题型：哈希表 + 双向链表 / 数据结构设计
- 核心：用 `unordered_map` 快速定位 key，用 `list` 维护“最近使用顺序”
- 结构：
  - `list<pair<int,int>> cache`：链表头部是最近使用，尾部是最久未使用
  - `unordered_map<int, list<pair<int,int>>::iterator> mp`：`key -> 链表节点位置`
- `get(key)`：
  - key 不存在：返回 `-1`
  - key 存在：取出 `it->second` 作为 value，把该节点移到链表头部，返回 value
- `put(key, value)`：
  - key 已存在：删除旧节点
  - 插入 `{key, value}` 到链表头部
  - 如果超过容量：删除链表尾部，并从哈希表中删除对应 key
- 关键判断：
  - `it->first` 是 key
  - `it->second` 是 value
  - `it` 是链表迭代器，所以 `it->second` 等价于 `(*it).second`
- 易错点：
  - `get` 也算一次使用，必须移动到头部
  - `put` 更新已有 key 时，也要移动到头部
  - 淘汰尾部节点时，链表和哈希表都要删除
- 口诀：**哈希定位，链表排序；头部最新，尾部淘汰**

### C++代码
```cpp
class LRUCache {
private:
    int cap;
    list<pair<int, int>> cache; // {key, value}，头部最近使用，尾部最久未使用
    unordered_map<int, list<pair<int, int>>::iterator> mp; // key -> 链表节点位置

public:
    LRUCache(int capacity) {
        cap = capacity;
    }

    int get(int key) {
        if (!mp.count(key)) return -1; // key 不存在

        auto it = mp[key];
        int value = it->second; // pair 的 second 是 value

        cache.erase(it);              // 删除旧位置
        cache.push_front({key, value}); // 放到头部，表示最近使用
        mp[key] = cache.begin();      // 更新位置

        return value;
    }

    void put(int key, int value) {
        if (mp.count(key)) {
            cache.erase(mp[key]); // 已存在则先删除旧节点
        }

        cache.push_front({key, value}); // 新节点放头部
        mp[key] = cache.begin();

        if (cache.size() > cap) {
            int oldKey = cache.back().first; // 尾部是最久未使用
            cache.pop_back();
            mp.erase(oldKey);
        }
    }
};
```

- 复杂度：
  - 时间复杂度：`get` / `put` 平均 `O(1)`
  - 空间复杂度：`O(capacity)`
- 一类题总结：只要题目同时要求“按 key 快速查找”和“维护访问/插入顺序并快速移动删除”，优先想到 **哈希表 + 双向链表**。

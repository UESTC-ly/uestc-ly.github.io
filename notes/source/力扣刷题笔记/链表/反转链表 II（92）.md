# 92. 反转链表 II

## 核心思路

- 题型：链表 + 区间处理 + 独立反转模板。
- 将从 1 开始计数的 [left, right] 区间反转，其余节点顺序不变。
- 模板化：定位边界 → 保存后继 → 断开区间尾部 → 调用 reverseList → 接回。
- pre 为区间前驱，start 为原区间头，end 为原区间尾，after 为区间后继。

```text
left = 2，right = 4
原链表：dummy → 1 → 2 → 3 → 4 → 5
              pre start   end after
断尾后，从 start 出发：2 → 3 → 4 → nullptr
反转后：             4 → 3 → 2 → nullptr
                     新头    start（新尾）
接回后：1 → 4 → 3 → 2 → 5
```

## C++ 模板

```cpp
class Solution {
public:
    // 通用模板：反转整条链表，返回新头
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* cur = head;
        while (cur != nullptr) {
            ListNode* nextNode = cur->next; // 保存原后继
            cur->next = prev;
            prev = cur;
            cur = nextNode; // 不能使用已经改过的 cur->next
        }
        return prev;
    }

    ListNode* reverseBetween(ListNode* head, int left, int right) {
        ListNode dummy(0);
        dummy.next = head;
        ListNode* pre = &dummy;
        for (int i = 0; i < left - 1; i++) {
            pre = pre->next;
        }

        ListNode* start = pre->next;
        ListNode* end = start;
        for (int i = 0; i < right - left; i++) {
            end = end->next;
        }

        ListNode* after = end->next; // 先保存，后断开
        end->next = nullptr;
        ListNode* newHead = reverseList(start);
        pre->next = newHead;  // 前面接新头
        start->next = after; // 旧头变新尾，接回后面
        return dummy.next;
    }
};
```

## 关键条件与正确性

- dummy 相当于位置 0，pre 从 dummy 走 left - 1 步；end 从 start 走 right - left 步。
- 不需要断开 pre->next：反转函数只从 start 沿 next 向后走，不会访问前面的 pre。
- 必须断开 end->next，否则通用反转函数会把后面的节点一起反转。
- reverseList 只处理截出的区间；返回新头，旧 start 成为新尾。将两端接回后，区间外节点及其顺序保持不变。
- left = 1 时 pre 为 dummy；right 在末尾时 after 为空；left = right 时反转单个节点，结果不变。
- 按题目有效位置范围处理；时间 O(n)，额外空间 O(1)。

## 追问与易错点

返回 prev、cur = nextNode 的原因见 [[链表/链表基础（160、206、234、141、142、21）#模板追问：返回 prev，以及为什么必须保存原后继]]。

若使用 new 创建 dummy，最后必须先保存结果再 delete：

```cpp
ListNode* result = dummy->next;
delete dummy;
return result;
```

说明见 [[基础与模板/C++基础#用 delete 释放虚拟头节点]]。

## 一类题总结

局部处理链表时，保存前驱和后继，把目标区间交给独立函数，处理完恢复两端连接。推广到 [[链表/链表进阶（2、25、138、148、146）#25. K 个一组翻转链表]] 时，只需重复定位每个完整分组。

口诀：**定位边界，存后断尾；调用反转，前接新头，旧头接后。**

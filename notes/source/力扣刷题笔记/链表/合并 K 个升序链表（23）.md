# 23. 合并 K 个升序链表

## 简短题意

给定包含 `k` 个链表头节点的数组 `lists`，各链表都按节点值升序排列。将所有节点合并成一个升序链表，返回其头节点；允许某些链表为空，全部为空时返回空指针。

## 题型与核心思路

小顶堆 + 多路归并。用 `N` 表示所有链表的节点总数。

每条链表未处理部分的最小值，一定在它当前的头节点。因此，下一次要取的全局最小值，只需要在这些头节点中寻找。

用小顶堆保存每条非空链表当前的候选节点。每次取出最小节点接到答案尾部，再把该节点原来的后继加入堆，让同一条链表提供下一位候选。

## 比较器为什么写大于号

`priority_queue` 默认是大顶堆。自定义比较器写 `a->val > b->val`，表示值较大的节点优先级更低，因此堆顶是值最小的节点。必须比较**节点值**，不能比较指针地址。

## C++ 主模板

力扣提供 `ListNode` 定义。以下模板复用原链表节点。

```cpp
class Solution {
    struct Compare {
        bool operator()(ListNode* a, ListNode* b) const {
            return a->val > b->val; // 小值位于堆顶
        }
    };

public:
    ListNode* mergeKLists(vector<ListNode*>& lists) {
        priority_queue<ListNode*, vector<ListNode*>, Compare> heap;
        for (ListNode* head : lists) {
            if (head != nullptr) heap.push(head);
        }

        ListNode dummy(0);
        ListNode* tail = &dummy;

        while (!heap.empty()) {
            ListNode* node = heap.top();
            heap.pop();

            // 同一路的后继成为新的候选
            if (node->next != nullptr) heap.push(node->next);
            tail->next = node;
            tail = node;
        }
        tail->next = nullptr; // 明确结束结果链表
        return dummy.next;
    }
};
```

## 示例与正确性

`[1→4→5, 1→3→4, 2→6]`：堆初始保存 `1、1、2`。取出某一路的 `1`，再放入它的后继；每次保持堆内只有各路当前最小候选。最终顺序为 `1→1→2→3→4→4→5→6`，相等节点取出的先后顺序不影响正确性。

任何尚未入堆的节点，都不会小于同一路已经入堆的候选；因此堆顶就是所有未处理节点中的全局最小值。每次追加堆顶并补入它的后继，既保持结果有序，也保证每个节点恰好处理一次。

## 复杂度与易错点

- 扫描头节点需要 `O(k)`；堆中最多有 `k` 个节点，每个真实节点入堆、出堆各一次。统一写时间 `O(k + N log(k+1))`，常见简写为 `O(N log k)`（`k>=2`，且计入节点处理阶段）。额外空间 `O(k)`。
- `lists` 为空，或全部链表为空时，返回 `nullptr`。
- 不能把空指针放入堆；比较器会读取 `val`。
- 先取 `top()` 再 `pop()`，因为 `pop()` 不返回被移除元素。
- 每路只需放入当前候选，无需一次性把所有节点装入堆。
- 模板修改原节点的连接；不额外分配结果节点，也不释放仍属于结果的节点。输入按题目模型是相互独立的链表。

## 一类题总结

识别信号：多个数据源分别有序，需要合成全局有序结果。小顶堆只保存每一路的当前最小候选，取出一项后，从同一路补下一项。这一模板同样适用于多个有序数组的归并。

口诀：**每路放一个，堆顶取最小，取完补同路。**

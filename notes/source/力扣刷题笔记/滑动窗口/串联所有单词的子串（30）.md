## 30. 串联所有单词的子串

[力扣原题](https://leetcode.cn/problems/substring-with-concatenation-of-all-words/)

### 简短题意

给定字符串 s 和等长非空单词数组 words，返回所有连续子串起点，使子串恰好由 words 中每个单词使用一次、任意顺序串联而成。重复单词也要达到相应次数。

### 思路解析

单词长度为 L，以 0..L-1 为起点偏移分别扫描，每次读一个长度为 L 的词。need 保存目标次数，have 保存窗口次数。遇到不在目标中的词清空窗口；某词超量时，从左侧逐词移除直到不过量。窗口含 words.size() 个词且每词不过量时，必然恰好覆盖整个多重集合。偏移枚举保证所有起点都能被扫描。

### C++ 主模板

```cpp
class Solution {
    // 按等长单词分块扫描，词频超量时从左侧缩窗。
public:
    vector<int> findSubstring(string s, vector<string>& words) {
        int len = words[0].size(), count = words.size(), n = s.size();
        unordered_map<string, int> need;
        for (const string& word : words) need[word]++;
        vector<int> ans;
        for (int offset = 0; offset < len && offset + len <= n; offset++) {
            unordered_map<string, int> have;
            int left = offset, used = 0;
            for (int right = offset; right + len <= n; right += len) {
                string word = s.substr(right, len);
                if (!need.count(word)) {
                    have.clear(); used = 0; left = right + len;
                    continue;
                }
                have[word]++; used++;
                while (have[word] > need[word]) {
                    string old = s.substr(left, len);
                    have[old]--; used--; left += len;
                }
                if (used == count) ans.push_back(left);
            }
        }
        return ans;
    }
};
```

### 示例与复杂度

s="barfoofoobarthefoobarman"，words=["bar","foo","the"]，答案为 [6,9,12]。重复 foo 超量时，从左侧移除直到只留允许的次数。

设 n=|s|、w=单词数、L=单词长度。字符串复制和哈希计入后，平均时间 O((n+w)L)，额外空间 O(wL)，输出另计。

### 易错点与一类题总结

移动步长是 L，不是 1；必须枚举所有偏移；答案顺序不限，不必为排序增加工作。只用集合会忽略重复次数。

等长词串联把字符窗口转为词块窗口；维护频次并删除超量元素，沿用字符计数的滑动窗口思想。

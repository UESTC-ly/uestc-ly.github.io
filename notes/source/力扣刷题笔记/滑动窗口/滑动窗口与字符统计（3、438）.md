# 滑动窗口与字符统计：无重复字符的最长子串、长度最小的子数组、找到所有字母异位词（3、209、438）

# 一、`unordered_set` 基础

## 1. 适用场景

`unordered_set` 是哈希集合，适合：

- 保存不重复的元素；
- 快速判断某个元素是否存在；
- 不关心元素的排列顺序。

常用定义：

```cpp
unordered_set<int> nums;
unordered_set<char> chars;
unordered_set<string> words;
```

平均情况下，插入、查找和删除的时间复杂度都是 `O(1)`。

## 2. 常用操作

```cpp
unordered_set<char> st;

st.insert('a');       // 插入元素
st.count('a');        // 存在返回 1，不存在返回 0
st.find('a');         // 找到则返回迭代器，否则返回 st.end()
st.erase('a');        // 删除元素
st.size();            // 元素数量
st.empty();           // 是否为空
st.clear();           // 清空集合
```

判断元素是否存在时，刷题中常写：

```cpp
if (st.count(c)) {
    // c 存在
}
```

`unordered_set` 没有数组下标语义，不能写：

```cpp
st[0]; // 错误
```

遍历顺序也不固定：

```cpp
for (char c : st) {
    cout << c << ' ';
}
```

## 3. `set` 与 `unordered_set`

| 容器 | 常见底层结构 | 元素顺序 | 查找、插入、删除 |
|---|---|---|---|
| `set` | 红黑树 | 自动排序 | `O(log n)` |
| `unordered_set` | 哈希表 | 无序 | 平均 `O(1)` |

只需要去重和判断存在、不要求有序时，一般优先考虑 `unordered_set`。

## 4. `size()` 与 `int` 的类型转换

`st.size()` 返回 `size_t`，而下面的 `ans` 是 `int`：

```cpp
int ans = 0;
```

直接写：

```cpp
ans = max(ans, st.size());
```

可能因为 `max` 的两个参数类型不同而编译失败。可以明确转换：

```cpp
ans = max(ans, static_cast<int>(st.size()));
```

在滑动窗口中，如果窗口边界都是 `int`，也可以直接计算窗口长度：

```cpp
ans = max(ans, right - left);
```

# 二、3. 无重复字符的最长子串

## 1. 题意

给定字符串 `s`，求不包含重复字符的最长连续子串长度。

本题要找的是**子串**，所以字符在原字符串中必须连续。

## 2. 核心思路：可变长度滑动窗口

维护左闭右开窗口：

```text
[left, right)
```

并使用：

```cpp
unordered_set<char> window;
```

记录当前窗口里的字符。

窗口始终满足：

> `window` 中没有重复字符，并且它保存的字符与 `[left, right)` 对应。

处理规则：

- `s[right]` 不在集合中：将其加入窗口，`right++`；
- `s[right]` 已在集合中：删除左端字符 `s[left]`，`left++`；
- 重复字符可能不在最左边，因此要持续缩小窗口，直到重复消失。

## 3. 易错点：删除的是字符，不是下标

集合的类型是：

```cpp
unordered_set<char> window;
```

因此错误写法是：

```cpp
window.erase(left);
```

`left` 是下标，而集合中保存的是字符。正确写法是：

```cpp
window.erase(s[left]);
```

记忆：

```text
右边进入的是 s[right]
左边离开的也是 s[left]
```

## 4. 示例推演：`"abba"`

开始时：

```text
left = 0, right = 0, window = {}
```

1. 加入 `'a'`，窗口为 `"a"`，答案为 `1`；
2. 加入 `'b'`，窗口为 `"ab"`，答案为 `2`；
3. 再遇到 `'b'`，先删除左端 `'a'`，但窗口中仍有 `'b'`；
4. 继续删除左端旧的 `'b'`，重复消失；
5. 加入新的 `'b'`，再继续处理最后的 `'a'`。

最终最长长度为 `2`。

这个例子说明：遇到重复字符时不能只删除一次，必须持续移动左边界，直到当前字符可以安全进入窗口。

## 5. C++ 代码

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int left = 0;
        int right = 0;
        int answer = 0;

        // 保存当前窗口 [left, right) 中的字符
        unordered_set<char> window;

        while (right < static_cast<int>(s.size())) {
            if (!window.count(s[right])) {
                // 当前字符不重复，可以进入窗口
                window.insert(s[right]);
                right++;

                // 此时窗口是 [left, right)，长度为 right - left
                answer = max(answer, right - left);
            } else {
                // 当前字符重复，先从左侧缩小窗口
                window.erase(s[left]);
                left++;
            }
        }

        return answer;
    }
};
```

也可以根据集合大小更新答案：

```cpp
answer = max(answer, static_cast<int>(window.size()));
```

不过使用 `right - left` 能直接体现窗口长度，并避免 `size_t` 与 `int` 的类型不一致。

## 6. 复杂度

- 时间复杂度：`O(n)`；
- 空间复杂度：`O(k)`，其中 `k` 是窗口中不同字符的数量。

虽然代码中发生了左右指针移动，但每个字符最多进入和离开窗口各一次，因此整体是线性的。

## 7. 方法归纳

```text
右端字符不重复 → 加入窗口，扩大右边界
右端字符重复   → 删除左端字符，缩小左边界
```

记忆：

> **最长无重复子串：集合判重复，重复就缩左边，不重复就扩右边。**

## 8. 本次补充：用哈希表记录最后出现位置

`lastPos[c]` 保存字符 `c` 在已扫描部分中最后出现的下标，**不是出现次数，也不只保存当前窗口内的字符**。此写法使用闭区间 `[left, right]`，长度为 `right - left + 1`。

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int n = s.size();
        int left = 0;
        int ans = 0;
        unordered_map<char, int> lastPos;

        for (int right = 0; right < n; right++) {
            char c = s[right];
            // 先确认存在，再判断旧位置是否在当前窗口内
            if (lastPos.count(c) && lastPos[c] >= left) {
                left = lastPos[c] + 1;
            }
            // 判断旧位置之后，统一更新最新位置
            lastPos[c] = right;
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
};
```

加入新字符之前窗口没有重复，所以只需排除新字符对应的旧位置。跳到旧位置之后，窗口重新合法；更早的左边界会包含这两个重复字符。因此每轮得到以 `right` 结尾的最长合法窗口。

### 为什么左指针不能后退

以 `"abba"` 为例：

| right | 字符 | 旧位置 | 更新后的 left | 合法窗口 |
|---|---|---|---|---|
| 0 | a | 不存在 | 0 | a |
| 1 | b | 不存在 | 0 | ab |
| 2 | b | 1 | 2 | b |
| 3 | a | 0，在窗口外 | 2 | ba |

最后一个 `a` 的旧位置是 `0`，已经被移出窗口。直接执行 `left = 0 + 1` 会把左边界从 `2` 退到 `1`，得到包含重复字符的 `"bba"`。

上面的条件也可等价写为：

```cpp
if (lastPos.count(c)) {
    left = max(left, lastPos[c] + 1);
}
```

这里先判断字符存在，`max` 再保证左边界只向右移动。这是本题的窗口维护要求，不是所有双指针算法都禁止向左移动。

### 本次代码中的易错点

- `count(c)` 检查字符键是否存在；`count(lastPos[c])` 却把存储的下标当作字符键查找，含义错误。
- 读写必须使用同一种键：采用 `char` 键时统一写 `c`，不要混用 `c - 'a'`。本题不只包含小写字母。
- `lastPos[c]` 在键不存在时会插入值 `0`。直接判断 `lastPos[c] >= left`，会把首次出现的字符误当成下标 `0` 处的旧字符；输入 `"a"` 就会错误返回 `0`。
- 先查询旧位置，再执行 `lastPos[c] = right`；只需在条件外统一赋值一次。
- `unordered_map<char, int> lastPos(26, {-1, -1})` 不是有效的“26 个位置填 -1”初始化方式。

这里涉及的 `unordered_map` 行为是 C++ 容器的通用规则：`find`/`count` 用于查询是否存在，`operator[]` 在缺少 key 时会插入默认值。

关于指定键初始化为 `-1`、`find` 写法及字符数组替代方案，见 [C++基础](../基础与模板/C++基础.md#unordered_map-的查询与默认值)。

### 复杂度与边界

平均时间 `O(n)`，额外空间 `O(min(n, K))`，`K` 为字符集大小；固定字符集下额外空间可视为 `O(1)`。哈希操作平均为常数时间，极端碰撞下不保证整体线性。

手推边界：空串返回 `0`，`"a"` 返回 `1`，`"bbbb"` 返回 `1`，`"abba"` 返回 `2`。

记忆：**查旧位置 → 排除窗口内重复 → 更新新位置 → 记录最长长度。**

# 三、209. 长度最小的子数组

## 1. 题意

给定正整数数组 `nums` 和正整数 `target`，找到总和大于等于 `target` 的连续子数组，并返回其中最小的长度；不存在时返回 `0`。

## 2. 为什么使用滑动窗口

数组元素都是正数，这是本题能够使用滑动窗口的关键：

- 右边加入一个数，窗口和只会变大；
- 左边移出一个数，窗口和只会变小。

因此可以先扩大窗口直到满足 `sum >= target`，再不断缩小左边界，寻找当前右边界下的最短窗口。

## 3. 核心步骤

维护闭区间 `[left, right]`：

1. `nums[right]` 加入窗口；
2. 当窗口和 `sum >= target` 时，先更新答案；
3. 移出 `nums[left]`，然后 `left++`，继续尝试缩小窗口；
4. 右指针遍历结束后，如果没有找到答案则返回 `0`。

注意条件是 `>=`，不是 `==`。例如 `target = 3`、`nums = [2, 2]` 时，窗口和为 `4`，仍然符合要求。

## 4. C++ 代码

```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int left = 0;
        int ans = INT_MAX;
        long long sum = 0;

        for (int right = 0; right < nums.size(); right++) {
            sum += nums[right];

            // 满足条件后持续缩小左边界，寻找最短窗口
            while (sum >= target) {
                ans = min(ans, right - left + 1);
                sum -= nums[left];
                left++;
            }
        }

        return ans == INT_MAX ? 0 : ans;
    }
};
```

## 5. 复杂度与适用边界

原先枚举长度、枚举起点、重新求和的写法，最坏时间为 `O(n³)`。按长度递增找到首个合法窗口就返回是可行的，但判断必须为 `>= target`，并且这种枚举仍可能超时。

手推 `target = 7, nums = [2,3,1,2,4,3]`：右端到下标 `3` 时首次得到和为 `8` 的窗口，记录长度 `4`；继续扩张、收缩，最终窗口 `[4,3]` 的和为 `7`，记录长度 `2`。必须先记录合法窗口，再移出左端元素；用 `while` 持续收缩，不能只缩一次。

- 时间复杂度：`O(n)`。左右指针都只向右移动一次；
- 空间复杂度：`O(1)`；
- 这里依赖数组元素为正数。若数组中允许负数，窗口和不再具有单调性，不能直接套用此模板。

## 6. 方法归纳

看到“正数数组 + 连续子数组 + 和至少达到某个目标”，优先想到：

> **先扩张到满足条件，再收缩到不满足条件；每次满足时更新最优答案。**

# 四、438. 找到字符串中所有字母异位词

## 1. 题意

给定字符串 `s` 和 `p`，找出 `s` 中所有是 `p` 的字母异位词的子串，并返回这些子串的起始下标。

字母异位词要求：

- 字符种类相同；
- 每种字符的出现次数相同；
- 字符排列顺序可以不同。

例如：

```text
"abc"、"cba"、"bac"
```

互为字母异位词。

图片中的示例：

```text
s = "cbaebabacd", p = "abc"
答案：[0, 6]
```

因为从下标 `0` 开始的 `"cba"` 和从下标 `6` 开始的 `"bac"` 都是 `"abc"` 的异位词。

另一个示例：

```text
s = "abab", p = "ab"
答案：[0, 1, 2]
```

对应的定长子串依次为 `"ab"`、`"ba"`、`"ab"`。

## 2. 为什么不能只使用 `unordered_set`

本题不仅要判断字符是否存在，还要比较每个字符出现了多少次。

例如：

```text
p = "aab"
```

需要保存：

```text
a 出现 2 次
b 出现 1 次
```

`unordered_set` 去重后只能保存 `'a'` 和 `'b'`，会丢失字符次数，因此不适合本题。

由于题目字符为小写英文字母，可以使用长度为 `26` 的频次数组：

```cpp
vector<int> need(26, 0);
vector<int> window(26, 0);
```

字符转换为数组下标：

```cpp
int index = c - 'a';
```

## 3. 核心思路：固定长度滑动窗口

异位词和 `p` 的长度一定相同，因此窗口长度固定为：

```cpp
m = p.size();
```

维护左闭右开窗口：

```text
[left, right)
```

每轮按以下顺序处理：

1. `s[right]` 进入窗口；
2. `right++`；
3. 如果窗口长度超过 `m`，删除 `s[left]` 并令 `left++`；
4. 当窗口长度等于 `m` 时，比较 `window` 和 `need`；
5. 两个计数数组相同，就记录 `left`。

关键模板：

```cpp
window[s[right] - 'a']++;
right++;

if (right - left > m) {
    window[s[left] - 'a']--;
    left++;
}

if (right - left == m && window == need) {
    answer.push_back(left);
}
```

## 4. 常见边界错误

### 错误一：移动 `right` 后再访问 `s[right]`

下面的顺序可能跳过 `s[0]`，并在末尾越界：

```cpp
right++;
window[s[right] - 'a']++;
```

当 `right` 原本等于 `s.size() - 1` 时，执行 `right++` 后再访问 `s[right]`，就访问了字符串末尾之外的位置。

正确顺序是：

```cpp
window[s[right] - 'a']++;
right++;
```

即先处理当前字符，再移动右边界。

### 错误二：指针区间与计数数组不同步

如果用：

```cpp
right - left + 1
```

表示闭区间 `[left, right]`，就必须确保 `window` 已经包含 `s[right]`。

为了减少混乱，推荐统一使用左闭右开区间：

```text
[left, right)
窗口长度 = right - left
```

这样 `right` 始终指向下一个尚未加入窗口的字符。

## 5. C++ 双指针写法

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        int n = static_cast<int>(s.size());
        int m = static_cast<int>(p.size());

        vector<int> answer;

        // p 比 s 长时，不可能存在符合要求的子串
        if (m > n) {
            return answer;
        }

        vector<int> need(26, 0);
        vector<int> window(26, 0);

        for (char c : p) {
            need[c - 'a']++;
        }

        int left = 0;
        int right = 0;

        // 窗口始终表示 [left, right)
        while (right < n) {
            // 当前右侧字符进入窗口
            window[s[right] - 'a']++;
            right++;

            // 固定窗口长度，超长时移出左侧字符
            if (right - left > m) {
                window[s[left] - 'a']--;
                left++;
            }

            // 长度相同且字符频次相同，就是异位词
            if (right - left == m && window == need) {
                answer.push_back(left);
            }
        }

        return answer;
    }
};
```

## 6. 更简洁的单指针写法

固定长度窗口也可以只显式使用右边界：

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        int n = static_cast<int>(s.size());
        int m = static_cast<int>(p.size());

        vector<int> answer;

        if (m > n) {
            return answer;
        }

        vector<int> need(26, 0);
        vector<int> window(26, 0);

        for (char c : p) {
            need[c - 'a']++;
        }

        for (int right = 0; right < n; right++) {
            // 当前字符进入窗口
            window[s[right] - 'a']++;

            // right >= m 时，移除窗口左侧多出的字符
            if (right >= m) {
                window[s[right - m] - 'a']--;
            }

            // 当前窗口长度达到 m，并且频次数组相同
            if (right >= m - 1 && window == need) {
                answer.push_back(right - m + 1);
            }
        }

        return answer;
    }
};
```

对于刚开始学习滑动窗口时，双指针写法更直观；熟悉固定窗口后，可以使用单指针写法。

## 7. 示例推演：`s = "abab"`，`p = "ab"`

目标频次：

```text
a = 1, b = 1
```

窗口长度固定为 `2`：

1. 加入 `s[0] = 'a'`，窗口 `"a"`，长度不足；
2. 加入 `s[1] = 'b'`，窗口 `"ab"`，记录起点 `0`；
3. 加入 `s[2] = 'a'` 后窗口暂时超长，移出 `s[0]`，得到 `"ba"`，记录起点 `1`；
4. 加入 `s[3] = 'b'` 后移出 `s[1]`，得到 `"ab"`，记录起点 `2`。

最终结果：

```text
[0, 1, 2]
```

## 8. 复杂度

比较两个长度为 `26` 的数组需要 `O(26)`，因为字符集大小固定，可以看作常数。

- 时间复杂度：`O(26n)`，简化为 `O(n)`；
- 空间复杂度：`O(26)`，简化为 `O(1)`。

## 9. 方法归纳

看到以下特征：

- 寻找连续子串；
- 合法子串长度固定；
- 需要比较字符出现次数；

可以考虑：

> **定长滑动窗口 + 字符频次数组。**

# 五、三道滑动窗口题对比

| 题目 | 窗口类型 | 窗口中保存的信息 | 缩小窗口的条件 | 收集答案 |
|---|---|---|---|---|
| 3. 无重复字符的最长子串 | 可变长度 | 当前字符集合 | 右侧字符重复 | 更新最大窗口长度 |
| 209. 长度最小的子数组 | 可变长度 | 当前窗口和 | 窗口和 `>= target` | 更新最小窗口长度 |
| 438. 找到所有字母异位词 | 固定长度 | 26 个字母的出现次数 | 窗口长度超过 `p.size()` | 频次数组相同时记录左边界 |

前文集合版 3 题与 438 题使用左闭右开窗口：

```text
窗口：[left, right)
长度：right - left
```

这两个版本的处理顺序：

```text
右侧元素进入窗口
        ↓
根据题目条件移动左边界
        ↓
检查当前窗口并更新答案
```

209 和最后位置版 3 题使用闭区间 `[left, right]`，长度要加 `1`。209 求最短合法窗口，应在收缩前更新答案；3 题求最长合法窗口，应在排除重复后更新答案。

最重要的是保持三者一致：

1. `left`、`right` 所表示的区间；
2. `window` 中实际保存的元素；
3. 计算窗口长度所使用的公式。

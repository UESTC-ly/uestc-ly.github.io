## 909. 蛇梯棋

[力扣原题](https://leetcode.cn/problems/snakes-and-ladders/)

### 简短题意

从棋盘编号 1 出发，每步可前进 1..6 格，落点若有蛇或梯子就传送一次。编号从左下角开始，每行方向交替。返回到 n² 的最少步数，不可达返回 -1；一次掷骰不能连续触发多次传送。

### 思路解析

把方格编号作为状态，每次掷骰作为一条等权边，BFS 首次到达终点就是最短步数。编号减 1 后，fromBottom=(id-1)/n，列为余数，奇数层从右向左；行坐标为 n-1-fromBottom。检查一次传送，再对传送后的真正落点判重。

### C++ 主模板

```cpp
class Solution {
    // 骰子和一次传送组成一步；队列记录最终落点。
public:
    int snakesAndLadders(vector<vector<int>>& board) {
        int n = board.size(), end = n * n;
        vector<int> distance(end + 1, -1);
        queue<int> q; q.push(1); distance[1] = 0;
        while (!q.empty()) {
            int current = q.front(); q.pop();
            if (current == end) return distance[current];
            for (int next = current + 1; next <= min(current + 6, end); next++) {
                int layer = (next - 1) / n, col = (next - 1) % n;
                int row = n - 1 - layer;
                if (layer % 2 == 1) col = n - 1 - col;
                int target = board[row][col] == -1 ? next : board[row][col];
                if (distance[target] == -1) {
                    distance[target] = distance[current] + 1;
                    q.push(target);
                }
            }
        }
        return -1;
    }
};
```

### 示例与复杂度

[[-1,4],[-1,3]]：从 1 落到 2 后只跳到 3，不再自动跳 4；也可以直接掷骰到 4，因此答案为 1。

时间 O(n²)，额外空间 O(n²)。

### 易错点与一类题总结

转换坐标按距底部的层数决定方向；不要递归追踪多条蛇梯；距离标记最终落点，入队即标记以阻止循环。

规则游戏的最少操作数：把局面或位置作为状态，每次合法操作生成等权邻居，再 BFS。

## 433. 最小基因变化

[力扣原题](https://leetcode.cn/problems/minimum-genetic-mutation/)

### 简短题意

基因串长度为 8，每位为 A、C、G、T。一次变化只改一个字符，变化后必须在 bank 中。返回 startGene 到 endGene 的最少变化次数，不能到达则返回 -1；起点不必在 bank。

### 思路解析

BFS 分层，每层代表多一次变化。对当前串逐位置枚举四种字符，仅将 bank 中尚未访问的候选入队；入队后从可用集合删除，防止重复搜索。

### C++ 主模板

```cpp
class Solution {
public:
    int minMutation(string startGene, string endGene, vector<string>& bank) {
        if (startGene == endGene) return 0;
        unordered_set<string> available(bank.begin(), bank.end());
        if (!available.count(endGene)) return -1;
        available.erase(startGene);
        queue<string> q; q.push(startGene);
        int steps = 0;
        while (!q.empty()) {
            int size = q.size();
            for (int k = 0; k < size; k++) {
                string current = q.front(); q.pop();
                if (current == endGene) return steps;
                for (int i = 0; i < 8; i++) {
                    char old = current[i];
                    for (char c : string("ACGT")) {
                        current[i] = c;
                        if (available.erase(current)) q.push(current);
                    }
                    current[i] = old; // 为下一个修改位置恢复原串
                }
            }
            steps++;
        }
        return -1;
    }
};
```

### 示例与复杂度

AACCGGTT→AACCGGTA→AAACGGTA，两次变化；两个中间/终点串均须在基因库中。

长度固定为 8，平均时间与空间均 O(B)，B 为 bank 大小；推广到长度 L、字符集 Σ 时，邻居生成和哈希的时间 O(BΣL²)。

### 易错点与一类题总结

每次枚举完一个位置必须恢复 old，否则一次可能改多个字符；返回变化次数而不是序列中的字符串个数。

有限候选集合上的单字符转换，枚举局部修改并在集合中验证邻居。

## 127. 单词接龙

[力扣原题](https://leetcode.cn/problems/word-ladder/)

### 简短题意

从 beginWord 到 endWord，每一步只改变一个字母，变化后的词必须在 wordList 中。返回最短转换序列中的单词个数，包含起点和终点；无解返回 0。

### 思路解析

BFS 每层增加一个单词。逐位置尝试 26 个小写字母，候选在字典中才入队，入队后移出可用集合。初始长度为 1，因此和最小基因变化的“操作次数”相差一。

### C++ 主模板

```cpp
class Solution {
    // BFS 层数从 1 开始，因为返回单词个数而非变化次数。
public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string> available(wordList.begin(), wordList.end());
        if (!available.count(endWord)) return 0;
        available.erase(beginWord);
        queue<string> q; q.push(beginWord);
        int length = 1;
        while (!q.empty()) {
            int size = q.size();
            for (int k = 0; k < size; k++) {
                string current = q.front(); q.pop();
                if (current == endWord) return length;
                for (int i = 0; i < static_cast<int>(current.size()); i++) {
                    char old = current[i];
                    for (char c = 'a'; c <= 'z'; c++) {
                        current[i] = c;
                        if (available.erase(current)) q.push(current);
                    }
                    current[i] = old;
                }
            }
            length++;
        }
        return 0;
    }
};
```

### 示例与复杂度

hit→hot→dot→dog→cog，字典含所需词时答案为 5；不含 cog 时直接返回 0。

单词长度 L、字典大小 W，计入字符串哈希和复制，平均时间 O(26WL²)，额外空间 O(WL)。

### 易错点与一类题总结

beginWord 不必在字典，endWord 必须在；不同路径会到同一个词，入队立即标记。主模板为单向 BFS，双向搜索可作为后续优化。

最短词转换的关键是明确返回“节点数还是边数”，再使用相同的 BFS 邻居生成模板。

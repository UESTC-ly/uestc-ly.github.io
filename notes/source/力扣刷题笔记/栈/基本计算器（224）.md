## 224. 基本计算器

[力扣原题](https://leetcode.cn/problems/basic-calculator/)

### 简短题意

给定合法算术表达式 s，包含整数、加减号、括号和空格，返回计算结果。支持一元负号，例如 -(2+3)，不能调用 eval 一类表达式求值函数。

### 思路解析

result 表示当前括号层已结算结果，sign 表示下一个数或括号块的正负。遇到左括号，把外层 result、sign 压栈并重置；遇到右括号，把当前层结果当成一个整体，按外层符号加回外层结果。数字连续读取，空格直接跳过。

### C++ 主模板

```cpp
class Solution {
public:
    int calculate(string s) {
        stack<pair<long long, int>> outer;
        long long result = 0;
        int sign = 1;
        for (int i = 0; i < static_cast<int>(s.size()); i++) {
            char c = s[i];
            if (c >= '0' && c <= '9') {
                long long number = 0;
                while (i < static_cast<int>(s.size()) && s[i] >= '0' && s[i] <= '9') {
                    number = number * 10 + s[i] - '0'; i++;
                }
                i--; // 外层循环还会递增一次
                result += sign * number;
            } else if (c == '+') sign = 1;
            else if (c == '-') sign = -1;
            else if (c == '(') {
                outer.push({result, sign});
                result = 0; sign = 1;
            } else if (c == ')') {
                auto [previous, multiplier] = outer.top(); outer.pop();
                result = previous + multiplier * result;
            }
        }
        return static_cast<int>(result);
    }
};
```

### 示例与复杂度

1-(2-3)：外层保存 (1,-1)，内层算出 -1，返回外层 1+(-1)×(-1)=2。

时间 O(n)，额外空间 O(d)，d 为括号嵌套深度，最坏 O(n)。

### 易错点与一类题总结

一元负号设 sign=-1 后等待数字或括号块，不能假定负号前都有数字；数值使用 long long 避免中间拼接边界风险。此模板只处理题目规定的加减法。

括号表达式可以将每层看作独立计算器，用栈保存外层上下文，右括号返回一个整体结果。

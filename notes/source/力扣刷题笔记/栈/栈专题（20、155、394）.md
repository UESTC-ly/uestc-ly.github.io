# 栈专题：括号匹配、最小栈与字符串解码

> 本笔记整理自本次会话中讨论的 LeetCode 20、155、394。统一主题：利用栈的“后进先出（LIFO）”特性处理匹配、嵌套和历史状态恢复。
>
> 相关笔记：[单调栈专题：每日温度与柱状图最大矩形](./单调栈专题（739、84）.md)

## 一、栈的核心特点

栈只能在同一端进行操作：

- `push`：元素入栈；
- `pop`：删除栈顶元素；
- `top`：查看栈顶元素；
- 特点：**后进先出**。

当题目具有下面的特征时，可以优先考虑栈：

- 括号、符号需要成对匹配；
- 结构存在嵌套，需要先处理内层再返回外层；
- 需要保存“进入当前层之前”的历史状态；
- 需要维护栈顶或辅助信息。

# 二、20. 有效的括号

## 1. 题意

给定只包含 `(`、`)`、`[`、`]`、`{`、`}` 的字符串，判断括号是否有效。

有效字符串需要满足：

1. 左括号必须由相同类型的右括号闭合；
2. 左括号必须按照正确顺序闭合；
3. 每个右括号都必须有对应的左括号。

例如：

```text
"()"       -> true
"()[]{}"   -> true
"(]"       -> false
"([)]"      -> false
"{[]}"      -> true
```

## 2. 核心思路

- 遇到左括号：压入栈；
- 遇到右括号：检查它是否匹配栈顶左括号，匹配后弹出；
- 如果遇到右括号时栈为空，说明没有左括号可以匹配；
- 遍历结束后，栈必须为空，否则说明还有未闭合的左括号。

括号的匹配顺序是“最后打开的括号最先关闭”，正好符合栈的后进先出特性。

## 3. C++ 代码

```cpp
#include <stack>
#include <string>
using namespace std;

class Solution {
public:
    bool isValid(string s) {
        // st 保存当前还没有匹配的左括号。
        stack<char> st;

        // 依次检查字符串中的每个括号。
        for (char c : s) {
            // 左括号先入栈，等待后面的右括号进行匹配。
            if (c == '(' || c == '[' || c == '{') {
                st.push(c);
            } else {
                // 右括号出现时，如果栈为空，说明没有对应的左括号。
                if (st.empty()) {
                    return false;
                }

                // 当前右括号必须与栈顶左括号属于同一种类型。
                if ((c == ')' && st.top() != '(') ||
                    (c == ']' && st.top() != '[') ||
                    (c == '}' && st.top() != '{')) {
                    return false;
                }

                // 匹配成功，删除已经完成匹配的左括号。
                st.pop();
            }
        }

        // 栈为空表示每个左括号都成功匹配了右括号。
        return st.empty();
    }
};
```

## 4. 复杂度

- 时间复杂度：`O(n)`，每个括号最多入栈和出栈一次；
- 空间复杂度：`O(n)`，最坏情况下所有字符都是左括号。

## 5. 方法归纳

> **左括号入栈；右括号检查栈顶并弹出；最后栈必须为空。**

# 三、155. 最小栈

## 1. 题意

设计一个支持以下操作的栈，并且每个操作都要在 `O(1)` 时间内完成：

```cpp
MinStack()          // 初始化
push(val)           // 入栈
pop()               // 删除栈顶元素
top()               // 获取栈顶元素
getMin()            // 获取当前栈中的最小元素
```

难点是：普通栈可以在 `O(1)` 时间内完成 `push`、`pop`、`top`，但不能直接在 `O(1)` 时间内找到整个栈的最小值。

## 2. 核心思路：数据栈 + 最小值栈

使用两个栈：

- `dataStack`：保存真正入栈的所有元素；
- `minStack`：保存每一层对应的当前最小值。

每次压入 `value` 时：

```text
minStack.push(min(value, minStack.top()))
```

因此，`minStack.top()` 始终就是当前数据栈中的最小值。

例如依次压入 `-2、0、-3`：

```text
dataStack: [-2, 0, -3]
minStack : [-2, -2, -3]
```

弹出 `-3` 后：

```text
dataStack: [-2, 0]
minStack : [-2, -2]
```

最小值自动恢复为 `-2`。

### 为什么只用一个变量记录最小值不够？

依次入栈 `3、5、2`，当前最小值是 2；弹出 2 后应恢复为 3。只保存当前最小值就丢失了旧状态，重新扫描又需要 O(n)。因此每一层都保存对应的最小值，即使它没变化也要入栈；两个栈始终等高，同步弹出即可恢复上一层状态。

本实现的 `pop`、`top`、`getMin` 按非空栈上的合法调用处理。

### 为什么重复的最小值也要保存？

例如：

```text
push(2), push(1), push(1)
```

最小值栈应为：

```text
[2, 1, 1]
```

两个 `1` 都要保存。弹出一个 `1` 后，另一个 `1` 仍然是最小值。

## 3. 变量含义

| 变量 | 含义 |
|---|---|
| `dataStack` | 保存所有真实数据的普通栈 |
| `minStack` | 保存每一层的历史最小值 |
| `value` | 即将入栈的新元素 |
| `currentMinimum` | 入栈后当前栈中的最小值 |

## 4. C++ 代码

```cpp
#include <algorithm>
#include <stack>
using namespace std;

class MinStack {
private:
    // 保存真正入栈的元素，用于实现普通栈的功能。
    stack<int> dataStack;

    // minStack[i] 表示 dataStack 当前对应层及以前元素的最小值。
    stack<int> minStack;

public:
    MinStack() {
        // 两个栈默认初始化为空。
    }

    void push(int value) {
        // 先把新元素放入数据栈。
        dataStack.push(value);

        // 计算加入 value 后的当前最小值，并同步放入最小值栈。
        if (minStack.empty()) {
            // 第一个元素同时就是当前最小值。
            minStack.push(value);
        } else {
            // 当前最小值是 value 和之前最小值中的较小者。
            int currentMinimum = min(value, minStack.top());
            minStack.push(currentMinimum);
        }
    }

    void pop() {
        // 两个栈必须同步弹出同一层状态。
        dataStack.pop();
        minStack.pop();
    }

    int top() {
        // 数据栈栈顶就是当前栈顶元素。
        return dataStack.top();
    }

    int getMin() {
        // 最小值栈栈顶保存当前所有元素中的最小值。
        return minStack.top();
    }
};
```

## 5. 复杂度

- `push`：`O(1)`；
- `pop`：`O(1)`；
- `top`：`O(1)`；
- `getMin`：`O(1)`；
- 空间复杂度：`O(n)`。

## 6. 方法归纳

> **普通结构负责原始数据，辅助结构负责维护额外信息；入栈、出栈时两个结构同步变化。**

# 四、394. 字符串解码

## 1. 题意

编码规则为：

```text
k[encoded_string]
```

表示方括号中的字符串重复 `k` 次。

例如：

```text
3[a]          -> "aaa"
2[bc]         -> "bcbc"
3[a]2[bc]     -> "aaabcbc"
3[a2[c]]      -> "accaccacc"
2[abc]3[cd]ef -> "abcabccdcdcdef"
```

题目保证输入格式合法，数字只表示重复次数，并且可能出现多位数字和嵌套括号。

## 2. 核心思路：保存每一层的上下文

遇到嵌套时，内层处理必须先于外层完成。例如：

```text
3[a2[c]]
```

处理内层 `2[c]` 时，外层已经有：

```text
外层字符串："a"
外层次数：2
```

进入 `[` 时，把外层状态压入栈；遇到 `]` 时，取出外层状态，把当前层结果重复后拼回外层。

栈中每个元素保存：

```cpp
{进入当前 '[' 之前的字符串, 当前 '[' 对应的重复次数}
```

## 3. 变量含义

| 变量 | 含义 |
|---|---|
| `st` | 保存各层外部上下文的栈 |
| `currentString` | 当前括号层已经解码出的字符串 |
| `repeatCount` | 当前正在读取的重复次数 |
| `character` | 当前遍历到的字符 |
| `previousString` | 进入当前括号前外层已有的字符串 |
| `times` | 当前括号内容需要重复的次数 |
| `repeatedString` | 当前层字符串重复后的结果 |

## 4. 四种字符处理规则

1. 数字：更新重复次数，支持多位数字；
2. `[`：保存 `{currentString, repeatCount}`，然后清空当前层状态；
3. 普通字母：加入 `currentString`；
4. `]`：弹出外层状态，重复当前字符串，再拼回外层。

多位数字的计算方式：

```cpp
repeatCount = repeatCount * 10 + (character - '0');
```

## 5. C++ 代码

```cpp
#include <stack>
#include <string>
#include <utility>
using namespace std;

class Solution {
public:
    string decodeString(string s) {
        /*
            st 中每个元素保存一层外部状态：

            first  ：进入当前 '[' 前，外层已经拼好的字符串
            second ：当前 '[' 对应的重复次数
        */
        stack<pair<string, int>> st;

        // 当前这一层已经解码出的字符串。
        string currentString = "";

        // 当前正在读取的重复次数，例如 "12[a]" 最终得到 12。
        int repeatCount = 0;

        // 依次处理输入字符串中的每个字符。
        for (char character : s) {
            // 情况 1：数字，计算重复次数，支持多位数字。
            if (character >= '0' && character <= '9') {
                repeatCount = repeatCount * 10 + (character - '0');
            }

            // 情况 2：左括号，保存外层状态并进入新的一层。
            else if (character == '[') {
                st.push({currentString, repeatCount});

                // 新的一层从空字符串开始收集内容。
                currentString = "";
                repeatCount = 0;
            }

            // 情况 3：右括号，当前层处理结束。
            else if (character == ']') {
                // 取出进入当前 '[' 前保存的外层字符串和重复次数。
                string previousString = st.top().first;
                int times = st.top().second;
                st.pop();

                // 将当前层字符串重复 times 次。
                string repeatedString = "";
                for (int i = 0; i < times; i++) {
                    repeatedString += currentString;
                }

                /*
                    恢复外层时，顺序必须是：
                    外层已有字符串 + 当前层重复后的字符串。

                    例如："aaa" + "bcbc" = "aaabcbc"。
                */
                currentString = previousString + repeatedString;
            }

            // 情况 4：普通字母，直接加入当前层字符串。
            else {
                currentString += character;
            }
        }

        // 所有字符处理完成后，currentString 就是完整解码结果。
        return currentString;
    }
};
```

### 与两个栈写法的对应关系

本节用一个 `stack<pair<string, int>>` 将同一层的两个状态打包；本次讲解的两个栈写法与它等价，不需要重复整份题解：

```cpp
stack<int> countSt;
stack<string> strSt;
// 遇到 '['：
countSt.push(num);
strSt.push(cur);
num = 0;
cur = "";
// 遇到 ']'：弹出 countSt.top() 得到 times，构建 repeated 后：
cur = strSt.top() + repeated;
strSt.pop();
```

两个栈必须同步保存和恢复同一层。嵌套例子 `3[a2[c]]` 中，内层结束先得到 `"a" + "c" × 2 = "acc"`，外层结束再得到 `"" + "acc" × 3 = "accaccacc"`。

## 6. 示例 `"3[a]2[bc]"` 推演

初始：

```text
栈 = []
currentString = ""
repeatCount = 0
```

处理 `3[a]`：

1. 读到 `3`：`repeatCount = 3`；
2. 读到 `[`：保存 `{ "", 3 }`，清空当前层；
3. 读到 `a`：`currentString = "a"`；
4. 读到 `]`：`"a"` 重复 3 次，得到 `"aaa"`，拼回外层。

处理 `2[bc]`：

1. 读到 `2`：`repeatCount = 2`；
2. 读到 `[`：保存 `{ "aaa", 2 }`，清空当前层；
3. 读到 `b`、`c`：`currentString = "bc"`；
4. 读到 `]`：`"bc"` 重复 2 次得到 `"bcbc"`；
5. 拼回外层：`"aaa" + "bcbc" = "aaabcbc"`。

最终返回：

```text
"aaabcbc"
```

## 7. 常见错误

- 遇到 `]` 时拼接顺序写反：

  ```cpp
  // 错误：repeatedString + previousString
  // 正确：previousString + repeatedString
  ```

- 栈中只保存重复次数，没有保存外层字符串；
- 读取数字时只处理一位，无法处理 `12[a]`；
- 进入新括号后没有清空 `currentString` 和 `repeatCount`。
- 判断数字的函数应拼作 `isdigit`，不是 `isdigig`；也可使用主代码中的字符范围判断。参见 [C++ 数字字符判断](../基础与模板/C++基础.md#判断单个字符是否为数字isdigit)。

## 8. 复杂度

设输入长度为 `n`，最终解码结果长度为 `L`：

- 时间复杂度：这份逐层展开并复制字符串的实现，保守上界为 `O(n(L + 1))`。扫描输入是 O(n)，但嵌套展开、保存外层前缀和拼接会重复复制已有字符，不能直接认定总时间为 O(n + L)。例如 `1[1[...1[a]...]]` 会在每层复制结果；不断拼接 `1[a]1[a]...` 也会重复复制越来越长的外层前缀。
- 空间复杂度：`O(n + L)`，栈保存嵌套状态，字符串保存解码结果。

# 五、栈专题统一归纳

| 题目 | 栈中保存的内容 | 核心用途 |
|---|---|---|
| 20. 有效的括号 | 未匹配的左括号 | 匹配嵌套括号 |
| 155. 最小栈 | 数据栈 + 每层最小值栈 | `O(1)` 获取最小值 |
| 394. 字符串解码 | 外层字符串 + 重复次数 | 保存和恢复嵌套上下文 |

共同思想：

> **栈不是只用来存数据，也可以保存“之后还要恢复的状态”。处理完当前层后，再从栈中恢复上一层。**

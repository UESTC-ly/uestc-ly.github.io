## 125. 验证回文串

[力扣原题](https://leetcode.cn/problems/valid-palindrome/)

### 简短题意

给定字符串 s，只保留字母和数字并忽略字母大小写，判断剩余字符是否正反读相同。过滤后为空也算回文。

### 思路解析

左右指针向中间移动，各自跳过非字母数字，再比较小写形式。比较的始终是两侧下一个有效字符，所以无需创建过滤字符串。

### C++ 主模板

```cpp
class Solution {
    // 两端跳过无效字符，比较时忽略大小写。
public:
    bool isPalindrome(string s) {
        int left = 0, right = static_cast<int>(s.size()) - 1;
        while (left < right) {
            while (left < right && !isalnum(static_cast<unsigned char>(s[left]))) left++;
            while (left < right && !isalnum(static_cast<unsigned char>(s[right]))) right--;
            if (tolower(static_cast<unsigned char>(s[left])) != tolower(static_cast<unsigned char>(s[right]))) return false;
            left++; right--;
        }
        return true;
    }
};
```

### 示例与复杂度

"A man, a plan, a canal: Panama" 过滤后是 amanaplanacanalpanama，返回 true。

时间 O(n)，额外空间 O(1)。

### 易错点与一类题总结

数字不能跳过；<cctype> 的分类函数参数转 unsigned char 可避免有符号 char 带来的未定义行为。

检查对称性质可用两端指针；过滤规则在移动指针时执行，比较规则只负责有效字符。

## 392. 判断子序列

[力扣原题](https://leetcode.cn/problems/is-subsequence/)

### 简短题意

给定字符串 s、t，判断能否从 t 中删除若干字符得到 s。删除后相对顺序保持不变，字符不必连续；空串是任意字符串的子序列。

### 思路解析

i 指向 s 下一个待匹配字符，扫描 t 时只有字符相等才前进 i。尽量选最早可用位置，给后续字符留下最长后缀；若最早位置都无法完成，选择更晚位置也不会改善。

### C++ 主模板

```cpp
class Solution {
    // 只在匹配到目标字符时，推进目标串指针。
public:
    bool isSubsequence(string s, string t) {
        int i = 0;
        for (char c : t) {
            if (i < static_cast<int>(s.size()) && s[i] == c) i++;
        }
        return i == static_cast<int>(s.size());
    }
};
```

### 示例与复杂度

s="abc"，t="ahbgdc"：依次匹配 a、b、c，返回 true；s="axc" 则返回 false。

时间 O(|t|)，额外空间 O(1)。

### 易错点与一类题总结

子序列不要求连续；i 可能已经等于 s.size()，读取 s[i] 前要检查范围。

保持相对顺序的匹配问题，使用“源串不断扫描，目标串按需前进”的双指针模板。

## 167. 两数之和II-输入有序数组

[力扣原题](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/)

### 简短题意

给定非递减数组 numbers 和目标 target，找到两个不同元素之和等于 target，返回从 1 开始的两个下标。题目保证唯一解，要求常数额外空间。

### 思路解析

左右指针夹逼。和太小时，右侧已经是最大可用值，固定左端也无法得到更大和，因此排除左端；和太大时对称排除右端。有序性保证每次排除不会漏解。

### C++ 主模板

```cpp
class Solution {
    // 和小则移动左端，和大则移动右端，依赖输入有序。
public:
    vector<int> twoSum(vector<int>& numbers, int target) {
        int left = 0, right = static_cast<int>(numbers.size()) - 1;
        while (left < right) {
            int sum = numbers[left] + numbers[right];
            if (sum == target) return {left + 1, right + 1};
            if (sum < target) left++;
            else right--;
        }
        return {};
    }
};
```

### 示例与复杂度

[2,7,11,15]，target=9：两端和 17 太大，右端左移直到和为 9，返回 [1,2]。

时间 O(n)，额外空间 O(1)。

### 易错点与一类题总结

返回下标加 1；left<right 保证不重复使用同一元素；无序数组不能直接套用这个排除依据。

有序数组的两端组合若随端点移动具有单调变化，可根据目标大小排除一端。

## 11. 盛最多水的容器

### 简短题意

给定非负整数数组 `height`，其中 `height[i]` 表示横坐标为 `i` 的竖线高度。选择两条竖线，与横轴组成容器，返回最多能装的水量；容器不能倾斜，宽度为两条线的下标差。

- 题型：双指针
- 核心：面积 = 宽度 × 短板高度
- 做法：左右夹逼，每次移动短板那一边
- 原因：宽度一定变小，只能尝试让短板变高
- 口诀：**面积看短板，谁短动谁**

### 为什么移动短板

容器由两根柱子组成，面积为 `min(height[left], height[right]) * (right - left)`，中间柱子不影响容量。

假设左柱更矮。如果保留左柱、只把右柱向左移动，宽度减小，而新高度最多仍是左柱高度，所以面积不可能超过当前面积。因此，以当前左柱为边界的其他组合都可以排除，下一步移动左指针。右柱更矮时同理；两边一样高时，移动任意一边都可以。

这说明每次丢弃的边界都不会让我们遗漏更优答案，而不仅仅是“希望找到更高的柱子”。

### C++ 主模板

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int left = 0;
        int right = static_cast<int>(height.size()) - 1;
        int ans = 0;

        while (left < right) {
            int width = right - left;
            int area = width * min(height[left], height[right]);
            ans = max(ans, area); // 先计算当前两根柱子的面积

            if (height[left] <= height[right]) {
                left++;          // 保留高柱，排除当前短柱
            } else {
                right--;
            }
        }
        return ans;
    }
};
```

### 示例、复杂度与易错点

`[1,8,6,2,5,4,8,3,7]`：初始下标 `0、8`，面积为 `1 × 8 = 8`，左边更矮，移动左指针；来到下标 `1、8`，面积为 `7 × 7 = 49`。继续按短板移动，最终最大面积为 `49`。

- 每一步移动一个指针，时间 `O(n)`，额外空间 `O(1)`。
- 宽度是 `right - left`，不是 `right - left + 1`。
- 先记录当前面积，再移动指针；答案取所有候选中的最大值。
- 移动高柱不能让保留的短板变高，因此不能用它作为排除边界的依据。
- 两根柱子时只计算一次；柱高全为零时答案为零。题目数值范围内，面积可用 `int` 保存。

### 一类题总结

识别信号：从数组中选两个位置，结果同时受距离和两端数值影响。先让左右指针覆盖最大范围，再证明某一端在当前状态下不可能参与更优组合，排除该端。双指针的关键是**移动依据能排除候选**，不能只凭直觉套用“谁小动谁”。

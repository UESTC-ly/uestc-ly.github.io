# 有序数组原地去重：最多保留一次与两次（26、80）

> 本笔记整理本次会话新增内容：有序数组原地去重、双指针循环逻辑、返回长度与数组前缀结果的关系，以及 LeetCode 26 和 80 的 C++ 实现。

## 一、共同前提：只关注数组前缀

这两道题都要求：

- 数组已经有序；
- 原地修改输入数组；
- 不使用额外数组，额外空间复杂度为 `O(1)`；
- 返回去重后的有效长度 `k`；
- 修改后的 `nums[0 ... k - 1]` 必须是正确答案；
- `nums[k]` 之后的内容不需要处理。

函数参数通常写成：

```cpp
int removeDuplicates(vector<int>& nums)
```

其中 `vector<int>& nums` 的 `&` 表示引用传递。函数内部直接修改的是调用者原来的数组，而不是数组副本。因此返回值负责告诉评测程序有效结果有多长，数组前 `k` 个位置负责保存具体结果。

例如返回 `5`，评测程序只检查：

```text
nums[0], nums[1], nums[2], nums[3], nums[4]
```

不要求把后面的元素清空。

# 二、26. 删除有序数组中的重复项：每个元素最多一次

## 1. 题意

给定一个非严格递增数组，也就是满足：

```text
nums[i] <= nums[i + 1]
```

原地删除重复元素，使每个元素只出现一次，并返回去重后的长度。

例如：

```text
输入：[0, 0, 1, 1, 2]
处理后：[0, 1, 2, ...]
返回：3
```

因为数组有序，所以相同元素一定连续出现。

## 2. 双指针含义

采用“`slow` 指向最后一个有效元素”的写法：

- `fast`：从左到右扫描数组，寻找新的元素；
- `slow`：指向当前不重复结果区域的最后一个元素；
- `nums[0 ... slow]`：已经处理好的不重复结果。

第一个元素一定保留，所以：

```cpp
int slow = 0;
```

`fast` 从 `1` 开始扫描。

## 3. 循环核心逻辑

```cpp
if (nums[fast] != nums[slow]) {
    slow++;
    nums[slow] = nums[fast];
}
```

解释：

1. 当前元素和结果区域最后一个元素相同：当前元素重复，跳过；
2. 当前元素和结果区域最后一个元素不同：发现新元素；
3. 先让 `slow` 向后移动到下一个写入位置；
4. 把新元素写入 `nums[slow]`。

循环结束时，`slow` 是最后一个有效元素的下标，而题目要求的是元素数量，所以返回：

```cpp
slow + 1
```

这是容易出错的地方：下标从 `0` 开始，数量等于最后下标加 `1`。

## 4. C++代码

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        if (nums.empty()) {
            return 0;
        }

        int slow = 0;

        // fast 扫描每个候选元素，nums[0] 已经默认保留。
        for (int fast = 1; fast < nums.size(); fast++) {
            // 当前元素与结果区域最后一个元素不同，说明它是新元素。
            if (nums[fast] != nums[slow]) {
                ++slow;
                nums[slow] = nums[fast];
            }
        }

        // slow 是最后一个有效元素的下标，长度应为 slow + 1。
        return slow + 1;
    }
};
```

## 5. 示例推演

```text
nums = [0, 0, 1, 1, 2]
```

- 初始 `slow = 0`，有效区域为 `[0]`；
- `fast = 1`：当前值 `0` 等于 `nums[slow]`，跳过；
- `fast = 2`：当前值 `1` 不等于 `0`，写入 `nums[1]`，`slow = 1`；
- `fast = 3`：当前值 `1` 等于结果区域最后一个值，跳过；
- `fast = 4`：当前值 `2` 不同，写入 `nums[2]`，`slow = 2`。

最终有效前缀为：

```text
[0, 1, 2]
```

返回：

```text
slow + 1 = 3
```

# 三、80. 删除有序数组中的重复项 II：每个元素最多两次

## 1. 题意

给定一个有序数组，原地删除重复元素，使每个元素最多出现两次，并返回修改后的有效长度。

例如：

```text
输入：[1, 1, 1, 2, 2, 3]
处理后：[1, 1, 2, 2, 3, ...]
返回：5
```

与第 26 题的区别是：

| 题目 | 每个元素最多保留 |
|---|---:|
| 26 | 1 次 |
| 80 | 2 次 |

## 2. 双指针定义

采用“`slow` 指向下一个写入位置”的写法：

- `fast`：扫描当前候选元素；
- `slow`：下一个合法元素应该写入的位置；
- `nums[0 ... slow - 1]`：已经处理好的结果区域，每个元素最多出现两次。

前两个元素无论是否相同，都可以保留，所以：

```cpp
int slow = 2;
```

从下标 `2` 开始判断后面的元素。

## 3. 循环核心逻辑

```cpp
for (int fast = 2; fast < n; fast++) {
    if (nums[fast] != nums[slow - 2]) {
        nums[slow] = nums[fast];
        ++slow;
    }
}
```

关键判断是：

```cpp
nums[fast] != nums[slow - 2]
```

为什么看 `slow - 2`？

因为 `nums[slow - 2]` 是当前结果区域的倒数第二个元素：

```text
结果区域：[ ... , 倒数第二个元素, 最后一个元素]
                         ↑
                    slow - 2
```

如果当前元素等于结果区域倒数第二个元素，说明结果区域末尾已经有两个相同元素。再保留当前元素，就会出现三次，因此跳过。

如果当前元素不等于倒数第二个元素，说明当前元素加入后不会使它出现超过两次，可以写入结果区域。

## 4. C++代码

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int n = nums.size();

        // 长度不超过 2 时，所有元素都可以保留。
        if (n <= 2) {
            return n;
        }

        // 前两个元素一定保留，slow 是下一个写入位置。
        int slow = 2;

        // fast 从第三个元素开始扫描。
        for (int fast = 2; fast < n; fast++) {
            /*
             * 如果当前元素等于结果区域倒数第二个元素，
             * 说明相同元素已经保留了两个，当前元素应跳过。
             */
            if (nums[fast] != nums[slow - 2]) {
                // 当前元素合法，写入结果区域的下一个位置。
                nums[slow] = nums[fast];
                ++slow;
            }
        }

        // slow 表示有效结果的长度。
        return slow;
    }
};
```

## 5. 重点示例：`[1, 1, 1, 2, 2, 3]`

初始保留前两个元素：

```text
结果区域：[1, 1]
slow = 2
```

### `fast = 2`

```text
当前元素：nums[2] = 1
比较元素：nums[slow - 2] = nums[0] = 1
```

两者相同，说明已经有两个 `1`，跳过当前 `1`。

```text
结果区域：[1, 1]
slow = 2
```

### `fast = 3`

```text
当前元素：2
比较元素：nums[0] = 1
```

不同，保留：

```text
nums[2] = 2
slow = 3
结果区域：[1, 1, 2]
```

### `fast = 4`

```text
当前元素：2
比较元素：nums[1] = 1
```

不同，保留：

```text
nums[3] = 2
slow = 4
结果区域：[1, 1, 2, 2]
```

### `fast = 5`

```text
当前元素：3
比较元素：nums[2] = 2
```

不同，保留：

```text
nums[4] = 3
slow = 5
结果区域：[1, 1, 2, 2, 3]
```

循环结束，返回 `5`。

## 6. 为什么不能比较 `nums[slow - 1]`？

如果比较最后一个有效元素：

```cpp
nums[fast] != nums[slow - 1]
```

那么遇到第二个相同元素时也会被跳过，结果就变成“每个元素最多保留一次”，退化成第 26 题的逻辑。

本题需要允许第二个相同元素通过，所以必须往前看两个位置，即比较：

```cpp
nums[slow - 2]
```

## 7. 循环不变式

每次循环开始时，始终保证：

```text
nums[0 ... slow - 1]
```

是目前已经处理好的合法结果，并且每个元素最多出现两次。

处理 `nums[fast]` 时只有两种情况：

- `nums[fast] == nums[slow - 2]`：保留后会出现第三次，跳过；
- `nums[fast] != nums[slow - 2]`：可以保留，写入 `nums[slow]`，然后 `slow++`。

因此循环结束后，前 `slow` 个元素就是正确答案。

# 四、通用规律：每个元素最多保留 `limit` 次

对于有序数组，如果要求每个元素最多保留 `limit` 次，可以使用同一个模板：

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        const int limit = 2;
        int slow = 0;

        for (int fast = 0; fast < nums.size(); fast++) {
            /*
             * 结果区域还没有达到 limit 个元素时，当前元素直接保留；
             * 否则比较当前元素和结果区域倒数第 limit 个元素。
             */
            if (slow < limit || nums[fast] != nums[slow - limit]) {
                nums[slow] = nums[fast];
                ++slow;
            }
        }

        return slow;
    }
};
```

当 `limit = 1` 时，判断变为：

```cpp
slow < 1 || nums[fast] != nums[slow - 1]
```

表示每个元素最多保留一次，对应第 26 题。

当 `limit = 2` 时，判断变为：

```cpp
slow < 2 || nums[fast] != nums[slow - 2]
```

表示每个元素最多保留两次，对应第 80 题。

记忆方式：

> **最多保留几次，就和结果区域倒数第几位比较。**

# 五、两道题的写法对照

| 内容 | 第 26 题 | 第 80 题 |
|---|---|---|
| 每个元素最多出现 | 1 次 | 2 次 |
| `slow` 初始含义 | 最后一个有效元素下标 | 下一个写入位置 |
| 扫描起点 | `fast = 1` | `fast = 2` |
| 判断依据 | `nums[fast] != nums[slow]` | `nums[fast] != nums[slow - 2]` |
| 返回值 | `slow + 1` | `slow` |

注意：两题的 `slow` 定义可以采用不同写法，但必须始终明确它表示“最后一个有效下标”还是“下一个写入位置”，不能混用。

# 六、复杂度与方法归纳

- 时间复杂度：`O(n)`；
- 额外空间复杂度：`O(1)`；
- 不需要额外数组，也不需要清理有效长度之后的元素。

## 一句话记忆

> **快指针扫描，慢指针写入；有序数组允许每个元素保留 `limit` 次时，当前元素要和结果区域倒数第 `limit` 个元素比较。**

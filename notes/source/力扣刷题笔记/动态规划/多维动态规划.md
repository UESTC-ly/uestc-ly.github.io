## 零、多维 DP 通用思路

二维 DP 的核心不是“必须有二维数组”，而是：**一个状态需要用两个维度描述**。

常见的两个维度有：

| 题目类型 | `dp` 的两个维度含义 |
|---|---|
| 网格题 | 行号、列号 |
| 单个字符串区间题 | 左端点、右端点 |
| 两个字符串题 | 两个字符串各自取了多少个字符 |

### 1. 写状态：先说清 `dp[i][j]` 是什么

做题前先用一句完整的话定义状态。例如：

```text
dp[i][j]：从起点走到网格 (i, j) 的最小路径和。

dp[i][j]：子串 s[i...j] 是否为回文串。

dp[i][j]：word1 的前 i 个字符变成 word2 的前 j 个字符的最少操作数。
```

> `dp` 的含义一旦不清楚，转移方程、初始化和返回值都容易写错。

### 2. 找“当前状态从哪里来”

不同题型的依赖方向不同：

- **网格 DP**：当前位置通常来自上方和左方；
- **回文区间 DP**：当前区间通常依赖去掉两端后的中间区间；
- **双字符串 DP**：当前状态通常依赖上方、左方、左上方。

### 3. 依赖关系决定遍历顺序

原则只有一句：

> 计算 `dp[i][j]` 前，它依赖的状态必须已经算好。

| 题型 | 典型依赖 | 合适的遍历顺序 |
|---|---|---|
| 网格 DP | 上方、左方 | 从上到下、从左到右 |
| 回文区间 DP | `dp[i + 1][j - 1]` | 按区间长度从小到大，或左端点从后往前 |
| 双字符串 DP | 上、左、左上 | 两层循环都从小到大 |

### 4. 初始化要单独看边界

边界上的状态往往不能直接套普通转移：

- 网格第一行只能从左边到达，第一列只能从上方到达；
- 空字符串与另一个字符串的关系需要单独定义；
- 单字符子串一定是回文串。

### 5. 通用解题步骤

```text
1. 明确 dp[i][j] 的含义
2. 写出当前状态依赖哪些旧状态
3. 处理第一行、第一列、空串或长度为 1 等边界
4. 根据依赖关系确定遍历顺序
5. 确定最终答案在哪个 dp 状态中
```

### 6. 常见易错点

1. `i`、`j` 表示“前几个字符”时，访问字符要写 `s[i - 1]`，而不是 `s[i]`。
2. 网格题中，`m` 是行数、`n` 是列数：第一行遍历 `j < n`，第一列遍历 `i < m`。
3. 遇到空字符串时，DP 数组通常要开成 `(m + 1) × (n + 1)`。
4. 不要只背遍历方向；要看当前状态依赖谁。
5. `min({a, b, c})` 中的 `{}` 是初始化列表，表示从三个数里取最小值。

## 一、62. 不同路径

### 1. 题目概述

机器人位于 `m × n` 网格左上角，每次只能向右或向下移动一步，求走到右下角的不同路径数。

### 2. 状态定义

```cpp
dp[i][j]
```

表示从左上角 `(0, 0)` 到格子 `(i, j)` 的不同路径数量。

### 3. 状态转移

到达 `(i, j)` 的最后一步只有两种来源：

- 上方 `(i - 1, j)` 向下走；
- 左方 `(i, j - 1)` 向右走。

所以：

```cpp
dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
```

> 当前路径数 = 上方路径数 + 左方路径数。

### 4. 初始化与遍历

第一行只能一直向右走，第一列只能一直向下走，因此都只有一种走法：

```cpp
dp[0][j] = 1;
dp[i][0] = 1;
```

当前状态依赖上方和左方，所以从上到下、从左到右遍历。

### 5. C++ 代码

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> dp(m, vector<int>(n, 1));

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }

        return dp[m - 1][n - 1];
    }
};
```

### 6. 示例

当 `m = 3, n = 3`：

```text
1  1  1
1  2  3
1  3  6
```

右下角为 `6`，即共有 `6` 条路径。

### 7. 复杂度

- 时间复杂度：`O(mn)`
- 空间复杂度：`O(mn)`

## 二、64. 最小路径和

### 1. 题目概述

给定一个非负整数网格 `grid`，从左上角走到右下角，每次只能向右或向下，求路径数字和的最小值。

### 2. 与“不同路径”的联系

移动规则完全相同，区别在于：

- 不同路径：把上方和左方的方案数相加；
- 最小路径和：从上方和左方中选择较小路径和，再加当前格子的值。

### 3. 状态定义

```cpp
dp[i][j]
```

表示从左上角走到 `(i, j)` 的最小路径和。

### 4. 状态转移

```cpp
dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j];
```

> 当前最小路径和 = `min(上方, 左方) + 当前格子的值`。

### 5. 初始化

```cpp
dp[0][0] = grid[0][0];
```

第一行只能从左边到达：

```cpp
for (int j = 1; j < n; j++) {
    dp[0][j] = dp[0][j - 1] + grid[0][j];
}
```

第一列只能从上方到达：

```cpp
for (int i = 1; i < m; i++) {
    dp[i][0] = dp[i - 1][0] + grid[i][0];
}
```

### 6. C++ 代码

```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size();
        int n = grid[0].size();

        vector<vector<int>> dp(m, vector<int>(n, 0));
        dp[0][0] = grid[0][0];

        // 第一行：只能从左边到达
        for (int j = 1; j < n; j++) {
            dp[0][j] = dp[0][j - 1] + grid[0][j];
        }

        // 第一列：只能从上方到达
        for (int i = 1; i < m; i++) {
            dp[i][0] = dp[i - 1][0] + grid[i][0];
        }

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1])
                           + grid[i][j];
            }
        }

        return dp[m - 1][n - 1];
    }
};
```

### 7. 示例

```text
grid =
1  3  1
1  5  1
4  2  1
```

对应的 `dp` 表：

```text
1  4  5
2  7  6
6  8  7
```

答案为 `7`，一条最优路径是：

```text
1 → 3 → 1 → 1 → 1
```

### 8. 易错点

- 第一行遍历列：`j < n`；第一列遍历行：`i < m`。
- 第一列累加的是 `grid[i][0]`，不是尚未计算的 `dp[i][0]`。

### 9. 复杂度

- 时间复杂度：`O(mn)`
- 空间复杂度：`O(mn)`

## 三、5. 最长回文子串

### 1. 题目概述

给定字符串 `s`，找出其中最长的回文**子串**。

回文串正读和反读相同，例如：

```text
"a"、"aba"、"abba"
```

注意：本题求的是子串，字符必须连续。

### 2. 状态定义

```cpp
dp[i][j]
```

表示子串 `s[i...j]` 是否为回文串：

- `true`：是回文串；
- `false`：不是回文串。

### 3. 回文判断

要判断 `s[i...j]` 是否回文：

1. 两端字符 `s[i]` 和 `s[j]` 必须相同；
2. 若子串长度大于 `3`，去掉两端后的 `s[i + 1...j - 1]` 也必须回文。

```cpp
if (s[i] == s[j] && (len <= 3 || dp[i + 1][j - 1])) {
    dp[i][j] = true;
}
```

其中 `len <= 3` 时，只要首尾相同就一定回文：

```text
长度 1："a"
长度 2："aa"
长度 3："aba"
```

### 4. 为什么按长度从小到大遍历？

`dp[i][j]` 依赖 `dp[i + 1][j - 1]`，而中间子串长度为 `len - 2`，更短。

因此先算短子串，再算长子串：

```cpp
for (int len = 1; len <= n; len++)
```

在这种写法中，左端点 `i` 从 `0` 开始是正确的，因为所依赖的更短子串已经在更早的长度轮次中算完。

### 5. C++ 代码

```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();
        if (n == 0) {
            return "";
        }

        // dp[i][j] 表示 s[i...j] 是否为回文串
        vector<vector<bool>> dp(n, vector<bool>(n, false));

        int start = 0;
        int maxLength = 1;

        // len 表示当前枚举的子串长度
        for (int len = 1; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;

                if (s[i] == s[j] &&
                    (len <= 3 || dp[i + 1][j - 1])) {
                    dp[i][j] = true;

                    if (len > maxLength) {
                        maxLength = len;
                        start = i;
                    }
                }
            }
        }

        return s.substr(start, maxLength);
    }
};
```

### 6. 示例

```text
s = "babad"
```

长度为 `3` 的回文子串有：

```text
"bab"
"aba"
```

二者都可以作为答案。

### 7. 复杂度

- 时间复杂度：`O(n²)`
- 空间复杂度：`O(n²)`

## 四、1143. 最长公共子序列

### 1. 题目概述

给定字符串 `text1` 和 `text2`，求它们的最长公共**子序列**长度。

子序列不要求连续，但必须保持原有相对顺序。例如：

```text
"ace" 是 "abcde" 的子序列
"aec" 不是 "abcde" 的子序列
```

### 2. 状态定义

```cpp
dp[i][j]
```

表示 `text1` 的前 `i` 个字符和 `text2` 的前 `j` 个字符的最长公共子序列长度。

`i`、`j` 表示字符数量，所以比较最后一个字符时使用：

```cpp
text1[i - 1]
text2[j - 1]
```

### 3. 状态转移

如果最后一个字符相同，说明它可以加入公共子序列：

```cpp
dp[i][j] = dp[i - 1][j - 1] + 1;
```

如果最后一个字符不同，则分别尝试舍弃其中一个字符串的最后一个字符：

```cpp
dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
```

口诀：

> 字符相同，左上加一；字符不同，上左取大。

### 4. 初始化

空字符串与任何字符串的最长公共子序列长度都是 `0`。

因此数组开为 `(m + 1) × (n + 1)`，并全部初始化为 `0`：

```cpp
vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
```

### 5. C++ 代码

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size();
        int n = text2.size();

        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1[i - 1] == text2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[m][n];
    }
};
```

### 6. 示例

```text
text1 = "abcde"
text2 = "ace"
```

最长公共子序列是 `"ace"`，长度为 `3`。

### 7. 复杂度

- 时间复杂度：`O(mn)`
- 空间复杂度：`O(mn)`

## 五、72. 编辑距离

### 1. 题目概述

给定字符串 `word1` 和 `word2`，求把 `word1` 转换成 `word2` 的最少操作数。允许：

- 插入一个字符；
- 删除一个字符；
- 替换一个字符。

### 2. 状态定义

```cpp
dp[i][j]
```

表示把 `word1` 的前 `i` 个字符转换成 `word2` 的前 `j` 个字符，所需的最少操作数。

最终答案是：

```cpp
dp[m][n]
```

### 3. 初始化

把 `word1` 前 `i` 个字符变成空字符串，只能删除 `i` 次：

```cpp
dp[i][0] = i;
```

把空字符串变成 `word2` 前 `j` 个字符，只能插入 `j` 次：

```cpp
dp[0][j] = j;
```

### 4. 状态转移

比较：

```cpp
word1[i - 1]
word2[j - 1]
```

如果字符相同，不需要操作：

```cpp
dp[i][j] = dp[i - 1][j - 1];
```

如果字符不同，有三种选择：

| 操作 | 变成的子问题 | 对应状态 |
|---|---|---|
| 删除 `word1` 的最后一个字符 | `word1` 前 `i - 1` 个变成 `word2` 前 `j` 个 | `dp[i - 1][j]` |
| 插入 `word2` 的最后一个字符 | `word1` 前 `i` 个变成 `word2` 前 `j - 1` 个 | `dp[i][j - 1]` |
| 替换 `word1` 的最后一个字符 | 两边都去掉最后一个字符 | `dp[i - 1][j - 1]` |

所以：

```cpp
dp[i][j] = min({
    dp[i - 1][j],
    dp[i][j - 1],
    dp[i - 1][j - 1]
}) + 1;
```

`min({ ... })` 的花括号表示初始化列表，可以让 `min` 同时比较三个数。

口诀：

> 字符相同看左上；字符不同三选一。  
> 删除看上方，插入看左方，替换看左上。

### 5. C++ 代码

```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        int m = word1.size();
        int n = word2.size();

        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1[i - 1] == word2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = min({
                        dp[i - 1][j],     // 删除
                        dp[i][j - 1],     // 插入
                        dp[i - 1][j - 1]  // 替换
                    }) + 1;
                }
            }
        }

        return dp[m][n];
    }
};
```

### 6. 示例

```text
word1 = "horse"
word2 = "ros"
```

一种最优转换过程：

```text
horse → rorse  （将 h 替换为 r）
rorse → rose   （删除 r）
rose  → ros    （删除 e）
```

最少操作数为 `3`。

### 7. 复杂度

- 时间复杂度：`O(mn)`
- 空间复杂度：`O(mn)`

---

## 总结：五题对比

| 题目 | 状态含义 | 核心转移 |
|---|---|---|
| 不同路径 | 到 `(i, j)` 的路径数 | 上 + 左 |
| 最小路径和 | 到 `(i, j)` 的最小和 | `min(上, 左) + 当前值` |
| 最长回文子串 | `s[i...j]` 是否回文 | 首尾相同且中间回文 |
| 最长公共子序列 | 两个前缀的最长公共子序列长度 | 相同左上 `+1`，不同取上左最大 |
| 编辑距离 | 一个前缀变成另一个前缀的最少操作数 | 相同看左上，不同取上左上最小 `+1` |

# 字符串双序列 DP：编辑距离与最长公共子串

> 来源：本次会话中的题目图片、状态定义讨论与 C++ 代码分析。仅整理本次新增内容。

## 一、编辑距离（Levenshtein Distance）

### 1. 题意

给定字符串 `s` 和 `t`，允许对字符串进行三种操作，每次操作代价为 `1`：

1. 插入一个字符；
2. 删除一个字符；
3. 将一个字符替换为另一个字符。

求把 `s` 变成 `t` 的最少操作次数。

例如：

```text
s = "abcdefg"
t = "abcdef"
```

删除 `s` 末尾的 `g` 即可，所以答案为 `1`。

### 2. 状态定义

```cpp
dp[i][j]
```

表示：把 `s` 的前 `i` 个字符变成 `t` 的前 `j` 个字符所需的最少操作次数。

这里的“前 `i` 个字符”不包含下标 `i`，因此实际对应：

```cpp
s[0 ... i - 1]
t[0 ... j - 1]
```

数组需要开成：

```cpp
vector<vector<int>> dp(sizeS + 1, vector<int>(sizeT + 1, 0));
```

多出的第 `0` 行和第 `0` 列用来表示空串状态。

### 3. 初始化

- `dp[i][0] = i`：`s` 的前 `i` 个字符变成空串，只能删除 `i` 次；
- `dp[0][j] = j`：空串变成 `t` 的前 `j` 个字符，只能插入 `j` 次。

### 4. 状态转移

比较当前两个字符：

```cpp
s[i - 1]
t[j - 1]
```

#### 当前字符相同

```cpp
if (s[i - 1] == t[j - 1]) {
    dp[i][j] = dp[i - 1][j - 1];
}
```

最后一个字符已经相同，不需要操作，只需解决前面的两个前缀。

#### 当前字符不同

有三种选择：

```cpp
dp[i][j] = min({
    dp[i][j - 1] + 1,      // 插入 t[j - 1]
    dp[i - 1][j] + 1,      // 删除 s[i - 1]
    dp[i - 1][j - 1] + 1   // 将 s[i - 1] 替换为 t[j - 1]
});
```

三种操作分别对应：

- **插入**：先把 `s` 前 `i` 个字符变成 `t` 前 `j - 1` 个字符，再插入 `t[j - 1]`；
- **删除**：先把 `s` 前 `i - 1` 个字符变成 `t` 前 `j` 个字符，再删除 `s[i - 1]`；
- **替换**：先解决两个前缀，再把最后一个字符替换掉。

### 5. C++ 代码

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string s, t;
    cin >> s >> t;

    int sizeS = static_cast<int>(s.size());
    int sizeT = static_cast<int>(t.size());

    // dp[i][j]：把 s 的前 i 个字符变成 t 的前 j 个字符的最少操作次数。
    vector<vector<int>> dp(sizeS + 1, vector<int>(sizeT + 1, 0));

    // s 的前 i 个字符变成空串：需要删除 i 次。
    for (int i = 0; i <= sizeS; ++i) {
        dp[i][0] = i;
    }

    // 空串变成 t 的前 j 个字符：需要插入 j 次。
    for (int j = 0; j <= sizeT; ++j) {
        dp[0][j] = j;
    }

    for (int i = 1; i <= sizeS; ++i) {
        for (int j = 1; j <= sizeT; ++j) {
            if (s[i - 1] == t[j - 1]) {
                // 最后一个字符相同，不需要额外操作。
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                // 插入、删除、替换三种操作取最小值。
                dp[i][j] = min({
                    dp[i][j - 1] + 1,      // 插入 t[j - 1]
                    dp[i - 1][j] + 1,      // 删除 s[i - 1]
                    dp[i - 1][j - 1] + 1   // 替换 s[i - 1]
                });
            }
        }
    }

    cout << dp[sizeS][sizeT] << '\n';
    return 0;
}
```

### 6. 复杂度

设 `n = s.size()`，`m = t.size()`：

- 时间复杂度：`O(nm)`；
- 空间复杂度：`O(nm)`。

题目中两个字符串长度最多为 `1000`，二维 DP 可以接受。

## 二、最长公共子串

### 1. 题意与关键区别

给定字符串 `s` 和 `t`，求它们的最长公共**子串**长度。

子串必须是原字符串中的一段**连续**字符。例如：

```text
s = "awaabb"
t = "aawbb"
```

`"aa"` 和 `"bb"` 都是公共子串，最长长度为 `2`。

不能因为字符都出现过，就把不连续的字符拼起来；那属于公共子序列的思路，而不是公共子串。

### 2. 直接按字符下标定义状态

可以直接定义：

```cpp
dp[i][j]
```

表示：以 `s[i]` 和 `t[j]` 作为结尾的最长公共子串长度。

这种定义是正确且直观的，数组大小为：

```cpp
vector<vector<int>> dp(sizeS, vector<int>(sizeT, 0));
```

### 3. 状态转移

#### 当前字符相同

```cpp
if (s[i] == t[j]) {
    dp[i][j] = dp[i - 1][j - 1] + 1;
}
```

当前两个字符相同，可以接在前一个位置结尾的公共子串后面。

当 `i == 0` 或 `j == 0` 时，没有左上角状态，当前两个相同字符本身构成长度 `1` 的公共子串：

```cpp
if (i == 0 || j == 0) {
    dp[i][j] = 1;
}
```

#### 当前字符不同

```cpp
s[i] != t[j]
```

由于子串必须连续，匹配被打断，必须重新开始：

```cpp
dp[i][j] = 0;
```

### 4. 为什么答案不是 `dp[sizeS - 1][sizeT - 1]`？

`dp[i][j]`只表示“以当前位置结尾”的结果，最长公共子串可能在任意位置结束。因此计算过程中要维护全局最大值：

```cpp
maxLen = max(maxLen, dp[i][j]);
```

### 5. C++ 代码

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string s, t;
    cin >> s >> t;

    int sizeS = static_cast<int>(s.size());
    int sizeT = static_cast<int>(t.size());

    // dp[i][j]：以 s[i] 和 t[j] 结尾的最长公共子串长度。
    vector<vector<int>> dp(sizeS, vector<int>(sizeT, 0));

    int maxLen = 0;

    for (int i = 0; i < sizeS; ++i) {
        for (int j = 0; j < sizeT; ++j) {
            // 必须比较两个不同字符串中的字符。
            if (s[i] == t[j]) {
                if (i == 0 || j == 0) {
                    // 当前字符本身构成长度为 1 的公共子串。
                    dp[i][j] = 1;
                } else {
                    // 接在左上角结尾的连续公共子串后面。
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                }
            } else {
                // 字符不同，连续性被打断，长度归零。
                dp[i][j] = 0;
            }

            // 最长公共子串可能在任意位置结束。
            maxLen = max(maxLen, dp[i][j]);
        }
    }

    cout << maxLen << '\n';
    return 0;
}
```

### 6. 本次代码中的关键错误

原代码曾写成：

```cpp
if (s[i] == s[j])
```

这里比较的是同一个字符串 `s` 的两个字符，不能判断 `s` 和 `t` 是否匹配。正确写法是：

```cpp
if (s[i] == t[j])
```

此外，当两个字符串长度不同时，`j` 可能超出 `s` 的下标范围，继续使用 `s[j]` 还可能造成越界。二维字符串 DP 中，要始终确认比较的是：

```text
s 的当前位置 与 t 的当前位置
```

### 7. 复杂度

设 `n = s.size()`，`m = t.size()`：

- 时间复杂度：`O(nm)`；
- 空间复杂度：`O(nm)`。

题目长度最多为 `150`，二维数组规模很小。

## 三、最长公共子串与最长公共子序列的区别

| 问题 | 是否要求连续 | 字符不同时的处理 | 答案位置 |
|---|---|---|---|
| 最长公共子串 | 必须连续 | `dp[i][j] = 0` | 所有状态中的最大值 |
| 最长公共子序列 | 不要求连续 | 通常取 `max(dp[i - 1][j], dp[i][j - 1])` | 通常看 `dp[n][m]` |

### 方法归纳

- **编辑距离**：两个前缀的最少修改次数；相同字符看左上角，不同字符在插入、删除、替换中取最小值。
- **最长公共子串**：两个字符串当前位置匹配时接左上角，不匹配就归零，并在所有状态中取最大值。

一句话记忆：

> **编辑距离关注“如何把两个前缀变相同”；最长公共子串关注“连续匹配能延伸多长”。**

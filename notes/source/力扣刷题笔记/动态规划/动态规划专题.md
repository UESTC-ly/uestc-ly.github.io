### 2. 动态规划是什么

动态规划适合解决这类问题：

> 大问题可以由更小的子问题推导出来，并且很多子问题会被反复使用。

我们使用 `dp` 数组保存已经算出的子问题答案，后面直接复用。

最重要的不是背公式，而是先用一句完整的话说清楚：

```text
dp[i] / dp[i][j] 到底表示什么？
```

本专题中的状态大致分为以下几类：

| 状态类型     | 例子                               |
| -------- | -------------------------------- |
| 方法数      | `dp[i]`：爬到第 `i` 阶的方法数            |
| 最小值      | `dp[i]`：凑出金额 `i` 的最少硬币数          |
| 最大值      | `dp[i]`：以 `nums[i]` 结尾的最长递增子序列长度 |
| 可行性      | `dp[i]`：能否凑出和 `i`                |
| 二维位置     | `dp[i][j]`：第 `i` 行第 `j` 列的值      |
| 同时维护两个状态 | 以当前位置结尾的最大乘积与最小乘积                |

## 二、动态规划通用解题步骤

### 1. 定义状态

必须先明确下标和状态含义，例如：

```text
dp[i]：凑出金额 i 的答案。
dp[i]：字符串前 i 个字符的答案。
dp[i]：以 nums[i] 结尾的答案。
```

“前 `i` 个元素”和“以第 `i` 个元素结尾”是两种不同的状态，不能混淆。

### 2. 找当前状态的来源或选择

常用提问：

```text
要得到 dp[i]，最后一步做了什么？
当前元素选还是不选？
当前值可以接在哪些旧状态后面？
```

例如打家劫舍中，第 `i` 间房只有两个选择：

```text
不偷：dp[i - 1]
偷：dp[i - 2] + nums[i]
```

### 3. 根据目标选择运算

| 目标 | 常见更新方式 |
|---|---|
| 求最大值 | `max(...)` |
| 求最小值 | `min(...)` |
| 求方案数 | 相加 `+` |
| 判断是否可行 | 逻辑或 `||` |

### 4. 初始化边界

常见初始化：

```cpp
dp[0] = 0;     // 凑出总和 0，数量为 0
dp[0] = true;  // 不选任何元素，可以凑出和 0
dp[i] = 1;     // 元素自己构成长度为 1 的序列
```

求最小值时，通常先初始化为一个不可能成为正确答案的大值：

```cpp
vector<int> dp(target + 1, target + 1);
```

### 5. 确定遍历顺序

唯一原则：

> 计算当前状态时，它依赖的旧状态必须已经计算完成。

背包问题尤其需要记住：

```text
0-1 背包：每个元素只能使用一次，容量倒序。
完全背包：每个元素可以重复使用，容量正序。
```

### 6. 确定答案位置

答案可能是：

```cpp
return dp[n];
return dp[n - 1];
return *max_element(dp.begin(), dp.end());
```

必须由状态定义决定，不能机械地返回最后一个状态。

<a id="templates"></a>
## 三、常用 DP 模板

### 1. 一维 DP：枚举当前状态的候选方案

```cpp
vector<int> dp(n + 1, 初始值);
dp[0] = 边界值;

for (int i = 1; i <= n; i++) {
    for (每一种合法选择) {
        dp[i] = min或max(dp[i], 新方案);
    }
}
```

### 2. 布尔 DP：判断是否可行

```cpp
vector<bool> dp(n + 1, false);
dp[0] = true;

for (...) {
    if (旧状态可行 && 当前条件满足) {
        dp[当前状态] = true;
    }
}
```

### 3. 完全背包模板

每个物品可以重复使用，容量从小到大：

```cpp
for (int item : items) {
    for (int capacity = item; capacity <= target; capacity++) {
        dp[capacity] = min(dp[capacity], dp[capacity - item] + 1);
    }
}
```

### 4. 0-1 背包模板

每个物品只能使用一次，容量从大到小：

```cpp
for (int item : items) {
    for (int capacity = target; capacity >= item; capacity--) {
        dp[capacity] = dp[capacity] || dp[capacity - item];
    }
}
```

### 5. 二维 / 逐行生成模板

```cpp
vector<vector<int>> ans;

for (int i = 0; i < 行数; i++) {
    vector<int> row(当前行长度, 初始值);

    for (int j = 中间位置起点; j < 中间位置终点; j++) {
        row[j] = ans[i - 1][j - 1] + ans[i - 1][j];
    }

    ans.push_back(row);
}
```

## 四、基础递推与二维生成

<a id="p70"></a>
### 4.1 70. 爬楼梯

#### 题意

每次可以爬 `1` 阶或 `2` 阶，求爬到第 `n` 阶有多少种方法。

#### 状态定义

```text
dp[i]：爬到第 i 阶的方法数。
```

#### 状态转移

到第 `i` 阶的最后一步只有两种情况：

- 从第 `i - 1` 阶爬 `1` 阶；
- 从第 `i - 2` 阶爬 `2` 阶。

所以：

```cpp
dp[i] = dp[i - 1] + dp[i - 2];
```

#### 初始化

```cpp
dp[1] = 1;
dp[2] = 2;
```

#### C++ 代码

```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n <= 2) return n;

        vector<int> dp(n + 1, 0);
        dp[1] = 1;
        dp[2] = 2;

        for (int i = 3; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }

        return dp[n];
    }
};
```

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

记忆：

> 到当前位置的方法数，等于所有可能前驱状态的方法数之和。

<a id="p118"></a>
### 4.2 118. 杨辉三角

#### 简短题意

给定正整数 `numRows`，返回杨辉三角的前 `numRows` 行，每行保存为一个数组。每行首尾都是 `1`，其余位置等于上一行左上方和右上方两个数之和。

#### 规律

第 `i` 行第 `j` 个数：

- 行首、行尾为 `1`；
- 中间位置等于上一行两个相邻数之和。

```cpp
ans[i][j] = ans[i - 1][j - 1] + ans[i - 1][j];
```

#### C++ 代码

```cpp
class Solution {
public:
    vector<vector<int>> generate(int numRows) {
        vector<vector<int>> ans;

        for (int i = 0; i < numRows; i++) {
            // 第 i 行有 i + 1 个元素，首尾默认是 1
            vector<int> row(i + 1, 1);

            // 只计算中间位置
            for (int j = 1; j < i; j++) {
                row[j] = ans[i - 1][j - 1] + ans[i - 1][j];
            }

            ans.push_back(row);
        }

        return ans;
    }
};
```

易错点：

- 第 `i` 行长度是 `i + 1`；
- 内层循环是 `j = 1` 到 `j < i`；
- 第 `0` 行没有中间位置，因此不会访问不存在的上一行。

- 时间复杂度：`O(numRows²)`
- 空间复杂度：`O(numRows²)`

<a id="p198"></a>
### 4.3 198. 打家劫舍

#### 简短题意

给定非负整数数组 `nums`，`nums[i]` 表示第 `i` 间房屋中的金额。不能偷相邻的两间房屋，求能偷到的最大总金额；允许跳过任意房屋。

#### 状态定义

```text
dp[i]：考虑下标 0 到 i 的房屋时，能偷到的最高金额。
```

#### 状态转移

对于第 `i` 间房：

```text
不偷第 i 间：dp[i - 1]
偷第 i 间：dp[i - 2] + nums[i]
```

因此：

```cpp
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i]);
```

#### C++ 代码

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];

        vector<int> dp(n, 0);
        dp[0] = nums[0];
        dp[1] = max(nums[0], nums[1]);

        for (int i = 2; i < n; i++) {
            dp[i] = max(dp[i - 1], dp[i - 2] + nums[i]);
        }

        return dp[n - 1];
    }
};
```

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

记忆：

> 当前元素受到相邻限制时，比较“选当前”和“不选当前”。

## 五、字符串与序列 DP

<a id="p139"></a>
### 5.1 139. 单词拆分

#### 题意

判断字符串 `s` 能否由字典中的一个或多个单词拼接出来。字典中的单词可以重复使用。

#### 状态定义

```text
dp[i]：字符串的前 i 个字符能否由字典单词拼出。
```

注意 `i` 表示字符数量：

```text
dp[0]：空字符串
dp[4]：前 4 个字符
dp[n]：整个字符串
```

#### 初始化

```cpp
dp[0] = true;
```

空字符串视为已经成功拆分，这样第一个单词才能从 `dp[0]` 开始转移。

#### 状态转移

判断前 `i` 个字符时，枚举最后一个单词的开始位置 `j`：

```text
s[0 ... j-1] | s[j ... i-1]
  已拆分前缀   最后一个单词
```

如果：

```cpp
dp[j] == true
```

并且：

```cpp
s.substr(j, i - j)
```

在字典中，那么：

```cpp
dp[i] = true;
```

这里必须是 `j < i`，而不是 `j <= i`。如果 `j == i`，截取到的是空字符串，并且会变成用 `dp[i]` 推导自己。

#### C++ 代码

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> dict(wordDict.begin(), wordDict.end());
        int n = s.size();

        vector<bool> dp(n + 1, false);
        dp[0] = true;

        for (int i = 1; i <= n; i++) {
            // j：最后一个单词的开始位置
            for (int j = 0; j < i; j++) {
                if (dp[j] && dict.count(s.substr(j, i - j))) {
                    dp[i] = true;
                    break;
                }
            }
        }

        return dp[n];
    }
};
```

两层循环可以翻译成：

> 依次判断每个前缀；对于当前前缀，枚举最后一个单词从哪里开始。

- `i`：当前判断的前缀长度；
- `j`：最后一个单词的开始位置；
- `dp[j]`：左边能否拆分；
- `s.substr(j, i - j)`：右边是否是一个字典单词。

复杂度：

- DP 枚举切割位置：`O(n²)`；
- C++ 的 `substr` 还会复制字符，严格最坏时间可能达到 `O(n³)`；
- 空间复杂度：`O(n + 字典大小)`。

### 5.2 300. 最长递增子序列

#### 题意

求最长严格递增子序列的长度。子序列可以不连续，但不能改变元素原来的顺序。

#### 状态定义

```text
dp[i]：以 nums[i] 结尾的最长严格递增子序列长度。
```

这里必须强调“以 `nums[i]` 结尾”，而不是“前 `i` 个元素的答案”。

#### 初始化

```cpp
vector<int> dp(n, 1);
```

每个元素自己都能构成长度为 `1` 的递增子序列。

#### 状态转移

计算 `dp[i]` 时，枚举前面的每个位置 `j`：

```cpp
if (nums[j] < nums[i]) {
    dp[i] = max(dp[i], dp[j] + 1);
}
```

含义是：如果 `nums[i]` 大于 `nums[j]`，就可以把 `nums[i]` 接到以 `nums[j]` 结尾的递增子序列后面。

#### C++ 代码

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;

        vector<int> dp(n, 1);
        int ans = 1;

        // dp[0] 已经初始化为 1，外层可以从 1 开始
        for (int i = 1; i < n; i++) {
            // 必须从 0 开始，检查 nums[i] 前面的所有元素
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }

            ans = max(ans, dp[i]);
        }

        return ans;
    }
};
```

为什么内层 `j` 不能从 `1` 开始？

> 因为这样会永远漏掉 `nums[0]`。例如 `[1, 2]` 中，计算 `2` 时必须检查 `1 < 2`。

为什么返回 `ans` 而不是 `dp[n - 1]`？

> 最长递增子序列不一定以最后一个元素结尾。例如 `[1,2,3,0]` 的答案是 `3`，但以最后一个 `0` 结尾的长度只有 `1`。

- 时间复杂度：`O(n²)`
- 空间复杂度：`O(n)`

<a id="p32"></a>
### 5.3 32. 最长有效括号

#### 题意

给定只包含 `(` 和 `)` 的字符串 `s`，求其中最长的、连续且括号格式正确的子串长度；不存在有效括号子串时返回 `0`。

#### 状态定义

```text
dp[i]：以 s[i] 结尾的最长有效括号子串长度。
```

因此：

- 如果 `s[i] == '('`，`dp[i] = 0`；
- 只有 `s[i] == ')'` 时才可能更新；
- 最终答案是所有 `dp[i]` 的最大值。

#### 情况一：结尾是 `...()`

如果：

```cpp
s[i - 1] == '('
```

那么当前的 `"()"` 贡献长度 `2`，并连接它前面的有效括号：

```cpp
dp[i] = 2 + (i >= 2 ? dp[i - 2] : 0);
```

#### 情况二：结尾是 `...))`

如果前一个字符也是右括号，先跳过以 `i - 1` 结尾的有效括号：

```cpp
int left = i - dp[i - 1] - 1;
```

`left` 是当前右括号可能匹配的左括号位置。

如果：

```cpp
left >= 0 && s[left] == '('
```

那么：

```cpp
dp[i] = dp[i - 1] + 2
      + (left >= 1 ? dp[left - 1] : 0);
```

三部分分别表示：

```text
以 i - 1 结尾的有效段
+ 当前新匹配的一对括号
+ left 前面连续的有效段
```

#### C++ 代码

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = s.size();

        // dp[i]：以 s[i] 结尾的最长有效括号子串长度
        vector<int> dp(n, 0);
        int ans = 0;

        // 要访问 s[i - 1]，所以从 1 开始
        for (int i = 1; i < n; i++) {
            if (s[i] != ')') continue;

            // 情况一：...()
            if (s[i - 1] == '(') {
                dp[i] = 2 + (i >= 2 ? dp[i - 2] : 0);
            }
            // 情况二：...))
            else {
                int left = i - dp[i - 1] - 1;

                if (left >= 0 && s[left] == '(') {
                    dp[i] = dp[i - 1] + 2
                          + (left >= 1 ? dp[left - 1] : 0);
                }
            }

            ans = max(ans, dp[i]);
        }

        return ans;
    }
};
```

关键理解：

```text
遇到 ()：直接加 2，再连接前面的有效段。
遇到 ))：跳过前面已有的有效段，寻找更前面的左括号。
```

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

<a id="complete-knapsack"></a>
## 六、完全背包：每个元素可以重复使用

完全背包的特点：

> 每种物品可以使用无限次。

一维 DP 中，容量通常从小到大遍历。这样本轮刚更新的状态可以继续被使用，从而实现重复选择当前物品。

<a id="p279"></a>
### 6.1 279. 完全平方数

#### 简短题意

给定正整数 `n`，返回和为 `n` 所需的最少完全平方数个数。完全平方数包括 `1、4、9、16…`，每个平方数可以重复使用，例如 `12 = 4 + 4 + 4`，答案为 `3`。

#### 状态定义

```text
dp[i]：凑出总和 i 所需的最少完全平方数数量。
```

#### 状态转移

如果最后选择平方数 `j * j`，前面需要先凑出：

```text
i - j * j
```

所以：

```cpp
dp[i] = min(dp[i], dp[i - j * j] + 1);
```

#### 初始化

```cpp
vector<int> dp(n + 1, n + 1);
dp[0] = 0;
```

`n + 1` 是一个足够大的暂定值。因为任何 `i` 最多都能由 `i` 个 `1` 凑出，正确答案不会超过 `n`。

#### C++ 代码

```cpp
class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n + 1, n + 1);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j * j <= i; j++) {
                dp[i] = min(dp[i], dp[i - j * j] + 1);
            }
        }

        return dp[n];
    }
};
```

这里的更新可以理解为：

```text
dp[i] = min(旧的当前最优值, 使用平方数 j*j 的新方案)
```

- 时间复杂度：`O(n√n)`
- 空间复杂度：`O(n)`

<a id="p322"></a>
### 6.2 322. 零钱兑换

#### 简短题意

给定正整数硬币面额数组 `coins` 和非负目标金额 `amount`，每种硬币可使用无限次。返回恰好凑出该金额所需的最少硬币数量；无法凑出时返回 `-1`，金额为 `0` 时返回 `0`。

#### 状态定义

```text
dp[j]：凑出金额 j 所需的最少硬币数量。
```

每种硬币可以使用无限次，因此属于完全背包。

#### 状态转移

当前硬币面额为 `coin`。如果选择一枚当前硬币，那么此前需要凑出：

```text
j - coin
```

因此：

```cpp
dp[j] = min(dp[j], dp[j - coin] + 1);
```

它比较的是：

```text
原来凑出 j 的最少硬币数
和
先凑出 j - coin，再加入一枚 coin
```

#### 为什么金额正序遍历

```cpp
for (int j = coin; j <= amount; j++)
```

例如当前硬币为 `2`：

```text
先更新 dp[2]
再用本轮更新后的 dp[2] 更新 dp[4]
```

这就允许使用两个面额为 `2` 的硬币。

#### C++ 代码

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        int INF = amount + 1;

        // dp[j]：凑出金额 j 所需的最少硬币数量
        vector<int> dp(amount + 1, INF);
        dp[0] = 0;

        for (int coin : coins) {
            // 正序：当前面额可以重复使用
            for (int j = coin; j <= amount; j++) {
                dp[j] = min(dp[j], dp[j - coin] + 1);
            }
        }

        return dp[amount] == INF ? -1 : dp[amount];
    }
};
```

为什么从 `j = coin` 开始？

- 金额小于 `coin` 时放不下当前硬币；
- 可以避免访问负下标 `dp[j - coin]`。

- 时间复杂度：`O(coins.size() × amount)`
- 空间复杂度：`O(amount)`

#### 279 与 322 的统一理解

| 题目 | 可以选择的物品 | 目标 |
|---|---|---|
| 279. 完全平方数 | `1、4、9、16……` | 凑出 `n` 的最少数量 |
| 322. 零钱兑换 | `coins` 中的面额 | 凑出 `amount` 的最少数量 |

核心转移完全相同：

```cpp
dp[j] = min(dp[j], dp[j - value] + 1);
```

## 七、0-1 背包：每个元素只能使用一次

<a id="p416"></a>
### 7.1 416. 分割等和子集

#### 简短题意

给定只包含正整数的非空数组 `nums`，判断能否将全部元素分成两个元素和相等的子集。每个元素必须且只能属于其中一个子集；子集不要求在原数组中连续。

#### 问题转换

设数组总和为 `sum`。

如果 `sum` 是奇数，不可能分成两个和相等的子集：

```cpp
if (sum % 2 != 0) return false;
```

如果 `sum` 是偶数，问题转换为：

> 能否从数组中选择一些元素，使它们的和恰好为 `sum / 2`？

令：

```cpp
target = sum / 2;
```

只要找到一个和为 `target` 的子集，剩余元素的和也一定是 `target`。

#### 状态定义

```text
dp[j]：能否从已经遍历的元素中选出一些数，使它们的和恰好为 j。
```

#### 初始化

```cpp
dp[0] = true;
```

不选择任何数字，可以凑出和 `0`。

#### 状态转移

当前数字为 `num`，凑出 `j` 有两种方法：

```text
不选 num：原来就能凑出 j，即 dp[j]
选择 num：原来能凑出 j - num，即 dp[j - num]
```

所以：

```cpp
dp[j] = dp[j] || dp[j - num];
```

`||` 是逻辑或：两种方案只要有一种可行，`dp[j]` 就是 `true`。

#### 为什么容量必须倒序

```cpp
for (int j = target; j >= num; j--)
```

倒序保证 `dp[j - num]` 是处理当前 `num` 之前的旧状态，使当前数组元素只使用一次。

如果正序更新，刚得到的 `dp[num]` 可能马上继续更新 `dp[2 * num]`，相当于同一个元素在一轮中被重复使用。

注意：如果数组中本来就有两个相同的数字，例如 `[5,5]`，它们是两个不同元素，仍然可以各使用一次。

#### C++ 代码

```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int sum = 0;

        for (int num : nums) {
            sum += num;
        }

        if (sum % 2 != 0) return false;

        int target = sum / 2;
        vector<bool> dp(target + 1, false);
        dp[0] = true;

        for (int num : nums) {
            // 倒序：保证当前数组元素只使用一次
            for (int j = target; j >= num; j--) {
                dp[j] = dp[j] || dp[j - num];
            }
        }

        return dp[target];
    }
};
```

这两层循环可以翻译成：

> 外层逐个考虑每个数字 `num`；内层倒序判断当前数字能否帮助我们凑出各个目标和 `j`。

- 时间复杂度：`O(n × target)`
- 空间复杂度：`O(target)`

## 八、特殊状态 DP

<a id="p152"></a>
### 8.1 152. 乘积最大子数组

#### 题意

找出乘积最大的非空连续子数组，并返回其乘积。

这里求的是子数组，因此元素必须连续。

#### 难点：负数会交换最大值和最小值

乘以负数后：

- 最大正数可能变成最小负数；
- 最小负数可能变成最大正数。

例如：

```text
-6 × -4 = 24
```

因此不能只保存最大乘积，还必须保存最小乘积。

#### 状态定义

```text
maxDp[i]：以 nums[i] 结尾的连续子数组的最大乘积。
minDp[i]：以 nums[i] 结尾的连续子数组的最小乘积。
```

#### 状态转移

以 `nums[i]` 结尾时有三种候选方案：

```text
1. 只选择 nums[i]，从当前位置重新开始
2. maxDp[i - 1] × nums[i]
3. minDp[i - 1] × nums[i]
```

所以：

```cpp
maxDp[i] = max({
    nums[i],
    maxDp[i - 1] * nums[i],
    minDp[i - 1] * nums[i]
});

minDp[i] = min({
    nums[i],
    maxDp[i - 1] * nums[i],
    minDp[i - 1] * nums[i]
});
```

把 `nums[i]` 自己放入候选方案，是为了允许从当前位置重新开始。遇到 `0` 时也能自然地重置状态。

#### C++ 代码

```cpp
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int n = nums.size();

        vector<int> maxDp(n, 0);
        vector<int> minDp(n, 0);

        maxDp[0] = nums[0];
        minDp[0] = nums[0];
        int ans = nums[0];

        for (int i = 1; i < n; i++) {
            maxDp[i] = max({
                nums[i],
                maxDp[i - 1] * nums[i],
                minDp[i - 1] * nums[i]
            });

            minDp[i] = min({
                nums[i],
                maxDp[i - 1] * nums[i],
                minDp[i - 1] * nums[i]
            });

            ans = max(ans, maxDp[i]);
        }

        return ans;
    }
};
```

为什么循环从 `1` 开始？

> 下标 `0` 的状态已经初始化；转移又要访问 `i - 1`，所以不能从 `0` 开始。

为什么返回 `ans` 而不是 `maxDp[n - 1]`？

> 最大乘积子数组不一定以最后一个元素结尾。例如 `[2,3,-2,4]` 的答案是 `[2,3]` 的乘积 `6`。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 3. `dp` 更新运算对比

```cpp
// 求方案数
 dp[i] = dp[i - 1] + dp[i - 2];

// 求最大值
 dp[i] = max(旧方案, 新方案);

// 求最小值
 dp[i] = min(旧方案, 新方案);

// 判断是否可行
 dp[i] = 旧方案 || 新方案;
```

### 4. 写代码前检查

```text
1. dp[i] / dp[i][j] 的完整含义是什么？
2. 它表示“前 i 个元素”，还是“以第 i 个元素结尾”？
3. 当前状态有哪些来源或选择？
4. 题目求最大值、最小值、方案数，还是可行性？
5. dp[0]、dp[1]、第一行、第一列如何初始化？
6. 当前状态依赖的旧状态是否已经计算？
7. 背包问题中，每个元素能使用一次还是无限次？
8. 容量应该倒序还是正序？
9. 最终返回 dp[n]、dp[n-1]，还是所有状态中的最大值？
10. 求最小值时，“无穷大”初始化是否会导致加法溢出？
```

### 5. 记忆口诀

> **先定义状态，再找最后一步；边界单独定，依赖决定顺序；最大用 `max`，最小用 `min`，计数通常相加，可行性使用逻辑或。**

背包问题再补一句：

> **只能一次就倒序，可以重复就正序。**

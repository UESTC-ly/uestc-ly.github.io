## 918. 环形子数组的最大和

[力扣原题](https://leetcode.cn/problems/maximum-sum-circular-subarray/)

### 简短题意

给定环形整数数组 nums，返回非空连续子数组的最大和。子数组可以跨数组末尾，但每个元素最多使用一次。

### 思路解析

答案分两种：不跨边界时是普通最大子数组和；跨边界时相当于总和减去中间被排除的最小子数组和。一次扫描同时算最大、最小 Kadane 状态及总和。全负数时最小段可能是整数组，补集为空不合法，必须直接返回普通最大和。

### C++ 主模板

```cpp
class Solution {
public:
    int maxSubarraySumCircular(vector<int>& nums) {
        int currentMax = nums[0], bestMax = nums[0];
        int currentMin = nums[0], bestMin = nums[0], total = nums[0];
        for (int i = 1; i < static_cast<int>(nums.size()); i++) {
            currentMax = max(nums[i], currentMax + nums[i]);
            bestMax = max(bestMax, currentMax);
            currentMin = min(nums[i], currentMin + nums[i]);
            bestMin = min(bestMin, currentMin);
            total += nums[i];
        }
        if (bestMax < 0) return bestMax; // 排除空补集
        return max(bestMax, total - bestMin);
    }
};
```

### 示例与复杂度

[5,-3,5]：总和 7，最小段 -3，跨边界和为 10；[-3,-2,-5] 必须返回 -2，而不是 0。

时间 O(n)，额外空间 O(1)。

### 易错点与一类题总结

所有状态从首元素初始化，保持非空；跨边界公式不能重复绕圈使用元素。

环形连续区间可分成“不跨边界”和“跨边界”，后一种常转化为整段减去中间补集。

## 120. 三角形最小路径和

[力扣原题](https://leetcode.cn/problems/triangle/)

### 简短题意

给定三角形 triangle，从顶层出发，每步到下一层同列或右下一列，返回到达底层的最小路径和。

### 思路解析

dp[r][c] 表示从当前位置到底层的最小和。最后一层直接等于该元素，向上转移为 triangle[r][c]+min(dp[r+1][c],dp[r+1][c+1])。保留完整二维表，方便看清状态和依赖方向。

### C++ 主模板

```cpp
class Solution {
    // 从底层反推，当前位置选择两条后续路径的较小值。
public:
    int minimumTotal(vector<vector<int>>& triangle) {
        vector<vector<int>> dp = triangle;
        for (int r = static_cast<int>(dp.size()) - 2; r >= 0; r--) {
            for (int c = 0; c <= r; c++) dp[r][c] += min(dp[r+1][c],dp[r+1][c+1]);
        }
        return dp[0][0];
    }
};
```

### 示例与复杂度

[[2],[3,4],[6,5,7],[4,1,8,3]]：最优路径 2→3→5→1，和为 11。

R 行包含 O(R²) 个元素，时间和额外空间均 O(R²)。进阶可压缩成一行 O(R) 空间，主模板保留二维表。

### 易错点与一类题总结

下一层位置是 c 或 c+1；从底向上才有已知子状态；负数也可以直接用相同转移。

选择路线的 DP 可从终点反推，把“当前位置最优结果”定义为当前代价加后继最优。

## 63. 不同路径II

[力扣原题](https://leetcode.cn/problems/unique-paths-ii/)

### 简短题意

给定障碍网格 obstacleGrid，1 表示不可经过的障碍，0 表示空格。机器人从左上角出发，只能向右或向下，返回到右下角的路径数。

### 思路解析

dp[r][c] 表示到当前格的路径数。障碍格保持 0，非障碍格由上方和左方方案相加。起点若为障碍，所有方案为 0；否则初始化为 1。

### C++ 主模板

```cpp
class Solution {
public:
    int uniquePathsWithObstacles(vector<vector<int>>& obstacleGrid) {
        int rows = obstacleGrid.size(), cols = obstacleGrid[0].size();
        vector<vector<long long>> dp(rows,vector<long long>(cols,0));
        if (obstacleGrid[0][0] == 1) return 0;
        dp[0][0] = 1;
        const long long limit = INT_MAX;
        for (int r = 0; r < rows; r++) for (int c = 0; c < cols; c++) {
            if (obstacleGrid[r][c] == 1 || (r == 0 && c == 0)) continue;
            long long ways = 0;
            if (r > 0) ways += dp[r-1][c];
            if (c > 0) ways += dp[r][c-1];
            dp[r][c] = min(limit,ways); // 与终点断开的区域可能有很大的计数
        }
        return static_cast<int>(dp.back().back());
    }
};
```

### 示例与复杂度

[[0,0,0],[0,1,0],[0,0,0]]：中央障碍为 0 条路径，沿上下两边各一条，答案为 2。

时间 O(mn)，额外空间 O(mn)。题目保证最终答案不超过 INT_MAX；饱和计数可避免无关区域中的中间溢出。

### 易错点与一类题总结

障碍不能按普通格累加；首行或首列遇到障碍后无法从同方向穿过。饱和到 INT_MAX 不影响结果：若一个超限格能到终点，其每条前缀都能延伸，最终也会超限，与题目保证矛盾。

网格计数 DP 加上状态合法性判断，非法格计数为 0；初始化应服从同一可达规则。

## 97. 交错字符串

[力扣原题](https://leetcode.cn/problems/interleaving-string/)

### 简短题意

给定字符串 s1、s2、s3，判断 s3 能否由 s1、s2 交错组成。每个源串中的字符相对顺序必须保留，且全部字符恰好使用一次。

### 思路解析

dp[i][j] 表示 s1 前 i 个字符与 s2 前 j 个字符能否组成 s3 前 i+j 个字符。最后一位若来自 s1，依赖 dp[i-1][j] 且 s1[i-1]=s3[i+j-1]；若来自 s2 则对称。两个来源满足任一个就可行。

### C++ 主模板

```cpp
class Solution {
    // 最后一字符来自哪个源串，就依赖对应的前缀状态。
public:
    bool isInterleave(string s1, string s2, string s3) {
        int m = s1.size(), n = s2.size();
        if (m + n != static_cast<int>(s3.size())) return false;
        vector<vector<bool>> dp(m+1,vector<bool>(n+1,false)); dp[0][0] = true;
        for (int i = 0; i <= m; i++) for (int j = 0; j <= n; j++) {
            if (i > 0 && s1[i-1] == s3[i+j-1]) dp[i][j] = dp[i][j] || dp[i-1][j];
            if (j > 0 && s2[j-1] == s3[i+j-1]) dp[i][j] = dp[i][j] || dp[i][j-1];
        }
        return dp[m][n];
    }
};
```

### 示例与复杂度

s1="aabcc"、s2="dbbca"、s3="aadbbcbcac" 返回 true；相同位置可能两种来源都能匹配，DP 同时保留可能性。

时间和额外空间 O((m+1)(n+1))。

### 易错点与一类题总结

长度和必须先相等；不能遇到相同字符就贪心固定来源；边界 i=0 或 j=0 只允许从另一个串取。

两个有序来源共同生成目标，使用双前缀状态，按目标最后一位的来源枚举转移。

## 221. 最大正方形

[力扣原题](https://leetcode.cn/problems/maximal-square/)

### 简短题意

给定字符矩阵 matrix，只含字符 0、1，返回全部由 1 组成的最大正方形面积。

### 思路解析

dp[r][c] 表示以该格为右下角的最大正方形边长。当前为 1 时，边长等于上、左、左上三处最小边长加一；任一方向不足都会限制新正方形。用多一行一列的零边界统一处理。

### C++ 主模板

```cpp
class Solution {
    // 当前为 1 时，由上、左、左上三个最小边长扩张。
public:
    int maximalSquare(vector<vector<char>>& matrix) {
        if (matrix.empty()) return 0;
        int rows = matrix.size(), cols = matrix[0].size(), best = 0;
        vector<vector<int>> dp(rows+1,vector<int>(cols+1,0));
        for (int r = 1; r <= rows; r++) for (int c = 1; c <= cols; c++) {
            if (matrix[r-1][c-1] == '1') {
                dp[r][c] = min({dp[r-1][c],dp[r][c-1],dp[r-1][c-1]}) + 1;
                best = max(best,dp[r][c]);
            }
        }
        return best * best;
    }
};
```

### 示例与复杂度

[[1,1],[1,1]] 的右下角边长为 min(1,1,1)+1=2，返回面积 4。矩阵代码中的元素是字符。

时间 O(mn)，额外空间 O(mn)。

### 易错点与一类题总结

返回面积，不是边长；检查字符 '1'，不能比较整数 1；三个相邻状态取 min 而不是 max。

二维形状 DP 先固定形状端点，寻找扩张一层所需的局部邻居条件。

# 背包专题：0/1 背包与完全背包

## 一、背包问题是什么

背包问题本质是：

> 从一堆物品中选一些，在容量限制下，达到某个目标。

经典模型：

```text
有 n 个物品，每个物品有：
- 重量 weight[i]
- 价值 value[i]

有一个容量为 bagSize 的背包。

问：在不超过容量的情况下，最多能装多少价值？
```

在 LeetCode 中，背包问题不一定真的出现“重量”和“价值”这两个词，常见变形是：

```text
能不能凑出某个和？
有多少种方式凑出某个和？
如何让两堆差值最小？
```

---

## 二、0/1 背包

### 1. 什么是 0/1 背包

0/1 背包的特点：

> 每个物品只能选一次，要么不选，要么选一次。

所以叫：

```text
0 = 不选
1 = 选一次
```

例如：

```text
nums = [1, 5, 11, 5]
```

每个位置上的数字只能使用一次。即使有两个 `5`，它们也是两个不同物品，每个都只能选 0 次或 1 次。

---

### 2. 二维 DP 写法：最容易理解

#### 状态定义

```cpp
dp[i][j]
```

表示：

> 从前 `i` 个物品中选择，背包容量为 `j` 时，能获得的最大价值。

#### 状态转移

对于第 `i` 个物品，有两种选择：

```text
不选当前物品
选当前物品
```

不选：

```cpp
dp[i][j] = dp[i - 1][j];
```

选，前提是容量够：

```cpp
dp[i][j] = dp[i - 1][j - weight[i - 1]] + value[i - 1];
```

所以：

```cpp
dp[i][j] = max(dp[i - 1][j],
               dp[i - 1][j - weight[i - 1]] + value[i - 1]);
```

#### 二维模板

```cpp
int knapsack01(vector<int>& weight, vector<int>& value, int bagSize) {
    int n = weight.size();
    vector<vector<int>> dp(n + 1, vector<int>(bagSize + 1, 0));

    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= bagSize; j++) {
            dp[i][j] = dp[i - 1][j];
            if (j >= weight[i - 1]) {
                dp[i][j] = max(dp[i][j],
                               dp[i - 1][j - weight[i - 1]] + value[i - 1]);
            }
        }
    }

    return dp[n][bagSize];
}
```

---

### 3. 一维 DP 优化：最常用

二维 DP 中，当前行只依赖上一行，所以可以压缩成一维。

#### 状态定义

```cpp
dp[j]
```

表示：

> 当前已经处理过的物品中，容量为 `j` 时的最大价值。

#### 状态转移

```cpp
dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
```

#### 为什么 0/1 背包必须倒序遍历容量

因为每个物品只能用一次。

```cpp
for (int j = bagSize; j >= weight[i]; j--)
```

如果正序遍历，当前物品可能会在同一轮被重复使用。

例如当前物品重量是 `5`：

```text
dp[5] 被当前 5 更新
dp[10] 又使用刚更新的 dp[5]
```

这样相当于同一个 `5` 用了两次，违反 0/1 背包规则。

#### 0/1 背包一维模板：最大价值

```cpp
int knapsack01(vector<int>& weight, vector<int>& value, int bagSize) {
    int n = weight.size();
    vector<int> dp(bagSize + 1, 0);

    for (int i = 0; i < n; i++) {
        for (int j = bagSize; j >= weight[i]; j--) {
            dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
        }
    }

    return dp[bagSize];
}
```

## 三、0/1 背包常见题型

### 类型 1：最大价值型

问题：

> 容量有限，每个物品只能选一次，问最大价值。

模板：

```cpp
vector<int> dp(bagSize + 1, 0);

for (int i = 0; i < n; i++) {
    for (int j = bagSize; j >= weight[i]; j--) {
        dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
```

---

### 类型 2：能否凑出 target

例如：LeetCode 416. 分割等和子集。

状态定义：

```cpp
dp[j]
```

表示：

> 能否从已经遍历过的数字中，选一些数凑出和 `j`。

初始化：

```cpp
dp[0] = true;
```

转移：

```cpp
dp[j] = dp[j] || dp[j - num];
```

模板：

```cpp
vector<bool> dp(target + 1, false);
dp[0] = true;

for (int num : nums) {
    for (int j = target; j >= num; j--) {
        dp[j] = dp[j] || dp[j - num];
    }
}

return dp[target];
```

---

### 类型 3：凑出 target 的方法数

状态定义：

```cpp
dp[j]
```

表示：

> 凑出和 `j` 的方法数。

初始化：

```cpp
dp[0] = 1;
```

转移：

```cpp
dp[j] += dp[j - num];
```

0/1 背包仍然倒序：

```cpp
vector<int> dp(target + 1, 0);
dp[0] = 1;

for (int num : nums) {
    for (int j = target; j >= num; j--) {
        dp[j] += dp[j - num];
    }
}
```

## 四、完全背包

### 1. 什么是完全背包

完全背包的特点：

> 每个物品可以选无限次。

例如：

```text
coins = [1, 2, 5]
amount = 11
```

每种硬币数量无限，可以反复使用。

这就是完全背包。

---

### 2. 完全背包和 0/1 背包的核心区别

```text
0/1 背包：每个物品只能用一次
完全背包：每个物品可以用无限次
```

所以一维 DP 时容量遍历方向不同。

```text
0/1 背包：倒序遍历容量
完全背包：正序遍历容量
```

---

### 3. 为什么完全背包要正序遍历容量

完全背包允许当前物品重复使用。

所以当处理当前物品 `num` 时，可以让较大的容量使用当前轮刚更新过的状态。

例如当前物品是 `5`：

```text
dp[5] 可以由 dp[0] + 5 得到
dp[10] 可以由当前轮刚更新的 dp[5] + 5 得到
```

这正好表示 `5` 可以使用两次。

因此完全背包正序：

```cpp
for (int j = num; j <= target; j++)
```

---

### 4. 完全背包模板：最大价值

```cpp
int completeKnapsack(vector<int>& weight, vector<int>& value, int bagSize) {
    int n = weight.size();
    vector<int> dp(bagSize + 1, 0);

    for (int i = 0; i < n; i++) {
        for (int j = weight[i]; j <= bagSize; j++) {
            dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
        }
    }

    return dp[bagSize];
}
```

## 五、完全背包常见题型

### 类型 1：最少物品数

例如：LeetCode 322. 零钱兑换。

问题：

> 每种硬币无限，凑出 `amount` 最少需要多少枚硬币？

状态定义：

```cpp
dp[j]
```

表示：

> 凑出金额 `j` 最少需要多少个硬币。

初始化：

```cpp
dp[0] = 0;
其他 dp[j] = INF;
```

转移：

```cpp
dp[j] = min(dp[j], dp[j - coin] + 1);
```

模板：

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        const int INF = amount + 1;
        vector<int> dp(amount + 1, INF);
        dp[0] = 0;

        for (int coin : coins) {
            for (int j = coin; j <= amount; j++) {
                dp[j] = min(dp[j], dp[j - coin] + 1);
            }
        }

        return dp[amount] == INF ? -1 : dp[amount];
    }
};
```

---

### 类型 2：组合数

例如：LeetCode 518. 零钱兑换 II。

问题：

> 每种硬币无限，凑出 `amount` 有多少种组合？

状态定义：

```cpp
dp[j]
```

表示：

> 凑出金额 `j` 的组合数。

初始化：

```cpp
dp[0] = 1;
```

转移：

```cpp
dp[j] += dp[j - coin];
```

组合数不考虑顺序，所以外层枚举物品，内层正序枚举容量：

```cpp
class Solution {
public:
    int change(int amount, vector<int>& coins) {
        vector<int> dp(amount + 1, 0);
        dp[0] = 1;

        for (int coin : coins) {
            for (int j = coin; j <= amount; j++) {
                dp[j] += dp[j - coin];
            }
        }

        return dp[amount];
    }
};
```

---

### 类型 3：排列数

例如：LeetCode 377. 组合总和 IV。

虽然题名叫组合，但它计算的是排列数，因为不同顺序算不同方案。

问题：

```text
nums = [1,2,3], target = 4
1+3 和 3+1 算两种
```

排列数通常：

> 外层枚举容量，内层枚举物品。

模板：

```cpp
vector<unsigned long long> dp(target + 1, 0);
dp[0] = 1;

for (int j = 1; j <= target; j++) {
    for (int num : nums) {
        if (j >= num) {
            dp[j] += dp[j - num];
        }
    }
}
```

## 六、0/1 背包 vs 完全背包：最重要区别

| 类型 | 每个物品使用次数 | 一维 DP 容量遍历方向 | 典型题 |
|---|---:|---|---|
| 0/1 背包 | 最多 1 次 | 倒序 | 416 分割等和子集、494 目标和、1049 最后一块石头 II |
| 完全背包 | 无限次 | 正序 | 322 零钱兑换、518 零钱兑换 II、377 组合总和 IV |

### 记忆重点

```text
0/1 背包：只能用一次，所以倒序，防止重复用当前物品。
完全背包：可以无限用，所以正序，允许重复用当前物品。
```

## 七、组合数和排列数的循环顺序

这个点在完全背包里特别容易错。

### 组合数：不考虑顺序

例如：

```text
1 + 2
2 + 1
```

算同一种。

循环顺序：

```cpp
for (int coin : coins) {
    for (int j = coin; j <= amount; j++) {
        dp[j] += dp[j - coin];
    }
}
```

典型题：LeetCode 518. 零钱兑换 II。

---

### 排列数：考虑顺序

例如：

```text
1 + 2
2 + 1
```

算两种。

循环顺序：

```cpp
for (int j = 1; j <= target; j++) {
    for (int num : nums) {
        if (j >= num) {
            dp[j] += dp[j - num];
        }
    }
}
```

典型题：LeetCode 377. 组合总和 IV。

## 八、背包题做题步骤

### 第一步：判断物品能用几次

```text
每个物品只能用一次 -> 0/1 背包 -> 容量倒序
每个物品可以无限用 -> 完全背包 -> 容量正序
```

### 第二步：判断 dp[j] 的含义

常见三种：

```text
最大价值：dp[j] = 容量 j 下的最大价值
能否凑出：dp[j] = 是否能凑出 j
方法数量：dp[j] = 凑出 j 的方法数
```

### 第三步：写初始化

```text
最大价值：dp 全部初始化为 0
能否凑出：dp[0] = true
方法数量：dp[0] = 1
最少数量：dp[0] = 0，其余初始化为 INF
```

### 第四步：确定遍历顺序

```text
0/1 背包：物品在外，容量倒序
完全背包组合数：物品在外，容量正序
完全背包排列数：容量在外，物品在内
```

## 十、一句话总结

> 背包问题先看“每个物品能用几次”，再看 `dp[j]` 表示什么。  
> 0/1 背包只能用一次，所以容量倒序；完全背包可以无限用，所以容量正序。  
> 求组合数通常物品在外，求排列数通常容量在外。

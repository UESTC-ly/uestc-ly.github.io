# HJ16：购物单（主件附件依赖背包）

> 题目来源：牛客 HJ16「购物单」  
> 相关专题：[动态规划专题](动态规划专题.md)

---

## 一、题意

给定预算 `n` 和 `m` 件商品。每件商品输入：

```text
v w q
```

- `v`：价格；
- `w`：重要度，范围为 `1 ~ 5`；
- `q`：主件编号。
  - `q = 0`：该商品是**主件**；
  - `q != 0`：该商品是**附件**，且属于编号为 `q` 的主件。

每件商品的满意度为：

\[
value = v \times w
\]

在总花费不超过预算的前提下，求最大总满意度。

### 购买规则

1. 主件可以单独购买；
2. 每个主件最多有两个附件；
3. 附件不能单独购买，购买附件时必须同时购买所属主件；
4. 每件商品最多买一次；
5. 所有价格都是 `10` 的倍数。

---

## 二、问题本质：有依赖关系的分组 0-1 背包

普通 0-1 背包中，每件物品互相独立，可以直接选择"买 / 不买"。

但这题的附件依赖主件。例如：

```text
主件 A
├── 附件 B
└── 附件 C
```

下面的选择不合法：

```text
只买 B
只买 C
买 B 和 C，但不买 A
```

因此，不能把主件和附件逐件直接放入普通背包。

正确做法是：

> 将"一个主件及其附件"看作一组，先列举这一组的所有合法购买方案；每组至多选择一种方案。

这就是**分组背包**。

---

## 三、一个主件有哪些合法方案？

设当前主件为 `main`，附件为 `a1`、`a2`。

### 1. 没有附件

```text
只买 main
```

### 2. 有一个附件

```text
只买 main
买 main + a1
```

### 3. 有两个附件

```text
只买 main
买 main + a1
买 main + a2
买 main + a1 + a2
```

注意：

- "什么都不买"不必显式加入方案；保留原来的 `dp` 值，就代表不买当前这一组。
- 绝对不能出现单独买附件的方案。

### 例子

```text
主件：价格 400，重要度 3  → 满意度 400 × 3 = 1200
附件1：价格 200，重要度 2 → 满意度 200 × 2 = 400
附件2：价格 300，重要度 5 → 满意度 300 × 5 = 1500
```

则方案为：

| 购买方案 | 总价格 | 总满意度 |
|---|---:|---:|
| 只买主件 | 400 | 1200 |
| 主件 + 附件1 | 600 | 1600 |
| 主件 + 附件2 | 700 | 2700 |
| 主件 + 附件1 + 附件2 | 900 | 3100 |

例如预算为 `700` 时，最优选择是"主件 + 附件2"，满意度为 `2700`。

## 四、数据组织：按主件编号收集附件

商品编号就是输入顺序，从 `1` 开始。

```cpp
struct Item {
    int cost;          // 价格
    int satisfaction;  // 价格 × 重要度
};

vector<Item> mainItems(m + 1);        // mainItems[i]：编号 i 的主件
vector<bool> isMain(m + 1, false);    // 标记编号 i 是否为主件
vector<vector<Item>> attachments(m + 1); // attachments[i]：主件 i 的附件
```

读取商品时：

```cpp
if (q == 0) {
    // 当前商品是主件
    mainItems[i] = item;
    isMain[i] = true;
} else {
    // 当前商品是主件 q 的附件
    attachments[q].push_back(item);
}
```

即使附件在输入中出现在主件之前，也没有问题：附件先按照主件编号存起来，全部读入后再统一处理各个主件。

### 为什么从 1 开始？

```cpp
for (int i = 1; i <= m; ++i)
```

因为：

- 题目规定商品编号从 1 开始；
- `i` 不只是循环变量，还直接表示商品编号；
- `q = 0` 是"当前商品是主件"的标记，不表示某个商品编号；
- 数组大小开 `m + 1`，让下标 `1 ~ m` 都合法，空出下标 `0`。

## 五、DP 状态定义

定义：

```cpp
dp[money]
```

表示：

> 处理完前面若干个主件后，在总花费**不超过** `money` 时能获得的最大满意度。

初始化：

```cpp
vector<int> dp(budget + 1, 0);
```

含义是：一个主件都不买时，不论预算是多少，满意度都是 `0`。

### 为什么数组大小是 `budget + 1`？

背包容量包括：

```text
容量 0, 容量 1, 容量 2, ..., 容量 budget
```

需要表示从 `0` 到 `budget` 的所有容量，因此数组大小应该是 `budget + 1`。

如果只开 `budget` 个元素，下标范围是 `0 ~ budget - 1`，无法访问 `dp[budget]`。

### `dp[0]` 表示什么？

```cpp
dp[0] = 0
```

表示预算为 0 时买不了任何商品，满意度为 0。这是动态规划的初始状态。

当选择一个价格为 `cost` 的组合时，可能会用到：

```cpp
dp[money - cost]
```

如果 `money == cost`，则 `money - cost == 0`，此时：

```cpp
dp[cost] = dp[0] + satisfaction
```

含义是：不使用之前的预算，直接购买当前组合。

## 六、状态转移详解

假设当前主件的一种合法组合为：

```text
组合价格 = cost
组合满意度 = satisfaction
```

当当前预算为 `money`，且 `money >= cost` 时：

```cpp
dp[money] = max(dp[money], dp[money - cost] + satisfaction);
```

### 两部分含义

**第一部分：`dp[money]`**

等号右边原来的 `dp[money]` 表示：

> 不购买当前主件，继续使用之前已经处理过的主件，得到原来的最大满意度。

例如之前主件得到的最大满意度是 `2500`，如果当前主件加入后没有更好的选择，就保持 `dp[1000] = 2500`。

**第二部分：`dp[money - cost] + satisfaction`**

可以拆开理解：

- `cost`：当前购买方案需要花费的钱；
- `money - cost`：买下当前方案后，还剩下多少预算可以用来购买之前的主件；
- `dp[money - cost]`：在剩余预算内，之前的主件最多能获得多少满意度；
- `satisfaction`：当前购买方案本身带来的满意度；
- 两部分相加：之前主件的最大满意度 + 当前购买方案的满意度。

**用具体数字演示**

假设之前处理过的主件，背包状态如下：

```text
dp[400] = 800
dp[1000] = 1500
```

当前主件有一个购买方案：

```text
方案价格 = 600
方案满意度 = 1600
```

现在计算：

```cpp
dp[1000] = max(
    1500,
    dp[400] + 1600
);

dp[1000] = max(1500, 800 + 1600);
dp[1000] = max(1500, 2400);
dp[1000] = 2400;
```

含义是：

```text
不买当前主件：满意度 1500
买当前方案：
    之前花费不超过 400 元的方案，满意度 800
    当前方案满意度 1600
    总满意度 = 2400
最终选择 2400
```

### 为什么预算要倒序？

```cpp
for (int money = budget; money >= 0; --money)
```

**倒序保证 `dp[money - cost]` 仍然是"处理当前主件之前"的结果**，因此当前主件最多选一次。

如果正序遍历，就可能在同一轮中重复使用当前主件，变成完全背包，不符合题意。

例如当前方案价格为 `400`，满意度为 `1000`：

- **正序**：`dp[400] = dp[0] + 1000 = 1000`，然后 `dp[800] = dp[400] + 1000 = 2000`，同一个主件被购买两次；
- **倒序**：先计算 `dp[800]`，此时 `dp[400]` 还未更新，不包含当前主件。

### 为什么同一组的多个方案不会同时被选？

处理预算 `money` 时，会枚举该主件组的不同方案：

```cpp
for (const auto& choice : choices) {
    dp[money] = max(dp[money], dp[money - cost] + satisfaction);
}
```

由于 `money - cost < money`，而预算是倒序遍历的，`dp[money - cost]` 在本轮还没有被当前组更新。因此，每次转移的基础都只来自**之前的主件组**，不会把当前主件的两个方案叠加起来。

内层循环只是让不同方案竞争：

```cpp
dp[money] = max(当前答案, 方案1结果);
dp[money] = max(当前答案, 方案2结果);
dp[money] = max(当前答案, 方案3结果);
dp[money] = max(当前答案, 方案4结果);
```

并不是把所有方案都购买。

### 为什么必须加 `if (money >= cost)` 判断？

如果当前预算不够购买某个方案：

```cpp
money < cost
```

表达式 `money - cost` 就会变成负数，导致数组越界。必须加上判断：

```cpp
if (money >= cost) {
    dp[money] = max(dp[money], dp[money - cost] + satisfaction);
}
```

## 七、价格为什么可以除以 10？

题目保证所有价格都是 `10` 的倍数，所以可做优化：

```cpp
cost = v / 10;
budget = n / 10;
```

例如：

```text
预算：1000 → 100
商品价格：400 → 40
```

这样不会改变可行方案，只会让 DP 数组从最大 `30001` 缩小到最大 `3001`。

注意：**只缩小价格和预算，满意度不能缩小。**

```cpp
item.cost = v / 10;
item.satisfaction = v * w;
```

## 八、C++ 参考代码

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

struct Item {
    int cost;          // 价格（可除以 10 优化）
    int satisfaction;  // 原价格 × 重要度
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    // 编号 i 对应的主件；只有 isMain[i] 为 true 时才有效。
    vector<Item> mainItems(m + 1);
    vector<bool> isMain(m + 1, false);

    // attachments[i] 保存主件 i 的附件，题目保证最多两个。
    vector<vector<Item>> attachments(m + 1);

    for (int i = 1; i <= m; ++i) {
        int v, w, q;
        cin >> v >> w >> q;

        Item item;
        item.cost = v;               // 可以除以 10 优化
        item.satisfaction = v * w;   // 满意度仍用原价计算

        if (q == 0) {
            mainItems[i] = item;
            isMain[i] = true;
        } else {
            attachments[q].push_back(item);
        }
    }

    int budget = n;
    vector<int> dp(budget + 1, 0);

    // 逐个处理每一组：一个主件及其附件。
    for (int i = 1; i <= m; ++i) {
        if (!isMain[i]) {
            continue;
        }

        Item mainItem = mainItems[i];

        // first：组合总价格；second：组合总满意度。
        vector<pair<int, int>> choices;

        // 方案 1：只买主件。
        choices.push_back({
            mainItem.cost,
            mainItem.satisfaction
        });

        if (attachments[i].size() >= 1) {
            Item attachment1 = attachments[i][0];

            // 方案 2：主件 + 附件 1。
            choices.push_back({
                mainItem.cost + attachment1.cost,
                mainItem.satisfaction + attachment1.satisfaction
            });
        }

        if (attachments[i].size() >= 2) {
            Item attachment1 = attachments[i][0];
            Item attachment2 = attachments[i][1];

            // 方案 3：主件 + 附件 2。
            choices.push_back({
                mainItem.cost + attachment2.cost,
                mainItem.satisfaction + attachment2.satisfaction
            });

            // 方案 4：主件 + 附件 1 + 附件 2。
            choices.push_back({
                mainItem.cost + attachment1.cost + attachment2.cost,
                mainItem.satisfaction
                    + attachment1.satisfaction
                    + attachment2.satisfaction
            });
        }

        // 0-1 背包：预算倒序，保证当前主件组至多选择一次方案。
        for (int money = budget; money >= 0; --money) {
            for (const auto& choice : choices) {
                int cost = choice.first;
                int satisfaction = choice.second;

                if (money >= cost) {
                    dp[money] = max(
                        dp[money],
                        dp[money - cost] + satisfaction
                    );
                }
            }
        }
    }

    cout << dp[budget] << '\n';
    return 0;
}
```

## 九、常见易错点

### 易错点 1：漏掉"主件 + 附件2"

有两个附件时，四种组合必须完整：

```cpp
main
main + fu1
main + fu2
main + fu1 + fu2
```

常见笔误是把 `main + fu1` 添加两次，从而漏掉 `main + fu2`。

正确写法：

```cpp
choices.push_back({
    mainItem.cost + attachment2.cost,
    mainItem.satisfaction + attachment2.satisfaction
});
```

### 易错点 2：不能在处理第一个主件后就输出

下面的写法会导致程序只处理第一个主件就结束：

```cpp
for (每个主件) {
    // 更新 dp
    cout << dp[budget] << '\n';
    return 0;
}
```

必须在所有主件处理完成后，再输出最终答案：

```cpp
for (每个主件) {
    // 更新 dp
}

cout << dp[budget] << '\n';
```

### 易错点 3：缺少 `money >= cost` 判断

如果不加判断，当 `money < cost` 时会访问负下标：

```cpp
dp[money - cost]  // money - cost < 0
```

必须写成：

```cpp
if (money >= cost) {
    dp[money] = max(dp[money], dp[money - cost] + satisfaction);
}
```

### 易错点 4：`ans` 未初始化

C++ 局部变量不初始化时值不确定：

错误：

```cpp
int ans;
for (int i = 0; i < n; i++) {
    ans = max(ans, left[i] + right[i]);
}
```

正确：

```cpp
int ans = 0;
```

## 十、复杂度

每个主件最多只有 4 种购买组合。

价格除以 `10` 后：

- 时间复杂度：\(O(m \times \frac{n}{10} \times 4)\)，通常记为 \(O(mn)\)；
- 空间复杂度：\(O(\frac{n}{10})\)。

题目中 `m ≤ 60`、`n ≤ 30000`，可以通过。

## 十一、方法归纳

遇到以下特征时，考虑"依赖背包 / 分组背包"：

```text
物品之间有从属关系
子物品不能独立选择
一个主体对应的子物品数量很少
每个主体的合法选择组合可以枚举
```

通用步骤：

```text
1. 按主体编号收集从属物品
2. 枚举每个主体的所有合法组合
3. 每个主体看作一个分组
4. 每组最多选择一个组合
5. 使用倒序 0-1 背包更新答案
```

一句话记忆：

> **附件不能单独购买，先把"主件 + 附件"枚举成合法组合，再按组做倒序 0-1 背包。**

## 123. 买卖股票的最佳时机III

[力扣原题](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iii/)

### 简短题意

给定每日股价 prices，最多完成两笔交易，任意时刻最多持有一股，求最大利润。每笔交易为先买后卖。

### 思路解析

用四个按“至多次数”定义的状态：buy1、sell1、buy2、sell2，分别表示第一次持股、第一次不持股、第二次持股、第二次不持股的最大收益。买入减价，卖出加价，每天保留旧状态或执行对应操作。用快照保证转移均来自前一天。初始两个持股状态为 -首日价，表示可以只用一笔交易；不持股初始为 0。

### C++ 主模板

```cpp
class Solution {
    // 四个收益状态从前一天快照转移，含义均为至多交易次数。
public:
    int maxProfit(vector<int>& prices) {
        if (prices.empty()) return 0;
        int buy1 = -prices[0], buy2 = -prices[0], sell1 = 0, sell2 = 0;
        for (int i = 1; i < static_cast<int>(prices.size()); i++) {
            int oldBuy1 = buy1, oldSell1 = sell1, oldBuy2 = buy2, oldSell2 = sell2;
            buy1 = max(oldBuy1,-prices[i]);
            sell1 = max(oldSell1,oldBuy1 + prices[i]);
            buy2 = max(oldBuy2,oldSell1 - prices[i]);
            sell2 = max(oldSell2,oldBuy2 + prices[i]);
        }
        return sell2;
    }
};
```

### 示例与复杂度

[3,3,5,0,0,3,1,4]：0 买 3 卖赚 3，1 买 4 卖再赚 3，总利润 6。

时间 O(n)，额外空间 O(1)，四个状态数量固定。

### 易错点与一类题总结

最多两笔而非恰好两笔，零利润和只做一笔都允许；持股收益可为负，不能初始化为 0。

少量固定交易次数可显式列出持股/不持股状态，状态数固定时无需构造庞大表格。

## 188. 买卖股票的最佳时机IV

[力扣原题](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/)

### 简短题意

给定每日股价 prices 和整数 k，最多完成 k 笔买卖交易，不能同时持有多股，求最大利润。

### 思路解析

cash[i][t] 表示到第 i 天、至多 t 次买入额度下的不持股最大收益；hold[i][t] 是对应持股收益。卖出从前一天 hold[i-1][t] 加当前价，买入从 cash[i-1][t-1] 减当前价。第 0 天所有 t>=1 的持股可用一笔买入初始化，cash 为 0。保留完整天数×次数二维表便于理解。

### C++ 主模板

```cpp
class Solution {
    // 次数额度在买入时增加，持股和不持股分别转移。
public:
    int maxProfit(int k, vector<int>& prices) {
        int n = prices.size();
        if (n == 0 || k == 0) return 0;
        vector<vector<int>> cash(n,vector<int>(k+1,0));
        vector<vector<int>> hold(n,vector<int>(k+1,INT_MIN / 2));
        for (int t = 1; t <= k; t++) hold[0][t] = -prices[0];
        for (int i = 1; i < n; i++) {
            for (int t = 1; t <= k; t++) {
                cash[i][t] = max(cash[i-1][t],hold[i-1][t] + prices[i]);
                hold[i][t] = max(hold[i-1][t],cash[i-1][t-1] - prices[i]);
            }
        }
        return cash[n-1][k];
    }
};
```

### 示例与复杂度

k=2，prices=[3,2,6,5,0,3]：2→6 赚 4，0→3 赚 3，返回 7。

时间 O(nk)，额外空间 O(nk)，满足题目 n<=1000、k<=100 的范围。

### 易错点与一类题总结

持股初值不可直接用 INT_MIN 后参与加减；t=0 不能买入；本题无手续费或冷冻期，若规则变化必须调整状态转移。

交易次数不固定时，将显式状态推广为“天数×次数×持有情况”；先统一次数含义再写买卖转移。

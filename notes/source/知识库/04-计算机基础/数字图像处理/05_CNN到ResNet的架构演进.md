# 05 CNN 到 ResNet 的架构演进

## 学习目标

- 理解 CNN 视觉骨干网络从 AlexNet、VGG、Inception 到 ResNet、EfficientNet 的演进逻辑。
- 掌握残差连接为什么能训练更深网络，以及它如何影响梯度传播和特征复用。
- 能从“特征提取能力、计算量、参数量、感受野、下采样策略”角度比较典型架构。
- 连接上一章 [深度学习视觉基础](./04_深度学习视觉基础.md)，并为下一章 [多尺度特征与 YOLO 检测链路](./06_多尺度特征与YOLO检测链路.md) 铺垫 Backbone 的作用。

## 1. 主线：更强的特征提取器

CNN 架构演进不是简单地“越深越好”，而是在几个目标之间平衡：

- 更强表达能力：能识别更复杂的视觉模式。
- 更稳定训练：深层网络不能因为梯度消失或退化而训不动。
- 更高计算效率：参数量、FLOPs、显存和延迟都要可控。
- 更好的迁移能力：分类预训练骨干能迁移到检测、分割等任务。

在完整视觉链路中，CNN Backbone 负责把输入图像变成多层特征：

```text
图像张量 -> CNN Backbone -> 层级特征 C2/C3/C4/C5 -> Neck/Head
```

分类模型通常只用最后一层高级语义特征；检测模型则会复用多个层级的特征，因为小目标需要高分辨率，大目标需要大感受野。

## 2. AlexNet：深度 CNN 的起点

AlexNet 的关键贡献是证明深度 CNN 在大规模数据和 GPU 训练下能显著超过传统视觉方法。它的典型特征包括：

- 多层卷积 + ReLU。
- Max Pooling 下采样。
- Dropout 缓解全连接层过拟合。
- 数据增强提升泛化。
- GPU 并行训练。

AlexNet 的直觉：前几层提边缘和纹理，中间层组合局部形状，后面全连接层做类别判别。它开启了“用深层网络自动学习视觉表示”的路线。

工程注意：

- AlexNet 后部全连接层参数巨大，对输入尺寸依赖强。
- 早期大卷积核如 `11x11, stride=4` 下采样激进，可能损失细节；现代检测骨干通常更谨慎。

## 3. VGG：用小卷积堆深网络

VGG 的核心思想是大量使用 `3x3` 卷积，结构规整：

```text
conv3x3 -> conv3x3 -> pool
conv3x3 -> conv3x3 -> pool
...
```

两个 `3x3` 卷积的感受野为 `5x5`，三个 `3x3` 为 `7x7`。相比直接使用大卷积核，小卷积堆叠有两个优势：

- 参数更少。若输入输出通道均为 `C`，一个 `5x5` 参数量是 `25C^2`，两个 `3x3` 是 `18C^2`。
- 非线性更多。两个卷积之间有激活函数，表达能力更强。

VGG 的局限也明显：

- 参数量大，尤其是全连接层。
- 网络更深但没有残差连接，继续加深会遇到训练退化。
- 对移动端和实时检测不友好。

## 4. Inception：多分支与计算压缩

Inception 的核心问题是：同一层应该用多大卷积核？小目标可能需要小核，大结构可能需要大核。Inception 的回答是并行多分支：

```text
1x1 conv
3x3 conv
5x5 conv
pool
-> concat
```

其中 `1x1` 卷积非常重要。它不改变空间尺寸，但可以改变通道数：

```text
输入: N x C_in x H x W
1x1卷积输出: N x C_out x H x W
参数量: C_in * C_out
```

`1x1` 卷积的主要用途：

- 通道压缩，降低后续 `3x3/5x5` 的计算量。
- 通道混合，让不同特征组合。
- 在瓶颈结构中先降维再升维。

计算例子：输入通道 `256`，直接做 `5x5` 输出 `128`：

```text
参数量 = 256 * 128 * 5 * 5 = 819200
```

若先用 `1x1` 降到 `64`，再做 `5x5` 输出 `128`：

```text
1x1参数 = 256 * 64 = 16384
5x5参数 = 64 * 128 * 25 = 204800
总计 = 221184
```

计算量显著降低。

## 5. 深层网络的退化问题

直觉上，网络越深表达能力越强；但实际训练中，普通深层网络可能出现退化：不是过拟合，而是训练误差也变差。原因包括：

- 梯度在多层链式传播中变小或不稳定。
- 深层网络很难学到“至少不比浅层差”的恒等映射。
- 优化空间更复杂，普通堆叠结构难以收敛。

这和过拟合不同：

- 过拟合：训练误差低，验证误差高。
- 退化：训练误差本身就高，说明优化困难。

## 6. ResNet：让网络学习残差

ResNet 的关键公式：

```text
y = F(x) + x
```

其中 `x` 是输入，`F(x)` 是若干卷积层学习到的残差。网络不再直接学习目标映射 `H(x)`，而是学习：

```text
F(x) = H(x) - x
```

如果某些层暂时没必要改变特征，只需让 `F(x)≈0`，输出就接近 `x`。这比让普通堆叠层自己学恒等映射容易。

反向传播角度：

```text
y = F(x) + x
dL/dx = dL/dy * (dF/dx + I)
```

其中 $I$ 是恒等映射的 Jacobian；标量速记时常写成 `+1`。这条直接路径减轻了深层网络的优化困难。

BasicBlock 常见于 ResNet-18/34：

```text
3x3 conv -> BN -> ReLU -> 3x3 conv -> BN -> add shortcut -> ReLU
```

Bottleneck 常见于 ResNet-50/101/152：

```text
1x1降维 -> 3x3卷积 -> 1x1升维 -> add shortcut
```

当输入输出通道数或空间尺寸不同，shortcut 不能直接相加，需要 projection：

```text
shortcut = 1x1 conv(x), stride可能为2
y = F(x) + shortcut
```

工程陷阱：

- 残差相加要求张量形状一致：`N,C,H,W` 都要对齐。
- stride 放在主分支还是 shortcut 会影响实现细节，不同 ResNet 版本略有差异。
- BN 和 ReLU 的顺序分 post-activation 与 pre-activation，不能随意混用预训练权重。

## 7. EfficientNet：复合缩放

EfficientNet 关注“如何同时缩放深度、宽度和输入分辨率”。单独加深、加宽或加大输入都会带来收益和成本，但不一定平衡。EfficientNet 使用 compound scaling：

```text
depth:      d = alpha^phi
width:      w = beta^phi
resolution: r = gamma^phi
```

原始复合缩放设定还要求 $\alpha,\beta,\gamma\ge 1$，并近似满足：

$$
\alpha\beta^2\gamma^2\approx 2
$$

因为卷积计算量大致与深度成正比、与宽度和分辨率的平方成正比，所以 $\phi$ 每增加 1，计算预算约翻倍。在给定资源预算下，三者按固定比例同时缩放，而不是任意独立放大。

直觉：

- 深度增加：能组合更复杂的层级特征。
- 宽度增加：每层能保留更多通道表达。
- 分辨率增加：输入细节更多，利于小目标和细粒度识别。

代价是更高计算量和显存占用。检测任务中，提高输入分辨率尤其昂贵，因为特征图面积近似随边长平方增长。

## 8. 从分类骨干到检测骨干

分类网络最终只需要一个类别，因此可以不断下采样，最后用全局池化得到语义向量。检测网络还需要定位，因此只用最后一层通常不够。

典型 ResNet 检测骨干会输出：

```text
C2: stride 4,  高分辨率，低层细节强
C3: stride 8
C4: stride 16
C5: stride 32, 低分辨率，高层语义强
```

这些层级会送入 FPN/PAN 等 Neck 进行多尺度融合。由此形成从 CNN 到 YOLO 的逻辑：

```text
CNN 学局部模式
-> ResNet 解决深层训练
-> 多层特征承载不同尺度
-> FPN/PAN 融合语义和细节
-> YOLO Head 在多尺度特征图上预测目标
```

## 9. 面试问答与速记

Q：VGG 为什么喜欢 `3x3`？

A：小卷积堆叠能用更少参数获得更大感受野，并引入更多非线性。

Q：`1x1` 卷积有什么用？

A：做通道压缩、通道升维和跨通道信息混合。它不改变空间尺寸，但能显著控制计算量。

Q：ResNet 为什么能训练更深？

A：残差连接让网络学习 `H(x)-x`，并给梯度提供直接路径。即使某些层暂时无用，也可以接近恒等映射。

Q：分类 Backbone 为什么能用于检测？

A：前中层学到的边缘、纹理、部件和高级语义具有通用性。检测模型通常去掉分类头，保留 Backbone 的多层特征，再接 Neck 和检测 Head。

速记：

```text
AlexNet: 深度CNN可行
VGG: 小卷积规整堆叠
Inception: 多尺度分支 + 1x1降维
ResNet: 残差解决深层退化
EfficientNet: 深度/宽度/分辨率复合缩放
```

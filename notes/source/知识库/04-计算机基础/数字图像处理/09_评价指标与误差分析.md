# 09 评价指标与误差分析

## 学习目标

- 掌握分类、检测、分割、跟踪和 OCR 的常用指标。
- 理解 PR 曲线、阈值选择、mAP@0.5 与 mAP@0.5:0.95 的差异。
- 能使用混淆矩阵、切片评估和失败案例归因做工程诊断。
- 与训练和部署联动：见 [08_训练_损失_数据与诊断.md](./08_训练_损失_数据与诊断.md)、[10_推理部署与工业视觉.md](./10_推理部署与工业视觉.md)。

## 指标设计原则

指标必须服务业务目标。一个模型“平均分高”不代表能上线，尤其在安全、质检、医疗、自动驾驶等场景中，漏检、误检、延迟和可解释性成本不同。

评估时至少同时看：

- 整体指标：便于横向比较。
- 分类别指标：发现长尾和混淆。
- 分场景指标：光照、设备、时间、材质、背景、尺寸、遮挡。
- 阈值相关指标：不同置信度阈值下的 precision/recall。
- 失败案例：用图像证据解释指标变化。

## 分类指标

混淆矩阵记录真实类别与预测类别的对应关系，是分类误差分析的入口。

常用指标：

- Accuracy：整体正确率，类别均衡时直观；类别极不平衡时可能误导。
- Precision：预测为正的样本中有多少是真的，关注误报成本。
- Recall：真实正样本中有多少被找回，关注漏报成本。
- F1：precision 与 recall 的调和平均，适合二者都重要的场景。
- Top-k accuracy：真实类别是否在前 k 个预测内，适合候选推荐或粗筛。
- ROC-AUC：不同阈值下 TPR/FPR 曲线面积，类别不平衡时要结合 PR-AUC。
- Calibration：预测概率是否可信，可用 reliability diagram、ECE 分析。

二分类四类结果：

| 结果 | 含义 |
| --- | --- |
| TP | 正样本预测为正 |
| FP | 负样本预测为正，误报 |
| FN | 正样本预测为负，漏报 |
| TN | 负样本预测为负 |

Precision = TP / (TP + FP)，Recall = TP / (TP + FN)。阈值升高通常 precision 上升、recall 下降；阈值降低通常 recall 上升、precision 下降。

## PR 曲线与阈值

PR 曲线比单点指标更能反映模型在不同阈值下的行为。阈值不是训练出来后随便取 0.5，而应按业务成本选择。

阈值选择方法：

- 漏检成本高：选择高 recall 工作点。
- 误报成本高：选择高 precision 工作点。
- 人工复核容量固定：选择每天可处理的告警量阈值。
- 多类别检测：不同类别可使用不同阈值。
- 线上分布变化：定期重估阈值和校准。

报告指标时应写清阈值、测试集版本、样本量和类别分布。

## 检测指标

检测预测需要同时匹配类别和位置。计算 AP 时，通常先按置信度排序，再在同类别内按 IoU 阈值把预测与尚未匹配的真实框进行一对一匹配；同一真实目标后续出现的重复框算 FP。类别正确且 IoU 达标只是成为 TP 的必要条件，还必须遵循评测协议的匹配顺序和忽略区域规则。

IoU = 预测框与真实框交集面积 / 并集面积。

常见指标：

- AP：某一类别按置信度排序得到的 precision-recall 曲线面积；VOC、COCO 和不同框架在插值、采样点、最大检测数、面积范围和 ignore 规则上可能不同。
- mAP：所有类别 AP 的平均。
- mAP@0.5：IoU 阈值为 0.5，定位要求较宽松。
- mAP@0.5:0.95：COCO 风格，在 IoU=0.50～0.95、步长 0.05 的多个阈值上平均，更强调定位质量。
- AP_small/medium/large：按目标尺寸分组。
- AR：平均召回，关注候选框召回能力。

mAP@0.5 高而 mAP@0.5:0.95 低，通常说明模型能大致找到目标，但框不够准、边界不稳或 NMS/回归质量不足。

检测误差类型：

- 分类错：框位置对，但类别错。
- 定位错：类别对，但 IoU 不够。
- 漏检：真实目标没有匹配预测。
- 误检：预测了不存在的目标。
- 重复检测：同一目标多个框，NMS 问题。
- 小目标失败：分辨率、anchor、stride、增强或标注粒度问题。

## 分割指标

语义分割和实例分割都关注像素级区域，但评价方式不同。

语义分割：

- Pixel Accuracy：像素正确率，背景占比大时容易虚高。
- IoU/Jaccard：每类交并比。
- mIoU：各类别 IoU 平均，是语义分割常用主指标。
- Dice/F1：2 * 交集 / (预测面积 + 真实面积)，医学和小目标常用。
- Boundary F-score：关注边界质量。

实例分割：

- mask AP：用 mask IoU 计算 AP。
- box AP 与 mask AP 要分开看：框准不代表 mask 准。
- 可按实例尺寸、遮挡程度、类别切片分析。

分割误差类型：

- 边界粗糙。
- 小区域缺失。
- 多个实例粘连。
- 同一实例断裂。
- 背景纹理被误分为前景。
- 类别混淆。

## 跟踪、OCR、深度与光流指标

跟踪：

- MOTA：综合 FN、FP、ID switch。
- IDF1：关注身份一致性。
- HOTA：同时考虑检测、关联和定位质量。
- ID switches：轨迹身份切换次数，工业计数和行为分析中很关键。

OCR：

- Character Error Rate：字符级编辑距离 / 字符数。
- Word Error Rate：词级编辑距离 / 词数。
- Exact Match：整串完全正确率。
- 检测部分可看 text detection precision/recall/Hmean。

深度估计：

- Abs Rel：平均相对误差。
- RMSE：均方根误差。
- delta accuracy：预测与真实深度比值是否在阈值内。

光流：

- EPE：Endpoint Error，预测向量与真实向量的欧氏距离。
- Fl-all：错误像素比例，自动驾驶数据集中常见。

## 超分、复原与生成指标

- PSNR：由均方误差推导，越高通常表示像素级失真越小；对轻微位移敏感，也不完全符合人类感知。
- SSIM：比较亮度、对比度与结构，相比 PSNR 更关注局部结构，但仍不能保证语义或纹理真实。
- LPIPS：用深层特征距离近似感知差异，通常越低越相似；结果依赖所用特征网络和版本。
- FID：比较真实与生成样本在特征空间的分布统计，常用于生成模型；它需要足够样本，且不能证明单张图正确或不存在记忆复制。
- 人工主观评价：可比较自然度、偏好或任务可用性，但必须控制盲测、随机顺序、评审一致性和样本规模。
- 任务驱动评价：若复原/超分服务检测或测量，应同时比较下游召回、定位误差和误报警，防止“看起来更清晰”却生成不存在的缺陷纹理。

没有单一指标能同时覆盖像素保真、感知质量、分布真实性和业务安全。工业场景应优先确保不凭空生成关键结构，并用真实退化数据和下游任务共同验收。

## 切片评估

切片评估是把测试集按业务维度拆开看指标，目的是发现平均值掩盖的问题。

常见切片：

- 类别：头部类、尾部类、易混类。
- 尺寸：小、中、大目标。
- 场景：白天/夜晚、室内/室外、不同产线。
- 设备：相机型号、镜头、安装点位。
- 质量：模糊、反光、遮挡、低照度、压缩。
- 时间：新旧批次、节假日、季节变化。
- 标注来源：人工、半自动、不同标注员。

切片样本太少时，指标波动很大。报告时要同时给样本量，必要时只做定性分析。

## 错误分析流程

1. 固定测试集和模型版本。
2. 导出预测结果、置信度、阈值、原图和标注。
3. 按 FP、FN、分类错、定位错、边界错分桶。
4. 每桶抽样可视化，标注主要原因。
5. 按类别、尺寸、场景、设备切片统计。
6. 判断应优先改数据、阈值、后处理、损失还是模型。
7. 建立 hard case 集，作为回归测试。

优先级判断：

- 如果训练和测试都差：先查数据、标签、loss、输入预处理。
- 如果训练好测试差：查过拟合、泄漏、域偏移。
- 如果只某些场景差：补数据和增强优先。
- 如果 mAP@0.5 高但高 IoU AP 低：改框回归、分辨率、标注一致性。
- 如果 precision 高 recall 低：阈值、召回能力、小目标和漏标。
- 如果 recall 高 precision 低：误检类别、背景负样本、阈值和 NMS。

## 指标报告模板

建议报告至少包含：

- 数据集版本、划分方式、样本量。
- 模型版本、输入尺寸、训练 checkpoint。
- 主指标和关键业务指标。
- 阈值和后处理参数。
- 分类别、分尺寸、分场景指标。
- 典型成功与失败案例截图。
- 与上一版本对比及显著变化原因。

# 第 5 章 相机标定与三维视觉

本章讨论 OpenCV 三维视觉链路：用标定板估计内参和畸变，校正图像，再用 PnP、双目和三角化连接像素与三维坐标。OpenCV 5 将原 `calib3d` 拆成 `calib`、`geometry`、`stereo`、`ptcloud`：`calibrateCamera/stereoCalibrate` 属于 `calib`，`solvePnP/triangulatePoints` 属于 `geometry`，`StereoBM/SGBM` 属于 `stereo`。OpenCV 4.12 仍主要放在 `calib3d`；C++ 旧头文件 `opencv2/calib3d.hpp` 在 5.0 中仍兼容。

官方资料参考：[OpenCV 5 calibration](https://docs.opencv.org/5.0/main_modules/calib.html)、[fisheye](https://docs.opencv.org/5.0/main_modules/calib_fisheye.html)、[PnP](https://docs.opencv.org/5.0/main_modules/geometry_pnp.html)、[stereo](https://docs.opencv.org/5.0/main_modules/stereo.html) 文档，[OpenCV 4.12 Camera Calibration 教程](https://docs.opencv.org/4.12.0/dc/dbb/tutorial_py_calibration.html)，以及 [OpenCV 4 到 5 迁移说明](https://github.com/opencv/opencv/wiki/OpenCV-4-to-5-migration)。

## 1. 针孔模型：像素不是三维，投影才是桥

针孔相机模型假设光线经过理想光心再落到成像平面。OpenCV 常用相机坐标系：`Xc` 向右，`Yc` 向下，`Zc` 向前；图像坐标 `(u, v)` 以像素为单位，原点在左上角。

一个世界点 `Pw = [Xw, Yw, Zw]^T` 先由外参变换到相机坐标：

```text
Pc = R * Pw + t
```

其中 `R` 是 `3x3` 旋转矩阵；`t` 是 `3x1` 平移向量，单位和 `Pw` 一致。OpenCV 常用 `3x1` 的 Rodrigues 旋转向量 `rvec`，可用 `cv.Rodrigues` 与 `R` 互转。随后针孔投影除以深度：

```text
x = Xc / Zc
y = Yc / Zc
```

这里 `(x, y)` 是无单位的归一化成像平面坐标，前提是 `Zc > 0`。最后用内参矩阵 `K` 转到像素：

```text
[u]   [fx  0 cx] [x]
[v] = [ 0 fy cy] [y]
[1]   [ 0  0  1] [1]
```

`K` 形状为 `3x3`，`fx/fy` 是像素焦距，`cx/cy` 是主点像素坐标。若图像等比例缩放，四个量同步缩放；若裁剪图像，焦距不变，主点减去裁剪偏移。

外参方向常被混淆。`calibrateCamera`、`solvePnP` 返回的 `rvec,tvec` 表示物体坐标到相机坐标：`Pc = R * Po + t`。相机在物体坐标系中的位置为：

```text
C_object = -R^T * t
```

## 2. 畸变模型：先用归一化坐标，再进像素

真实镜头不是理想针孔。OpenCV 普通相机模型主要描述径向畸变和切向畸变。径向畸变让直线向外鼓或向内收，切向畸变来自镜头与传感器不完全平行。模型在归一化坐标上计算，令 `r2 = x^2 + y^2`：

```text
x_radial = x * (1 + k1*r2 + k2*r2^2 + k3*r2^3 + ...)
y_radial = y * (1 + k1*r2 + k2*r2^2 + k3*r2^3 + ...)

x_tangent = 2*p1*x*y + p2*(r2 + 2*x^2)
y_tangent = p1*(r2 + 2*y^2) + 2*p2*x*y
```

常见 `distCoeffs` 形状可以是 `1x5`、`5x1`、`1x8`、`1x12` 或 `1x14`。最基础的 5 个参数顺序是：

```text
[k1, k2, p1, p2, k3]
```

启用 `CALIB_RATIONAL_MODEL` 后，8 参数模型增加 `k4, k5, k6`，它们不是继续加在分子上，而是位于径向缩放因子的分母中：`(1 + k1*r2 + k2*r2^2 + k3*r2^3) / (1 + k4*r2 + k5*r2^2 + k6*r2^3)`；12/14 参数继续增加薄棱镜和倾斜传感器参数。参数越多越需要充分样本，否则容易过拟合噪声。

鱼眼模型与普通广角模型不同。`cv.fisheye` 使用 4 个参数 `D = [k1, k2, k3, k4]`，用于视场角很大的镜头。普通模型与鱼眼模型不能混用。

## 3. 标定板、角点与 objectPoints

标定的本质是已知标定板三维点及其图像像素点，求让投影误差最小的 `K`、畸变和每张图外参。常见图案包括棋盘格、圆点阵、非对称圆点阵和 ChArUco。`findChessboardCorners` 检测的是内角点，不是格子数。

如果棋盘格是 `9x6` 内角点，单格边长是 `25 mm`，可以定义标定板坐标：

```text
(0,0,0), (25,0,0), ..., (200,0,0)
(0,25,0), ...
```

棋盘格是平面，所以所有点 `Z=0`。`objectPoints[i]` 与 `imagePoints[i]` 必须一一对应。Python 常用 `np.float32/float64`；C++ 常用 `vector<vector<Point3f>>` 和 `vector<vector<Point2f>>`。

角点定位通常先粗检测，再亚像素精修：

```text
gray -> findChessboardCorners -> cornerSubPix -> append points
```

模糊、过曝、棋盘不完整、图案顺序错误时，应丢弃该图，而不是指望优化阶段“平均掉”错误。

## 4. 单目标定：calibrateCamera 的输入输出

普通相机单目标定的 Python API：

```python
ret, K, dist, rvecs, tvecs = cv.calibrateCamera(
    objectPoints, imagePoints, imageSize, None, None
)
```

`objectPoints` 长度为 `N`，每个元素约 `(M,3)`；`imagePoints` 长度为 `N`，每个元素约 `(M,1,2)` 或 `(M,2)`；`imageSize` 是 `(width,height)`。`ret` 是全局 RMS 重投影误差，单位是像素。`rvecs/tvecs` 每张图一组。

关键 C++ API：

```cpp
#include <opencv2/calib3d.hpp>   // 4.12；5.0 仍兼容。5.0 也可用 calib/geometry/stereo 新头文件
#include <opencv2/imgproc.hpp>   // findChessboardCorners/cornerSubPix
double rms = cv::calibrateCamera(objectPoints, imagePoints, imageSize,
                                 cameraMatrix, distCoeffs, rvecs, tvecs, flags, criteria);
cv::findChessboardCorners(gray, patternSize, corners);
cv::cornerSubPix(gray, corners, cv::Size(11, 11), cv::Size(-1, -1), criteria);
cv::projectPoints(objectPoints[i], rvecs[i], tvecs[i], cameraMatrix, distCoeffs, projected);
```

常见 flags：

| 参数 | 含义 | 何时使用 |
|---|---|---|
| `CALIB_FIX_ASPECT_RATIO` | 固定 `fx/fy` 比例 | 已知像素长宽比或已有可信初值 |
| `CALIB_ZERO_TANGENT_DIST` | 假设 `p1=p2=0` | 镜头装配较好且样本不足 |
| `CALIB_FIX_PRINCIPAL_POINT` | 固定主点 | 已知主点或只想估计畸变 |
| `CALIB_RATIONAL_MODEL` | 使用分母中的 `k4-k6` rational 模型 | 广角镜头且样本覆盖充分 |
| `CALIB_USE_INTRINSIC_GUESS` | 使用给定 `K` 初值 | 已有厂家参数或上一轮结果 |

鱼眼标定关键 API：

```python
rms, K, D, rvecs, tvecs = cv.fisheye.calibrate(
    objectPoints, imagePoints, imageSize, K, D,
    flags=cv.fisheye.CALIB_RECOMPUTE_EXTRINSIC
)
```

```cpp
double rms = cv::fisheye::calibrate(
    objectPoints, imagePoints, imageSize, K, D, rvecs, tvecs, flags, criteria);
```

鱼眼 `objectPoints` 在 Python 中常整理为 `(1,M,3)` 或 `(M,1,3)` 的浮点数组，具体以当前绑定断言为准。

## 5. 完整 Python 示例：采集图像、标定、误差、校正

下面示例假设已有 `calib/*.jpg`，棋盘格内角点 `9x6`，单格 `25 mm`。它完成角点检测、单目标定、逐图误差统计、保存参数和校正图生成。

```python
import glob

import cv2 as cv
import numpy as np

PATTERN_SIZE = (9, 6)
SQUARE_SIZE_MM = 25.0
IMAGE_GLOB = "calib/*.jpg"

criteria = (
    cv.TERM_CRITERIA_EPS + cv.TERM_CRITERIA_MAX_ITER,
    30,
    1e-3,
)

objp = np.zeros((PATTERN_SIZE[0] * PATTERN_SIZE[1], 3), np.float32)
grid = np.mgrid[0:PATTERN_SIZE[0], 0:PATTERN_SIZE[1]].T.reshape(-1, 2)
objp[:, :2] = grid * SQUARE_SIZE_MM

object_points = []
image_points = []
image_size = None

for filename in sorted(glob.glob(IMAGE_GLOB)):
    img = cv.imread(filename)
    if img is None:
        continue

    gray = cv.cvtColor(img, cv.COLOR_BGR2GRAY)
    current_size = (gray.shape[1], gray.shape[0])
    if image_size is None:
        image_size = current_size
    elif image_size != current_size:
        raise ValueError(f"mixed image sizes: {filename} has {current_size}, expected {image_size}")

    found, corners = cv.findChessboardCorners(
        gray,
        PATTERN_SIZE,
        flags=cv.CALIB_CB_ADAPTIVE_THRESH + cv.CALIB_CB_NORMALIZE_IMAGE,
    )
    if not found:
        print(f"skip: {filename}")
        continue

    corners = cv.cornerSubPix(
        gray,
        corners,
        winSize=(11, 11),
        zeroZone=(-1, -1),
        criteria=criteria,
    )
    object_points.append(objp.copy())
    image_points.append(corners)

if len(object_points) < 10:
    raise RuntimeError(f"need more valid views, got {len(object_points)}")

rms, K, dist, rvecs, tvecs = cv.calibrateCamera(object_points, image_points, image_size, None, None)

per_view_errors = []
for i, obj in enumerate(object_points):
    projected, _ = cv.projectPoints(obj, rvecs[i], tvecs[i], K, dist)
    err = cv.norm(image_points[i], projected, cv.NORM_L2) / np.sqrt(len(projected))
    per_view_errors.append(float(err))

print("image size:", image_size)
print("valid views:", len(object_points))
print("RMS reprojection error:", rms)
print("K:\n", K)
print("dist:", dist.ravel())

sample = cv.imread(sorted(glob.glob(IMAGE_GLOB))[0])
new_K, roi = cv.getOptimalNewCameraMatrix(K, dist, image_size, alpha=0.2, newImgSize=image_size)
undistorted = cv.undistort(sample, K, dist, None, new_K)

x, y, w, h = roi
preview = undistorted[y:y+h, x:x+w] if w > 0 and h > 0 else undistorted
cv.imwrite("undistorted_preview.jpg", preview)

map1, map2 = cv.initUndistortRectifyMap(
    K, dist, R=None, newCameraMatrix=new_K, size=image_size, m1type=cv.CV_16SC2
)
remapped = cv.remap(sample, map1, map2, interpolation=cv.INTER_LINEAR)
cv.imwrite("remap_preview.jpg", remapped)
np.savez("camera_calibration.npz", K=K, dist=dist, new_K=new_K, rms=rms)
```

`cv.undistort` 适合少量图像；`initUndistortRectifyMap + remap` 适合视频流，因为映射表可复用。`alpha=0` 倾向裁黑边，`alpha=1` 尽量保留视场。

## 6. 重投影误差与采集清单

重投影误差是把三维角点用估计参数重新投影到图像，再与检测角点比较，单位是像素。逐图 RMS 可按 `norm(points - projected) / sqrt(point_count)` 计算；也可以使用 `calibrateCameraExtended` 直接读取 `perViewErrors`。全局 RMS 小不等于结果一定好；逐图误差、误差空间分布、校正后直线是否变直同样重要。

采集清单：

1. 使用刚性、平整、尺寸准确的标定板；打印纸容易翘曲，最好贴在硬板上。
2. 至少 10 到 20 张有效图，广角、鱼眼、双目更多。
3. 标定板覆盖中心、四角和边缘，姿态包含平移、旋转、倾斜。
4. 棋盘边缘清晰，避免模糊、过曝、反光和强压缩。
5. 使用最终业务分辨率；若后续缩放，必须同步缩放内参。
6. 双目左右图同步采集；记录单格边长单位，`tvec`、基线和深度继承该单位。

误差诊断表：

| 现象 | 可能原因 | 处理 |
|---|---|---|
| RMS 很大 | 角点误检、尺寸错误、图像混尺寸 | 可视化角点，剔除异常图 |
| 中心好，边缘差 | 畸变模型不足或边缘样本少 | 增加边缘姿态，考虑 rational 或 fisheye |
| `fx/fy` 异常 | 棋盘尺寸、内角点数量、图像方向错误 | 核对 `patternSize` 与 `squareSize` |
| 直线仍弯或外参跳变 | 样本覆盖不足、模型选错、角点顺序错 | 增加倾斜样本，检查编号 |

最终是否合格应由业务误差决定，例如测距误差、姿态误差或重建尺度误差。

## 7. PnP：用 3D-2D 对应求物体位姿

PnP 解决的问题是：已知物体三维点、对应图像点、`K` 和 `distCoeffs`，求物体坐标系到相机坐标系的 `rvec, tvec`。

```python
ok, rvec, tvec = cv.solvePnP(
    object_points_3d,
    image_points_2d,
    K,
    dist,
    flags=cv.SOLVEPNP_ITERATIVE,
)
projected, _ = cv.projectPoints(axis_points_3d, rvec, tvec, K, dist)
```

关键 C++ API：`cv::solvePnP(objectPoints, imagePoints, K, distCoeffs, rvec, tvec, false, cv::SOLVEPNP_ITERATIVE)`；含离群点时用 `cv::solvePnPRansac(...)` 并检查 `inliers`。

方法选择：`SOLVEPNP_ITERATIVE` 是常用稳定入口；`EPNP` 快，适合 RANSAC 候选；`P3P/AP3P` 用少量点但可能多解；`IPPE` 适合共面点；`IPPE_SQUARE` 适合四点方形标记且要求固定点序。

PnP 的尺度来自 `objectPoints`。三维点单位是米，`tvec` 就是米；单位是毫米，`tvec` 就是毫米。PnP 不能从单张图恢复未知物体真实尺度。

## 8. 双目标定、极线几何、F/E 矩阵

双目系统有两台相机，各自有内参 `K1,D1` 和 `K2,D2`，还需要左右相机之间的 `R,T`。通常先分别单目标定，再用 `CALIB_FIX_INTRINSIC` 固定内参估计双目外参。

```python
rms, K1, D1, K2, D2, R, T, E, F = cv.stereoCalibrate(
    object_points,
    image_points_left,
    image_points_right,
    K1,
    D1,
    K2,
    D2,
    image_size,
    flags=cv.CALIB_FIX_INTRINSIC,
)
```

`R` 是右相机相对左相机的旋转，`T` 是平移，单位来自 `object_points`。符号取决于相机顺序，关键是与 `P1/P2/Q` 保持一致。

基础矩阵 `F` 描述像素坐标中的极线约束：

```text
x2^T * F * x1 = 0
```

其中 `x1=[u1,v1,1]^T`、`x2=[u2,v2,1]^T` 是齐次像素点。`F` 是 `3x3`，无绝对尺度，不要求已知内参。

本质矩阵 `E` 描述归一化相机坐标中的极线约束：

```text
E = K2^T * F * K1
```

`E` 也是 `3x3`，可由 `recoverPose` 分解出 `R,T` 的方向，但平移没有真实尺度。标定板双目标定得到的 `T` 才有实际尺度。

## 9. stereoRectify、视差和 Q 矩阵

双目校正把左右图重映射到同一极线方向，使对应点位于同一行，匹配从二维搜索变成水平一维搜索。核心 API：

```python
R1, R2, P1, P2, Q, roi1, roi2 = cv.stereoRectify(
    K1, D1, K2, D2, image_size, R, T,
    flags=cv.CALIB_ZERO_DISPARITY,
    alpha=0,
)

map1x, map1y = cv.initUndistortRectifyMap(K1, D1, R1, P1, image_size, cv.CV_16SC2)
map2x, map2y = cv.initUndistortRectifyMap(K2, D2, R2, P2, image_size, cv.CV_16SC2)
left_rect = cv.remap(left, map1x, map1y, cv.INTER_LINEAR)
right_rect = cv.remap(right, map2x, map2y, cv.INTER_LINEAR)
```

`R1/R2` 是左右相机的校正旋转，`3x3`；`P1/P2` 是校正后的投影矩阵，形状 `3x4`；`Q` 是 `4x4` 视差到三维的重投影矩阵。校正后，一个点的视差通常定义为：

```text
disparity = x_left - x_right
```

理想平行双目中：

```text
Z = f * B / disparity
```

`f` 是像素焦距，`B` 是基线长度，`disparity` 是像素，因此 `Z` 的单位与 `B` 一致。视差越小，深度越大。

OpenCV 的 `reprojectImageTo3D(disparity, Q)` 使用 `Q` 把每个像素和视差转成三维点。若 `StereoSGBM` 输出的是定点格式，通常要除以 `16.0` 得到真实像素视差：

```python
matcher = cv.StereoSGBM_create(
    minDisparity=0,
    numDisparities=128,     # 16 的倍数
    blockSize=5,
)
raw_disp = matcher.compute(left_rect_gray, right_rect_gray)
disp = raw_disp.astype(np.float32) / 16.0
points_3d = cv.reprojectImageTo3D(disp, Q)
```

`StereoBM` 速度快但更敏感；`StereoSGBM` 更稳、代价更高。纯色、重复纹理、反光、运动和遮挡都会产生错误视差。

关键 C++ API：`cv::stereoCalibrate`、`cv::stereoRectify`、`cv::initUndistortRectifyMap`、`cv::StereoSGBM::create`、`cv::reprojectImageTo3D`。

## 10. triangulatePoints：从两幅图恢复稀疏三维点

`triangulatePoints` 用两个投影矩阵和两组对应点恢复齐次三维点，适合稀疏特征点，不负责匹配本身。

```python
points4d = cv.triangulatePoints(P1, P2, pts1.T, pts2.T)
points3d = (points4d[:3] / points4d[3]).T
```

`P1/P2` 是 `3x4`，`pts1/pts2` 通常是 `2xN`。若用 `stereoRectify` 后的 `P1/P2`，输入点也应是校正后的点。输出坐标系与投影矩阵一致。

三角化精度受基线、焦距、匹配误差和距离影响。远距离视差很小，1 个像素误差可能造成很大深度误差。

## 11. 坐标系、单位和尺度统一表

| 名称 | 形状 | 单位 | 说明 |
|---|---:|---|---|
| 图像点 `(u,v)` | `2` | 像素 | 原点左上 |
| 归一化点 `(x,y)` | `2` | 无单位 | 已除以深度 |
| `K` | `3x3` | 像素 | 内参矩阵，随图像缩放改变 |
| `distCoeffs` | `1x5/8/12/14` | 无单位 | 普通畸变参数 |
| `fisheye D` | `1x4` | 无单位 | 鱼眼模型参数 |
| `R` | `3x3` | 无单位 | 旋转矩阵 |
| `rvec` | `3x1` | 弧度语义 | Rodrigues 旋转向量 |
| `tvec/T` | `3x1` | 与 objectPoints 一致 | 平移和尺度来源 |
| `P` | `3x4` | 混合 | 投影矩阵 |
| `F/E` | `3x3` | 无绝对尺度 | 极线约束矩阵 |
| `Q` | `4x4` | 由 `T` 决定 | 视差转三维 |

OpenCV 不知道真实单位，只保持数值一致。把 `squareSize=25` 当毫米标定却解释成米，会让 `tvec` 和深度差 1000 倍。

## 12. 常见退化与诊断

平面标定板方便，但有退化风险：

- 所有图片几乎正对标定板：主点、焦距和畸变耦合，外参不稳定。
- 标定板只出现在画面中心：边缘畸变不可观，校正边缘会失败。
- 图像数量多但姿态重复：有效约束仍然少。
- 棋盘格尺寸填错：内参像素值可能看似正常，但所有外参尺度错误。
- 左右相机不同步：双目角点对应的不是同一板姿态，`T` 和 `E/F` 会被污染。
- 滚动快门、自动对焦、变焦、电子防抖开启：模型在采集中变化。
- 标定后改变分辨率、裁剪、对焦距离或镜头位置：原参数不再适用。

诊断步骤：

1. 画出每张图的角点编号，确认顺序和数量正确。
2. 统计逐图重投影误差，剔除明显离群图后重新标定。
3. 把三维角点重投影回图像，观察误差箭头是否集中在边缘或某一方向。
4. 用校正结果检查真实直线，尤其是画面边缘的门框、桌边、棋盘线。
5. 双目校正后画水平辅助线，看左右对应点是否在同一行。
6. 用已知距离物体验证深度尺度，不只看视差图是否“好看”。

## 13. OpenCV 5 与 4.12 差异小结

OpenCV 4.12 仍由 `calib3d` 集中提供标定、几何和双目；OpenCV 5 拆成 `calib`、`geometry`、`stereo`、`ptcloud`。旧 C++ include 仍兼容，新项目可按模块 include，例如 `calibrateCamera` 可看 `opencv2/calib.hpp`，`solvePnP` 可看 `opencv2/geometry.hpp`，角点精修仍需要 `opencv2/imgproc.hpp`。Python 入口基本延续。官方迁移说明还提到 USAC 成为更多鲁棒估计默认后端，`calib` 增加多相机标定流水线。

## 14. 练习

1. 采集 15 张棋盘格图片，用 `alpha=0/0.5/1` 生成校正图，比较视场和黑边。
2. 只用中心图标定，再加入边缘和倾斜姿态，比较 RMS、`K` 和边缘直线。
3. 分别尝试 5 参数模型和 `CALIB_RATIONAL_MODEL`，观察误差和校正图。
4. 在标定板上定义 3D 坐标轴，用 `solvePnP` 求每张图外参，并把红绿蓝三轴投影到图像上。
5. 双目采集棋盘格，完成 `stereoCalibrate -> stereoRectify -> remap`，检查校正后左右角点的 `y` 坐标差。
6. 用 `StereoBM` 和 `StereoSGBM` 计算视差，改变 `numDisparities`、`blockSize`、`uniquenessRatio`，记录错误区域。
7. 用 `Q` 重投影已知距离物体，比较测量距离与真实距离。

本章核心是保持坐标系、单位、矩阵形状和模型前提一致；约束清楚后，标定、校正、PnP、双目和三角化才能稳定组成可诊断的三维视觉流水线。

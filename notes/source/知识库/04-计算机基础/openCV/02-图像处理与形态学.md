# 第 2 章：图像处理与形态学

本章讨论 OpenCV 图像预处理主干：颜色空间、缩放插值、滤波卷积、梯度边缘、阈值分割、直方图增强与形态学。默认以 OpenCV 5 `imgproc` 为准，示例兼容 OpenCV 4.12。目标不是背函数，而是能按噪声、光照和目标形状选择参数，并把灰度图或二值图稳定送入轮廓、OCR、检测或测量流程。

## 1. 颜色空间与 `cvtColor`

OpenCV 读入彩色图像的默认通道顺序是 BGR，不是显示库常用的 RGB；`cv.imread()` 图像直接用 Matplotlib 显示会红蓝互换。`cv.cvtColor(src, code[, dst[, dstCn[, hint]]])` 用转换码说明源和目标空间，例如 `COLOR_BGR2GRAY`、`COLOR_BGR2RGB`、`COLOR_BGR2HSV`、`COLOR_BGR2Lab`。C++ 对应 `cv::cvtColor(src, dst, code, dstCn, hint)`。

灰度图适合阈值、边缘、形态学；HSV 把色相与饱和度/亮度分开，适合彩色目标粗分割；Lab/Luv 适合光照变化下的颜色差异和局部对比；YCrCb/YUV 把亮度与色度拆开，常用于视频和肤色任务。非线性颜色转换对浮点范围敏感：8 位是 0..255，`CV_32F` 通常应归一化到 0..1 后再做 BGR 到 Luv/Lab。

```python
import cv2 as cv

bgr = cv.imread("input.jpg", cv.IMREAD_COLOR)
if bgr is None:
    raise FileNotFoundError("input.jpg")
gray = cv.cvtColor(bgr, cv.COLOR_BGR2GRAY)
hsv = cv.cvtColor(bgr, cv.COLOR_BGR2HSV)
luv32 = cv.cvtColor(bgr.astype("float32") / 255.0, cv.COLOR_BGR2Luv)
```

## 2. 缩放、采样与插值

`cv.resize(src, dsize[, dst[, fx[, fy[, interpolation]]]])` 改变像素网格。`dsize` 非零时优先生效；否则由 `fx`、`fy` 推出输出尺寸。C++ 对应 `cv::resize(src, dst, dsize, fx, fy, interpolation)`。几何变换通常用目标像素反查源像素的逆映射，源坐标常是小数，因此必须插值。

缩小时推荐 `INTER_AREA`，通常更少摩尔纹；放大时 `INTER_LINEAR` 均衡，`INTER_CUBIC` 更平滑但慢，`INTER_LANCZOS4` 质量更高；`INTER_NEAREST` 保持硬边，适合标签图、mask 和像素风格图。OpenCV 5 还保留 `INTER_LINEAR_EXACT`、`INTER_NEAREST_EXACT`；几何变换不支持 `CV_8S`、`CV_32S`。

```python
small = cv.resize(bgr, None, fx=0.5, fy=0.5, interpolation=cv.INTER_AREA)
large = cv.resize(bgr, None, fx=2, fy=2, interpolation=cv.INTER_CUBIC)
mask_small = cv.resize(mask, None, fx=0.5, fy=0.5, interpolation=cv.INTER_NEAREST)
```

## 3. 卷积、滤波与边界处理

滤波把每个像素的邻域计算成一个新值。线性滤波是加权求和：

`dst(x,y)=sum kernel(i,j) * src(x+i-anchor.x, y+j-anchor.y)`

`kernel` 决定邻域大小和权重；`anchor=(-1,-1)` 表示核中心；`ddepth=-1` 表示输出深度与输入一致；`delta` 在写入前加偏置。Python API 是 `cv.filter2D(src, ddepth, kernel[, dst[, anchor[, delta[, borderType]]]])`，C++ 是 `cv::filter2D(src, dst, ddepth, kernel, anchor, delta, borderType)`。

边界处理决定边缘处卷积是否可信。核在图像边缘会访问不存在的像素，OpenCV 用 `borderType` 外推：`BORDER_REPLICATE` 复制边缘值；`BORDER_CONSTANT` 填常数，易制造黑/亮框；`BORDER_REFLECT`/`BORDER_REFLECT_101` 镜像，适合平滑滤波，很多滤波默认 `BORDER_DEFAULT` 即反射类边界；`BORDER_WRAP` 多数场景不适合。中值滤波内部使用 `BORDER_REPLICATE`。

噪声模型决定滤波选择。高斯噪声是小幅随机扰动，均值或高斯滤波能降方差；椒盐噪声是孤立黑白点，中值滤波更有效；压缩块、运动模糊、散焦不是简单随机噪声，盲目平滑会损伤边缘；低光彩噪可先处理亮度通道。

```python
import numpy as np

k = np.array([[0, -1, 0], [-1, 5, -1], [0, -1, 0]], np.float32)
sharp = cv.filter2D(bgr, -1, k, borderType=cv.BORDER_REFLECT_101)
```

## 4. 均值、高斯、中值与双边滤波

`cv.blur(src, ksize)` 是归一化盒滤波，核越大噪声越低但细节越糊。`cv.boxFilter` 可选择是否归一化，未归一化时可算局部和。`cv.GaussianBlur(src, ksize, sigmaX[, sigmaY])` 用高斯权重，中心权重大、远处权重小；`ksize` 必须为正奇数，`sigma<=0` 时可由核大小推导。`cv.medianBlur(src, ksize)` 取邻域中位数，适合孤立脉冲点，`ksize` 是大于 1 的奇数。`cv.bilateralFilter(src, d, sigmaColor, sigmaSpace)` 同时考虑空间距离和颜色差异，能保边去噪但慢；`d=5` 常用于实时，`d=9` 适合离线强滤波，过大的 `sigmaColor` 会卡通化。

```python
mean5 = cv.blur(bgr, (5, 5))
gauss5 = cv.GaussianBlur(bgr, (5, 5), sigmaX=1.2)
median3 = cv.medianBlur(bgr, 3)
bilateral = cv.bilateralFilter(bgr, 7, 50, 50)
```

## 5. 梯度：Sobel、Scharr、Laplacian

梯度描述亮度变化率，是边缘检测和 Canny 的基础。`cv.Sobel(src, ddepth, dx, dy, ksize=3, scale=1, delta=0, borderType=...)` 计算 x/y 导数。`dx=1,dy=0` 对垂直边敏感，`dx=0,dy=1` 对水平边敏感。Sobel 结合平滑和差分，比直接差分抗噪。8 位输出会截断负梯度，常用 `CV_16S` 或 `CV_32F` 中间结果。

Scharr 是 3x3 一阶导数的改进核，`cv.Scharr(src, ddepth, dx, dy)` 等价于 `Sobel(..., ksize=cv.FILTER_SCHARR)`，小核下方向精度更好。Laplacian 计算二阶导数，`cv.Laplacian(src, ddepth, ksize)` 对边缘和细噪声都敏感，通常先轻微高斯平滑。

```python
gray_blur = cv.GaussianBlur(gray, (3, 3), 0)
gx = cv.Sobel(gray_blur, cv.CV_32F, 1, 0, ksize=3)
gy = cv.Sobel(gray_blur, cv.CV_32F, 0, 1, ksize=3)
mag8 = cv.normalize(cv.magnitude(gx, gy), None, 0, 255, cv.NORM_MINMAX).astype("uint8")
scharr_x = cv.Scharr(gray, cv.CV_32F, 1, 0)
lap = cv.Laplacian(gray_blur, cv.CV_32F, ksize=3)
```

## 6. Canny 边缘检测

Canny 是边缘流水线：高斯平滑降噪，计算梯度幅值和方向，非极大值抑制把粗边压细，最后用双阈值和滞后连接保留可靠边缘。Python API 为 `cv.Canny(image, threshold1, threshold2[, edges[, apertureSize[, L2gradient]]])`，C++ 为 `cv::Canny(image, edges, threshold1, threshold2, apertureSize, L2gradient)`。

`threshold2` 是强边缘阈值，`threshold1` 是弱边缘阈值；弱边缘只有与强边缘连通时保留。常用比例 `1:2` 或 `1:3`。`apertureSize` 是 Sobel 核大小，通常 3；噪声大时先外部 `GaussianBlur`。`L2gradient=False` 用 `|Gx|+|Gy|`，快；`True` 用欧氏幅值，更准但略慢。Canny 输入通常是 8 位单通道图。

```python
blurred = cv.GaussianBlur(gray, (5, 5), 1.2)
edges = cv.Canny(blurred, 60, 180, apertureSize=3, L2gradient=True)
```

阈值经验：边缘断裂时降低低阈值或减少平滑；噪声边太多时提高高阈值或增加平滑；目标边缘弱时先做 CLAHE 或亮度归一化。

## 7. 阈值、Otsu 与自适应阈值

阈值把灰度图转为二值图。`cv.threshold(src, thresh, maxval, type)` 返回 `(retval, dst)`；C++ 为 `double cv::threshold(src, dst, thresh, maxval, type)`。基本类型包括 `THRESH_BINARY`、`THRESH_BINARY_INV`、`THRESH_TRUNC`、`THRESH_TOZERO`、`THRESH_TOZERO_INV`。形态学和轮廓流程通常让前景为白、背景为黑。

Otsu 是 `type` 的附加标志：`cv.THRESH_BINARY | cv.THRESH_OTSU`。传入的 `thresh` 会被自动阈值替代，返回值 `retval` 是计算阈值。Otsu 适合前景/背景近似双峰的图；光照不均、背景渐变或目标比例极小时常失败。OpenCV 5 文档说明 Otsu 当前用于 `CV_8UC1` 和 `CV_16UC1`，Triangle 用于 `CV_8UC1`。

自适应阈值 `cv.adaptiveThreshold(src, maxValue, adaptiveMethod, thresholdType, blockSize, C)` 为每个像素按局部邻域算阈值。`MEAN_C` 用均值减 `C`，`GAUSSIAN_C` 用高斯加权均值减 `C`；`blockSize` 必须是 3、5、7... 的奇数，越大越接近全局阈值，越小越易跟随噪声。`C` 变大时局部阈值降低：对 `THRESH_BINARY` 会让更多像素为白，对 `THRESH_BINARY_INV` 则会让更少像素为白。

```python
_, binary = cv.threshold(gray, 120, 255, cv.THRESH_BINARY)
otsu_t, otsu = cv.threshold(gray, 0, 255, cv.THRESH_BINARY | cv.THRESH_OTSU)
adapt = cv.adaptiveThreshold(gray, 255, cv.ADAPTIVE_THRESH_GAUSSIAN_C,
                             cv.THRESH_BINARY, 31, 5)
```

## 8. 直方图、均衡化与 CLAHE

直方图统计每个灰度或颜色区间有多少像素。`cv.calcHist(images, channels, mask, histSize, ranges)` 观察亮度分布；`cv.equalizeHist(gray)` 用累积分布函数重映射灰度，让动态范围更充分。C++ API 是 `cv::calcHist(...)` 与 `cv::equalizeHist(src, dst)`。全局均衡化只接受单通道 8 位灰度图；彩色图更推荐转到 YCrCb/Lab，只处理亮度通道。

CLAHE 是受限自适应直方图均衡化：`cv.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))` 后 `apply(gray)`。它分块增强，并用 `clipLimit` 限制噪声放大。`tileGridSize` 越小局部对比越强、块感越明显；`clipLimit` 越大增强越强、暗部噪声越明显。

```python
hist = cv.calcHist([gray], [0], None, [256], [0, 256])
eq = cv.equalizeHist(gray)

ycrcb = cv.cvtColor(bgr, cv.COLOR_BGR2YCrCb)
y, cr, cb = cv.split(ycrcb)
clahe = cv.createCLAHE(2.0, (8, 8))
y2 = clahe.apply(y)
enhanced = cv.cvtColor(cv.merge([y2, cr, cb]), cv.COLOR_YCrCb2BGR)
```

## 9. 形态学：结构元素与基本操作

形态学用结构元素滑动图像，以邻域最大值或最小值重写像素，常用于二值图，也可用于灰度图。结构元素由 `cv.getStructuringElement(shape, ksize[, anchor])` 生成，形状包括 `MORPH_RECT`、`MORPH_CROSS`、`MORPH_ELLIPSE`，OpenCV 5 还列出 `MORPH_DIAMOND`。矩形核作用最强；十字核更保留水平/垂直骨架；椭圆核适合圆形颗粒。核越大、`iterations` 越多，操作越激进。

`cv.erode(src, kernel)` 腐蚀，取覆盖区域最小值：白色前景收缩，孤立白噪声消失，细线可能断裂。`cv.dilate(src, kernel)` 膨胀，取最大值：白色前景扩大，小黑洞变小，邻近目标可能粘连。形态学默认 `BORDER_CONSTANT`，边界值使用 `morphologyDefaultBorderValue()`。

复合操作由 `cv.morphologyEx(src, op, kernel)` 完成。开运算 `MORPH_OPEN` 先腐蚀后膨胀，去小白噪点；闭运算 `MORPH_CLOSE` 先膨胀后腐蚀，填小黑洞、连断笔；形态学梯度 `MORPH_GRADIENT` 是膨胀减腐蚀；顶帽 `MORPH_TOPHAT` 是原图减开运算，突出小亮结构；黑帽 `MORPH_BLACKHAT` 是闭运算减原图，突出暗裂缝或暗文字。

```python
kernel3 = cv.getStructuringElement(cv.MORPH_RECT, (3, 3))
eroded = cv.erode(binary, kernel3, iterations=1)
dilated = cv.dilate(binary, kernel3, iterations=1)
opened = cv.morphologyEx(binary, cv.MORPH_OPEN, kernel3)
closed = cv.morphologyEx(binary, cv.MORPH_CLOSE, kernel3, iterations=2)
outline = cv.morphologyEx(binary, cv.MORPH_GRADIENT, kernel3)
tophat = cv.morphologyEx(gray, cv.MORPH_TOPHAT,
                         cv.getStructuringElement(cv.MORPH_RECT, (25, 1)))
```

## 10. 二值图预处理流水线

实用流程：读图转灰度；按光照做归一化或 CLAHE；按噪声选高斯/中值/双边滤波；选择全局阈值、Otsu 或自适应阈值；确认前景白、背景黑；用开运算去孤立点，闭运算补断裂；最后用面积、长宽比、连通域或轮廓筛误检。不要一开始堆很多操作，每一步都应能解释要去掉哪类错误。

```python
import cv2 as cv
import numpy as np

def preprocess_document(path: str) -> np.ndarray:
    bgr = cv.imread(path, cv.IMREAD_COLOR)
    if bgr is None:
        raise FileNotFoundError(path)

    gray = cv.cvtColor(bgr, cv.COLOR_BGR2GRAY)

    clahe = cv.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
    norm = clahe.apply(gray)
    blur = cv.GaussianBlur(norm, (3, 3), 0)

    bw = cv.adaptiveThreshold(blur, 255,
                              cv.ADAPTIVE_THRESH_GAUSSIAN_C,
                              cv.THRESH_BINARY_INV,
                              blockSize=31, C=7)

    dot_kernel = cv.getStructuringElement(cv.MORPH_RECT, (2, 2))
    link_kernel = cv.getStructuringElement(cv.MORPH_RECT, (3, 3))
    clean = cv.morphologyEx(bw, cv.MORPH_OPEN, dot_kernel, iterations=1)
    clean = cv.morphologyEx(clean, cv.MORPH_CLOSE, link_kernel, iterations=1)
    return clean

mask = preprocess_document("input.jpg")
cv.imwrite("binary.png", mask)
```

关键 C++ API 对照：

```cpp
#include <opencv2/imgproc.hpp>
#include <opencv2/imgcodecs.hpp>

cv::Mat bgr = cv::imread("input.jpg", cv::IMREAD_COLOR);
cv::Mat gray, blur, edges, binary;
cv::cvtColor(bgr, gray, cv::COLOR_BGR2GRAY);
cv::GaussianBlur(gray, blur, cv::Size(5, 5), 1.2, 0, cv::BORDER_DEFAULT);
cv::Canny(blur, edges, 60, 180, 3, true);

double t = cv::threshold(gray, binary, 0, 255,
                         cv::THRESH_BINARY | cv::THRESH_OTSU);
cv::Mat kernel = cv::getStructuringElement(cv::MORPH_RECT, cv::Size(3, 3));
cv::morphologyEx(binary, binary, cv::MORPH_OPEN, kernel);

cv::Ptr<cv::CLAHE> clahe = cv::createCLAHE(2.0, cv::Size(8, 8));
cv::Mat enhanced;
clahe->apply(gray, enhanced);
```

## 11. 参数选择速查

| 操作 | 首调参数 | 变大后的效果 | 常见起点 |
| --- | --- | --- | --- |
| `resize` | `interpolation` | 质量/速度/类别保持不同 | 缩小 `AREA`，放大 `LINEAR/CUBIC`，mask `NEAREST` |
| `GaussianBlur` | `ksize`, `sigmaX` | 去噪更强、边缘更软 | `(3,3)` 或 `(5,5)` |
| `medianBlur` | `ksize` | 去椒盐更强、小结构更易消失 | `3` |
| `Canny` | `threshold1/2` | 阈值高边少，低阈值低连通多 | `60/180` 或按梯度分位数 |
| `adaptiveThreshold` | `blockSize`, `C` | 块大更接近全局；C 变大时 `THRESH_BINARY` 白像素通常增多，`THRESH_BINARY_INV` 白像素通常减少 | `31, 5..10` |
| `CLAHE` | `clipLimit`, `tileGridSize` | 增强更强，噪声/块感更明显 | `2.0, (8,8)` |
| `erode/dilate` | `kernel`, `iterations` | 形态改变更激进 | 目标最小结构的 1/2 到 1 倍 |
| `morphologyEx` | `op`, `kernel shape` | 决定去点、补洞、提轮廓方向 | 开去小白点，闭补小黑洞 |

## 12. 常见失败模式

1. BGR 当 RGB 使用：颜色阈值和显示都异常。先确认 `imread`、显示库和模型输入约定。
2. mask 用线性缩放：二值图有灰边，标签图有非法类别。mask 优先 `INTER_NEAREST`。
3. 8 位图直接存梯度：负数被截断。梯度中间结果用 `CV_16S`/`CV_32F`。
4. Otsu 用在光照不均图：背景渐变导致误分。改用 CLAHE、背景校正或自适应阈值。
5. 自适应 `blockSize` 太小：阈值跟着噪声走。窗口应大于目标笔画宽度数倍。
6. 形态学核过大：字符粘连、细线断裂。核大小从最小孔洞、间隙和噪点尺度反推。
7. 双边滤波过强：边缘保住但区域卡通化。只在保边平滑必要时使用。
8. 均衡化放大噪声：暗部颗粒被增强。优先 CLAHE 并限制 `clipLimit`。

## 13. 练习

1. 转 HSV、Lab、YCrCb，比较只增强亮度通道与分别增强 BGR 三通道的差异。
2. 构造高斯噪声和椒盐噪声，比较 `GaussianBlur`、`medianBlur`、`bilateralFilter` 的边缘清晰度和时间。
3. 用 `Sobel` 和 `Scharr` 检测细斜线，比较 3x3 核下方向响应。
4. 固定 Canny 高阈值，逐步降低低阈值，观察弱边缘连接和噪声边缘。
5. 对光照不均文档图比较 Otsu 与自适应阈值，调节 `blockSize` 与 `C`。
6. 用 `(25,1)` 矩形核开运算提取横线，并解释它为何压制竖线和小点。

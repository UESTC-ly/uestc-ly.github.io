# 第 3 章：轮廓、形状与几何变换

本章讨论轮廓提取、层级、形状度量、匹配、仿射、透视、单应性和重映射。除特别说明外，API 以 OpenCV 5.0 为准；OpenCV 4.12 常用 Python/C++ 调用基本一致，主要差别是 5.x 文档中部分 shape 函数归入 geometry 模块，且 warp 文档多了 `AlgorithmHint` 参数。

## 1. 二值图是轮廓分析的前提

`cv.findContours` 查找的是二值图中的连通边界，而不是颜色相近的区域。官方定义中，输入通常是 8 位单通道图像，非零像素被当作 1，零像素仍为 0。因此工程流程一般是：

1. `cvtColor` 得到灰度图。
2. 用 `threshold`、`adaptiveThreshold`、`inRange` 或 `Canny` 得到二值/边缘图。
3. 必要时用开运算去小噪声、闭运算补断裂。
4. 再调用 `findContours`。

坐标顺序要记住两套写法：数组索引是 `img[y, x]`，点坐标是 `(x, y)`。`shape` 返回 `(height, width)`，而 warp 的 `dsize` 是 `(width, height)`。

轮廓点本质上是二维点列。Python 中常见形状是 `(N, 1, 2)`，最后一维是 `[x, y]`；C++ 中通常是 `std::vector<cv::Point>`。轮廓只描述边界，不等于填充后的所有像素。`contourArea` 用 Green 公式算面积；自交轮廓通常不可靠。

## 2. `findContours`：返回值、层级与检索模式

Python 调用：

```python
contours, hierarchy = cv.findContours(binary, cv.RETR_TREE, cv.CHAIN_APPROX_SIMPLE)
```

OpenCV 3.2 以后，`findContours` 不再修改源图；4.12 与 5.0 都可按这一点使用。Python 的 `hierarchy` 外面多包一层，访问第 `i` 个轮廓应写 `hierarchy[0][i]`。每个层级元素是 `[next, previous, first_child, parent]`，都是 `contours` 中的 0 基索引；没有对应关系时为负数。

检索模式决定保留哪些轮廓以及是否建立拓扑关系：`RETR_EXTERNAL` 只取最外层；`RETR_LIST` 取全部但不建父子关系；`RETR_CCOMP` 建两层结构，外边界一层、洞一层；`RETR_TREE` 重建完整嵌套树；`RETR_FLOODFILL` 可配合 32 位标签图。近似模式决定点列压缩：`CHAIN_APPROX_NONE` 存所有相邻边界点，`CHAIN_APPROX_SIMPLE` 压缩直线段只留端点，`CHAIN_APPROX_TC89_L1/KCOS` 使用 Teh-Chin 近似。

从 ROI 中查轮廓时，可用 `offset=(roi_x, roi_y)` 把点平移回整图坐标，避免后续矩形和透视点落在局部坐标系。

## 3. 面积、周长、矩与质心

轮廓面积：

```python
area = cv.contourArea(cnt, oriented=False)
signed_area = cv.contourArea(cnt, oriented=True)
```

`oriented=True` 返回有符号面积，可用符号判断点序方向。但要注意 OpenCV 图像坐标的 y 轴向下，而很多几何教材默认 y 轴向上；因此“顺/逆时针”的直觉可能相反。自交轮廓、点数太少、边界锯齿非常强时，面积不是稳定指标。

周长/弧长：

```python
peri = cv.arcLength(cnt, closed=True)
```

`closed=True` 表示最后一个点与第一个点也算一条边。边缘断裂时设为 `True` 会把断口直接连起来，周长可能偏大或偏小；先做闭运算或检查首尾距离更稳。

矩提供形状的积分量。几何矩可理解为对区域内像素坐标的加权和：`m00` 对应面积，`m10/m00` 与 `m01/m00` 给质心。

```python
M = cv.moments(cnt)
if abs(M["m00"]) > 1e-6:
    cx = M["m10"] / M["m00"]
    cy = M["m01"] / M["m00"]
else:
    cx, cy = np.mean(cnt.reshape(-1, 2), axis=0)
```

退化条件是 `m00` 接近 0，例如轮廓只有一条线、点重复、自交抵消或阈值结果极薄。此时应回退到点均值或外接矩形中心，并把目标标为低置信度。

## 4. 外接矩形、最小外接矩形与外接圆

正外接矩形：

`x, y, w, h = cv.boundingRect(cnt)`。它与坐标轴对齐，速度快、鲁棒，但不能表达旋转角。`x, y` 是左上角，ROI 裁剪写 `img[y:y+h, x:x+w]`。

最小外接旋转矩形：

```python
rect = cv.minAreaRect(cnt)             # ((cx, cy), (w, h), angle)
box = cv.boxPoints(rect).astype(np.int32)
```

`minAreaRect` 返回 `RotatedRect`，包含中心、尺寸和角度。角度在长宽交换时容易跳变，不宜当成绝对稳定的物体朝向。做文档矫正时更可靠的方法是用 `boxPoints` 得到四个角，再自行排序为左上、右上、右下、左下。

最小外接圆：

`(cx, cy), radius = cv.minEnclosingCircle(cnt)`。圆对旋转不敏感，适合硬币、孔、圆形标记；但对离群点敏感。项目中常用面积、圆度 `4*pi*area/peri**2`、半径范围和边缘支持点比例联合筛选。

## 5. 多边形逼近、凸包与凸缺陷

`approxPolyDP` 使用 Douglas-Peucker 思路，用距离阈值 `epsilon` 保留能代表原轮廓的少量点：

```python
peri = cv.arcLength(cnt, True)
approx = cv.approxPolyDP(cnt, epsilon=0.02 * peri, closed=True)
```

`epsilon` 越大，顶点越少；过小会留下锯齿，过大会吞掉真实角点。文档扫描常尝试 `0.01~0.04 * perimeter`，得到 4 个点才进入透视矫正。常见退化是面积过小、边缘断裂、阴影形成比纸张更大的外框。

凸包是包含所有点的最小凸多边形：

```python
hull_pts = cv.convexHull(cnt, clockwise=False, returnPoints=True)
hull_idx = cv.convexHull(cnt, returnPoints=False)
```

OpenCV 5 文档中 `convexHull` 位于 geometry/2d 说明；4.12 常见代码包含 `opencv2/imgproc.hpp` 也能使用。`clockwise` 的方向说明基于 x 向右、y 向上的坐标系；图像显示坐标 y 向下，所以可视化时要谨慎解释。凸包不支持原地输入输出。

凸缺陷描述轮廓偏离凸包的凹陷。它要求传入“凸包点索引”，不是凸包点坐标：

```python
hull_idx = cv.convexHull(cnt, returnPoints=False)
defects = cv.convexityDefects(cnt, hull_idx)
if defects is not None:
    for s, e, f, depth256 in defects[:, 0]:
        start = tuple(cnt[s, 0])
        end = tuple(cnt[e, 0])
        far = tuple(cnt[f, 0])
        depth = depth256 / 256.0
```

四元组分别是起点索引、终点索引、最远凹点索引、8 位小数固定点深度。手势识别中常用深度和夹角过滤指缝，但它对阈值、遮挡和手腕裁剪极敏感，不能只数 defects 就决定手指数。

## 6. 形状匹配与 Hu 矩

`cv.matchShapes` 比较两个轮廓或灰度图，三种方法都基于 Hu 不变矩：

`score = cv.matchShapes(cnt_a, cnt_b, cv.CONTOURS_MATCH_I1, 0.0)`。分数越小越相似。Hu 矩对平移、尺度、旋转有较好不变性，但仍受噪声、遮挡、局部缺口和镜像影响。实际使用应在同一预处理流程中采集正负样本，再结合面积比、长宽比、凸性、角点数过滤。

## 7. Hough 直线与圆

Hough 变换把图像空间里的点投票到参数空间。直线常写成极坐标形式：

```text
rho = x cos(theta) + y sin(theta)
```

`rho` 是线到左上角原点 `(0,0)` 的距离，`theta` 是弧度。OpenCV 文档中 `theta=0` 近似垂直线，`theta=pi/2` 近似水平线。

```python
edges = cv.Canny(gray, 50, 150)
lines = cv.HoughLines(edges, rho=1, theta=np.pi/180, threshold=120)
segments = cv.HoughLinesP(edges, 1, np.pi/180, 60,
                          minLineLength=80, maxLineGap=10)
```

`HoughLines` 输出 `(rho, theta)` 或带 votes 的向量，适合估计全局方向；`HoughLinesP` 输出线段端点 `(x1, y1, x2, y2)`，适合画线和测量长度。阈值过低会有重复线，过高会漏检。

圆的参数是 `(x_center, y_center, radius)`，完整三维投票代价高，OpenCV 使用 Hough Gradient 方法：

```python
blur = cv.medianBlur(gray, 5)
circles = cv.HoughCircles(blur, cv.HOUGH_GRADIENT, dp=1.2, minDist=30,
                          param1=100, param2=30,
                          minRadius=10, maxRadius=80)
```

`param1` 通常传给内部 Canny 的高阈值，`param2` 是圆心累加器阈值，越小越容易检出也越容易误检。`minDist` 防止同一圆附近出现多个圆心。强反光、圆弧缺失、半径范围过宽都会让结果不稳定。

## 8. 仿射、透视、单应性与矩阵

仿射变换保留直线和平行关系，可表达平移、旋转、缩放、剪切。矩阵是 2x3：

```text
[x']   [a00 a01 b0] [x]
[y'] = [a10 a11 b1] [y]
                      [1]
```

三个不共线点对可以确定一个仿射矩阵：

```python
src3 = np.float32([[0, 0], [w - 1, 0], [0, h - 1]])
dst3 = np.float32([[20, 30], [w - 40, 10], [30, h - 20]])
M = cv.getAffineTransform(src3, dst3)
warped = cv.warpAffine(img, M, (w, h), flags=cv.INTER_LINEAR,
                       borderMode=cv.BORDER_CONSTANT, borderValue=(0, 0, 0))
```

三点共线或几乎共线时矩阵退化。可检查三角形面积 `abs(cross(p1-p0, p2-p0))` 是否足够大。

透视变换可表达平面在针孔相机下的投影。矩阵是 3x3，齐次坐标写法为：

```text
[t x']   [h00 h01 h02] [x]
[t y'] = [h10 h11 h12] [y]
[t   ]   [h20 h21 h22] [1]
```

四个对应点可由 `getPerspectiveTransform` 求矩阵；多于四个点且有外点时，用 `findHomography` 配合 RANSAC 更鲁棒。四点不能三点共线，四边形面积不能接近 0，点顺序必须一致。常用顺序是左上、右上、右下、左下。

`warpAffine` 与 `warpPerspective` 的核心是反向采样：对目标图每个像素找到源图位置再插值。设置 `WARP_INVERSE_MAP` 时，传入矩阵被视为目标到源的逆映射；不设置时函数会先求逆再采样。两者都不能原地操作。

`remap` 是更一般的映射：直接提供每个目标像素去源图采样的 `map_x/map_y`，常用于鱼眼校正、波浪变形和标定查表。

```python
yy, xx = np.indices((h, w), dtype=np.float32)
map_x = xx + 10 * np.sin(yy / 30.0)
map_y = yy
dst = cv.remap(img, map_x, map_y, interpolation=cv.INTER_LINEAR,
               borderMode=cv.BORDER_REFLECT101)
```

插值和边界会影响视觉质量：`INTER_NEAREST` 快但锯齿明显，`INTER_LINEAR` 是默认平衡，`INTER_CUBIC/LANCZOS4` 更平滑但慢；`BORDER_CONSTANT` 常数填充，`BORDER_REPLICATE` 复制边缘，`BORDER_REFLECT101` 镜像反射。5.x 的 warp 文档出现 `AlgorithmHint hint` 参数；4.12 常见 Python 调用通常不用。

## 9. 文档扫描案例

目标：从拍斜照片得到俯视、裁正的文档图。流程如下：

1. 灰度化、降噪、边缘检测。
2. 找外部轮廓，按面积从大到小排序。
3. 对大轮廓做多边形逼近，找到四边形候选。
4. 对四点按左上、右上、右下、左下排序。
5. 根据边长估计输出宽高。
6. 求透视矩阵并 `warpPerspective`。
7. 对结果做自适应阈值或亮度校正。

完整 Python 示例：

```python
import cv2 as cv
import numpy as np


def order_quad(pts):
    pts = pts.reshape(4, 2).astype("float32")
    s = pts.sum(axis=1)
    d = np.diff(pts, axis=1).reshape(-1)
    return np.float32([
        pts[np.argmin(s)], pts[np.argmin(d)],
        pts[np.argmax(s)], pts[np.argmax(d)]
    ])


def scan_document(path):
    img = cv.imread(path)
    if img is None:
        raise FileNotFoundError(path)

    scale = min(1.0, 1200 / max(img.shape[:2]))
    small = cv.resize(img, None, fx=scale, fy=scale, interpolation=cv.INTER_AREA)
    gray = cv.cvtColor(small, cv.COLOR_BGR2GRAY)
    gray = cv.GaussianBlur(gray, (5, 5), 0)
    edges = cv.Canny(gray, 50, 150)
    edges = cv.morphologyEx(edges, cv.MORPH_CLOSE, np.ones((5, 5), np.uint8))

    contours, _ = cv.findContours(edges, cv.RETR_EXTERNAL, cv.CHAIN_APPROX_SIMPLE)
    page = None
    for cnt in sorted(contours, key=cv.contourArea, reverse=True)[:10]:
        if cv.contourArea(cnt) < 0.15 * small.shape[0] * small.shape[1]:
            break
        peri = cv.arcLength(cnt, True)
        approx = cv.approxPolyDP(cnt, 0.02 * peri, True)
        if len(approx) == 4 and cv.isContourConvex(approx):
            page = approx
            break

    if page is None:
        raise RuntimeError("no document-like quadrangle found")

    quad = order_quad(page) / scale
    tl, tr, br, bl = quad
    width = int(round(max(np.linalg.norm(br - bl), np.linalg.norm(tr - tl))))
    height = int(round(max(np.linalg.norm(tr - br), np.linalg.norm(tl - bl))))
    if width < 20 or height < 20 or abs(cv.contourArea(quad.reshape(-1, 1, 2))) < 100:
        raise RuntimeError("degenerate quadrangle")

    dst_quad = np.float32([[0, 0], [width - 1, 0],
                           [width - 1, height - 1], [0, height - 1]])
    H = cv.getPerspectiveTransform(quad, dst_quad)
    return cv.warpPerspective(img, H, (width, height),
                              flags=cv.INTER_LINEAR,
                              borderMode=cv.BORDER_REPLICATE)


if __name__ == "__main__":
    cv.imwrite("paper_scanned.png", scan_document("paper.jpg"))
```

关键 C++ 对照。下面假定已包含 `opencv2/imgproc.hpp`，并已使用 `cv::` 前缀或 `using namespace cv;`：

```cpp
std::vector<std::vector<Point>> contours;
findContours(edges, contours, RETR_EXTERNAL, CHAIN_APPROX_SIMPLE);
std::vector<Point2f> src{{120,80}, {900,110}, {940,1300}, {80,1280}};
std::vector<Point2f> dst{{0,0}, {799,0}, {799,1099}, {0,1099}};
Mat H = getPerspectiveTransform(src, dst);
warpPerspective(img, warped, H, Size(800, 1100), INTER_LINEAR, BORDER_REPLICATE);
```

示例里的 C++ 只突出 API 对照；真实代码必须从轮廓得到四点并排序。

## 10. API 速查表

| API | 输出/要点 |
| --- | --- |
| `findContours` | `contours, hierarchy`；Python 层级用 `hierarchy[0][i]` |
| `drawContours` | 画轮廓或填充；有洞时层级很重要 |
| `contourArea` / `arcLength` | 面积、周长；自交轮廓不可靠 |
| `moments` | 矩和质心；质心需检查 `m00` |
| `boundingRect` / `minAreaRect` / `boxPoints` | 正矩形、旋转矩形和 4 角点 |
| `minEnclosingCircle` | 圆心、半径；对离群点敏感 |
| `approxPolyDP` | 多边形近似；`epsilon` 常按周长比例给 |
| `convexHull` / `convexityDefects` | 凸包和凹陷；缺陷深度为 `fixpt_depth/256.0` |
| `matchShapes` | Hu 矩相似度；越小越相似 |
| `HoughLines` / `HoughLinesP` | 极坐标线或线段端点 |
| `HoughCircles` | `(x,y,r)`；先平滑并限制半径 |
| `getAffineTransform` / `warpAffine` | 3 点求 2x3 矩阵；`dsize=(w,h)` |
| `getPerspectiveTransform` / `warpPerspective` | 4 点求 3x3 矩阵；点顺序一致 |
| `findHomography` | 多点单应性，可用 RANSAC 抗外点 |
| `remap` | `map_x/map_y` 直接给目标到源的采样坐标 |

## 11. 常见错误场景

常见问题包括：彩色图直接传给 `findContours`；前景/背景反导致整图外框被当作轮廓；用 `RETR_EXTERNAL` 却想分析孔洞；忘记 Python 的 `hierarchy[0][i]`；`convexityDefects` 传入凸包点而不是索引；质心计算未检查 `m00`；`dsize` 写成 `(height,width)`；四点未排序就透视；Hough 参数只在单张图上调好；对自交轮廓计算面积和 Hu 矩。对应修复是先看二值图、非零比例、层级、点序和退化断言。

## 12. 调试步骤

保存灰度、二值、轮廓覆盖、候选四边形、最终 warp 图。打印尺寸、非零比例、轮廓数、最大面积、顶点数、`hierarchy`、输出宽高。断言面积、边长、点重复和矩阵 NaN/Inf。最后画出 TL/TR/BR/BL；排序错时通常会交叉。

## 13. 练习

练习：用 `RETR_TREE` 分析 0、6、8 的孔洞；比较 `CHAIN_APPROX_NONE/SIMPLE` 的点数、面积、周长；用面积、圆度、外接圆和 Hough 圆过滤零件；实现书页扫描并标角点；构造近共线三点观察 `warpAffine` 退化；用 `remap` 做波浪并比较插值和边界。

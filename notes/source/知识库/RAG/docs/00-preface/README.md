# 00 前言：开始之前

这一部分不要求你已经学过人工智能、机器学习或 RAG。它只做三件事：帮助你选对学习
路线，确认当前环境足以完成后续练习，并建立最基本的安全与诚实边界。

| 章节 | 你要解决的问题 | 完成标志 |
|---|---|---|
| [00-01 如何使用本教程](01-how-to-use-this-tutorial.md) | 先读什么、什么时候动手、怎样判断自己真的学会了 | 能为自己选一条主线，并说清每一步要留下什么证据 |

## 建议路线

第一次学习时，按 `00-01 → 00-02 → 00-03 → 00-04 → 00-05` 阅读。完成前言后再进入
基础知识和 RAG 原理，不必先安装向量数据库、在线模型 SDK 或任何付费服务。

如果你已经熟悉 Python，也不要跳过 00-02 和 00-05。会写代码不等于知道某个结论的
证据等级，也不等于自动具备安全默认值。如果环境检查失败，先回到 00-03 选择补救
路线，不要一次性安装大量工具来“碰碰运气”。

完成本章后，你应该能够：

- 判断自己在文件、命令行、Python、JSON/HTTP 和数学直觉上的准备程度；
- 把“我基础不好”改写成一个可以补救的具体缺口；
- 选择继续主线、边学边补或先补基础三种路线之一；
- 避免为了开始学习而一次性安装大量非必要工具。

## 准备度检查不是入学考试

你不需要先成为 Python 工程师，也不需要先学完线性代数。准备度检查的作用是提前发现
会阻塞下一步的最小缺口。

“我不会 RAG”不是问题，因为教程就是用来学习 RAG 的；“我不知道终端当前在哪个
目录，因此找不到示例文件”才是一个需要先解决的具体问题。

把每项标成下面三种状态之一：

- **绿**：能独立完成并解释结果；
- **黄**：看提示后能完成，但还不稳定；
- **红**：不知道从哪里开始，或无法判断结果是否正确。

黄色不阻止你继续。红色只在它属于下一章的硬前置时才需要先补救。

## 一、文件和路径

你需要知道文件、文件夹和路径不是同一个概念，并能回答：

1. 当前教程仓库保存在哪个文件夹？
2. `docs/00-preface/` 是从仓库根目录开始的相对路径，还是操作系统中的任意位置？
3. 终端提示“文件不存在”时，怎样先检查当前目录？
4. 文件名大小写是否可能在不同系统上表现不同？

最小练习：在文件管理器中找到本章文件，再从本章返回 `docs/README.md`。如果你能说清
“当前文件—部分目录—文档总索引”三层关系，这一项就是绿色。

常见误区是照抄一条命令，却没有先进入命令要求的目录。后续教程出现命令时，应先看
代码块前的“从哪个目录运行”说明。

## 二、终端和命令

终端是向操作系统提交命令并读取文本结果的工具。Windows 常见 PowerShell，macOS 和
Linux 常见兼容 POSIX 的 shell。它们的路径分隔、激活虚拟环境方式和部分命令不同。

你暂时只需要做到：

- 打开终端；
- 查看当前目录；
- 列出目录中的文件；
- 运行一条 Python 命令；
- 复制完整错误信息，而不是只截取最后一句。

不知道某个 shell 命令并不等于不能学习。关键是识别教程给出的代码块标记：
`bash` 命令不要原样当成 PowerShell 语法；`powershell` 命令也不要直接粘贴到 bash。

## 三、Python 最低能力

本教程的目标兼容 Python 3.11 或更高兼容版本。进入代码主线前，你需要能阅读下面这段
程序，而不是立刻写出复杂类和算法：

```python
question = "怎样重置密码？"
candidates = ["重置密码说明", "请假流程"]

for position, text in enumerate(candidates, start=1):
    print(position, text)
```

你应该能指出：

- `question` 保存一个字符串；
- `candidates` 保存两个候选文本；
- `for` 循环依次取出候选；
- `print` 产生可以观察的输出。

如果你完全看不懂，先补变量、字符串、列表、循环、函数和异常的最小基础。如果大致
能懂但写不出来，可以继续主线，在每次示例前补齐对应知识。早期章节不会要求你训练
模型或实现复杂数学库。

## 四、JSON、HTTP 和 API 直觉

JSON 是一种常见的结构化文本格式。下面的内容表示一个问题和最多返回两个结果：

```json
{
  "question": "怎样重置密码？",
  "top_k": 2
}
```

你现在不需要记住完整规范，只需要看出键和值的对应关系，并知道字符串使用双引号。

HTTP 可以先理解为一套请求与响应约定，API 是程序之间约定好的操作入口。进入基础章后
会完整解释。当前准备度只检查你能否接受下面这个心智模型：客户端提交请求，服务端
返回状态和数据；超时、无权限和服务错误都是正常失败类型，不应被吞掉或伪装成成功。

如果 JSON 完全陌生，标黄色即可；如果你马上要进入依赖 API 的项目却无法区分请求和
响应，再先走基础补救路线。

## 五、数学只需要最小直觉

在第一次理解 RAG 时，你只需要知道“可以用一组数字表示对象，并用某种规则比较接近
程度”。暂时不要求推导向量、余弦相似度或概率公式。

下面的问题能用于自检：如果查询 A 与文档 1 的匹配分数是 0.8，与文档 2 是 0.2，
在其他条件相同且分数越高越相关的简化规则下，哪个候选排在前面？

能回答“文档 1”，并意识到“分数高不等于事实正确”，就足以进入直觉章节。公式推导
可以在后续按需补齐。

## 根据结果选择路线

| 结果 | 推荐路线 | 不建议做什么 |
|---|---|---|
| 文件、终端、Python 均为绿或黄 | 继续 00-04，再进入主线 | 为了追求“完美基础”无限推迟动手 |
| 只有 Python 为红 | 先补变量、列表、循环、函数和错误信息，再做 00-04 | 直接安装 RAG 框架来绕过 Python |
| 文件或终端为红 | 先练当前目录、相对路径和运行命令 | 在不知道目录时反复重装依赖 |
| JSON/HTTP 为红 | 可以先读离线概念章，在进入 API 项目前补基础 | 把所有网络错误都归咎于代码 |
| 数学为红 | 继续直觉主线，遇到相似度章节再补 | 先学完整高等数学才允许自己开始 |

## 自测

2. 为什么“数学为红”通常不阻止第一次建立 RAG 直觉？

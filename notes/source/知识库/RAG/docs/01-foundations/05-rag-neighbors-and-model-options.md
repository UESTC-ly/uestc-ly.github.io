完成本章后，你应该能够：

- 比较本地模型与云端模型的主要权衡，而不是只看模型名称；
- 区分 RAG、微调、长上下文和工具调用各自主要改变哪一部分；
- 说明这些方法可以组合，不能当成永远互斥的四选一；
- 根据知识变化、来源追溯、行为调整、实时动作和运维约束提出初步方案。

## 先问“问题在哪里”

假设客服助手总是答错新版退货规则。可能原因至少包括：

- 模型没有看到最新规则；
- 应用虽然提供了规则，但上下文太长或选错段落；
- 模型知道事实，却没有按规定格式回答；
- 问题需要查询当前订单状态，而不是阅读静态文档；
- 当前模型、硬件或网络无法满足延迟和隐私要求。

如果不先定位问题，就容易把“换更大的模型”当成唯一答案。技术选择应从数据、行为、
动作和约束出发。

## 本地模型与云端模型

**本地模型**通常指在自己控制的设备或环境中运行模型；**云端模型**通常通过远程服务
API 使用。两者不是绝对的安全与质量标签。

| 维度 | 本地运行要问 | 云端调用要问 |
|---|---|---|
| 数据 | 数据是否能留在受控环境，日志如何处理 | 哪些数据会发送，服务如何保留和处理 |
| 能力 | 当前硬件能否运行目标模型并达到任务质量 | 服务提供的模型是否满足任务与地区要求 |
| 延迟 | 加载、推理和并发是否可接受 | 网络往返、限流和服务波动是否可接受 |
| 成本 | 硬件、运维、电力和人员成本 | 调用、流量、配额和增长成本 |
| 更新 | 谁负责模型、驱动和依赖升级 | 服务版本变化怎样测试和回滚 |
| 可用性 | 单机故障与容量怎样处理 | 断网、超时和供应商故障怎样降级 |

本地不自动等于无泄露风险，云端也不自动等于不安全。结论取决于部署、合同、权限、
日志、配置和实际威胁模型。

## 四种方法主要改变什么

### RAG：改变当前请求可见的外部证据

RAG 先检索外部知识，再把选定内容交给回答步骤。它适合知识经常变化、需要回查来源或
资料不能全部写入参数的场景。它仍会受到检索失败、过期数据和生成误读影响，不能消除
幻觉。

### 微调：改变模型的参数化行为

微调（fine-tuning）使用任务样本继续训练模型，常用于调整格式、风格或特定行为模式。
它不天然适合作为频繁更新事实的数据库，也不自动提供逐条来源。训练数据、评估、成本
和遗忘风险都需要单独管理。

### 长上下文：扩大一次请求可放入的内容

长上下文允许一次提供更多文本，适合资料规模可控、需要跨较长内容分析的任务。但能放下
不等于能正确使用；噪声、位置、延迟和成本仍存在。资料很大或频繁更新时，先筛选再放入
通常仍有价值。

### 工具调用：让模型请求外部动作或结构化结果

工具调用让模型按约定请求搜索、数据库查询、计算或业务操作。它适合“查当前库存”“计算
税额”“创建工单”等需要实时数据或动作的任务。工具必须有参数校验、权限控制、超时和
副作用保护；模型提出调用不等于调用一定安全。

## 它们可以组合

一个订单助手可能同时：

1. 用 RAG 找到退货政策；
2. 调用订单工具查询当前状态；
3. 使用经过微调的模型稳定输出客服格式；
4. 在上下文中放入少量对话历史和检索证据；
5. 根据数据要求选择本地或云端部署。

所以正确问题不是“RAG 和微调谁赢”，而是“当前失败来自事实、行为、实时动作还是运行
约束，哪些组件各自负责”。

## 一个初步决策表

| 主要需求 | 优先调查 | 仍要验证的边界 |
|---|---|---|
| 文档频繁更新且要引用 | RAG | 检索质量、权限、来源是否支持答案 |
| 输出格式长期不稳定 | 提示与验证，必要时评估微调 | 训练样本代表性与新任务泛化 |
| 一次分析一份有限长文档 | 长上下文或分段处理 | 是否遗漏中间信息、成本和延迟 |
| 获取实时订单或执行动作 | 工具调用 | 授权、参数、幂等和副作用确认 |
| 数据不能离开受控环境 | 本地或符合要求的受控部署 | 硬件、维护、日志与模型质量 |
| 网络波动但必须继续服务 | 本地能力或明确降级路径 | 离线能力范围和数据同步 |

这张表只用于提出下一步实验，不替代安全、法律、成本和质量评审。

## 自测与实践

选择一个场景，例如“公司制度问答”或“个人笔记助手”，回答：

1. 知识多久变化一次，是否需要引用？
2. 任务主要是回答、改写格式，还是执行实时动作？
3. 数据能否发送到外部服务？
4. 可接受的延迟、费用和离线需求是什么？
5. 你会先做哪个最小实验，记录什么失败信号？

## 本章小结

本地与云端是运行位置和责任边界的选择；RAG 主要提供外部证据，微调主要调整参数化
行为，长上下文扩大一次请求的信息容量，工具调用连接实时数据与动作。它们可以组合，
选择前应先定位问题。

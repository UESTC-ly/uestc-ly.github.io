# 01 零基础必备知识

这一部分只补齐继续学习 RAG 所需的最低前置。你不需要先成为机器学习研究者、后端
工程师或运维专家；目标是看懂后续章节中的术语、数据和命令，并知道什么时候应该停下
来检查，而不是把不确定结果当成成功。

## 学完后你能做什么

- 说清 AI、机器学习、深度学习、大语言模型和 Transformer 的关系；
- 理解 Token、上下文窗口与提示词的基本限制；
- 读懂一个简单的 JSON 请求和 HTTP 响应；
- 使用 Python、虚拟环境、命令行和 Git 完成最低限度的本地操作；
- 区分本地模型与云端模型，并比较 RAG、微调、长上下文和工具调用；
- 用固定样本、相关性标签和简单指标记录一次可比较的实验。

01-01 至 01-03 建立术语和数据流直觉；01-04 是动手操作的最低准备；01-05 帮你避免
把不同技术当成互斥的万能选项；01-06 则让后续实验留下可以比较的证据。

本批次只交付教学正文，不声称计划中的演示脚本或图表已经实现、运行或渲染。正文中的
计算和静态示例用于建立直觉，后续可执行项目会另行提供运行证据。

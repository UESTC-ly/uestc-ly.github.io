# 08-02 章节摘要：使用大语言模型重排

- **本章新增知识：** LLM 可以按复杂文字标准为候选排序或分级，但需要以候选标识为中心的结构化协议、严格解析、语义评估和明确回退。
- **新术语：** 列表式重排、逐项评分、成对比较、结构化输出、位置偏差、弃权状态。
- **新代码接口：** 本批次不实现结构化打分适配器、解析器或攻击样例测试，也未调用具体 LLM 服务。
- **后续必须知道：** 格式正确不等于排序正确；候选文本是不可信数据，不能改变系统规则；权限过滤与数据最小化必须发生在外部调用前。
- **与其他章节的关联：** 在 [08-01](../../docs/08-reranking/01-why-rerank-bi-encoder-and-cross-encoder.md) 的两阶段边界上扩展可选 LLM 方法，并为 09 的上下文注入隔离预告风险。
- **未解决问题：** 模型、提示、列表大小、稳定性、数据处理条款、延迟、费用和失败预算需要实际评估。

# 03-02 章节摘要：PDF、OCR、图片与不可信文件

- **本章新增知识：** PDF 可能有文本层、扫描页或混合内容；OCR 是有误差的识别路径，不是原文的无损复制；外部文件需要隔离与资源限制。
- **新术语：** 文本层、光学字符识别（OCR）、分流、质量状态、隔离、资源上限。
- **新代码接口：** PDF 摄取示例、OCR 可选适配器、契约测试和分流图仍是后续计划。
- **后续必须知道：** 图片中的空间关系不一定能由 OCR 恢复；失败要区分策略拒绝、资源超限和解析错误；任何单一措施都不保证绝对安全。
- **与其他章节的关联：** 使用 [03-01](../../docs/03-data-ingestion/01-document-model-loaders-and-parsers.md) 的 Loader/Parser 边界，并继承 [00-05](../../docs/00-preface/05-security-baseline.md) 的不可信输入原则。
- **未解决问题：** 具体 OCR 引擎、质量阈值、沙箱实现与人工复核流程需按项目环境验证。

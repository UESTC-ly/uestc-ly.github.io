# 01-04 摘要：Python、虚拟环境、命令行与 Git

## 核心结论

- Python 解释器执行脚本；虚拟环境把当前项目的 Python 包与其他项目隔离。
- 命令在当前工作目录和特定 shell 中运行；先确认路径、版本和退出状态。
- `python -m pip` 可让 pip 明确跟随当前解释器；`.venv` 通常可以重建，不提交到 Git。
- Git 提交保存本地版本历史，不等于已经上传远端。

## 必须保留的边界

虚拟环境不隔离系统服务、驱动、网络或密钥；安装成功不等于项目已通过运行和测试；不要
用管理员权限掩盖不明原因的权限错误。

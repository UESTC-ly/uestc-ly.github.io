# 03-07 章节摘要：版本、增量更新与删除

- **本章新增知识：** 逻辑身份、来源版本、内容版本和处理/索引版本需要分开；增量更新依赖变更识别、幂等、检查点与可见的状态转换；删除必须传播到所有可查询派生物。
- **新术语：** 增量更新、检查点、幂等（idempotency）、当前版本切换、墓碑（tombstone）、知识撤回。
- **新代码接口：** 增量 diff、墓碑与撤回测试以及 D16 生命周期图仍是后续计划。
- **后续必须知道：** 权限变化可能不改变正文摘要；检查点只能在结果持久化后推进；临时读取失败不等于来源删除；缓存也是撤回范围的一部分。
- **与其他章节的关联：** 使用 [03-05](../../docs/03-data-ingestion/05-cleaning-encoding-and-deduplication.md) 的内容版本和 [03-06](../../docs/03-data-ingestion/06-metadata-permissions-and-provenance.md) 的血缘，将稳定输入交给后续切分与索引阶段。
- **未解决问题：** 具体存储的原子切换能力、事件顺序、备份保留与删除完成标准需要在系统设计中验证。

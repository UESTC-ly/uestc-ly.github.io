# 04-03 章节摘要：语义、父子与小块召回大块

- **本章新增知识：** 语义切分尝试寻找主题变化；父子切分让小子块负责聚焦检索、较大父块负责补足阅读上下文；小块召回大块描述查询后的显式范围扩展。
- **新术语：** 语义切分（semantic chunking）、父子切分（parent-child chunking）、小块召回大块（small-to-big retrieval）。
- **新代码接口：** 无已实现接口；本章给出父子标识、去重、预算和权限流程设计。
- **后续必须知道：** 语义变化不一定是正确边界；父块扩展必须重新满足权限和预算；相关性不代表真实、可信或授权。
- **与其他章节的关联：** 使用 [04-02](../../docs/04-chunking/02-structure-aware-and-recursive-chunking.md) 的结构范围建立父块，并与 [04-05](../../docs/04-chunking/05-size-overlap-metadata-and-quality.md) 的重叠方案比较。
- **未解决问题：** 表示模型、语义阈值、父子大小和扩展策略均需固定查询集验证。

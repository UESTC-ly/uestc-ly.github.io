# 01-03 摘要：JSON、HTTP 与 API

## 核心结论

- JSON 用对象、数组、字符串、数字、布尔值和 `null` 表示数据；键和字符串使用双引号。
- HTTP 请求要关注方法、地址、头、正文和超时；响应要同时处理状态码、头与正文。
- API 是调用双方的接口契约，不是某个特定网站或模型。
- 重试前要判断错误是否短暂、请求是否幂等以及是否可能产生重复副作用。

## 必须保留的边界

超时不能当作空答案，`2xx` 也不能替代响应结构校验；密钥不能进入源码、Git、用户输入
或未脱敏日志。

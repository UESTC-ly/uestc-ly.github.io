# 06-06 章节摘要：分片、复制、备份与一致性

- **本章新增知识：** 分片负责分布数据和负载，复制保留在线副本，备份提供历史恢复；一致性决定写入、更新、撤回和跨组件状态何时可见。
- **新术语：** 分片（sharding）、复制（replication）、备份（backup）、写入可见性、恢复点目标、恢复时间目标。
- **新代码接口：** 本批次不实现分布式故障自动化或恢复工具；故障场景设计和拓扑验证仍是后续计划。
- **后续必须知道：** 复制不能替代备份；每分片本地 Top-K 可能影响全局召回；权限撤回与法律删除需要明确旧读窗口；恢复必须覆盖原文、元数据、向量、映射和配置。
- **与其他章节的关联：** 建立在 [06-05](../../docs/06-indexes-vector-databases/05-database-boundaries-and-abstractions.md) 的存储契约之上，并为 [07 检索](../../docs/07-retrieval/README.md) 提供可见性、过滤和故障边界。
- **未解决问题：** 分片键、副本确认规则、允许旧读窗口、备份频率与恢复目标需要由业务风险和实际演练确定。

# 代码规范

## 运行基线

- 教程目标为 Python 3.11 及以上；作者环境可能更高，但不得使用 3.11 不支持的语法。
- `pyproject.toml` 是依赖、extra、测试和工具配置的唯一真源。
- `requirements/*.txt` 只能是明确标注来源的导出或场景安装文件，不得维护冲突版本。
- 不增加未经用户批准的教程依赖。作者侧检查工具与教程运行依赖分开登记。

## 分层

1. 最小实现：局部、透明、无付费 API，优先标准库和确定性 Mock。
2. 模块化实现：放在 `src/rag_tutorial_core/`，提供稳定领域接口。
3. 生产化扩展：通过 adapters、配置、监控和安全边界接入外部系统。

框架对象不能穿透领域层。核心接口至少包括 `Document`、`Chunk`、
`EmbeddingProvider`、`Retriever`、`Reranker`、`Generator` 和 `Citation`。

## Python 风格

- 公共函数和方法使用类型注解；复杂公共接口写必要 docstring。
- 优先清晰的小模块，避免为教学示例引入没有实际收益的抽象。
- 对无效输入抛出具体异常；外部错误保留可诊断上下文但不泄露密钥或敏感数据。
- 使用 `logging`，不在库代码中散布 `print`；CLI 的用户输出除外。
- 文件、网络和模型资源必须设置超时、异常路径与释放策略。
- 随机过程固定种子；Mock embedding/generator 的行为必须确定且可解释。

## 安全默认值

- 禁止硬编码 API Key、真实凭据和敏感样例数据。
- 配置通过环境变量或显式配置对象注入，仓库只提交 `.env.example`。
- 检索文本作为不可信数据放入独立上下文区，不能拼接为系统指令。
- 权限过滤必须在返回候选、缓存、重排、引用和日志前保持租户边界。
- 输入验证包括类型、长度、文件类型、页数/大小、超时和资源上限。

## 外部服务与版本

外部模型、Embedding、向量库、Reranker 和 LLM Judge 使用接口适配器。每个项目
README 必须说明版本、环境变量、是否付费、是否联网、离线/Mock 替代和验证等级。

## 测试

重要模块至少覆盖正常、边界、错误、基础集成和冒烟路径。安全关键代码增加跨租户、
越权引用、缓存隔离和删除后不可检索测试。真实外部服务测试单独标记，默认不作为
离线 CI 必需项。

测试状态只能使用：`unverified`、`static-checked`、`unit-passed`、
`integration-passed`、`external-verified`。报告记录真实命令、环境、结果和已知缺口。

## 什么是回溯消费？

回溯消费是指 Consumer 已经消费成功的消息，由于业务上需求需要重新消费，在 RocketMQ 中， Broker 在向 Consumer 投递成功消息后，**消息仍然需要保留** 。并且重新消费一般是按照时间维度，例如由于 Consumer 系统故障，恢复后需要重新消费 1 小时前的数据，那么 Broker 要提供一种机制，可以按照时间维度来回退消费进度。RocketMQ 支持按照时间回溯消费，时间维度精确到毫秒。

## 回溯算法的核心思想是什么？

回溯是在搜索空间中逐步做选择，遇到不满足条件的路径就撤销选择并尝试其他路径。

适合问题：

- 组合。
- 排列。
- 子集。
- N 皇后。
- 数独。
- 路径搜索。
- 约束满足问题。

回溯的核心不是“暴力”，而是“系统性枚举 + 剪枝”。

在 AI 中，很多生成问题也像搜索：

- 多条推理路径选择。
- Agent 工具调用顺序规划。
- prompt 组合搜索。
- 超参数搜索。
- 结构化输出候选生成。

## 如何用三种语言实现回溯组合枚举？

Python：

```python
def combine(n, k):
    ans, path = [], []

    def dfs(start):
        if len(path) == k:
            ans.append(path[:])
            return
        for x in range(start, n + 1):
            path.append(x)
            dfs(x + 1)
            path.pop()

    dfs(1)
    return ans
```

C/C++：

```cpp
#include <vector>
using namespace std;

void dfs(int n, int k, int start, vector<int>& path, vector<vector<int>>& ans) {
    if ((int)path.size() == k) {
        ans.push_back(path);
        return;
    }
    for (int x = start; x <= n; ++x) {
        path.push_back(x);
        dfs(n, k, x + 1, path, ans);
        path.pop_back();
    }
}

vector<vector<int>> combine(int n, int k) {
    vector<vector<int>> ans;
    vector<int> path;
    dfs(n, k, 1, path, ans);
    return ans;
}
```

Java：

```java
import java.util.*;

class Combine {
    List<List<Integer>> ans = new ArrayList<>();
    List<Integer> path = new ArrayList<>();

    List<List<Integer>> combine(int n, int k) {
        dfs(n, k, 1);
        return ans;
    }

    void dfs(int n, int k, int start) {
        if (path.size() == k) {
            ans.add(new ArrayList<>(path));
            return;
        }
        for (int x = start; x <= n; x++) {
            path.add(x);
            dfs(n, k, x + 1);
            path.remove(path.size() - 1);
        }
    }
}
```

## 递归的三要素是什么？

递归三要素：

1. **递归定义**

   函数的含义是什么，输入输出是什么。

2. **终止条件**

   什么时候不再继续调用自己。

3. **递推关系**

   当前问题如何拆成更小的同类问题。

例子：二叉树最大深度。

```python
def max_depth(root):
    if not root:
        return 0
    return max(max_depth(root.left), max_depth(root.right)) + 1
```

AI 场景：

- AST 递归遍历函数、类、表达式。
- Agent 把任务递归拆成子任务。
- 计算图中递归分析依赖节点。
- JSON / YAML 配置树递归解析。

递归风险：

- 栈溢出。
- 重复计算。
- 终止条件错误导致死递归。
- 状态修改后没有恢复。

如果递归深度很大，可以改成显式栈或迭代。

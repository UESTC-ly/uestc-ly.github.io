# 计算机面试笔记

按知识主题整理的面试学习笔记。每个主题先读基础笔记，再按需要查阅专题问答；相关出处保留在知识点旁。

## 阅读路线

- 公共基础：数据结构与算法、操作系统、计算机网络。
- 后端开发：目标语言、数据库、缓存、分布式与系统设计。
- AI 方向：机器学习与视觉、大模型训练与推理、RAG 与 Agent。
- 按岗位补充前端、移动端、测试、运维、安全、数据工程或嵌入式。

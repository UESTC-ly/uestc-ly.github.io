## 分章节讲解
### 1. 向量空间
**核心定义：** 向量空间由向量集合和加法、数乘构成，基和维度刻画表达能力。

**理解路径：**
- 先明确它解决的具体问题，再判断它依赖的前提条件。
- 把它放回“线性代数把数据、变换和模型参数统一到空间与矩阵语言中。”这条主线中理解，不要孤立记忆。
- 学习时至少能说出：输入是什么、输出是什么、代价是什么、失败边界是什么。

**常见误区：** 维度不是元素个数，而是基向量数量；基必须线性无关且能张成空间。

### 2. 矩阵乘法
**核心定义：** 矩阵乘法表示线性变换复合，也可看成行列内积或基变换。

**理解路径：**
- 先明确它解决的具体问题，再判断它依赖的前提条件。
- 把它放回“线性代数把数据、变换和模型参数统一到空间与矩阵语言中。”这条主线中理解，不要孤立记忆。
- 学习时至少能说出：输入是什么、输出是什么、代价是什么、失败边界是什么。

**常见误区：** 矩阵乘法一般不满足交换律；维度匹配比公式记忆更重要。

### 3. 秩与线性相关
**核心定义：** 秩表示矩阵中独立信息的数量，决定线性方程组解的结构和降维能力。

**理解路径：**
- 先明确它解决的具体问题，再判断它依赖的前提条件。
- 把它放回“线性代数把数据、变换和模型参数统一到空间与矩阵语言中。”这条主线中理解，不要孤立记忆。
- 学习时至少能说出：输入是什么、输出是什么、代价是什么、失败边界是什么。

**常见误区：** 行秩等于列秩；满秩与可逆只对方阵严格对应。

### 4. 特征值与矩阵分解
**核心定义：** 特征值描述变换在特定方向上的伸缩，SVD 可分解任意矩阵并支撑降维和推荐系统。

**理解路径：**
- 先明确它解决的具体问题，再判断它依赖的前提条件。
- 把它放回“线性代数把数据、变换和模型参数统一到空间与矩阵语言中。”这条主线中理解，不要孤立记忆。
- 学习时至少能说出：输入是什么、输出是什么、代价是什么、失败边界是什么。

**常见误区：** 不是所有矩阵都可对角化；SVD 比特征分解适用范围更广。

### 1. 底层机制拆解
向量表示对象，矩阵表示线性变换，特征值、奇异值和分解揭示变换的尺度、方向和可压缩性。

### 2. 适用与不适用
| 判断点 | 适用信号 | 不适用/风险信号 |
|---|---|---|
| 前提 | 对象、约束和目标清晰 | 概念边界含糊或约束缺失 |

| 成本 | 复杂度、维护成本或风险可接受 | 资源、复杂度或安全边界失控 |
| 验证 | 有样例、测试、证明或观测证据 | 无法复现、无法审计、无法回滚 |

### 3. 案例理解
推荐系统中的用户-物品矩阵可通过低秩分解获得隐因子，但稀疏、冷启动和噪声会影响解释。

### 4. 常见误区与纠正
- **误区：** 只记概念定义，不问前提。**纠正：** 每次回答都先说适用条件。
- **误区：** 用单个样例证明普遍正确。**纠正：** 补充边界样例、反例或不变量。
- **误区：** 忽略工程成本。**纠正：** 同时说明性能、可靠性、安全性和维护代价。

2. 和相邻方案相比，它牺牲了什么、换来了什么？
3. 如何用最小反例证明误用会失败？
4. 工程落地时需要哪些监控、测试或回滚手段？

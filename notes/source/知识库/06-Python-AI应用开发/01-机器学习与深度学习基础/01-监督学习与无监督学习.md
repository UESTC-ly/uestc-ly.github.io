## 2. 什么是机器学习

传统编程通常由开发者明确编写规则：

```text
输入数据 + 人工规则 → 输出结果
```

机器学习则让算法从数据中学习规律：

```text
历史数据 + 学习算法 → 模型
模型 + 新数据 → 预测或数据结构
```

模型可以理解为：从历史数据中学习到的一组参数及计算规则。

### 基本术语

- **样本（Sample）**：一条数据记录；
- **特征（Feature）**：描述样本的输入信息，通常记作 `X`；
- **标签（Label）**：希望模型学习和预测的目标，通常记作 `y`；
- **模型（Model）**：从数据中学习输入与目标之间规律的函数；
- **训练（Training）**：利用数据调整模型参数的过程；
- **推理（Inference）**：训练完成后，用模型处理新输入的过程。

例如，在根据房屋信息预测价格的任务中：

```text
样本：一套房屋
特征 X：面积、楼层、房龄、位置等
标签 y：成交价格
```

## 3. 监督学习

### 3.1 定义

监督学习使用**带标签的数据**训练模型。每个训练样本既包含输入特征 `X`，也包含期望输出 `y`。

```text
(X, y) → 学习 X 到 y 的映射关系 → 对新 X 预测 y
```

“监督”并不是指有人实时观察模型，而是指训练数据已经提供了相对明确的正确答案。

### 3.2 示例

| 输入特征 X | 标签 y | 模型学习目标 |
|---|---|---|
| 邮件正文、发件人等 | 是否为垃圾邮件 | 预测新邮件是否为垃圾邮件 |
| 面积、位置、房龄等 | 房屋价格 | 预测新房屋价格 |
| 用户问题、标准答案 | 目标答案 | 学习如何根据问题产生答案 |

### 3.3 典型过程

1. 收集并标注数据；
2. 将样本表示为模型可处理的特征；
3. 让模型根据输入产生预测；
4. 比较预测结果与真实标签；
5. 调整模型参数，减小预测误差；
6. 使用训练后的模型处理新数据。

### 3.4 优点与限制

**优点：**

- 目标明确，结果通常容易衡量；
- 有足够高质量标签时，往往能获得较好的任务效果；
- 适合答案标准相对清晰的问题。

**限制：**

- 获取高质量标签可能成本很高；
- 错误、偏见或不一致的标签会影响模型；
- 训练数据与真实使用场景差异过大时，效果可能下降。

## 4. 无监督学习

### 4.1 定义

无监督学习使用**没有目标标签的数据**。算法需要从特征 `X` 本身发现数据中的结构、相似性、分布或异常模式。

```text
X → 发现数据内部结构
```

无监督学习通常不是预测一个预先提供的标准答案，而是帮助我们理解数据。

### 4.2 示例

| 输入数据 X | 没有提供的内容 | 希望发现的结构 |
|---|---|---|
| 用户浏览和购买行为 | 用户类别标签 | 行为相似的用户群体 |
| 大量文章的文本表示 | 文章主题标签 | 内容相近的文章组 |
| 设备运行指标 | 异常标签 | 与常见模式差异较大的记录 |

### 4.3 典型过程

1. 收集数据，不要求每条数据都有目标标签；
2. 提取或构造特征；
3. 选择希望发现的结构，例如相似群体或低维表示；
4. 运行算法并分析结果；
5. 结合业务知识解释结果是否有意义。

### 4.4 优点与限制

**优点：**

- 不依赖大规模人工标注；
- 可以探索未知的数据结构；
- 适合数据分析、用户分群和异常发现等场景。

**限制：**

- 结果通常没有唯一标准答案；
- 算法发现的结构不一定具有业务意义；
- 结果解释与评估通常比监督学习困难。

---

## 5. 核心区别

| 对比维度 | 监督学习 | 无监督学习 |
|---|---|---|
| 是否有目标标签 `y` | 有 | 没有 |
| 学习目标 | 学习 `X → y` 的关系 | 发现 `X` 内部的结构 |
| 结果形式 | 对新样本进行目标预测 | 分组、表示、结构或异常模式 |
| 评估难度 | 通常可与真实标签比较 | 经常需要结合数据结构和业务判断 |
| 数据成本 | 标注成本可能较高 | 不要求目标标签，但仍需要清洗数据 |

最简单的判断方法是：

```text
是否拥有希望模型预测的目标 y？
├── 有：通常考虑监督学习
└── 没有：通常考虑无监督学习
```

这只是初步判断。真实项目中还需要考虑数据质量、业务目标、评估方法与成本。

### 6.1 监督学习示例

下面让模型根据二维特征学习目标标签，然后预测一个新样本：

```python
from sklearn.neighbors import KNeighborsClassifier

# X 是特征，y 是每个样本对应的标签
X = [
    [1.0, 1.1],
    [1.2, 0.9],
    [4.0, 4.1],
    [3.9, 4.2],
]
y = [0, 0, 1, 1]

model = KNeighborsClassifier(n_neighbors=1)
model.fit(X, y)

prediction = model.predict([[1.1, 1.0]])
print(prediction)  # 预期接近标签 0
```

关键点：

```python
model.fit(X, y)
```

训练时同时提供了特征 `X` 和标签 `y`，因此这是监督学习。

### 6.2 无监督学习示例

下面只提供特征，让算法根据样本间的相似性进行分组：

```python
from sklearn.cluster import KMeans

X = [
    [1.0, 1.1],
    [1.2, 0.9],
    [4.0, 4.1],
    [3.9, 4.2],
]

model = KMeans(n_clusters=2, random_state=42, n_init=10)
cluster_ids = model.fit_predict(X)

print(cluster_ids)
```

关键点：

```python
model.fit_predict(X)
```

这里只提供了特征 `X`，没有提供正确分组标签 `y`，因此这是无监督学习。

> 分组编号本身没有固定含义。一次运行中的第 `0` 组，在另一次运行中可能编号为第 `1` 组；重点是哪些样本被分到一起。

## 7. 在大模型应用中的联系

AI 应用开发者通常不会从零训练大模型，但仍需要理解：

- 许多基础模型的早期训练会利用海量未人工标注文本学习语言规律；
- 后续训练阶段可以利用带目标答案或偏好信息的数据，让模型更符合任务要求；
- Embedding 可将文本转换为向量，这些向量可以用于发现文本之间的相似关系；
- 数据和标签的质量会直接影响模型能力与限制。

这里只建立直觉，具体训练方式、Embedding 和大模型对齐方法会严格按照后续课程顺序学习。

## 8. 常见误区

### 误区一：无监督学习等于完全不需要人工参与

错误。人仍然需要选择数据、特征和算法，并解释算法发现的结构。

### 误区二：有数据就能进行监督学习

错误。监督学习不仅需要输入数据，还需要与学习目标对应的标签。

### 误区三：无监督学习的结果天然正确

错误。算法只能根据数学上的结构处理数据，结果是否有业务价值仍需验证。

### 误区四：模型是在背诵人工编写的规则

不准确。机器学习模型主要通过数据调整参数，从样本中拟合规律；它也可能学到噪声、偏见或偶然相关性。

## 11. 本课小结

```text
监督学习：有特征 X，也有目标标签 y，学习 X → y。
无监督学习：只有特征 X，从数据中发现结构或模式。
```

判断两者的第一步，是确认训练数据中是否存在明确的目标标签。

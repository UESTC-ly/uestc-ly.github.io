# 工程基础学习笔记

本目录面向已有 C++ 或后端开发基础、希望补齐工程化基本功的学习者。建议按下面顺序学习，因为后续主题会默认你能读懂命令行、理解项目目录、并能在版本控制下安全试错。

## 推荐顺序

1. [Linux 与 Shell](02-操作系统与命令行.md)
   - 先掌握文件、进程、权限、管道、重定向和脚本基础。
   - 这是阅读构建日志、部署脚本和 CI 命令的基础。
2. [Git 和分支协作](01-版本控制与分支协作.md)
   - 再学习提交、分支、变基、冲突处理和多人协作约定。
   - 之后的练习建议都放在 Git 工作区中完成。
3. [CMake](03-构建系统.md)
   - 学习现代 C++ 项目的配置、目标、依赖、构建类型和安装导出。
   - 重点理解“声明目标能力”，而不是把 CMake 当成命令拼接器。
4. [Python 环境和依赖管理](04-脚本环境与依赖管理.md)
   - 学习虚拟环境、依赖锁定、包管理、工具隔离和可复现脚本。
   - 这对测试、代码生成、数据处理和 CI 辅助脚本都很常见。

## 学习方式

- 每章先读“学习目标”和“核心概念”，再照着“典型工作流”在临时目录里做一遍。
- 所有命令示例都应先确认当前目录，尤其是会修改文件、分支、依赖或构建产物的命令。
- 遇到问题时优先按“排障步骤”收集证据：当前目录、版本、环境变量、错误日志、最小复现。
- 每章最后用“检查清单”自测；能解释命令的影响和风险，才算真的掌握。

## 目录约定

- 本组笔记只依赖本目录内的相对链接。
- 示例命令默认在 Unix-like Shell 中运行；Windows 用户可在 WSL、Git Bash 或对应工具中调整。
- 示例以学习为目的，不假设某个公司或仓库的特定规范。

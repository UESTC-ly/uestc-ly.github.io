# 李杨的个人主页

在线主页：https://uestc-ly.github.io/

纯静态个人作品集，包含简介、DocMind / CoScribe / QQCode / AgenticRAG-Lab 项目、关注方向和 GitHub 联系入口。页面内容依据公开 GitHub 项目整理。

## 修改页面

- `index.html`：个人介绍、项目文案与链接。
- `styles.css`：颜色、排版与移动端样式。
- `assets/coscribe-workspace.png`：CoScribe 公开 README 的工作台截图。

无需安装依赖或运行构建。GitHub Pages 从 `main` 分支根目录发布，提交修改后自动更新。

本地预览：`python3 -m http.server 8765`，然后访问 `http://localhost:8765/`。

字体使用 Google Fonts 的 Noto Sans SC；网络不可用时会自动使用系统字体。页面无追踪脚本、无后台服务。
